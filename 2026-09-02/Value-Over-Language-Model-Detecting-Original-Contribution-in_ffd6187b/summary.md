# 论文速读：Value-Over-Language-Model-Detecting-Original-Contribution-in

## 一句话总结
论文提出了 **VOLM（Value Over Language Model）** 框架，通过衡量文档信息内容相对于仅凭任务描述即可生成的替换级基线文档的"惊喜度"，量化人类作者对文档的原创贡献，而非测量表面文本由 LLM 生成的比例。

## 研究问题与动机
- **现有 LLM 检测工具的局限性**：已有工具（如 DetectGPT、EditLens）测量的是文档表面文本中有多少由 LLM 生成，无法区分"人类提供核心观点让 LLM 扩展成文"与"人类仅给出单行提示让 LLM 从头创作"的本质差异。
- **实质性贡献 vs. 文本贡献的混淆**：审稿人提供关键缺陷点（如"Lemma 3 在 n=2 时证明不成立"），让 LLM 扩写成完整评审，现有检测器会标记为"高 LLM 参与"，但实际上审稿人的原创思想正是同行评审的核心价值。
- **非英语母语作者的惩罚问题**：用 LLM 将母语论证翻译为英语的场景下，文档表面全部由 LLM 生成，但论证和观点属于作者本人，现有方法会错误惩罚此类合理辅助。
- **理论层面：信息内容与表面风格的解耦需求**：自信息（self-information）和困惑度类方法容易受风格变化干扰，需要一种能剥离风格、只测量信息内容原创性的方法。

## 核心贡献（创新点）
1. **重新定义 LLM 参与度的衡量目标**：从"文档中多少文本由 LLM 写出"转变为"文档中多少信息内容源自人类作者"，这是现有检测器从未区分的维度。
2. **提出 VOLM 通用框架**：借鉴棒球 sabermetrics 中 VORP（Value Over Replacement Player）的思路，将"替换级选手"替换为"语言模型"，衡量人类在 LLM 可轻易生成内容之上的增量贡献。
3. **设计无需训练和标注数据的实现算法**：完全基于现成 LLM 的 log-probability 计算，不涉及任何模型训练，操作简便。
4. **证明对内容保持不变变换的鲁棒性**：LLM 改写、往返翻译（德译/韩译）、bullet 压缩+重建等变换后，VOLM 分数保持稳定，表明其真正测量的是信息内容而非表面风格。

## 方法详解
**核心思想**：如果一个文档仅凭通用任务描述就能被 LLM 生成，则其内容已"隐含在模型权重中"，人类贡献最小；反之，若生成该文档需要大量具体指导（如详细结构和特定论点），则人类贡献较大。

**Pipeline 三阶段**：

1. **Extract（提取）**：给定文档 $D$ 和任务描述 $T$，提取器 $E$ 在 $k$ 个递增粒度级别生成内容摘要 $g_i = E(D, T, i)$，其中 $g_k$ 近似文档全部内容，低 $i$ 保留更粗糙的信息。
   - 粒度定义方式：可基于"事实数量"（逐条加入事实）或"长度比例"（固定分数压缩）。

2. **Reconstruct（重建）**：重建器 $R$ 使用 LLM $M$，以任务描述 $T$ 和当前粒度级别的内容 $g_i$ 为上下文，重建文档 $\hat{D}_i = R(T, g_i, |D|)$，长度与原文档匹配（误差 < 10%）。
   - **关键设计**：原始文档 $D$ 从不被直接评分，只评分重建后的文档，避免风格混淆。

3. **Scoring（评分）**：对每个重建文档计算其平均 token 级 log-probability（仅以 $T$ 为条件）：
   $$s_i = \frac{1}{|\hat{D}_i|} \sum_{j=1}^{|\hat{D}_i|} \log P_M(\hat{d}_{i,j} \mid T, \hat{d}_{i,<j})$$
   - 由于提取和重建是随机过程（LLM 推理），每个粒度级别产生 $m \times n$ 个分数，形成分布 $S_i(X)$。

4. **Baseline 构建**：替换级文档 $D_{\text{ref}} = M(T)$，即用 LLM 仅凭任务描述生成的文档，与待评文档走相同 pipeline。

5. **统计检验与最终分数**：在每个粒度级别 $i$，对 $S_i(D)$ 和 $S_i(D_{\text{ref}})$ 做双侧检验（$p < 0.05$）。令 $i^*$ 为首次显著差异且此后持续显著的最小粒度级别，则：
   $$\text{VOLM}(D) = 1 - \frac{i^*}{k}$$
   - $i^*$ 小 → 人类贡献大 → VOLM 接近 1
   - $i^*$ 大或未检测到差异 → 人类贡献小 → VOLM 接近 0

## 实验与结果
**数据集**：
- **All the News**：100 篇新闻文章，$T$ 为文章标题
- **ICLR Reviews**：200 篇论文各随机选一篇评审，$T$ 为论文全文 + 评审指南 + 评分量表
- **Persuade 2.0**：8 个提示 × 25 篇 = 200 篇议论文，$T$ 为论文题目本身

**评估模型**：Llama 3.1 8B Instruct（同时作为提取器和重建器）

**主要结果**：
- **人群级别分离**：Human 文档的分数曲线在粒度 0.1 处即与参考 LLM 曲线产生统计显著差异，而参考 LLM 曲线随粒度增加下降缓慢（因其额外上下文本就隐含在模型中）。
- **变换不变性**：Bullet 压缩+重建、德语往返翻译、韩语往返翻译三种变体的分数曲线均紧密追踪原始 Human 曲线，显著偏离参考 LLM 曲线，证明方法测量的是信息内容而非表面风格。
- **对抗鲁棒性**：Qwen 3-8B 生成的文档和 DIPPER humanizer 处理后的 Llama 文档形成中间层级（VOLM > 0 但低于真正的人类原创文档），分析表明这是残留风格差异所致，非真正的原创内容。
- **提取器演进效果**：从简单 condensation 提取器逐步改进为 WordNet 规范化的等量模式约束事实提取器，Llama 参考文档与 Humanized 文档之间的 AUC 差距从 0.367 降至 0.101（减少 72.4%），其中 WordNet 词义消歧单独贡献了 16.2% 的进一步缩小。Humanized-Human 差距则几乎不变（0.181 → 0.174），证明优化只影响与参考 LLM 的比较。

**最强结果**：在 All the News 数据集上，使用最优提取器时 Human 与 Reference LLM 在粒度 0.1 即显著分离；Llama-Humanized 差距缩减至 0.101，证明信息内容与风格可以有效解耦。

## 相关工作脉络
- **DetectGPT / Liang et al. (2024)**：零样本/基于分布的 LLM 检测器，测量的是"文本是否像 LLM 写的"，与本文测量"信息内容原创贡献"的目标根本不同。
- **EditLens (Thai et al., 2025)**：估计文档中 LLM 编辑的比例（0~1 连续值），但仍聚焦于表面文本的 LLM 参与程度，而非信息来源。
- **Xie et al. (2026)**：信息论视角衡量人类贡献 $\phi = I(x;y)/I(y)$，但其分母使用无条件自信息（无上下文基线），而 VOLM 以任务描述 $T$ 为基线，更贴合实际场景；且 Xie 的方法需要知道人类输入 $x$，而 VOLM 仅需文档和任务描述。
- **Schwarzschild et al. (2024) Adversarial Compression Ratio**：通过最短 prompt 测试模型是否"记忆"了目标字符串，关注的是精确复现；VOLM 评估完成文档的贡献，不要求逐字复现。
- **HCI 贡献归因研究（He et al., 2025; Kim et al., 2026）**：从感知或对话轨迹角度衡量贡献，需要访问交互记录；VOLM 无需对话历史，仅分析最终文档。

## 局限性与未来方向
- **残留风格差异**：即使使用最优提取器，不同模型生成的文档和 humanizer 处理的文档仍获得非零 VOLM 分数，说明风格与信息的完全解耦尚未实现。
- **单一评估模型偏置**：非 Llama 模型生成的文档会因训练数据/风格差异而获得非零分数，未来需引入多评估模型交叉验证。
- **阈值确定问题**：如何判定单个文档的 VOLM 分数是否"显著"仍待研究。
- **提取器设计是核心瓶颈**：当前事实提取器仍不够完善，未来需探索更 principled 的提取器和重建器设计。
- **文档长度匹配限制**：当前要求重建文档长度与原文档误差 < 10%，可能引入额外约束。

## 研究启发与可借鉴点
- **评估目标的范式转移**：从"检测 LLM 写了多少"转向"衡量人类贡献了多少"，这一思路可直接迁移到论文评审、学术诚信检测、AI 辅助写作评估等场景。
- **提取-重建-评分的解耦设计**：通过对重建文档评分而非原文档评分，天然免疫于风格混淆，这一技巧可借鉴到任何需要剥离风格只测内容的评估任务中。
- **迭代式提取器优化实验**：从 condensation → fact → schema-constrained → WordNet canonicalization 的逐步改进路径，展示了如何通过约束提取器的表达空间来剥离风格因素，为类似研究提供了可复用的实验设计范式。
- **AUC 差值配对比较**：以 paired AUC difference 作为单一标量指标，同时消除了文档难度差异的影响，这一统计设计值得借鉴。
- **与团队方向的结合机会**：本方法可应用于学术诚信检测（识别学生论文中真正属于学生的原创思想 vs. LLM 生成的内容）、AI 辅助代码审查（衡量工程师提供的 review 要点 vs. LLM 扩展内容）等场景。

## 关键术语表
**VOLM（Value Over Language Model）**：衡量文档中人类原创贡献相对于语言模型可轻易生成内容的框架，类比棒球中的 VORP 统计。

**替换级文档（Replacement-level Document）**：$D_{\text{ref}} = M(T)$，即 LLM 仅凭任务描述生成的文档，作为衡量人类贡献的基线。

**Surprisal（惊奇度）**：负对数概率 $-\log p$，衡量模型对某 token 的"惊讶程度"，VOLM 的核心度量基础。

**内容保留变换（Content-preserving Transformation）**：不增删文档信息内容的变换，如往返翻译、bullet 压缩+重建，用于验证方法的稳健性。

**Fact Extractor（事实提取器）**：将文档分解为有序事实列表的提取器，本文使用带固定 schema（subject/action/object/quantity/date/quote）的结构化事实。

**WordNet Canonicalization**：通过 WordNet 词义消歧将动作动词规范化为标准形式，以减少提取过程中的风格变异。

**AUC Paired Difference**：对每篇文档计算两个来源的 AUC 差值后取平均，消除文档难度差异的统计指标。

# 论文速读：SOURCE-PRESERVING-ALIGNMENT-FOR-ROBUST-EVIDENCE-LOCALIZATION

## 一句话总结
本文提出一种"源保持对齐"（source-preserving alignment）框架，通过规范化文本进行鲁棒匹配、同时保留来源字符级溯源信息以精确定位科学PDF中的证据片段并渲染高亮。在1020篇化学论文（18,580条引用）上，该方法实现了92.6%的引用级自动定位率，大幅超越文本搜索（43.6%）与预计算边界框基线（19.1%）。

## 研究问题与动机
- **证据定位的核心矛盾**：RAG和科学主张验证系统返回的证据字符串来自Markdown/逻辑格式层，而需在高亮显示的原始PDF文本层找到对应位置；两层因换行、Unicode变体、上标、引用标记、项目符号碎裂等产生严重的表示差异。
- **已有方法的缺陷**：朴素文本搜索对规范化差异极度敏感；预计算边界框索引无法应对检索时未预期的文本，且对布局/编码变化脆弱；两者均无法建立字符级溯源到页面几何信息的链路。
- **科学PDF的额外复杂度**：化学分子式、希腊字母、分数、方程式等导致PDF文本模型提取顺序被打乱、字符编码异常、条目碎片化，普通搜索常"看似命中实则越界"。
- **精确定界需求**：即使匹配成功，若沿整个PDF.js text item高亮会包含后续无关句子（如证据止于"activities"却把同item中的"It is worth noting that"也高亮），需字符级裁剪。

## 核心贡献（创新点）
1. **提出source-preserving alignment框架**：将规范化匹配、来源溯源、页面几何渲染三阶段统一在同一表征下，实现"匹配时用规范化文本，定位时回溯到来源字符"。与以往仅做模糊匹配或仅做几何渲染的方法本质不同——它显式维护了从规范化字符到源(text item, offset)的映射。
2. **设计确定性规范化函数 N(·)**：集成Unicode兼容性规范化、破折号/减号统一、畸形编码修复、科学符号映射、布局分隔符移除，并保持源字符对输出字符的追溯记录 `(i, c)`；区别于通用文本清洗，该规范化专为PDF提取产物设计，保留溯源是硬约束。
3. **引入line-break-aware token alignment + LCS回退机制**：当精确匹配失败时，按多个缩放比例枚举候选窗口并用LCS比值评分，设置阈值τ=0.8决定回退是否生效；与神经匹配方法相比，这是无参数、确定性、可解释的容错选择。
4. **实现character-range clipping几何渲染**：基于来源区间仅在单个text item内按比例估算字符级x坐标，避免整item过界高亮；配合邻近同线合并策略，保证高亮边界贴合证据本身。
5. **构建1,020篇化学论文+18,580条引用级的PDF证据定位基准**：提供PDF-Markdown配对规则、引用解析器、BBOX记录与比较脚本，填补科学PDF证据定位定量评测的空白。

## 方法详解
- **整体流程**：输入证据引用q和PDF文本项序列P={p₁,...,pₙ}（每项含源文本sᵢ和变换矩阵Tᵢ），先对q和所有sᵢ应用规范化N(·)得到q̂和p̂，进行精确匹配；若失败则进入token级LCS回退；命中后沿provenance map投影回源字符区间，用几何变换渲染高亮矩形。
- **规范化函数N(·)**：依次执行（1）Unicode兼容性规范化；（2）各种破折号/减号统一；（3）畸形编码修复；（4）科学符号映射（化学式/希腊字母等）；（5）移除仅布局用的分隔符。每个输出字符保留 `(i, c)` 对，标识来源text item编号与源字符偏移。规范化仅用于比对，不改写原始页面文本。
- **精确匹配**：若q̂在p̂中连续出现，收集所有触达的源区间[c_start, c_end)，对每项按比例估算水平范围：x_start = x₀ + w·c_start/|sᵢ|，x_end = x₀ + w·c_end/|sᵢ|，再用Tᵢ变换后裁剪至页面视口，防止跨句子越界。
- **LCS回退对齐**：对m≥5的引用，按α∈{0.70, 0.85, 1.00, 1.15, 1.30}生成候选窗口长度ℓ_α=round(αm)（半值向上取整），跳过超长的窗口；对每个候选w用LCS评分：score(q,w)=LCS(q,w)/max(m,ℓ)，阈τ=0.8时返回回退结果。高亮仅渲染LCS对齐的token，排除未对齐噪声。
- **几何渲染**：对每个匹配源区间用PDF.js变换矩阵计算四角，矩形限制在规范化页面边界内；仅在"同渲染行上的邻近碎片"时合并，避免跨栏/表头/不相关区域误合并。
- **确定性原则**：全程无学习参数，依靠固定规则与有限候选集搜索，保证可复现性与可诊断性。

## 实验与结果
- **数据集**：1,020篇公开可访问的化学论文，与Markdown证据文件一一配对，共18,580条引用（平均每篇18.2条）；PDFs含多栏排版、化学式、图表引用和噪声文本层。
- **评估指标**：引用级定位率（返回至少一个候选区域的引用占比）；人工核验18,572条引用，分Correct/Incorrect/Not found三类。
- **主要结果**（Table 1）：
  - Proposed：定位率92.1%，人工正确率91.9%，未找到率7.9%
  - Text-search baseline（PyMuPDF）：43.6%/43.6%/56.4%
  - Precomputed-BBOX baseline：19.1%/19.1%/80.9%
- **提升幅度**：相对文本搜索定位率提升约2.1倍（+48.5pp），相对BBOX提升约4.8倍（+73.0pp）。
- **组件消融**：去掉近似token对齐（仅保留规范化精确匹配）和去掉规范化（直接用PDF.js提取文本做LCS）两者均降低定位率，其中规范化贡献更大；LCS回退进一步恢复被打断的token序列。
- **渲染裁剪消融**：在17,213条成功定位引用上，字符裁剪使平均每条少高亮62.8个源字符（占被高亮字符的26.8%），证明provenance映射显著提升高亮特异性。
- **按长度鲁棒性**：Proposed在81–160字符区间达峰值，长引用仍大幅领先；最短组BBOX略优；PyMuPDF在41–80字符段达峰后下降。
- **人工评估**：6名评估者（含教师与高年级研究生），随机分配，Proposed的Correct率最高，两基线Not found显著更多。
- **错误分析**：残余误差来自复杂布局打乱提取顺序、比例宽度近似不等宽字符、超出规范化规则与LCS阈值的严重提取错误。

## 相关工作脉络
1. **RAG与科学主张验证**（Lewis et al., 2020; Wadden et al., 2020）：本文解决的是其下游"证据需在原始PDF中高亮呈现"的定位问题，而非检索或验证本身。
2. **S2ORC与引用生成**（Lo et al., 2020; Gao et al., 2023）：结构化科学文本与带引用的生成研究假设证据可被引用，但未处理从逻辑表示到PDF几何的落地图径。
3. **PDF解析库**（PDF.js, PyMuPDF）：暴露页面字符串与几何，但未提供跨规范化差异的鲁棒对齐与溯源高亮能力。
4. **神经文档解析**（Nougat, 2024）：改善结构化抽取，但不保证可追溯的视觉源区间；本文强调"不依赖黑盒模型"的确定性方案。
5. **文档布局数据集**（PubLayNet, DocBank, LayoutParser, DocLayNet）：展示科学/学术PDF的布局异质性，印证定位任务需容忍布局与编码变异。
6. **近似字符串匹配与序列对齐**（Navarro, 2001; Needleman-Wunsch, 1970; Hirschberg, 1975）：本文借鉴LCS作为回退评分，但创新在于将其通过provenance map投影到字符级几何，而非仅做文本对齐。
7. **布局感知预训练**（LayoutLMv3, 2022）：融合文本与图像的文档理解，定位精度受限于训练数据与泛化；本文的确定性方法提供了一条不依赖大规模标注的替代路径。

## 局限性与未来方向
- **字符几何近似**：基于text item宽度的比例估算在variable-width字体下会产生较松边界；未来可用glyph-level metrics或原生text-layer定位改善。
- **多栏阅读顺序**：复杂布局（多栏、跨栏表格）下提取顺序可能被破坏，当前方法未显式建模；可引入layout-aware分析（如引用[19,14]所述）。
- **规范化规则覆盖**：对超出当前规则的严重提取错误（如大量编码损坏）无能为力；可扩展符号映射规则。
- **置信度校准**：当前阈值τ=0.8为固定值，未来可做轻量校正以支持大规模验证场景。
- **PDF文本层依赖**：框架假设存在可用的PDF文本层，对纯图像型PDF不适用。

## 研究启发与可借鉴点
1. **"规范化用于匹配、溯源用于定位"的分离设计哲学**可迁移到任何需跨表示层对齐的任务（如网页内容匹配、代码片段定位、多语言文档对照），是一种通用的"解耦+映射"范式。
2. **LCS回退+多缩放候选窗口**是一种轻量、可解释的容错策略，无需训练即可覆盖部分结构化差异，适合资源受限或需强可解释性的生产环境。
3. **Character-range clipping结合比例几何估算**在保证精度的同时避免了重新训练定位器，对任何基于text-item的PDF高亮工具均有直接参考价值。
4. **确定性全流程**（无学习参数）使得误差可诊断、结果可复现，对科研工具链的可靠性要求尤为契合。
5. **公开基准与配对规则**（PDF-Markdown配对、引用解析器、BBOX记录、比较脚本）为后续工作提供了可直接扩展的评测平台，可衍生到物理/生物/材料等其他学科PDF。

## 关键术语表
- **Source-preserving alignment**：一种对齐范式，匹配阶段使用规范化文本以容忍差异，定位阶段通过显式的溯源映射把匹配结果投影回原始PDF字符区间。
- **Normalization function N(·)**：对PDF提取文本执行Unicode规范化、符号统一、编码修复、布局分隔符移除的确定性函数，输出字符携带源(item, offset)对。
- **Provenance map**：从规范化字符到源text item编号与字符偏移的双向映射表，是实现字符级裁剪的核心数据结构。
- **Character-range clipping**：在单个text item内按字符比例估算命中区间[x_start, x_end]并裁剪高亮矩形，避免整item越界包含无关文本。
- **LCS token alignment fallback**：精确匹配失败时，对多长度候选窗口计算最长公共子序列比值的回退机制，阈值τ=0.8决定是否接受。
- **Quote-level localization rate**：自动评测指标，定义为方法返回至少一个候选页面区域的引用数占总引用数的比例。
- **PDF.js transform matrix**：每个text item附带的4×4仿射变换矩阵，用于将局部字符坐标映射到页面坐标系以计算高亮几何。
- **BBOX baseline**：预计算页面文本与边界框索引的基线方法，检索时直接返回离线存储的矩形，无法处理索引时未预料到的文本。

# 论文速读：SOURCE-PRESERVING-ALIGNMENT-FOR-ROBUST-EVIDENCE-LOCALIZATION

## 一句话总结
本文提出了一种**源保持对齐（Source-Preserving Alignment）框架**，解决科学PDF中证据定位难题：通过文本标准化实现鲁棒匹配，同时保留字符级溯源映射，将证据精准定位回原始PDF页面几何坐标，在1020篇化学论文上达到92.6%的定位率。

---

## 研究问题与动机

1. **证据定位的表征差异**：科学信息提取系统（如RAG、claim verification）返回的证据字符串来自Markdown或逻辑格式，而PDF文本层存在换行断裂、Unicode变体、上标/下标分离、引用标记插入等差异，导致直接文本搜索失效。
2. **现有方法的局限性**：纯文本搜索对标准化差异敏感；预计算边界框（BBOX）无法处理索引时未预见的新文本，且对布局/编码变化敏感，两者均无法保留字符级溯源链接。
3. **高亮精度需求**：科学文献中公式、希腊字母、化学式、多栏布局普遍存在，匹配成功后还需精确裁剪高亮边界，避免整段高亮污染（如证据仅到"activities"但高亮延伸至下一句）。
4. **可验证性闭环**：RAG和科学主张验证系统需要用户能在原始PDF上直接查看证据，但当前缺乏从逻辑文本到页面几何的可靠映射机制。

---

## 核心贡献（创新点）

1. **源保持标准化表示**：设计确定性标准化函数N(·)，将Unicode兼容性归一化、破折号统一、编码修复、科学符号映射、布局分隔符移除应用于匹配，同时为每个输出字符保留(source item i, offset c)溯源对，本质区别在于标准化仅用于比较，原文本永不改写。
2. **精确匹配+容错对齐双阶段框架**：先尝试标准化后精确匹配，失败则切换至Line-Break-Aware Token Alignment（基于LCS的近似对齐），通过多尺度窗口枚举（α∈{0.70,0.85,1.00,1.15,1.30}）和阈值τ=0.8过滤噪声，与纯模糊匹配的本质差异是引入了源跨度裁剪。
3. **几何感知的字符级高亮渲染**：将LCS对齐的token投影回源字符区间[c_start, c_end)，通过比例估计x_start=x₀+w·(c_start/|s_i|)计算水平范围，再用PDF变换矩阵转换并裁剪至页边距，避免整项高亮污染，与预计算BBOX的本质差异是动态生成而非静态索引。
4. **系统性评估基准**：构建1020篇化学论文+18580条引文的公开数据集，配套PDF-Markdown配对规则、引文解析器、BBOX记录与比较脚本，填补科学PDF证据定位评测空白。

## 方法详解

### 3.1 确定性匹配流程
- **输入**：证据引文q，PDF文本项序列P={p₁,...,pₙ}，每项含源文本s_i和变换矩阵T_i。
- **第一阶段（精确匹配）**：
  ```
  q̂ = N(q), p̂ = N(s₁) ∥ ... ∥ N(sₙ)
  ```
  若q̂在p̂中连续出现，记录匹配区间的源字符区间[c_start, c_end)。
- **第二阶段（容错对齐）**：当精确匹配失败且m≥5时，枚举候选窗口集合C(q,p)，选择：
  ```
  w̃ = argmax_{w∈C(q,p)} score(q, w)
  ```
  仅当score≥τ=0.8时返回结果，否则报告未找到。

### 3.2 标准化与溯源映射
标准化函数N(·)包含：
- Unicode兼容性归一化（NFC/NFD统一）
- 破折号/减号统一（—, –, - → 统一字符）
- 畸形编码修复（替换非法字节序列）
- 科学符号映射（Greek字母、上下标规范化）
- 布局分隔符移除（段落换行、列表标记剥离）

**关键设计**：每个输出字符存储溯源对(i,c)，i为源文本项索引，c为该文本项内的字符偏移量。映射关系在标准化过程中显式构建，原文本s_i永不修改。

### 3.3 精确匹配与字符区间裁剪
- 若q̂在p̂中连续匹配，收集所有被匹配文本项的源区间。
- 对每个文本项p_i，仅渲染区间[c_start, c_end)，水平范围按比例估算：
  ```
  x_start = x₀ + w · (c_start / |s_i|)
  x_end   = x₀ + w · (c_end   / |s_i|)
  ```
- 用PDF变换矩阵T_i将(x_start, y)转换至页面坐标，并裁剪至视口边界。
- **优势**：避免证据在文本项中间结束时，高亮延伸至同项内后续内容。

### 3.4 断行与噪声文本对齐
- **分词规则**：字母式断行连字符合并（如"activ-\nity"→"activity"），公式类字符串保留（如"ZSM-5°"）。
- **多尺度窗口枚举**：对quote长度m，生成候选长度ℓ_α=round(α·m)，α∈{0.70,0.85,1.00,1.15,1.30}，向上取整。
- **LCS评分**：
  ```
  score(q, w) = LCS(q, w) / max(|q|, |w|)
  ```
  分子分母均以token计数，阈值τ=0.8。
- **渲染策略**：仅高亮LCS对齐的token，排除未对齐的引用标记或噪声。

### 3.5 几何渲染
- 对每个匹配源区间，计算文本矩形四个角的变换坐标。
- 矩形裁剪至归一化页面边界。
- 仅当相邻矩形位于同一渲染行且距离接近时才合并，避免跨栏/页眉/无关区域的错误合并。

## 实验与结果

### 数据集
- **规模**：1020篇公开化学论文，每篇配对1个Markdown证据文件，共18,580条引文（平均18.2条/篇）。
- **特点**：多栏页面、化学公式、图表引用、噪声文本层，覆盖普通搜索失败场景。
- **开源**：提供配对规则、引文解析器、BBOX记录、比较脚本、数据集清单（含标识符、访问源、日期、重分发状态）。

### 基线方法
1. **Proposed**：源保持标准化+对齐+溯源恢复+几何渲染。
2. **PyMuPDF Text Search**：直接使用PyMuPDF标准搜索接口。
3. **Precomputed BBOX**：离线构建页面文本-边界框索引，检索后渲染预存框。

### 评估指标
- **自动定位率**：返回至少一个候选页面区域的引文占比。
- **手动验证**：18,572条引文由6名评估者标注，分三档：Correct（完全准确）、Incorrect（位置/边界误差）、Not Found（无可用定位）。

### 主要结果（Table 1）
| 方法 | 定位率 | 准确率 | 未找到率 |
|------|--------|--------|----------|
| Proposed | **92.6%** | 92.1% | 7.9% |
| Text Search | 43.6% | 43.6% | 56.4% |
| BBOX Baseline | 19.1% | 19.1% | 80.9% |

- **提升幅度**：相比文本搜索提升+49.0pp，相比BBOX提升+73.5pp。
- **长度鲁棒性**：Proposed在81-160字符区间达到峰值，长引文（>160字符）仍显著优于基线；BBOX在所有长度组均单调下降。
- **消融实验**：移除标准化使定位率下降最显著；移除LCS容错对齐进一步降低长引文表现。
- **渲染裁剪效果**：字符区间裁剪相比整项渲染，平均每引文减少62.8个多余源字符（占高亮字符26.8%）。

## 相关工作脉络

1. **PDF解析库**：PDF.js、PyMuPDF暴露页面字符串/文本项/几何信息，但未提供标准化匹配与溯源映射机制；神经网络解析器（如Nougat）提升结构化提取质量，但不保证可追溯的视觉源跨度。
2. **文档布局分析**：PubLayNet、DocBank、LayoutParser、DocLayNet聚焦版面检测与结构识别，但未解决跨格式文本对齐与精确定位问题。
3. **近似字符串匹配**：经典算法（Needleman-Wunsch、LCS）处理文本错误，但未结合PDF几何投影；本文将其迁移至token级对齐并引入溯源裁剪。
4. **科学文献提取**：GROBID、Cermine专注元数据与术语抽取，不处理证据字符串到页面几何的映射。
5. **RAG与可验证生成**：RAG系统需证据定位支持，但现有方案依赖粗粒度搜索；本文提供从逻辑文本到字符级高亮的完整链路。

## 局限性与未来方向

1. **字体宽度近似**：当前通过项宽度比例估算字符坐标，等宽字体假设在比例字体下产生松散边界；未来可引入glyph-level度量或原生文本层定位。
2. **复杂布局处理**：多栏阅读顺序、跨栏引文、浮动元素尚未建模；可结合LayoutLMv3等布局感知方法进行阅读顺序分析。
3. **严重提取错误**：标准化规则与LCS阈值无法覆盖极端编码损坏或OCR失败场景；需探索置信度校准与轻量级纠正机制。
4. **规模化验证支持**：当前为确定性规则，缺乏学习式纠错；未来可结合轻重量级模型进行残差修正。

## 研究启发与可借鉴点

1. **源保持范式可迁移**：标准化与溯源分离的设计思路适用于任何"逻辑文本↔物理渲染"对齐任务（如法律文档、医疗报告的高亮定位）。
2. **多尺度窗口枚举策略**：通过α∈{0.70,0.85,1.00,1.15,1.30}生成候选长度，无需训练即可适应不同噪声程度，可作为零样本容错匹配的通用模板。
3. **LCS评分+阈值裁剪**：以token为单位计算LCS并设阈值τ=0.8，有效排除引用标记等噪声，可复用于学术引用解析、公式匹配等场景。
4. **比例估算几何渲染**：x_start=x₀+w·(c/|s_i|)的简单启发式在缺乏glyph级信息时提供合理近似，可与深度学习边界检测结合。
5. **公开基准构建方法**：PDF-Markdown配对规则、引文解析器、数据集清单（含访问日期、重分发状态）的完整披露，为领域基准建设提供范式。

## 关键术语表

**Source-Preserving Alignment**：在文本标准化匹配过程中保留字符级溯源映射（源文本项索引+偏移量），实现从标准化空间到原始PDF几何的精准回投。

**Provenance Map**：标准化过程中显式构建的映射结构，将每个输出字符关联至源文本项i和字符偏移c，支持匹配结果的区间裁剪。

**Line-Break-Aware Token Alignment**：考虑断行连字符合并与公式字符串保留的分词策略，结合多尺度窗口枚举与LCS评分的容错对齐方法。

**Character-Range Clipping**：根据溯源映射将高亮区间裁剪至证据实际覆盖的字符范围，避免整项高亮污染（如证据在句末但高亮延伸至下一句）。

**Quote-Level Localization Rate**：评估指标，定义为方法返回至少一个候选页面区域的引文数量占总引文数量的比例。

**LCS Score**：最长公共子序列（Longest Common Subsequence）长度与引文/窗口最大长度的比值，衡量token级匹配质量。

**Glyph-Level Metrics**：基于单个字符字形（glyph）的几何度量，可提供比宽度比例更精确的字符坐标估计。

**Layout-Aware Reading Order**：考虑多栏排版、浮动元素、页眉页脚的阅读顺序分析，当前方法假设线性文本流。

# 论文速读：TIMELINE-BENCH-EVALUATING-AGENTS-ON-REALISTIC-VIDEO-EDITING

## 一句话总结
本文提出了 TIMELINE-BENCH，一个包含 56 个真实视频剪辑任务的基准测试，要求 AI Agent 将原始制作素材和编辑简报转化为最终成品视频；评测 16 个前沿 Agent 发现，最佳 Agent 仅能解决 26.8% 的任务，主要差距在于剪辑"工艺"（节奏、镜头选择、润色）而非形式合规。

## 研究问题与动机
- **现有 Agent 评测缺乏创意交付物评估**：当前主流基准（如 SWE-bench、GDPval）主要评估代码生成和工具使用，但缺乏对"从原始素材到完整创意交付物"这一完整工作流的评估。
- **视频剪辑是极具挑战性的评测环境**：剪辑需要解读简报、理解原始素材、协调画面与声音的时间关系，且决策相互依存——改变一个镜头可能改变旁白含义，改变时长会影响节奏和同步。
- **现有视频基准只评测剪辑的"组件能力"**：如 VEBench、MEDit-Bench 等只评测镜头识别或从长视频中选片段，无法反映真实剪辑工作流中多步骤、多模态、时间敏感的综合能力。
- **需要可复现的自动化+人工混合评测协议**：由于同一简报可以有多种合法剪辑方案，仅靠测试不够，需要结合程序化验证、LLM 质量评估和人类专家偏好的三轨评测体系。

## 核心贡献（创新点）
1. **提出 TIMELINE-BENCH 基准**：包含 56 个从真实影视制作中提取的剪辑任务，每个任务提供简报、源素材、Docker 执行环境和一套测试，首次系统评估 Agent 完成"从原始素材到成品视频"的完整工作流能力。
2. **设计三轨混合评测协议**：将交付测试（格式合规）、内容/简报测试（显式要求）与质量测试（参考编辑校准的 LLM 判断）相结合，既容纳多种合法剪辑方案，又评估观看体验。
3. **构建校准于 43 位专业剪辑师 2,582 次盲评的质量测试**：使用 Gemini 3.8 Flash、GPT-6 Astra、Claude Opus 5.5 三个多模态 LLM 评委进行交叉评分，评分阈值在人类判断上拟合，与人类胜率高度相关（Spearman ρ = 0.93）。
4. **系统性归因分析揭示 Agent 剪辑能力差距的本质**：发现 73% 的未解决运行通过了所有形式测试但仅失败于质量测试；Agent 以 0.72× 参考剪辑速率剪切、主要依赖静态帧和转录理解素材、检查渲染缺陷而非节奏和故事，且 93% 的运行声称成功。

## 方法详解
- **任务定义**：每个 TIMELINE-BENCH 任务由五部分组成：剪辑简报（edit brief）、源素材（source assets，约 33 小时原始 footage）、Docker 镜像（含 FFmpeg、Python、Node、Remotion、HyperFrames 等工具）、测试套件（tests）、300 分钟时间上限。
- **四层测试体系**：① 交付测试（4 项/任务）：检查输出文件是否存在、视频流、音频流、时长是否符合简报；② 内容测试（6 项通用）：拒绝大部分静音、冻结、循环等退化剪辑；③ 简报测试（1-6 项/任务，共 180 项）：153 项为程序化测试（OCR 检测屏幕文字、Whisper 转录语音、帧匹配源片段），27 项为可见内容的多模型多数投票；④ 质量测试：将 Agent 剪辑与参考剪辑对比。
- **质量测试设计**：三个 LLM 评委（Gemini 3.8 Flash 看视频+声音，GPT-6 Astra 和 Claude Opus 5.5 读 1fps 联系表）各独立评分（1-10 分），结合整体分和五个维度（故事与组装、节奏、画面、声音、图形）得分计算综合分，转换到 z-score 后取平均。通过阈值为参考剪辑的 panel score + 集合特定 margin（Cinestudy: 0.30, Commercial: 0.52, EditStock: 0.21, UGC: 1.54），margin 在人类判断上拟合且不超出人类胜率。
- **人类偏好研究**：43 位专业视频剪辑师进行盲评，每对编辑出现随机顺序（Version A/B），需完整观看两段视频后才能作答，共 2,582 次有效判断；Agent 胜率定义为人类偏好其编辑或无显著偏好的比例。
- **参考隔离**：参考剪辑不与任务输入一起提供，不在容器内，所有 896 次运行轨迹审计确认无网络搜索获取参考编辑的行为。

## 实验与结果
- **数据集**：56 个任务来自三个来源——EditStock 购买项目包 11 个、Cinestudy 公开项目 15 个、专业剪辑工作室委托制作 30 个；涵盖叙事场景、纪录片、访谈、动作序列、预告片、产品广告等类型。
- **评测 Agent**：16 个 Agent，10 个前沿模型在开源 OpenCode 中运行，4 个模型额外在官方 harness（Codex CLI、Claude Code）中运行，另加带有策展编辑指导和计算机使用模式的 GPT-6 Astra 变体。
- **主要结果**：最佳 Agent **GPT-6 Astra in Codex CLI with curated guidance** 解决 15/56 任务（26.8%，95% CI [15.8, 40.3]）；其次为 Claude Opus 5 in Claude Code（23.2%）和 GPT-6 Astra in Codex CLI（21.4%）；所有 Agent 平均解决 14.0%。
- **人类偏好**：人类剪辑师在 83.5% 的判断中偏好参考剪辑，Agent 仅获 11.1%，无显著偏好 5.5%；平均 Agent 胜率为 16.5%。
- **质量测试与人类判断高度一致**：Spearman ρ = 0.93，Pearson r = 0.93，平均偏差仅 3.0 个百分点。
- **成本与效率**：最佳 Agent 每次运行成本约 $9.76，中位运行时间 16-61 分钟；更昂贵的 Agent 倾向于解决更多任务（ρ = 0.79）。
- **失败归因**：771 次未解决运行中 562 次（73%）通过了交付、内容和简报测试，仅失败于质量测试；中位失败幅度为 0.82 个评委标准差（约 1 分），属于"近 miss"。

## 相关工作脉络
- **SWE-bench / Terminal-Bench / MLE-bench**：这些是编程/终端类 Agent 基准，关注代码正确性和任务完成度，而 TIMELINE-BENCH 关注创意交付物的质量和工艺。
- **GDPval / Agents' Last Exam**：评估 Agent 完成现实经济价值任务的基准，包含专家判断，但 TIMELINE-BENCH 专注于视频剪辑这一特定创意工作流，并设计了更精细的多轨测试体系。
- **VEBench / MEDit-Bench**：评测多模态模型的视频编辑"组件能力"（镜头识别、从长视频中选片段），而非端到端完整剪辑工作流。
- **AgenticVBench / CutVerse / MMTB**：评估后制作操作和 GUI 轨迹，分析技术故障；TIMELINE-BENCH 额外评估剪辑"工艺"（节奏、镜头选择、润色）并从专业剪辑师笔记中分析失败原因。
- **Chatbot Arena / MT-Bench**：LLM 人类偏好评测的代表；本文借鉴了盲评设计但扩展为视频剪辑领域，并使用 LLM 评委交叉校准减少位置偏差。

## 局限性与未来方向
- **每任务单次运行**：置信区间未考虑运行间方差，可能存在偶然性。
- **质量测试仅在 Agent 层面有效**：单条编辑的 LLM 判断与人类判断一致性较低（κ = 0.15），质量测试适用于 Agent 排名但不适合评估单条输出。
- **参考剪辑非认证 ground truth**：参考编辑是专业剪辑作品但不等于唯一正确答案。
- **未来方向**：需要原生音视频感知能力（而非仅依赖静态帧和转录）、内置润色工具、以及判断创意质量而非仅判断正确性的能力。

## 研究启发与可借鉴点
- **混合评测协议的设计**：将程序化测试（保证形式合规）+ LLM 质量评估（校准于人类判断）+ 人类偏好研究（gold standard）相结合的三轨评测方法，可迁移到其他创意工作流基准（如图像编辑、音频混音、3D 场景构建）。
- **Margin 校准方法**：在人类判断上拟合 LLM 质量测试通过阈值（使得 LLM 通过率尽可能接近但不超过人类胜率），这一方法可用于其他需要主观质量评估的 Agent 基准。
- **轨迹级归因分析**：将 Agent 行为分解为感知/规划/构建/验证阶段，统计各阶段行为比例并与结果关联，揭示了"Agent 花 54% 时间感知源素材、仅 9% 时间构建"的模式，这种方法可应用于任何长 horizon Agent 评测。
- **与团队方向的结合机会**：可借鉴此基准思路评估团队在多模态 Agent 上的视频理解能力，或设计面向特定剪辑任务（如字幕同步、色校正）的细分基准。

## 关键术语表
- **TIMELINE-BENCH**：一个包含 56 个真实视频剪辑任务的基准，评估 Agent 从原始素材到成品视频的端到端能力。
- **Task Resolution Rate**：Agent 通过全部测试（含质量测试）的任务占比，是主要评估指标。
- **Win-or-Tie Rate**：人类剪辑师偏好 Agent 编辑或与参考编辑无显著偏好的判断比例。
- **Quality Test**：基于三个 LLM 评委交叉评分并与人类判断校准的质量评估测试，用于区分"形式合规但工艺不足"的剪辑。
- **Harbor Format**：任务打包格式，固定每个任务的简报、输入和交付测试，确保可复现性。
- **Contact Sheet**：每秒一帧的缩略图序列，供文本/图像-only 的 LLM 评委"观看"视频。
- **Panel Score**：三个 LLM 评委各自 z-score 后的平均分，用于质量测试的定量比较。
- **Cut Rate**：每分钟剪辑次数（cuts per minute），反映编辑节奏，Agent 的平均剪切率仅为参考剪辑的 0.72 倍。

## 可复现要素
- **数据集**：56 个 Harbor 格式任务已发布（https://timelinebench.tensortest.com），但源媒体和参考编辑仅向获批研究团队开放（受限于版权和隐私）。
- **代码/权重**：验证器（verifier）和重计算脚本已开源（Apache-2.0 许可），可在 https://timelinebench.tensortest.com/code 获取；模型权重不涉及。
- **关键超参**：每个 Agent 运行 300 分钟时限、32 vCPUs + 256GB 内存；质量测试 z-score 标准化基于 919 条视频（863 条 Agent 编辑 + 56 条参考）；三个 LLM 评委分别为 Gemini 3.8 Flash、GPT-6 Astra、Claude Opus 5.5。

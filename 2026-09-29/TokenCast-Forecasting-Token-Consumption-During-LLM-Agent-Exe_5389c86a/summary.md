# 论文速读：TokenCast-Forecasting-Token-Consumption-During-LLM-Agent-Exe

## 一句话总结
TokenCast 是一种面向 LLM Agent 执行过程的轻量级在线 Token 消耗预测框架，通过可组合的段代价表示与精确组合恒等式，将上下文累积引起的重复输入计费显式建模，无需额外 LLM 调用即可在四个执行节点动态刷新预测，在四项基准与六种 Agent 模型上平均降低 14.5% 的 MAE，并在离线预算控制回放中节省 21.3% 的 Token。

## 研究问题与动机
- **执行随机性与上下文膨胀耦合**：同一任务在不同运行中 Token 消耗可相差 30 倍，Agent 的工具反馈、重试循环与中间结果会不断累积到后续调用的输入上下文中，使总消耗高度依赖于执行轨迹而非仅任务描述。
- **现有请求级预测无法直接迁移**：TRAIL、EGTP、TIE 等方法针对单次请求输出长度设计，依赖 prompt 特征或生成中模型内部状态；而开放 Agent 的后续请求在前期根本不存在，且无法保证对模型内部表征的访问权限。
- **现有任务级估计缺乏运行时刷新能力**：Self-Prediction 等任务级方法依赖 Agent 自检或静态环境检查，虽可给出总消耗估计，但执行过程中无法利用已观测到的调用历史、工具结果与生成前缀进行增量修正。
- **重复输入计费机制未被显式建模**：Provider 对保留上下文的重复计费使得“历史段上下文增长”会线性放大后续所有调用的输入成本，现有方法多将消耗视为黑盒回归目标，忽略了这一可拆解的组合结构。

## 核心贡献（创新点）
- **段代价因式分解与精确组合恒等式**：将执行轨迹划分为若干段并用 $(n, g, b)$ 三元组表征，推导出相邻段组合时残差项增加 $n_B g_A$ 的恒等式，显式量化前一段上下文增长被后一段重复读取的输入成本。与已有工作相比，本质区别在于将复合成本预测转化为可叠加的组合子问题，而非对总消耗进行端到端黑盒回归。
- **分阶段前缀-后缀双路径预测器**：任务级预测同时维护直接剩余成本路径与基于预测边界条件化的后缀组合路径，并在 Call Start / In-call Update / Task Update 处利用最新观测特征刷新预测，全程零额外 LLM 调用。与 Self-Prediction 等依赖 Agent 自检或外部 LLM 辅助估算的方法本质区别在于，预测完全由离线训练的 LightGBM 基于观测特征驱动，延迟仅毫秒级。
- **面向误差传播的成本加权损失与交叉拟合训练**：为前缀上下文变化误差与后缀调用次数误差分配正比于下游影响系数 $n_B$ 与 $L_B$ 的局部损失权重，并采用 F-fold 交叉拟合生成 out-of-fold 边界预测以避免训练-推理分布偏移。与常规回归/排序方法相比，训练协议严格对齐组合恒等式的误差传播链路，抑制级联预测的累积偏差。
- **校正模型与校准分位数区间**：在固定直接/前缀/后缀模型后训练残差校正模型，并结合独立分位数模型输出 90% 预测区间，区间端点经校准集残差分位数对称拓宽。与仅输出点估计的基线相比，提供概率化不确定性量化，并证明预测质量可直接转化为预算控制下的实际 Token 节约。

## 方法详解
- **问题设定与预测点**：Agent 执行由 $K$ 次逻辑调用组成，第 $k$ 次消耗 $C_k$，总消耗 $T = \sum_{j=1}^K C_j$，已确认消耗 $S_k$，剩余消耗 $R_k = T - S_k$。定义四个预测时间点：Task Start（预测 $T$）、Call Start（请求组装后预测 $C_k$）、In-call Update（生成前缀流式到达时更新 $C_k$）、Task Update（调用完成后预测 $R_k$，刷新 $\hat{T}_k = S_k + \hat{R}_k$）。

# 论文速读：What-Drives-Citations-in-Production-Large-Language-Models-An

## 一句话总结
本研究基于四个商业化大模型引擎的约 200 万条 AI 引用数据，首次系统性地识别了影响 LLM 引用频率的核心页面级与领域级特征，发现**提示词-内容对齐度（prompt-content alignment）**是主导性预测因子，而传统 AEO/SEO 结构化信号的作用在控制领域固定效应后被证实为辛普森悖论假象。

## 研究问题与动机
1. **核心问题**：在真实生产环境中，哪些页面级特征能够预测 LLM 引用频率？现有实践界推荐的结构化数据、FAQ、Core Web Vitals 等干预措施是否真正有效？
2. **现有方法不足**：已有研究多基于合成提示词、单一引擎或小样本案例研究，缺乏多引擎、大规模、控制混杂因素的实证；此前 GEO/AEO 文献采用池化估计，未处理品牌级混杂，导致错误归因。
3. **实证空白**：尚无研究对"答案引擎优化"实践界的处方进行大规模、混杂控制的检验。

## 核心贡献（创新点）
1. **规模与范围创新**：首个覆盖四个生产引擎、19 个 B2B SaaS 工作空间、约 200 万条引用的多引擎大规模观察性研究，提供前所未有的数据基础。
2. **对齐度作为主导预测因子**：提出操作化的"提示词-内容对齐"指标（基于完整工作空间提示词语料计算的 Jaccard 重叠），该指标通过九方法共识检验，β = +0.37，q ≈ 10⁻⁷³，远超其他页面级特征。
3. **揭示辛普森悖论**：发现传统 AEO 清单（结构化数据、FAQ、Core Web Vitals）的正面效应在控制领域固定效应后消失或反转，修正了 practitioner literature 的误导结论。
4. **九方法共识框架**：提出可复用的观测性 LLM 引用研究协议，综合混合效应回归、FDR 校正、稳定性选择 Lasso、双重机器学习、广义加性模型等九种方法的三角验证，确保效应声明的可靠性。
5. **跨引擎异质性刻画**：系统揭示四个引擎在引用年龄、品牌声量、第三方平台分布上的显著差异，证明"优化 AI"不是单一目标问题。

## 方法详解
**数据收集**：
- 从 Discovered Labs AEO 基准测试平台收集约 2.1 × 10⁶ 条 ⟨提示词, 引擎, 被引 URL, 位置⟩ 元组，覆盖 ChatGPT、Claude、Google AI Overviews、Gemini 四个引擎，时间跨度六个月。
- 对至少被引用两次的 URL 进行采样，共 10,042 个去重 URL，提取 60+ 特征。

**目标变量**：
- 采用对数变换：y = log₂(1 + n_c)，缓解计数数据的偏斜性。
- 所有连续预测变量在拟合前进行 z-score 标准化。

**九方法框架**：
1. **混合效应回归（域固定效应）**：y_i = α_d(i) + x_i^T β + p_i^T γ + ε_i，其中 α_d 为域固定效应，HC1 稳健标准误。
2. **FDR 校正**：Benjamini-Hochberg 校正，q < 0.05。
3. **稳定性选择 Lasso**：B = 200 次bootstrap，λ 通过 10 折交叉验证，选择概率 Π̂_j ≥ 0.60。
4. **双重机器学习（DML）**：正交化部分效应 y - ĝ(w) = θ[X - m̂(w)] + u，梯度提升回归器进行交叉拟合。
5. **速度指标因子分析**：LCP、INP、CLS 等通过 promax 旋转的探索性因子分析降维。
6. **广义加性模型（GAM）**：惩罚立方样条检测非线性关系。
7. **SHAP 特征重要性**：XGBoost 结合 target-encoded 域，计算平均绝对 SHAP 值。
8. **敏感性分析**：五种子集重新拟合。
9. **留一域验证**：依次删除八个最大域重新拟合。
10. **时间保持验证**：以 2026 年 4 月 1 日为界划分训练/验证集。

**共识协议**：效应需同时满足五个条件——(i) q < 0.05, (ii) Π̂ ≥ 0.60, (iii) DML 后非零, (iv) GAM 平滑单调或单峰, (v) 五分之四敏感性子集符号一致。

## 实验与结果
**数据集**：
- 引用语料：约 2.1 × 10⁶ 条，来自四个引擎（Claude: 24,333；Gemini: 52,244；Google AI: 69,824；ChatGPT: 12,121）
- 页面语料：10,042 个去重 URL，5 类 60+ 特征族
- 品牌控制子集：N = 4,015 页面，D = 297 个域
- 真第三方引用：1.27 × 10⁶ 条

**主要结果**：
| 预测因子 | β (标准化) | 95% CI | q 值 |
|---------|-----------|--------|------|
| **提示词-内容对齐** | **+0.37** | [+0.33, +0.41] | **≈10⁻⁷³** |
| 页面长度 | +0.13 | — | <10⁻⁷ |
| 标题-提示词相似度 | +0.09 | — | <10⁻⁴ |
| 页面年龄 | +0.05 | — | <10⁻³ |
| FAQ 板块 | +0.07 | — | 不显著(域控制后) |
| Core Web Vitals | 近零 | — | 不显著(域控制后) |

**关键发现**：
- **对齐度效应**：每增加一个标准差的对齐度，引用数几何均值约增加 30%。DML 校正后 θ_align = +0.35 (p < 10⁻⁵⁰)。时间保持验证中训练集 β = +0.61，验证集 β = +0.34。
- **最佳匹配段落深度**：中位数 0.36，表明引擎优先引用页面上三分之一的段落（Wilcoxon 检验 p < 10⁻²⁰）。
- **辛普森悖论**：速度指标在池化数据中呈现显著的负相关（较快页面反而引用更少），但控制域固定效应后效应坍缩至零或反转符号——大品牌网站积累更多引用但同时页面较慢，池化估计将品牌混杂误归因为速度效应。
- **SHAP 分析**：域权威的 mean |SHAP| = 0.381，是次强非对齐页面级特征的 6 倍。域仅模型 R² = 0.320，全特征集 R² = 0.450，页面级增量 ΔR² = 0.130。
- **跨引擎异质性**：Claude 引用年龄中位数 5.1 月，ChatGPT 为 8.0 月；ChatGPT 品牌控制 URL 占比 39.3%，Gemini 仅 13.8%；LinkedIn 的 96.6% 引用来自 Google AI Overviews，Gemini 贡献为零。
- **页面类型效应**：定价页面残差效应最大（β = +0.39），listicle-review 为负（β = -0.12）；漏斗越深，结构化信号越显著。

**最强结果**：提示词-内容对齐（β = +0.37, q ≈ 10⁻⁷³）是唯一通过全部九方法检验且效应量最大的页面级预测因子。

## 相关工作脉络
1. **Bohnet et al. (2022), Gao et al. (2023)**：评估 LLM 引用是否支持生成主张的归因研究；本文反向提问——哪些页面特征预测引用频率。
2. **Aggarwal et al. (2023)**：提出系统性 GEO 干预测试框架；本文扩展至多引擎大规模实证。
3. **Kumar & Palkhouski (2025)**：对 1,100 URL 应用逻辑回归，发现元数据新鲜度和语义 HTML 为最强预测因子；但未控制域级混杂，本文指出其估计可能受辛普森悖论污染。
4. **Zhang et al. (2025, 2026)**：训练分类器比较 LLM 引用与传统搜索的差异；本文提供因果推断框架下的横断面效应估计。
5. **Kumar & Lakkaraju (2024)**：证明策略性词汇插入可改变 LLM 推荐概率；本文对齐指标基于自然提示词而非操纵实验。
6. **Lewis et al. (2020)**：RAG 系统基础工作；本文聚焦生产系统中不可观测的检索管道对外部可观测特征的依赖。

## 局限性与未来方向
**自述局限**：
- 观察性设计，无随机干预，所有系数为域内偏关联而非因果效应；DML 控制已测量混杂，但未测量混杂（内容质量、编辑投入）无法排除。
- 19 个工作空间均来自单一 B2B SaaS 基准平台，结论向新闻、电商、B2C 等域迁移需重新验证。
- 仅覆盖四个引擎，Perplexity、Bing Chat 等缺失；六个月窗口可能错过引擎管道季度性变化。
- 语义相似度指标仍基于引用提示词计算，存在循环风险；Jaccard 仅捕获 unigram/bigram 层级语义。
- Schema 提取在部分品牌控制页面失败（CMS JSON-LD 渲染问题）。

**未来方向**：
- 通过受控提示词操纵实现因果识别。
- 纵向稳定性检验（滚动捕捉窗口）。
- 扩展到非 B2B SaaS 内容域。
- 基于当代 embedding 模型的 richer semantic alignment 指标。

## 研究启发与可借鉴点
1. **九方法共识协议可迁移**：该协议（FDR + 稳定性选择 + DML + GAM + 敏感性分析 + 留一域 + 时间保持）可作为观测性 LLM 研究的标准验证流程，适用于任何黑盒系统的外部观测分析。
2. **域固定效应的必要性**：本文清晰展示了池化估计的辛普森悖论风险——任何观察性 LLM 研究若忽略高层级（域/发布者）固定效应，都可能将品牌相关协变量误认为实质性特征。
3. **对齐指标的构造思路**：基于完整工作空间提示词语料（含未引用提示）计算 Jaccard 重叠，避免了使用引用提示词导致的循环论证，这一构造策略值得借鉴。
4. **漏斗深度的异质性分析**：发现结构化信号在交易型页面（pricing）比信息型页面更有效，提示未来研究应分层分析而非单一全局估计。
5. **R² 分解的诠释框架**：本文对 R² 分解给出了反直觉的诠释——域权威虽解释大量方差，但它是可积累的战略资产而非外生禀赋，页面级 ΔR² = 0.130 在实际营销科学中属有意义范围。

## 关键术语表
**Prompt-content alignment**：页面 tokens 与工作空间完整提示词语料（含未引用提示）之间的 Jaccard 重叠度，是本文发现的最强页面级预测因子。
**AEO (Answer Engine Optimization)**：针对 AI 答案引擎的内容优化实践，类似传统 SEO 但面向 LLM 引用场景。
**GEO (Generative Engine Optimization)**：生成引擎优化，与 AEO 同义或近义，强调在生成式搜索结果中获得可见性。
**Double machine learning (DML)**：Chernozhukov 等人提出的正交化部分效应估计方法，通过交叉拟合梯度提升回归器控制高维混杂。
**Stability-selection Lasso**：Meinshausen & Bühlmann 提出的正则化变量选择方法，通过 bootstrap 重复拟合估计特征选择概率。
**Simpson's paradox**：在汇总数据中观察到的统计关联在控制混杂变量后消失或反转的现象，本文用于解释 AEO 文献中虚假的结构化信号效应。
**Domain fixed effects**：在混合效应模型中作为固定效应引入的域级别截距，用于消除品牌/发布者层面的混淆。
**SHAP (SHapley Additive exPlanations)**：基于合作博弈论的特征重要性解释方法，本文用于量化各特征对模型预测的边际贡献。

## 可复现要素
- **数据集**：引用语料和页面语料均未公开（客户隐私保护）；域名标识在第三方分析中使用真实公开域名。
- **代码/分析管线**：分析管线已发布（论文声明 "We release the analytic pipeline as a methodological contribution"）。
- **关键超参**：稳定性选择 B = 200 次 bootstrap，Π* = 1.0  headline 阈值；DML 采用 5 折交叉拟合；GAM 使用惩罚立方样条；FDR 校正阈值 q < 0.05。
- **特征覆盖**：对齐特征 100%，结构特征 100%，时效特征 80.6%，Real-user CWV 90.6%，页面类型 100%。

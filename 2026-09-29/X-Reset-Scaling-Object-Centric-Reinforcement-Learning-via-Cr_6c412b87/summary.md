# 论文速读：X-RESET: Scaling Object-Centric Reinforcement Learning via Cross-Embodiment Resets

## 一句话总结
提出 X-RESET 框架，将人类手-物体交互演示通过运动学重定向转化为 RL 训练中的重置状态分布，使仅依赖任务无关物体中心奖励的灵巧操作策略能够突破高自由度从零探索的瓶颈，并实现跨执行器泛化与零样本 sim-to-real 迁移。

## 研究问题与动机
- **高自由度 RL 探索瓶颈：** 从纯仿真 RL 从零开始学习接近、抓取与重定向物体时，22-DoF 多指手面临极高的探索维度，常规奖励难以及时提供成功信号。
- **现有方案的成本或性能代价：** 演示驱动的课程学习需昂贵的机器人演示数据；通用物体中心控制器通常依赖复杂的任务特定奖励塑形，或被迫限制行为模式（如仅操作工具柄、仅学习顶抓）。
- **人类视频数据的利用缺口：** 人类日常手-物体交互视频丰富，但直接运动学重定向用于模仿学习会因 embodiment gap 与真实接触动力学失配而失败；如何将人类数据转化为探索引导而非模仿目标尚未被系统探索。

## 核心贡献（创新点）
1. **提出 X-RESET 重置分布框架：** 将人类手-物体状态经重定向与稳定性过滤后，作为 RL 训练时的初始状态采样来源，使任务无关奖励可解；与已有工作的本质区别在于**不将演示作为模仿目标或参考轨迹**，仅通过重置分布提供高价值探索起点。
2. **跨三形态执行器训练通用策略：** 在 UR7e+Sharpa（22-DoF）、KUKA iiwa 14+Sharpa 与 Robotiq 2F-85 夹爪上实现训练；物体中心奖励下平均重定向成功率从 **11.0% → 66.6%**，手-物体联合奖励下从 **42.1% → 59.6%**，证明低偏差奖励配合重置即可解锁多形态灵巧操作。
3. **扩展性、鲁棒性与零样本迁移：** 策略随训练物体数量增加而扩展，对 EBench 未见物体实现零样本泛化；预训练后无需新演示即可微调至新物体（微调 85.9% vs 从头训练 39.1%）；对离线手姿估计噪声鲁棒，并在 UR7e+Sharpa 硬件上完成 seen/unseen 物体的 sim-to-real 零样本部署。

## 方法详解
- **演示数据运动学重定向：** 基于 DexYCB 的 MANO 手部关键点序列，使用 PyRoki 通过优化 fingertip/wrist 目标将人手姿态映射为机器人手指关节角；随后使用 cuRobo 进行碰撞感知逆向运动学（IK）求解手臂关节，生成机器人手-物体状态对数据集 $\mathcal{D}_{\text{robot}}$。
- **不稳定状态过滤：** 在无重力条件下将 IK 配置保持若干物理步，剔除超出关节限位、发生穿透、产生非有限测量值或速度超标的仿真帧，仅保留稳定可复现的状态入库。
- **物体中心奖励函数：** 采用跨物体统一的通用奖励：
  $$r_t = r_{\text{prox}} + \mathbb{1}_{\text{prox}} r_{\text{reorient}} + \mathbb{1}_{\text{prox}} r_{\text{success}} + r_{\text{smooth}} + r_{\text{safety}}$$
  其中近接奖励 $r_{\text{prox}}$ 鼓励指尖/掌心靠近物体表面；重定向奖励 $r_{\text{reorient}} \propto -d_{\text{kp}}$ 基于物体表面 64 个关键点与目标关键点的均方距离驱动位姿对齐；成功奖励在 $d_{\text{kp}} \leq 0.02\,\text{m}$ 时提供额外激励；$r_{\text{smooth}}$ 惩罚动作幅值与变化率；$r_{\text{safety}}$ 惩罚物体出界或机械臂持续触碰桌面（>5 N 持续 0.5 s）。
- **重置采样与策略架构：** 训练时每回合以概率 $1-p$ 从默认随机分布 $\rho_{\text{default}}$ 采样，以概率 $p$ 从演示重置分布 $\rho_{\text{demo}}$ 均匀采样。策略 $\pi_\phi$ 为 PPO 框架下的 Actor-LSTM，输入当前/目标物体关键点、本体感知与交互历史；采用不对称 Critic 访问仿真特权信息（精确速度、接触力等）以稳定训练。默认 $p=0.9$。

# 论文速读：RELMEM-LEARNING-RECURRENT-MEMORY-FORLONGITUDINAL-EHR-MODELIN

## 一句话总结
论文提出 ReLMem，一个为纵向电子健康记录（EHR）建模设计的循环记忆学习框架，使用冻结的 LLM 配合轻量级压缩适配器，以固定容量维护患者历史状态，避免信息累积丢失。该方法在药物预测和诊断预测任务上接近全历史基线的 F1 分数，同时减少 97.1% 的历史存储开销。

## 研究问题与动机
- **长期 EHR 的历史累积问题**：每次新访问都会增加临床信息，导致 LLM 处理完整病史时的计算和内存成本持续上升（attention 成本二次增长，KV cache 线性增长）。
- **现有压缩方法的局限**：传统方法（如 SnapKV、KVzip、LLM-Rsum）需要重新压缩完整历史或逐次累积压缩表示，无法维持固定容量状态。
- **信息丢失的累积风险**：在固定预算下，循环更新必须在新信息整合与历史信息保留之间平衡，早期步骤的信息损失会在后续步骤中累积。
- **缺乏对中间状态的监督**：仅依赖最终答案监督无法约束中间记忆状态是否有效保留对下游任务关键的历史证据。

## 核心贡献（创新点）
1. **提出 ReLMem 框架**：首次将循环记忆机制引入纵向 EHR 建模，使用冻结 LLM 配合可训练的压缩适配器实现固定容量患者记忆的持续更新。
   - 与已有工作（如 CCM、RMT）的本质区别：面向临床纵向数据，通过层间 KV 状态实现压缩而非仅依赖最终层隐藏状态。

2. **多粒度优化策略**：设计中间注意力对齐损失（L_inter）与最终预测监督损失（L_pred）联合优化，确保循环更新过程中历史信息保留与下游预测准确性。
   - 与已有工作的本质区别：首次在纵向 EHR 循环记忆中引入注意力输出对齐，显式约束中间状态对完整历史的检索能力。

3. **课程学习策略**：从短病史开始逐步引入更长历史的训练样本，帮助模型在更深循环深度下保持信息保留能力。
   - 与已有工作的本质区别：针对循环信息累积丢失问题设计的训练调度策略。

4. **系统性实验验证**：在 MIMIC-IV 药物预测和诊断预测两个任务上，证明了 ReLMem 在减少 97.1% 存储的同时保持接近全历史的性能，并超越所有压缩记忆基线。

## 方法详解
**整体架构**：使用任务自适应 LLM 主干（冻结参数 θ）+ 轻量级压缩适配器（可训练参数 φ），每个新访问通过循环更新函数 M_t = C_{θ,φ}(M_{t-1}, v_t) 替换前序记忆。

**关键设计**：
1. **记忆表示**：采用层间 KV 对形式 M_t = {(K_t^l, V_t^l)}_{l=1}^{L}，每层每头固定 B 个槽位，容量恒定。

2. **记忆条件编码**：冻结主干先将当前访问 v_t 与历史记忆 M_{t-1} 一起编码，得到当前访问的 KV 表示 P_t = KV_θ(v_t | M_{t-1})。

3. **固定容量更新**：在 P_t 后追加 B 个记忆 token，通过 token-conditional LoRA 适配器处理，使记忆 token 能同时 attend 到前序记忆和当前访问：M_t = KV_{θ,φ}(<mem>_{1:B} | [M_{t-1}; P_t])，仅保留记忆 token 位置的 KV 输出。

4. **中间注意力对齐损失**（L_inter）：
   - 独立编码完整历史 H_s 得到参考 F_s = KV_θ(H_s)
   - 用相同查询向量 Q_s（来自下一个访问或任务查询）分别读取 M_s 和 F_s，得到 O_s^M 和 O_s^H
   - 最小化归一化平方差：L_inter = (1/|S|H_q) Σ_{l∈S} Σ_{h=1}^{H_q} ||O_{s,l,h}^M - O_{s,l,h}^H||_F² / (||O_{s,l,h}^H||_F² + εn_s d_h)
   - 训练时在每个例子上均匀采样一个更新边界进行对齐，减少开销

5. **最终预测监督损失**（L_pred）：
   - 基于最终记忆 M_T 和任务查询 q，直接最小化答案的交叉熵：L_pred = -(1/N) Σ_{j=1}^N log p_θ(y_j | M_T, q, y_{<j})

6. **联合目标**：min_φ E[L_pred(φ) + (λ/T) Σ_{s=1}^T L_inter(φ; s)]，其中 λ=0.1 控制对齐权重。

7. **课程学习**：按访问数阈值 τ_e 逐步扩展训练集 D_e = {(H_T, q, y) ∈ D : T ≤ τ_e}，从短病史开始训练，缓解信息累积丢失。

## 实验与结果
**数据集**：MIMIC-IV，包含两个任务：
- 药物预测：基于已完成访问预测目标住院前 24 小时的药物类别（ATC level-3）
- 诊断预测：基于已完成访问预测下次就诊的诊断类别（ICD-9/10）

**评估基线**：Full History（无压缩）、LLM-Rsum（文本摘要）、SnapKV、KVzip、Attention Matching（KV 压缩）、RMT、CCM-merge（循环记忆）

**主要结果**：
- **药物预测（Qwen3-4B）**：ReLMem 达到 Macro-F1 61.93%、Micro-F1 63.24%，接近 Full History（62.22%/63.32%），使用历史预算仅为 Full History 的 2.9%（1,024 vs 35,279 slots）
- **超越最强基线**：相比 CCM-merge（Macro-F1 57.27%、Micro-F1 58.49%），ReLMem 提升 4.66pp（Macro）和 4.75pp（Micro）
- **资源效率**：历史 KV 存储从 4,961 MiB 降至 144 MiB；峰值 GPU 显存降低 48.8-49.1%；更新延迟降低 26.3%

**消融实验**：
- 移除 L_inter 导致 Macro-F1 下降 14.26pp，证明中间对齐对信息保留的关键作用
- 课程学习进一步带来性能提升（61.00→61.93 Macro-F1）
- 4 层对齐层数达到最佳性价比，8 层无进一步提升

**跨模型扩展**：在 Qwen3-8B、Llama-3.1-8B 上 ReLMem 与 Full History 差距均 <2.5pp；在更长病史（最大 69 访问、201,398 tokens）上仍保持接近全历史性能

## 相关工作脉络
- **EHR 建模前作**：BEHRT、TransformEHR、Foresight 等利用预训练 Transformer 处理 EHR，但未解决长历史效率问题；ReLMem 与之互补，聚焦高效纵向建模。
- **上下文压缩方法**：LLMLingua/KVzip/SnapKV 面向静态上下文压缩；ReLMem 首次将其适配到持续更新的纵向场景，强调循环而非一次性压缩。
- **循环记忆方法**：Transformer-XL、Compressive Transformer、RMT 等学习跨段记忆传递；ReLMem 区别在于面向临床任务、保留层间 KV 而非最终隐藏状态、引入多粒度监督。
- **CCM（Kim et al. 2024）**：在线交互循环压缩的近期工作；ReLMem 改进其累积平均更新策略，改为直接替换，并通过中间对齐解决信息丢失问题。

## 局限性与未来方向
- 仅在 MIMIC-IV 单中心数据集上验证，未跨机构测试或前瞻性验证
- 仅覆盖药物和诊断预测两个任务，每个任务需单独适配主干和记忆模块
- 仅在 Qwen、Llama 系列 4B-8B 模型上验证，更广泛的模型族和规模待探索
- 未探索任务无关的通用患者记忆表示，可能限制跨任务迁移能力

## 研究启发与可借鉴点
1. **中间对齐监督机制**：L_inter 通过匹配注意力输出对齐压缩记忆与完整历史，该思想可迁移至任何需要循环压缩序列信息的场景（如长对话、文档摘要）。
2. **课程学习缓解累积误差**：从短序列开始逐步增加深度，对任何涉及信息逐层压缩的任务均有借鉴价值。
3. **层间 KV 记忆表示**：相比仅保留最终层隐藏状态（如 RMT），层间 KV 提供更细粒度的历史保留，适合需要多粒度上下文的下游任务。
4. **多粒度联合优化设计**：L_inter + L_pred 的分工——前者保历史信息、后者保任务准确性——可推广到其他记忆压缩框架。

## 关键术语表
**ReLMem**：Recurrent Longitudinal Memory，面向纵向 EHR 的循环记忆学习框架，通过固定容量状态持续整合新访问信息。
**中间注意力对齐（L_inter）**：在训练时对中间记忆状态施加的监督，使压缩记忆的注意力输出与完整历史的注意力输出对齐。
**固定容量记忆**：无论历史长度如何，患者记忆始终保持相同大小的 KV 槽位（如 1,024 slots），避免随访问累积而膨胀。
**任务自适应主干**：先用完整历史对 LLM 进行 SFT 适配，再冻结权重仅训练轻量级压缩适配器。
**token-conditional LoRA**：仅在记忆 token 位置激活的低秩适配器，其他 token 使用冻结主干投影。
**课程学习**：训练时从短病史样本开始，逐步引入更长病史，帮助模型适应更深层循环更新。
**MIMIC-IV**：麻省理工学院发布的公开重症监护电子健康记录数据集，本文用于药物和诊断预测任务。

# 论文速读：RELMEM-LEARNING-RECURRENT-MEMORY-FORLONGITUDINAL-EHR-MODELIN

## 一句话总结
ReLMem 面向纵向电子健康记录（EHR）建模，提出一种在冻结 LLM 骨干网络上学习固定容量循环患者记忆的框架；通过中间注意力对齐与最终预测监督的多粒度优化，在将历史存储压缩 97.1% 的同时，使药物处方与下一访视诊断预测性能逼近完整历史基线。

## 研究问题与动机
- **历史膨胀导致的计算/内存开销不可持续**：LLM 处理纵向 EHR 时，密集自注意力预填充成本随序列长度呈二次增长，KV cache 存储呈线性增长，直接保留完整病史难以扩展。
- **现有压缩方法在循环更新场景下存在信息丢失或累积问题**：单次压缩（如 SnapKV、KVzip）或文本摘要（如 LLM-Rsum）在多次就诊迭代中仍会导致上下文膨胀，或无法显式保留后续任务所需的历史证据。
- **纯最终监督不足以约束中间记忆质量**：仅用最终答案交叉熵优化，无法保证每次循环更新后的中间状态仍具备可检索的历史信息，误差会随就诊步数累积。
- **如何以固定容量完成“增量融合、不重读历史”的循环记忆更新，同时保障下游临床预测精度**，是本文要解决的核心挑战。

## 核心贡献（创新点）
- **提出 ReLMem 固定容量循环记忆框架**：在冻结任务适配 LLM 的前提下，通过轻量级压缩适配器逐访视更新患者记忆状态，避免历史 KV 缓存无限扩张。
- **设计多粒度联合优化策略**：创新性地将中间注意力对齐损失与最终预测监督损失结合，从表示级与任务级双重约束循环压缩过程，防止临床证据渐进式丢失。
- **引入面向更新深度的课程学习机制**：按就诊数量阈值逐步开放长病史样本，显著提升模型在多次循环更新后的记忆稳定性。
- **在两项代表性纵向 EHR 任务上实现接近完整历史的性能与极高的压缩效率**：药物预测 Macro-F1 仅下降 0.29pp，存储降低 97.1%，且较最强压缩基线 CCM-merge 提升 4.66/4.75pp。

## 方法详解
- **任务特定适应（Task-Specific Adaptation）**：首先在完整病史 $H_T$ 上使用 LoRA 对预训练 LLM 进行 SFT，最小化答案交叉熵 $\mathcal{L}_{\text{SFT}}$；合并 LoRA 权重后得到冻结骨干 $\theta$。
- **循环记忆表示与更新**：将患者记忆 $M_t$ 表示为各层 KV 对 $\{( \mathbf{K}^\ell_t, \mathbf{V}^\ell_t )\}_{\ell=1}^L$，每层每头固定 $B$ 个 slot。新访视 $v_t$ 先以 $M_{t-1}$ 为上下文经冻结骨干编码得到 $P_t$；随后拼接 $B$ 个记忆 token $\langle \text{mem}\rangle_{1:B}$，仅在 memory 位置激活 token-conditional 低秩适配器，令其 attend 到 $[M_{t-1}; P_t]$，输出新的 $M_t$ 替换旧状态，完成 $M_t = \mathcal{C}_{\theta,\phi}(M_{t-1}, v_t)$。
- **中间注意力对齐损失 $\mathcal{L}_{\text{inter}}$**：随机采样更新步 $s$，用冻结骨干独立编码完整历史前缀 $H_s$ 得到参考 KV $F_s$；以相同 query $\mathbf{Q}_s$（来自下一访视或最终 query）分别从 $M_s$ 与 $F_s$ 读取 attention 输出 $\mathbf{O}^M_s, \mathbf{O}^H_s$，最小化归一化 Frobenius 范数差异。该损失迫使压缩记忆在检索行为上与完整历史保持一致。
- **最终预测监督损失 $\mathcal{L}_{\text{pred}}$**：基于最终记忆 $M_T$ 与任务 query $q$ 计算答案交叉熵，直接优化下游临床预测精度。
- **联合目标与课程学习**：$\min_\phi \mathbb{E}[\mathcal{L}_{\text{pred}} + \frac{\lambda}{T}\sum_{s=1}^T \mathcal{L}_{\text{inter}}]$，全历史参考仅训练时使用。课程学习按非递减阈值 $\tau_e$ 逐步引入更长病史样本，前期稳定短序列更新规则，后期克服长程信息累积丢失。

## 实验与结果
- **数据集**：MIMIC-IV，构建药物预测（Medication Prediction）与下一访视诊断预测（Next-Visit Diagnosis Prediction）两个任务；训练/验证/测试集按患者严格划分无重叠，测试集各 300 例。
- **评估基线**：Full History、LLM-Rsum、SnapKV、KVzip、Attention Matching、RMT、CCM-merge，所有方法共享同一任务适配骨干。
- **主要结果（药物预测，Qwen3-4B）**：ReLMem Macro-F1=61.93，Micro-F1=63.24，与 Full History（62.22/63.32）差距仅 0.29/0.08pp；历史 KV 存储从 35,279 slot 降至 1,024 slot（减少 97.1%），在相同预算下超越最强压缩基线 CCM-merge 4.66/4.75pp。
- **资源效率**：峰值 GPU 显存由 17.44 GiB 降至 9.24 GiB（近减半），单次更新延迟降低 26.3%。
- **消融与分析**：仅用 $\mathcal{L}_{\text{pred}}$ 时 F1 骤降至 <1%，仅用 $\mathcal{L}_{\text{inter}}$ 仅 37% 左右，两者强互补；4 层对齐性价比最优；记忆容量从 1,024 降至 128 仅损失 2.81/3.00pp；扩展至 Qwen3-8B、Llama-3.1-8B 及诊断预测任务，与 Full History 差距均 <2.5pp；在扩展至 16.72 次平均就诊的长病史下仍能逼近完整历史且显著优于 CCM-merge。

## 相关工作脉络
- **纵向 EHR 建模**：TransformEHR、EHR-R1、EHRAgent、Foresight 等依赖完整或近似完整病史进行预测；本文聚焦固定容量循环压缩，解决历史无限扩张的工程瓶颈。
- **上下文压缩**：LLMLingua/KVzip/SnapKV/Attention Matching 等多为静态或单次压缩，易在多轮访问后累积或需反复重读；本文将其重构为在线循环替代机制。
- **循环记忆机制**：Transformer-XL、Compressive Transformer、RMT、CCM 探索跨段记忆传递；本文区别在于采用层间 KV 表示、引入中间注意力对齐监督，并专门针对临床预测的信息保留需求设计。
- **医疗 LLM 适配**：BEHRT、Med-BERT、Apollo 等以全量数据微调为主；本文采用“冻结骨干+轻量适配器”范式，更适合临床在线增量更新与隐私保护部署。

## 局限性与未来方向
- 仅在单中心回顾性数据集 MIMIC-IV 上验证，缺乏跨机构、前瞻性临床场景验证。
- 仅测试 Qwen 与 Llama 的 4B/8B 模型，更大规模或不同架构的泛化性有待探索。
- 当前为任务特异性适配（药物/诊断分别训练），尚未支持单一记忆模块跨多类 EHR 任务的统一表征。
- 未探讨动态调整记忆容量、结合结构化知识图谱或外部临床指南的增强路径。

## 研究启发与可借鉴点
- **中间注意力对齐范式**可迁移至其他需长期记忆更新的序列压缩任务（如多轮对话、时序日志建模），以查询一致性监督替代难以直接比对的隐状态对齐。
- **Token-conditioned LoRA 仅在记忆位置激活**的设计兼顾骨干冻结与参数效率，适合资源受限的临床边缘部署与在线增量学习。
- **按更新深度递进的课程学习**可有效缓解循环压缩中的误差累积，对任意需多步信息融合的增量模型具有普适参考价值。
- **固定容量 KV 循环更新框架**可与现有风险评分、给药决策模块解耦耦合，快速构建低延迟的纵向临床决策支持系统。

## 关键术语表
- **Longitudinal EHR**：纵向电子健康记录，按时间顺序累积的患者多次就诊诊断、用药、检验与文本记录。
- **Recurrent Memory**：循环记忆

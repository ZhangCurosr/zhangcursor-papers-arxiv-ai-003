# 论文速读：Spatiotemporal-Hyperedges-for-EEG-Seizure-Detection-and-Pred

## 一句话总结
论文提出 HyBrain，一种基于可学习时空超边的轻量编码器，通过对通道-时间 token 的软分组聚合建模癫痫的多通道-跨时间耦合模式；在 TUSZ 和 CHB-MIT 上的检测与预测三项任务中均取得最佳 AUROC，且训练时间与峰值显存显著低于边缘流动态 GNN 基线。

## 研究问题与动机
- 癫痫 EEG 信号具有稀有性、时空局域性与跨通道协调传播特征，自动化检测与预测是临床监测的关键需求。
- 传统序列/CNN-RNN 方法仅沿时间轴处理，电极间关系隐含；静态图 GNN 能建模电极拓扑但无法捕获癫痫过程中的时变耦合。
- 动态 GNN 在每时步维护成对通道边并对其进行时序建模，仍只能表达两两关系，难以直接刻画跨时步、跨通道的更高阶协调；同时需保留密集边级激活，带来较大计算与显存开销。
- 现有基线多采用较粗的窗口级监督，未充分利用一秒级标注；癫痫预测需从微弱、分散的痫前期信号中聚合证据，对模型的全局聚合能力提出更高要求。

## 核心贡献（创新点）
- 在通道-时间 token 上引入可学习时空超边，以少量软分组 embedding 直接建模高阶跨通道/跨时间耦合，避免逐时步成对图的显式构造与分解。
- 同一编码器支持窗口级检测、逐秒点级检测与痫前期预测三项任务，仅更换轻量化读出头；通过超边成员关系的任务相关学习实现多目标共享表征。
- 理论证明超边聚合等价于全局混合算子，秩上界为超边数 $E_h$，并从渐近复杂度角度分析其相对边缘流基线的计算与激活显存优势。
- 在 TUSZ 与 CHB-MIT 上，HyBrain 在十项基线对比中取得各设置下的最高 AUROC，长窗预测提升最显著；训练时间与峰值 GPU 显存接近最高效基线。

## 方法详解
- 输入表示：原始 EEG 重采样至 200 Hz，按通道分割为不重叠 1 秒窗口并做 STFT，得到维度 $X \in \mathbb{R}^{N \times T \times F}$ 的通道-时间频谱张量（$F=100$）。
- 通道-时间 Token 编码：对各通道时序独立堆叠 $L_M$ 层 Mamba，产生每（通道，秒）一个 token；添加可学习通道嵌入以保留通道身份。
- 时空超边聚合块：将所有 $NT$ 个通道-时间 token 投影到 $E_h$ 个可学习超边查询上，采用 sigmoid 软成员关系；按成员权重均值聚合为组 embedding，并将组上下文广播回各 token，配合残差与门控形成局部与全局上下文的融合表示。
- 时序注意力层：在各通道内沿时间轴执行多头自注意力并乘以门控系数 $\beta$，进一步细化长程时序依赖，输出共享表示 $G$。
- 任务头：基于 PMA 式通道读头+线性分类器；窗口级与预测任务在时间轴池化后读头输出单 logit；点级检测保留时间维度并在每步独立读头输出每秒 logit，且加入相邻帧 logit 平滑正则以约束 seizures 的时序连续性。
- 损失：检测与预测任务使用 BCE；点级检测总损失为 $BCE$ 项加相邻帧 logit 差的平方惩罚项。

## 实验与结果
- 数据集与设定：TUSZ 与 CHB-MIT；采用 EvoBrain 的分裂与评估协议；窗口级检测使用 12s 与 60s 两段；点级检测在 1s 分辨率上评估；预测任务在 TUSZ 上进行，痫前期窗口 $\Delta_p=60s$，并构造包含缓冲区的 interictal 负样本池。
- 基线覆盖：序列方法（LSTM、CNN-LSTM）、EEG 基础模型（BIOT、LaBraM、EEGPT）、动态 GNN（EvolveGCN、DCRNN、GraphS4mer、GRU-GCN、EvoBrain）。
- 主要结果：HyBrain 在三项任务的所有报告设置中均取得最佳 AUROC；在 12s 窗口检测上 AUROC 达 0.899，60s 窗口检测 AUROC 达 0.908，CHB-MIT 12s 检测 AUROC 达 0.924；预测任务在 TUSZ 60s 上 AUROC 达 0.758、F1 达 0.434，提升幅度最大。
- 效率：在 A6000 上训练每 epoch 时间约 29s，峰值显存约 332 MB；相较 GRU-GCN 与 EvoBrain，显存分别降低约 13.8 倍与 12 倍，推理延迟明显更优。
- 消融：移除超边聚合块在 60s 设置上 AUROC 下降 4.2pt、F1 下降 9.2pt；替换 Mamba 骨干为 GRU 影响较小，表明超边聚合是关键模块。
- 可视化：单条学习到的超边能够在单个 seizure clip 上清晰呈现 preictal→ictal→postictal 三阶段成员模式，体现其对高阶时空轨迹的压缩表征。
- 超边敏感性：$E_h \in \{1,3,5,7,9\}$ 范围内性能稳定，说明癫痫相关结构可由少量协作通道-时间组支撑。

## 相关工作脉络
- 序列/静态图方法与本文定位：LSTM、CNN-LSTM、EEGNet、TGCN 等方法仅沿时间或固定拓扑建模，缺乏对癫痫时变跨通道耦合的直接刻画；本文在不构造逐时步边图的前提下实现时空联合建模。
- 动态 GNN 与边缘流方法：DCRNN、EvolveGCN、GraphS4mer、GRU-GCN、EvoBrain 等方法在每时步更新通道图，并在边上施加时序模型；本文将其替换为固定预算的软超边聚合，避免边级显存瓶颈并显式建模跨时步-跨通道高阶耦合。
- 超图学习：HGNN、HyperGCN、AllSet 等多依赖预定义或 $\epsilon$-NN 确定的超边；STHGCN 将空间与时间超图分离用于情绪识别；HyBrain 在通道-时间网格上联合学习条件化超边，并以少量可学习超边 query 适应检测与预测任务。
- EEG 基础模型：BIOT、LaBraM、EEGPT 在大语料上预训练后微调；本文强调轻量、任务相关的时空超边表征，在检测与预测上匹配甚至超越这些重型基础模型的 AUROC 同时显著降低训练成本。
- 点级评估与平滑正则：SzCORE 等基准倡导一秒级评估；本文重新将点级检测作为一等训练目标，并通过 logit 平滑正则显式编码 seizure 标签的时序连续性。
- 癫痫预测任务：预测强调对分散、渐进的痫前期证据进行长程聚合；本文通过全窗口超边池化与低秩全局混合，在长窗预测中取得最大增益。

## 局限性与未来方向
- 超边查询为固定集合且共享整段 clip，可能对高度患者特异或病灶异质性较强的样本泛化受限。
- 当前仅在 TUSZ 与 CHB-MIT 上验证；对更复杂的长程监测、多中心数据以及跨患者泛化情形的表现仍需进一步检验。
- 预测任务对 12s 短窗性能提升有限，说明极短上下文下痫前期证据仍然稀缺，需要更强的先验或外部知识辅助。
- 模型主要面向二分类任务，尚未扩展到 seizure onset zone 定位、发作类型分类或多标签输出。
- 未系统比较与更大规模基础模型的融合策略；如何结合自监督预训练与超边表示是值得探索的方向。

## 研究启发与可借鉴点
- 用少量可学习软超边聚合通道-时间 token，可将"边流"的高阶耦合建模转化为低秩全局混合，值得迁移到多通道生理信号（如 ECoG、MEG、ECG）的多尺度关联任务。
- 同一 encoder 共享表示、不同 task head 适配多种监督粒度（clip/second/interval）的多任务框架，便于构建统一的 EEG 分析与预警系统。
- 在点级检测中引入 logit 平滑正则，直接编码标签的时序连续结构；该思路可推广到任意需要尊重时间邻接性的序列分割任务。
- 理论分析给出全局混合算子的低秩上界并与边缘流代价进行渐近对比，为后续工作提供清晰的计算-表征权衡分析范式。
- 超边成员的可视化能够直接展示 preictal/ictal/postictal 相位切换，这种解释性工具可用于临床可信验证与误差诊断。

## 关键术语表
- **Spatiotemporal hyperedge**：在通道-时间二维网格上可学习的软分组，用于在一次聚合中捕获跨通道与跨时间的联合模式。
- **Soft membership**：通过 sigmoid 计算 token 对各超边的隶属度，允许 token 属于多个超边以表示重叠时空模式。
- **Channel-time token**：将每个通道的每秒频谱特征视作一个 token，构成超边聚合的基本单元。
- **PMA readout**：基于 Set Transformer 的多头注意力池化读头，用于从通道维度抽取判别性摘要。
- **Point-wise detection**：在一秒分辨率上逐帧预测 seizure 标签的任务，要求精确定位发作起止。
- **Preictal prediction**：区分痫前期（发作前短时间窗口）与发作间期的二分类任务，目标是提前预警。
- **Edge-stream dynamic GNN**：在每个时步维持并随时间更新成对通道边及其激活的动态图方法。
- **Global mixing operator**：由超边聚合诱导的全局混合映射，其秩上界由超边数控制并覆盖所有通道-时间 token。

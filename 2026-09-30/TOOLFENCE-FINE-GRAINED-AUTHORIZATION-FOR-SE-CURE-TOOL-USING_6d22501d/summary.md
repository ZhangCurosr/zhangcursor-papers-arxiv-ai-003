# 论文速读：TOOLFENCE-FINE-GRAINED-AUTHORIZATION-FOR-SE-CURE-TOOL-USING

## 一句话总结
ToolFence 是一种面向工具调用型 LLM Agent 的推理时防御框架，通过在执行前编译基于溯源约束的能力授权蓝图、确定性监控器与运行时能力授予机制，有效阻断传统内容过滤与共识类方法难以防御的“工具内攻击”（within-tool attack），在仅损失 3.80pp 干净效用的同时将整体攻击成功率从 21.20% 降至 0.20%，且运行时开销仅 1.63×。

## 研究问题与动机
- **现有防御未能覆盖“工具内劫持”威胁**：主流方法（输入过滤、多路径共识 SecInfer）主要检查内容或聚合输出，忽视了对工具调用实际效果（effect）的授权；攻击者可保留合法工具名仅篡改敏感参数（如收件人、金额、URL），此类攻击对现有防御仍保持高成功率。
- **强隔离方案开销过高**：CaMeL 等提供严格的数据流隔离与溯源，但依赖定制执行管线与多次 LLM 调用，导致 10×–13× 的运行时延迟，难以在低延迟场景中落地。
- **静态过滤与逐调用裁判的两难**：静态工具白名单会误杀合法但未被预见的步骤；逐调用 LLM 裁判虽灵活，但重复决策成本高且攻击面随调用次数线性扩大。
- **授权粒度缺失**：核心矛盾在于“逐调用过于精细、整会话过于粗粒度”，缺乏一种以**能力形状（capability shape）**为单位、支持动态扩展且可跨会话复用的中间层授权机制。

## 核心贡献（创新点）
- **首次系统性刻画并实证“工具内劫持”威胁**：通过参数感知划分（parameter-aware split）证明仅限制工具可见性的静态过滤无法防范敏感参数篡改，将防御焦点从工具选择上移至参数溯源与效果授权。
- **提出动态能力授权蓝图机制**：将静态预编译与运行时裁判结合，首次以“能力形状”而非“具体调用”为单位进行授权扩展，避免了 CaMeL 等方案对同形调用的重复 LLM 裁决，将安全边界与执行效率解耦。
- **设计跨会话无值签名缓存**：以 $(tool, effect, provenance)$ 元数据为键复用已批准的能力形状，严格隔离值级信息；与依赖完整上下文的重放防御相比，在保障新会话参数仍按当前轨迹重新校验的前提下，将裁判调用频次降低 43%。
- **重构提示注入防御范式**：以“确定性快速路径 + 能力级慢路径”替代传统的逐动作 LLM 裁判，与 SecInfer 等多路径聚合方法相比从源头限制不可信内容的执行权限，最终实现 0.20% ASR 与 1.63× 开销的最优权衡。

## 方法详解
ToolFence 为推理时防御架构，核心由四个协同组件构成：
1. **类型化授权蓝图（Typed Authorization Blueprint）**：执行前由隔离 LLM 架构师仅基于认证查询 $q$ 与工具 Schema 编译生成 $\mathcal{P}=(\mathcal{M}, \mathcal{C})$。每个能力定义为 $c = (\mathrm{tool},\ e,\ \{p_j \mapsto \beta_j\},\ \kappa,\ r)$，其中溯源绑定 $\beta_j$ 分为 LITERAL（直接来自 $q$）、DERIVED（来自指定源工具输出）、TEMPLATE（匹配认证模板）与 FREE（非敏感）。蓝图只记录约束形状而非具体值。
2. **确定性监控器（Deterministic Monitor）**：零 LLM 开销的快速路径。对每次候选调用 $a=(\mathrm{tool},\mathbf{x})$ 检查三项：能力匹配、绑定合规（参数值严格符合声明的溯源类型）、执行预算。全部满足则直接派发。
3. **运行时动态能力授予（Runtime Capability Grant）**：当调用未命中蓝图时，控制器计算各参数溯源标签 $\pi(p_j) \in \{\mathrm{USER, TOOL, MODEL}\}$。若任何敏感参数溯源为 MODEL（模型自生），直接拒绝 $\hat{c}=\bot$；否则构造无具体值的能力形状提交裁判。裁判仅评估形状是否服务认证请求且敏感参数受控于 USER/指定工具，通过后调用 $\mathrm{GRANTCAPABILITY}(\hat{c})$ 追加至运行蓝图，后续同形调用自动走快速路径。
4. **跨会话能力缓存（Cross-Session Capability Cache）**：以 $\mathrm{sig}(c) = (\mathrm{tool},\ e,\ \{p_j \mapsto (\beta_j, \mathrm{source\_tools}_j)\})$ 为键存储已授权形状。新会话启动时注入缓存，严格不缓存具体参数值或证据文本，但每次调用仍按当前会话轨迹重新校验绑定，实现成本摊薄而不牺牲安全性。

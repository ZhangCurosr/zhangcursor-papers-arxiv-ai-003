# 论文速读：WHEN-SHOULD-AGENTS-CHECK-EXTERNAL-STATE-BUDGETING-OBSERVATIO

## 一句话总结
本文首次将长期Agent中存储意图所依赖的外部状态检查形式化为共享剧集预算下的资源分配问题，提出了BudgetPM框架——包含基于局部决策改进估计的BudgetPM-Static和基于整剧 hindsight 调度的BudgetPM-Sequential两种策略变体，在两个基准上显著超越了现有记忆Agent系统及天然监控规则。

## 研究问题与动机
- **存储意图需要主动外部观测**：Agent可记住"当供应商门户检查状态变为通过时释放订单"这类意图，但必须主动查询外部状态才能判断条件是否满足，每次查询可能涉及Web访问、API调用和付费操作。
- **现有工作未解决观测预算分配**：已有前瞻性记忆系统（如PMA、PIS）关注"何时意图需要关注"，但均未在共享观测预算下分配重复的外部状态检查请求。
- **固定间隔/启发式规则的局限**：固定轮询、到期前密集检查、退避等天然规则依赖预设节奏或过去观测，无法直接比较"现在检查"与"为未来保留容量"之间的机会成本。
- **核心问题**：哪些观测在当前有价值？Agent应在何时节约容量以供未来检查？

## 核心贡献（创新点）
1. **首个预算化外部状态观测分配形式化**：将存储意图所需的外部状态检查建模为共享剧集硬预算约束下的资源分配问题，而非单纯的触发决策问题。
2. **BudgetPM-Static：轻量级局部结果监督**：用Logistic分类器学习"某项外部检查是否会改进当前决策"，无需昂贵的高容量scorer即可达到竞争力质量-成本前沿。
3. **BudgetPM-Sequential：轻量级未来感知调度**：通过动态规划在冻结轨迹上构建完整剧集最优调度标签，蒸馏为仅依赖预查询信息的轻量策略，实现跨时间维度的容量分配。
4. **揭示需求-容量边界规律**：通过预算扫描和固定预算负载干预，证明当容量覆盖需求时局部门控足够；当现在与未来机会竞争时未来感知调度才增加价值，为Agent内存-观测接口提供设计原则。

## 方法详解
**问题设定**：设剧集ξ含T步，每步t前有历史$ h_t $（含活跃意图和已收集观测），意图指向可查询的外部状态资源集$\mathcal{R}_t$，查询资源$ r \in \mathcal{R}_t $的成本为$ c(r) > 0 $。目标是：
$$\max_\pi \mathbb{E}_\xi[M(\tau_\xi(\pi))] \quad \text{s.t.} \quad \sum_{t=1}^T \sum_{r \in S_t^\pi(\xi)} c(r) \leq B \quad \forall \xi$$

**BudgetPM-Static（局部监督）**：
- 利用冻结轨迹缓存候选资源集$ A_t $的观测结果。
- 对每个候选资源$ r $，定义局部Outcome效应：$ \Delta_{t,r} = m_t(A_{t,r}^{\text{ref}} \cup \{r\}) - m_t(A_{t,r}^{\text{ref}}) $，其中$ m_t(A) = M_t(a_t(A; z_t)) $为插入证据后的步级得分。
- 标签$ y_{t,r}^{\text{Out}} = \mathbb{I}[\Delta_{t,r} > 0] $表示该资源是否能改进当前决策。
- 使用标准 logistic 回归（$ C=1 $，L2正则）拟合，特征为27维预查询向量。

**BudgetPM-Sequential（未来感知调度监督）**：
- 离线用动态规划求解最优完整剧集调度：$ S_{1:T}^\star \in \arg\max Q_\xi(S_{1:T}) $，满足预算约束，保留累计(TP, FP)状态并剔除被支配状态。
- 标签$ y_{t,r}^{\text{Seq}} = \mathbb{I}[r \in S_t^\star] $表示该资源是否属于最优调度的一部分。
- 在线部署时增加9维时序特征：剩余预算、剧集进度、近期查询使用量等。
- 同样用Logistic回归拟合，阈值从OOF预测中按目标预算分数选择。

**共享硬预算执行器**：
- 两变体共享同一执行器：按$ s_{t,r}/c(r) $降序排列提议集，依次选择直到触及剧集剩余预算、每步成本上限L或查询数上限$ N_{\max} $。
- 执行前锁定所有查询计划，不使用当前查询结果。

**精确成本结构余量（Exact-Cost Structural Headroom）**：
- 定义$ H = Q_{\text{DP}} - Q_{\text{CG}} $，即在相同整数查询成本下，hindsight-DP与当前贪婪Oracle的质量差，用于诊断跨时间分配的潜力。

## 实验与结果
**数据集与评估**：
- **PM-Bench**（7天流式前瞻记忆基准）：报告episode Set F1，预算时钟和命名状态频道查询。
- **GoodAI LTM**：报告宏观准确率，闸门语义验证器调用。
- **三个Backbone**：Llama-3-8B、Qwen2.5-14B、Qwen3-14B。

**完整系统对比（B60预算）**：
- BudgetPM-Static在全部6个backbone-基准组合中均达最高端到端质量。
- **Qwen3-14B + PM-Bench**: Set F1 = **0.885**（vs Mem0: 0.433, PMA: 0.432）；**GoodAI**: 准确率 = **0.944**（vs Mem0: 0.500, PMA: 0.500）。
- 相比最强Mem0/PMA工作流，差距达0.362–0.452 Set F1（PM-Bench）和0.433–0.920准确率（GoodAI）。

**轻量Outcome门控（PM-Bench）**：
- BudgetPM-Static（Logistic）在B40达到0.814 F1，比LambdaMART少3.53次查询，比Ensemble少5.56次。
- 在B60/B80下F1仅差0.002以内。
- **关键效率数字**：保留**99.9–100%**无约束质量，同时减少**42–54%**观测次数。

**严重稀缺场景（B5/B10）**：
- Sequential比最强天然规则Deadline-Outcome高**1.92–2.58 Set F1点**。
- 达到相同Set F1和on-time recall时，Sequential少用**16–33%**观测。
- Sequential超过Myopic（仅本地监督对照）：B5 +0.0183 F1，B10 +0.0085 F1。

**需求-容量边界发现**：
- B5/B10处hindsight-DP优于current-greedy（精确成本下+0.00737/F1 @ B5，+0.00367 @ B10）。
- B15/B20处两者完全一致，时序分配无增益。
- 固定B10下，增加$ k=3 $的潜在触发机会使结构余量从0升至+0.00652 F1，学习增益同步增加。

## 相关工作脉络
1. **前瞻记忆系统（PMA、PIS、TriggerBench）**：决定"何时意图需要关注"，但未在共享预算下分配重复外部检查；BudgetPM聚焦分配问题而非触发决策。
2. **预算感知外部交互（FrugalGPT、RouteLLM、WISERouter、BATS）**：将外部交互受限于成本/工作负载/调用配额；BudgetPM将这一思想连接到存储意图所需的外部状态检查。
3. **序列观测分配（Value-of-Information、Adaptive Submodularity、Bandits with Knapsacks）**：从理论角度分析何时采集状态有价值；BudgetPM通过离线调度蒸馏提供可部署的轻量策略。
4. **记忆增强Agent（Mem0、LongMemEval、MemoryArena）**：关注记忆构造/检索/压缩；BudgetPM关注记忆系统与观测预算之间的接口管理。
5. **意图感知工具规划（INTENT、CostBench、When2Tool）**：研究何时工具调用有价值；BudgetPM将工具调用预算扩展到多意图共享剧集预算的场景。
6. **观测-成本权衡（OSL-MR）**：分配存储/上下文预算；BudgetPM提出观测预算而非存储预算的分配机制。

## 局限性与未来方向
- **预查询特征局限性**：所有27/36特征均为预查询信息，不含当前查询结果和未来的观测值，在极端不确定场景下可能遗漏关键信号。
- **冻结轨迹依赖**：标签构建依赖完整冻结开发轨迹的重播，对于在线部署的新任务可能需重新收集。
- **仅评估两个基准**：PM-Bench和GoodAI LTM均为前瞻记忆场景，其他agent任务类型（如代码生成、多跳推理）下的适用性未验证。
- **单步成本同质化假设**：多数实验假设单位成本，异构成本下的扩展仅在附录中简要讨论。
- **未来方向**：可探索在线自适应预算、跨剧集迁移学习、与反思/自我改进模块的结合。

## 研究启发与可借鉴点
1. **"Outcome vs Due"监督目标的可分离性测试**：通过固定所有组件仅更换监督标签（Matched Due vs Outcome），精准隔离了监督目标的价值，这种设计值得在类似决策学习工作中借鉴。
2. **离线教师→在线轻量策略的蒸馏范式**：Full-episode hindsight-DP作为教师蒸馏为仅依赖预查询信息的Logistic策略，实现了离线计算与在线效率的分离，可迁移到其他需要长期规划的agent模块。
3. **精确成本结构余量诊断法**：通过冻结轨迹上的exact-cost比较分离"当前值排名"和"时序分配"的贡献，为理解模型增益来源提供了可复用的分析框架。
4. **需求-容量边界的实证判定方法**：通过预算扫描+固定预算负载干预双重验证，给出了"何时简单规则足够、何时需要复杂规划"的可操作判据，对agent系统设计有直接指导价值。
5. **零迁移适应的gate部署**：BudgetPM-Static在Llama-3-8B上训练后无需微调或重新校准即可直接用于Qwen系列，展示了轻量分类器在跨模型迁移上的优势。

## 关键术语表
**Prospective Memory（前瞻性记忆）**：Agent记住与未来条件绑定的意图，并在条件满足时执行的能力。

**BudgetPM**：本文提出的框架，将外部状态检查视为需在共享剧集预算下分配的资源。

**Outcome Supervision（结果监督）**：以"某项观测是否改进当前决策"为标签的监督信号，区别于"该意图是否到期"的Due监督。

**Structural Headroom（结构余量）**：在相同精确成本下，hindsight-DP与current-greedy Oracle的 episode 质量差，衡量跨时间分配的潜在提升空间。

**Demand-Capacity Boundary（需求-容量边界）**：当观测容量足以覆盖有用检查时局部门控足够；当现在与未来机会竞争时未来感知调度才增值。

**Hard-Budget Executor（硬预算执行器）**：在预查询阶段基于得分排序选择可行子集，严格保证每步和剧集级预算约束的执行组件。

**Matched Due Label（匹配到期标签）**：标记某资源是否被用于解决当前到期触发，而非其对环境状态评分的因果影响。

# 论文速读：WHEN-TOOLS-SILENTLY-LIE-EVALUATING-AND-MIT-IGATING-BLIND-COM

## 一句话总结
论文提出 ToxicBench 基准，通过固定源数据并静默篡改工具返回观测值（silent tool poisoning），将“证据检查”与“答案采纳”解耦评估；结果表明普通重试在一 Shot 中毒下显著提升恢复率，但显式验证提示并无额外增益，且反复中毒时 Agent 仍会在核查后盲目采纳错误答案。

## 研究问题与动机
1. 工具增强型数据分析 Agent 依赖工具输出做决策，但工具执行成功返回的观测值可能看似合理实则错误（如标签绑定错配、分母错误、过时字典）。
2. 现有基准仅看最终答案对错题，无法区分 Agent 是盲目接受脏证据、尝试核查但未成功，还是核查后获取干净证据并纠正结论。
3. 普通重试（Double-pass）的收益究竟来自“再次尝试机会”还是“显式验证指令”？需在预算与路由数严格对齐的条件下剥离两者影响。
4. 当后续检查本身也可能被污染时，Agent 是否仍会采纳错误答案？需同时度量盲从（BCR）与核查后采纳（VPA）两类隐蔽失败。

## 核心贡献（创新点）
1. **提出 ToxicBench 静默中毒配对基准**：源数据固定不变，仅由代理修改工具返回观测值，构建数值、语义/Schema 与多表三类可追溯任务；与现有工作的本质区别在于不改变底层数据或系统提示，仅针对已执行工具的返回结果进行保接口、保成功状态的篡改。
2. **区分“检查”与“采纳”的双维轨迹指标体系**：定义 TSR、PDR、ADR、VR、RR、PAR、BCR、VPA，首次将“是否发现异常/重新取证”与“最终是否采纳干净答案”分层度量；区别于仅统计最终正确率或额外调用次数的传统评测。
3. **设计预算对齐的多协议对照（Base / Double-pass / Verification-only / Generic Guard）**：在相同模型、温度、步数上限与 Token 上限下隔离“再次执行机会”、“显式验证提示”与“通用期望清单”的独立贡献；与以往直接比较单条路由性能的做法不同，强调证据可得性与提示干预的可分离性。
4. **冻结评分器 + 独立人工审计的三角验证**：在 200 条与开发集任务 ID 完全不相交的轨迹上获得 96% 评分一致率（Precision 1.000, Recall 0.957），公开轨迹、版本化评分与审计记录，使 BCR 与 VPA 现象可复现可核查。

## 方法详解
- **静默中毒机制**：代理先执行 $o = f(x)$，再以 $\tilde{o} = P(f, x, o; \theta)$ 替换返回观测，保持接口类型、成功状态与任务相关性。数值算子包括聚合缩放、符号翻转、排名/标签交换、比率反转、分母交换、过滤遗漏与单位转换；语义/Schema 算子包括标签交换、治疗-对照翻转、列语义交换、过时元数据与偏差检索。源 CSV 哈希全程不变。
- **双路径协议**：
  - *Base*：单一路由普通执行。
  - *Double-pass*：两次独立路由，不传递第一次答案，取第二次回答。
  - *Verification-only*：将第一次答案作为“不可信声明”传入第二路由，要求重新核查源数据，取第二次回答。
  - *Generic Guard*：两路由均附加通用检查清单提示（值域、单位、分母、实体-值绑定、列含义、时间戳、来源支持），强制新工具调用并字面提取标签，始终取第二路由输出。
- **轨迹度量**：ADR（显式识别冲突/异常/过期来源）；VR（中毒后产生新且任务相关的工具观测事件）；RR（ADR/VR 后最终答案与干净参考一致）；PAR（最终答案匹配中毒参考）；BCR（PAR 且无 ADR 或 VR）；VPA（PAR 且含 VR）。行为率以实际暴露运行数为分母，TSR 以全部保留运行为分母。
- **反复中毒**：对每条候选返回以概率 $p \in \{0.25, 0.5, 0.75, 1.0\}$ 独立注入，检验后续检查是否同样被污染。

## 实验与结果
- **设置**：118 个保留任务（58 数值 + 60 语义/Schema），跨 GPT、Claude、Qwen 与 LangGraph ReAct、smolagents、AutoGen；另在 Palmer Penguins、Auto MPG、Bike Sharing 三个公开表上验证 24 个结构化控制任务。
- **主要数字**：
  - 清洁 TSR 0.92–0.99，中毒后下降 26–39 个百分点；GPT 全适配器中毒 TSR 降至 0.59–0.67，BCR 达 0.27–0.53。
  - 一 Shot 中毒下 Double-pass 将 Claude Haiku 的中毒 TSR 从 0.89 提升至 1.00（差值 +0.110，模板聚类 95% CI [0.056, 0.171]）；三类双路由 BCR 均归零，但 Verification-only 仍保留非零 PAR/VPA。
  - 显式验证对比：Guard 相对 Double-pass 中毒 TSR 差值 −0.025（CI [-0.054, 0.000]），统计上不显著，说明普通重试收益主要来自“获取后续干净观测的机会”。
  - 反复中毒（$p=1$）1,572 条轨迹中出现 101 例 VPA，其中 78 例仅依赖被污染的后续检查，23 例含未修改检查但仍采纳错误答案。
  - 公开表结构化控制：固定第一阶全目标中毒转录后，二阶段重试/复核在获得干净证据时正确率 48/48 与 47/48，全目标中毒证据下两者均为 0/48，证明恢复能力高度依赖“可供的检查证据”。
  - 200 条冻结轨迹人工校验：TSR 一致率 96%（Precision 1.000, Recall 0.957），VR Recall 0.953，全部 4 例 VPA 被识别。
- **最强结果**：Double-pass 在一 Shot 中毒下达到 1.00 TSR 且 BCR=0；人工与自动评分一致率 96%。

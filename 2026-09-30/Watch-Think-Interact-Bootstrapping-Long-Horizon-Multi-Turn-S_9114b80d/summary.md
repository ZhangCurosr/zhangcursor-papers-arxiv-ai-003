# 论文速读：Watch-Think-Interact: Bootstrapping Long-Horizon Multi-Turn Streaming Video Reasoning with Reinforcement Learning

## 一句话总结
该论文提出 Watch-Think-Interact (WTI) 框架，通过紧凑的时间索引记忆与选择性视觉召回，解决流式视频多轮推理中远期相关信息被前向压缩不可逆丢失的问题，在 StreamingBench 和 OVO-Bench 上刷新了开源模型的最优记录。

## 研究问题与动机
*   **核心问题**：在多轮流式视频推理中，针对异步到达的问题，模型需要在有限的在线状态下（仅能观察已流入的视频片段）回答。然而，后续问题可能依赖于已被前向压缩丢弃的、过去观察到的视觉细节，这些细节一旦丢失便无法恢复。
*   **现有方法不足**：
    1.  **前向压缩不可逆**：现有流式视频大模型对早期观察片段的压缩是单向的，当相关问题在后继轮次出现时，已压缩状态中丢失的细粒度证据无法被恢复。
    2.  **潜在表示不透明**：不透明的潜在摘要（如压缩的KV状态或文本记忆）无法让模型知晓保留了什么信息以及这些信息在时间流中的具体位置。
    3.  **重放成本高**：对于长视频流，重新播放整个历史序列代价高昂。WTI旨在提供对源视频的按需访问能力，避免完整的重放。

## 核心贡献（创新点）
*   **闭环流式推理框架**：提出了一个整合了主动窗口感知、紧凑时间索引记忆、响应时序决策和选择性源视频召回的闭环框架。**与已有工作的本质区别在于**，其他工作多依赖对历史的前向压缩摘要，而本文通过时间索引记忆关联源视频时间段，支持后续的直接推理和选择性视觉回溯。
*   **WTI-82K 轨迹数据集**：构建了包含 82,335 个带时间戳问题、4,812 条因果对齐轨迹的数据集，涵盖了实时、回溯追溯和前向等待等多种交互模式。**与已有数据集的本质区别在于**，它并非孤立的问答对，而是按查询时间、可答时刻、证据、状态更新和交互动作因果对齐的多轮流式轨迹，覆盖了从当前窗口到超长历史的推理需求。
*   **Stream-GDPO 轨迹级强化学习**：开发了 Stream-GDPO，将 GDPO 扩展到针对完整多轮展开轨迹的轨迹级优化。**与已有方法的本质区别在于**，它不仅优化最终答案，还对回忆动作、记忆更新以及不同阶段奖励进行分别归一化后聚合，使训练目标与流式决策（早期动作影响后期状态）的因果特性对齐。
*   **开源 SOTA 性能**：在 StreamingBench (83.3%) 和 OVO-Bench (73.6%) 上建立了新的开源模型最强记录，并在多种评测类型（实时、回溯、前向）上领先。

## 方法详解
*   **在线多轮流式视频推理定义**：视频以连续数据块流的形式到达 $V = (c_1, ..., c_T)$。在时刻 $t$，只能观察前缀 $c_{\le t}$。多个问题以不同时间 $\tau_r$ 到达，模型需在 $\hat{t}_r \ge \tau_r$ 时输出答案 $\hat{y}$，且答案必须基于已观察到的内容。
*   **Watch-Think-Interact 框架**：
    *   **状态**：模型可见状态为 $s_{t,k} = (W_t, M_t, Q_t, H_t, E_{t,k}^{rec})$，包括活跃的视觉窗口 $W_t$（固定大小，如最近8个chunk）、紧凑的文本记忆 $M_t$、当前活跃问题集 $Q_t$、交互历史 $H_t$ 和召回证据 $E_{t,k}^{rec}$。
    *   **动作空间**：模型在每个assistant子回合执行一个动作：`silence`（沉默，等待后续证据）、`response(q_r, y)`（回答问题）、`recall(\tau_s, \tau_e)`（召回指定时间区间 [τ_s, τ_e] 的源视频证据）。
    *   **记忆管理**：在控制器触发边界，使用紧凑函数将模型生成的记录 $Z_b$ 与旧记忆 $M_{pre}$ 合并，生成紧凑记忆 $M_{post}$。每条记忆条目包含语义摘要和源时间范围。
    *   **推理循环**：`recall` 是非终止动作，召回后视觉证据被加入状态，策略在同一时间步重新进行 `think` 和决策，形成“动作-反馈-重决策”循环。
*   **Masked Supervised Fine-Tuning**：
    *   在训练时限制模型只能看到近期的视觉窗口 $W_t$，并通过流式因果掩码和标签掩码，使模型适应推理时的受限上下文和交互协议。
    *   损失函数对动作目标（silence, response, recall）和状态更新目标（thinking, memory）分别加权平均后求和。
*   **Stream-GDPO 强化学习**：
    *   **奖励信号**：包含四个组件：问题级结果奖励 $R_{out}$（答案是否正确）、格式奖励 $R_{fmt}$（动作语法是否合法）、回忆工具奖励 $R_{tool}$（仅在教师轨迹涉及回忆且模型正确使用时给予奖励）、轨迹级记忆质量奖励 $R_{mem}$（评估时间索引的改善和重要事实的保持）。
    *   **优势计算**：在采样组内对每个奖励分量进行归一化（减去均值除以标准差），加权求和得到轨迹级优势 $A_i$，用于优化整个多轮展开轨迹。
    *   **策略优化**：使用带裁剪的 PPO 类目标函数进行优化，KL散度惩罚保持策略不偏离参考模型过远。

## 实验与结果
*   **数据集与基线**：
    *   **数据集**：自建的 WTI-82K；评测基准为 OVO-Bench 和 StreamingBench。
    *   **基线**：包括专有模型（GPT-4o, Gemini-1.5-Pro）、开源离线模型（LLaVA系列, Qwen2.5-VL, MiniCPM-o等）和开源流式模型（StreamForest-7B, StreamBridge-7B, VST-7B等）。
*   **主要结果**：
    *   **OVO-Bench**：WTI-8B 取得 **73.6%** 加权总体准确率，远超次优开源流式模型 StreamBridge-7B (62.6%) 和 ViSpeak-7B (61.1%)。在 Real-Time (76.9%), Backward (73.4%), Forward (70.0%) 三个子组上均领先。
    *   **StreamingBench**：WTI-8B 达到 **83.3%** 平均分，领先次优 VST-7B (79.5%)。在 OP, CS, ATP, EU, TR, SU, ACP 等多个类别上取得提升。
    *   **离线长视频能力**：在 Video-MME (66.9%), MLVU (69.9%), LongVideoBench (62.9%) 上保持了强劲的离线长视频理解能力，部分指标接近或优于其他流式模型。
*   **消融实验结论**：
    *   Masked SFT 初始化协议有效提升了 Real-Time 性能，但在 Backward 和 Forward 推理上仍有明显不足，凸显了轨迹级强化学习的必要性。
    *   Compact Memory 和 Source-Video Recall 是互补而非可替代的组件。移除任一一都会显著降低 Backward 推理和离线长视频性能。
    *   Stream-GDPO 相比基线 GSPO 在回忆触发率、回忆后准确率和记忆质量上均有更好表现，并带来了更大的性能提升。

## 相关工作脉络
*   **流式视频理解**：早期工作（如 VideoLLM-online, Streamo）关注基于观察前缀的响应状态建模。本文区别于它们的地方在于显式地解决了**后期问题对早期已被丢弃视觉证据的依赖**问题，通过选择性召回弥补了这一缺陷。
*   **长流式记忆**：相关方法（如 LongVU, StreamForest, StreamBridge）使用视觉token压缩、KV状态管理或事件记忆来保持流式上下文。本文与之的本质差异是，这些方法多为**前向压缩且信息不可逆丢失**，而 WTI 的记忆是**时间索引化的，并与源视频片段链接**，支持按需回溯。
*   **智能体多模态推理**：一些工作利用工具或额外视觉检查来获取证据，或设计可回顾的记忆智能体。本文的贡献是将**感知（窗口+记忆）与行动（回忆、回答、等待）整合到一个统一的、专为流式视频设计的闭环推理框架**中，并通过轨迹级 RL 进行优化。
*   **流式视频基准**：OVO-Bench 和 StreamingBench 定义了流式视频理解的评测标准。本文的贡献在于提出了能真正应对这些基准中长程、多轮、异步交互挑战的方法，并在这些基准上取得了最优的开源模型成绩。

## 局限性与未来方向
*   **数据规模与多样性**：WTI-82K 数据集规模（82K问题，4812条轨迹）相对于大规模预训练数据仍显有限，可能限制了模型在某些边缘场景或长尾领域的泛化能力。未来可探索更多样化的视频来源和更复杂的交互场景。
*   **记忆压缩的保真度**：当前记忆压缩依赖于 LLM 的文本生成能力，可能在极度复杂或需要高度精确视觉细节的场景下丢失关键信息。未来可研究更鲁棒的记忆表示或更精细的检索机制。
*   **推理延迟与开销**：选择性召回虽然避免了全量重放，但仍需额外处理召回的视觉片段并进行状态更新，这在实时性要求极高的场景下可能引入延迟。未来可优化召回策略和计算效率。
*   **泛化至其他流式模态**：目前方法主要针对视频流，未来可探索将其核心思想（紧凑记忆+选择性源数据召回）应用于音频流、多模态流等其他在线推理场景。

## 研究启发与可借鉴点
*   **紧凑记忆与源数据链接**：将压缩的文本/状态记忆与源数据（如视频片段）的时间戳或索引关联，为后续可能的选择性回溯提供锚点。这一设计思路可迁移至任何需要长期上下文但计算资源受限的流式或多轮交互任务。
*   **轨迹级多奖励 RL 优化**：Stream-GDPO 对过程信号（回忆、记忆更新）和结果信号进行分别归一化后聚合的优势计算，能更精细地引导模型学习复杂的多步骤交互策略。该方法可借鉴用于训练需要多步规划、工具调用或环境交互的智能体。
*   **模拟推理环境的训练与测试一致性**：WTI 在 Masked SFT 和 Stream-GDPO 训练中使用的数据分块、记忆预算、召回工具和动作语法，与推理时完全一致。这种**训练-评估环境对齐**的策略有助于更真实地反映模型能力，并减少分布偏移，对构建流式或在线系统具有重要参考价值。
*   **动作空间设计**：将模型的输出动作明确划分为“沉默（等待）”、“回答”和“召回（获取更多信息）”，并将决策过程显式建模。这种将控制流与推理流结合的设计，可以有效提升模型在信息不完全场景下的策略鲁棒性。

## 关键术语表
*   **Watch-Think-Interact (WTI)**：论文提出的闭环流式视频推理框架，包含主动感知窗口、紧凑时间索引记忆、以及“等待/回答/召回”决策循环。
*   **Streaming Video Reasoning**：在多轮异步提问的流式视频场景中，仅基于已观察到的视频前缀和演化中的交互状态进行推理和回答的任务。
*   **Time-indexed Memory**：WTI 中使用的紧凑文本记忆，每条记录不仅包含语义摘要，还关联源视频的时间范围，以便后续定位和召回。
*   **Selective Visual Recall**：WTI 的核心机制之一，允许模型在不推进视频流的情况下，请求并获取特定过去时间区间的原始视觉证据，以补充当前压缩状态的不足。
*   **Masked SFT**：在流式视频推理的因果约束下（仅能看到近期窗口）进行的监督微调，用于初始化模型的交互协议。
*   **Stream-GDPO**：一种针对完整多轮流式轨迹的强化学习算法，通过对结果、格式、回忆和记忆四类奖励分别归一化后聚合优势，优化轨迹级性能。
*   **OVO-Bench**：一个评估视频语言模型在线视频理解能力的基准，包含实时、回溯和前瞻等多种交互模式的子任务。
*   **Active Visual Window**：在推理时模型直接处理的、固定大小的近期视频片段窗口，超过此窗口的信息需通过记忆或召回机制间接访问。

## 可复现要素
*   **数据集**：WTI-82K 据论文描述为构建的方法，**论文未明确声明是否开源**。评测基准 OVO-Bench 和 StreamingBench 通常为公开数据集。
*   **代码/权重**：论文声称 WTI 设定了新的开源 SOTA，但**未明确提供代码和权重的开源链接**（如 GitHub、Hugging Face 等）。通常此类工作会在会议投稿或作者主页公布。
*   **关键超参**：
    *   视觉窗口大小 $K_v = 8$ 个 chunk (16帧)。
    *   每次召回最多返回 $K_r = 4$ 个 chunk。
    *   SFT 学习率：$1 \times 10^{-5}$。
    *   RL 参数：prompt batch size 64, 每 prompt 4 rollouts, actor 学习率 $1 \times 10^{-5}$, 非对称裁剪 $\epsilon_{low}=0.2, \epsilon_{high}=0.28$, 动作分支损失权重 0.15。
    *   训练硬件：8 张 H20 GPU。
    *   基础模型：Qwen3-VL-8B-Instruct。

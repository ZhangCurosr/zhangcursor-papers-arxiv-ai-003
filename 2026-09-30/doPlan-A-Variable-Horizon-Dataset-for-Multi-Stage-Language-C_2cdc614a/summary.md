# 论文速读：doPlan: A Variable-Horizon Dataset for Multi-Stage Language-Conditioned Planning in Autonomous Driving

## 一句话总结
本文引入了**doPlan**——首个面向自动驾驶中乘客自然语言指令的公开数据集，基于nuPlan构建，包含5,154条覆盖可变时间跨度（30–508.8秒）的乘客指令。通过评估四个语言条件驾驶模型，揭示当前模型对指令的敏感性不等于方向遵从性，且多数指令对应的机动行为远超现有5秒预测窗口的时域范围。

## 研究问题与动机
- 现有语言条件驾驶数据集（如doScenes）主要聚焦短时、局部化交互（固定12秒片段），未充分探索乘客意图随时间演进、跨多阶段、依赖未来事件的长时程场景。
- 乘客指令（如"经过施工区后变道去下一个出口"）具有持续性任务上下文属性，当前模型缺乏对未解决意图的保持能力与阶段性追踪机制。
- 已有语言驱动驾驶模型（如OpenEMMA、AutoVLA等）是否在长时程指令下真正实现方向遵从、而非仅产生轨迹扰动，尚缺乏系统诊断。
- 现有评估基准以轨迹对齐误差（ADE）为主，无法区分"对语言敏感"与"按指令方向执行"的本质差异，需要引入时间对齐与方向一致性等新评估维度。

## 核心贡献（创新点）
1. **首个面向长时程、多阶段乘客指令的公开数据集**：doPlan基于nuPlan构建，提供5,154条自由格式指令，覆盖169.1小时累计指令对齐上下文与50.9小时独特驾驶片段，时间跨度为30.0–508.8秒，填补了短视数据集（如doScenes固定12秒）的空白。
2. **引入变量时间窗口的乘客导向标注协议（taxi-test）**：延续doScenes的"乘客视角"标注范式，但允许多句、多步骤指令，并区分即时、延迟、事件条件化、持久性意图等类型，支持更复杂的语言结构建模。
3. **提出面向语言条件驾驶的时序诊断评测框架**：不仅测量轨迹对齐误差（ADE），还引入"轨迹分离度"（trajectory separation）与"方向遵从率"（directional compliance）指标，以及"未来机动时间分布"分析，揭示模型对语言响应的真实语义对齐能力。
4. **系统性基准评估揭示三大模型缺陷**：语言敏感度提升并不保证方向一致性；仅9.8%的匹配机动发生在5秒预测窗口内；多数模型（除AutoVLA外）在长时指令下方向响应微弱，表明当前端到端架构缺乏持久意图保持与时序规划能力。

## 方法详解
- **数据集来源与标注接口**：基于nuPlan训练集（连续真实驾驶日志），通过自定义标注界面提供8路同步摄像头视角（前/侧/后向）及航向对齐地图，辅助标注员理解完整驾驶上下文。
- **片段采样策略**：对长度为T的连续序列，采样窗口时长 $L \sim \mathrm{Uniform}(30, T)$ 秒，起始时间 $S \sim \mathrm{Uniform}(0, T-L)$，确保上下文覆盖从短机动到长段驾驶的多样性，且允许片段重叠以获取独立标注。
- **标注协议（taxi-test）**：标注员（19名持照司机）基于"想象你是这辆出租车的乘客，你会对司机说什么指令来产生视频中的行为？"生成自由格式指令；标注无需固定模板，涵盖单句、多句、多步骤指令，以及对无合理指令场景的"无指令提交"。
- **参考标签体系**：每条指令标注环境参照类型（静态物体、动态智能体、两者兼具、无参照等），其中静态参照占53.34%，两者兼具占18.51%，体现长时指令对场景上下文的高度依赖。
- **模型评估设置**：在4,315条指令子集上零样本评估OpenEMMA、AutoVLA、Alpamayo 1.5与Alpamayo 2.0；所有模型使用相同传感器观测，仅改变语言输入，以固定5秒共同预测窗口度量ADE。
- **导航引导权重消融**：针对Alpamayo 2.0，在推理时调节导航引导权重 $w \in [1.0, 4.0]$，衡量语言敏感度变化；定义轨迹分离度 $S = \frac{1}{10}\sum_{k=1}^{10} \|\hat{p}^{\mathrm{orig}}(t_k) - \hat{p}^{\mathrm{cf}}(t_k)\|_2$ 量化原指令与反事实指令的差异幅度。
- **方向遵从评估**：选取含单一左/右转请求的851条指令，识别记录轨迹中匹配转向起点，仅当转向在5秒窗口内时评估方向遵从率（预测终点偏离≥1米至请求侧）；定义方向响应 $R_i = d_i(\theta_i^{\mathrm{orig}} - \theta_i^{\mathrm{rev}})$，并按至转向的时间分组分析。
- **时序验证实验**：利用CLIP构建视频-指令匹配器，验证扩展时间窗是否包含指令相关额外信息；以R@1/R@5/R@10衡量检索性能，并对比纯时长、纯文本、冻结CLIP等基线。

## 实验与结果
- **数据集规模**：6,549条提交，其中5,154条含有效乘客指令，1,395条为无指令提交；来自988个nuPlan原始片段，覆盖169.1小时累积上下文与50.9小时独特驾驶。
- **指令结构随时间增长**：最短窗口组（30–45.2秒）平均9.8词、24.2%多句、28.8%多步；最长窗口组（169.8–508.8秒）增至27.8词、52.3%多句、62.6%多步。
- **参考标签分布**：静态参照53.34%，动态参照12.20%，两者兼具18.51%，无参照15.17%。
- **时序验证**：CLIP匹配器R@1从5秒窗口的13.9%提升至完整窗口23.1%，R@10从52.2%升至68.6%，远超时长/文本/冻结CLIP基线（2.7%/1.3%/3.5%）。
- **轨迹对齐（ADE）**：正确指令相比无指令基线，OpenEMMA改善1.1%，AutoVLA恶化4.5%，Alpamayo 1.5恶化6.1%，Alpamayo 2.0恶化26.4%；正确指令与无关/反事实指令的ADE差异极小，说明模型未能可靠区分语义匹配指令。
- **导航引导消融**：Alpamayo 2.0轨迹分离度S从w=1.0时的0.219m单调增至w=4.0时的0.679m，表明语言敏感度可调。
- **方向遵从**：在默认引导权重w=3.0下，方向遵从率仅提升1.3个百分点（49.3% vs 48.0%）；反事实方向一致性在任何预测中均未观察到。
- **未来机动时序错位**：2,161条含有效匹配的指令中，对应机动事件距评估点中位数为24.6秒，仅9.8%落在5秒预测窗口内。
- **方向响应与时距关系**：AutoVLA在时距≤5秒时方向响应最强（+0.818），且即使在>60秒时仍保持正响应；其他三个模型响应微弱或噪声级。

## 相关工作脉络
- **doScenes (Roy et al., 2025)**：首个基于nuScenes的短视（12秒固定窗口）乘客指令数据集，采用taxi-test标注，本文在其基础上扩展至nuPlan长时连续上下文。
- **OpenEMMA / AutoVLA / Alpamayo系列**：当前主流端到端语言条件驾驶模型，本文作为zero-shot基准，揭示其在长时指令下的方向遵从缺陷。
- **HAD (Kim et al., 2019)**：30小时驾驶视频配自然语言建议，侧重短程场景指导，本文强调多阶段、事件条件化的持久意图。
- **Talk2Nav (Vasudevan et al., 2020)**：远距离导航长程指令，本文借鉴其"指令随进展逐步激活"思想，但聚焦驾驶场景中的多阶段机动。
- **Lang2LTL (Liu et al., 2023)**：将自然语言指令归约为线性时序逻辑，本文采用自由格式指令保留语言灵活性，但挑战在于何时激活。
- **Covla / Simlingo / Vega等近期语言条件驾驶数据集**：多聚焦闭环仿真或固定场景，本文首次在真实nuPlan日志上实现可变时间跨度标注与多模型诊断评测。

## 局限性与未来方向
- 未对保留指令进行第二轮人工复核，标注风格存在主观差异，但设计上不假设唯一地面真值。
- 标注员可回放完整片段，导致部分参照信息在评估时间点不可见（依赖路线记忆或背景知识），未标注指令实际说出时刻。
- 时序报告基于评估时间窗口起点，非指令发出时刻，时延解释受限。
- 模型评估仅限于四个端到端架构，未涉及显式分层规划或持久意图保持方法。
- 未来方向包括：持久意图建模、事件条件化执行、多阶段进度追踪、反事实指令诊断协议扩展、以及跨越车辆—行人非语言交互的研究。

## 研究启发与可借鉴点
- **可复用的诊断协议**：轨迹分离度（S）与方向响应（R）指标可有效区分"语言敏感性"与"语义遵从性"，建议纳入后续语言条件驾驶评测体系。
- **时序对齐评测设计**：将评估点与未来机动时距分组分析，可揭示模型在"准备期"与"执行期"的不同响应模式，适用于长时规划诊断。
- **可变时间窗口采样策略**：$L \sim \mathrm{Uniform}(30, T)$ 的采样方式兼顾场景多样性与标注可行性，可迁移至其他长时程驾驶数据集构建。
- **多阶段指令结构标注体系**：静态/动态参照标签、多句/多步分类、无指令提交类别可作为复杂指令标注的通用模板。
- **团队可结合的创新机会**：将持久意图保持（persistent intent retention）与阶段性目标激活机制引入现有规划架构，或开发"指令生命周期管理"模块（待处理/激活/完成/失效），弥补当前端到端模型在长时指令下的语义对齐缺陷。

## 关键术语表
- **doPlan**：首个面向自动驾驶长时程、多阶段乘客语言指令的公开数据集，基于nuPlan构建，含5,154条自由格式标注。
- **taxi-test**：乘客导向标注协议，要求标注员以"你会对出租车司机说什么指令来产生视频中的行为"生成指令，而非描述场景。
- **轨迹分离度（Trajectory Separation, S）**：原指令与反事实指令预测轨迹的欧氏距离均值，量化语言变化对轨迹的影响幅度。
- **方向响应（Directional Response, R）**：原指令与反向指令预测航向差的加权量，正值表示预测向请求方向偏移。
- **持久任务上下文（Persistent Task Context）**：乘客指令作为持续存在的任务约束，其相关性随驾驶情境演化而动态变化，非一次性扰动。
- **事件条件化执行（Event-Conditioned Execution）**：指令中部分动作依赖未来特定事件（如"经过施工区后变道"），需识别条件满足时刻再执行。
- **多阶段意图（Multi-Stage Intent）**：单一指令包含多个有序行为阶段，不同阶段在不同时间生效，需时序分解与追踪。
- **CLIP视频-指令匹配器**：基于CLIP提取视觉与文本特征，用于验证扩展时间窗是否包含指令相关额外信息的检索验证工具。

## 可复现要素
- **数据集**：doPlan，公开可访问于 https://github.com/Mi3-Lab/doPlan；基于nuPlan训练集构建，需nuPlan访问权限。
- **代码**：数据集标注接口与资源公开，模型评测脚本未明确声明开源。
- **权重**：评估使用的模型（OpenEMMA、AutoVLA、Alpamayo 1.5/2.0）均为公开开源模型。
- **关键超参**：Alpamayo 2.0导航引导权重默认w=3.0，评估时测试w∈[1.0, 4.0]；预测窗口统一为5秒（10个0.5秒间隔）；CLIP匹配器未在论文中给出具体实现细节。

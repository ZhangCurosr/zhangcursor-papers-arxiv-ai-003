# 论文速读：PRETEXT-Defeating-Malicious-Skill-Detection-Frameworks-for-A

## 一句话总结
本文提出PRETEXT，一种针对AI Agent技能检测框架的白盒迭代攻击方法，通过跨代持久记忆与反思机制将攻击载荷隐入自然语言并跨文件拆分，成功绕过NVIDIA SkillSpector的“静态规则+LLM语义判定”双阶段架构，在固定与自适应防御场景下分别达到最高96.7%和77%的攻击成功率。

## 研究问题与动机
- 第三方技能市场（如OpenClaw、Claude Code生态）分发大量技能，但其中存在经刻意隐藏的恶意技能，可劫持Agent执行不可逆破坏操作。
- 现有防御（以SkillSpector为代表）采用确定性静态检查与LLM语义判定结合的双阶段架构，但未评估其对知情攻击者的鲁棒性。
- 静态规则层对代码特征敏感，但将恶意逻辑转为自然语言描述、并将完整攻击链拆分至多文件可使静态层失效，同时单文件语义评分可被控制在阻断阈值以下。
- 既有自动化攻击工作多为单轮重写或缺乏跨次运行的知识沉淀，且未针对具备自适应演进能力的防御方进行对抗验证。

## 核心贡献（创新点）
1. 提出PRETEXT白盒迭代攻击框架，通过持久化记忆与跨代反思持续优化技能结构以规避双阶段检测；与Skillject等单轮重写工作相比，本文首次实现攻击策略的跨代累积与自收敛演进。
2. 构建固定检测器（Mode A）与自适应协同演化检测器（Mode B）两种对抗场景，首次验证具备 learns-from-false-negatives 能力的防御方同样无法完全阻断攻击；与纯静态/黑盒评测相比，本文揭示了防御方自适应往往以高误报率换取微弱安全增益。
3. 设计恶意-良性配对驱动的GAN式演化评估协议，要求检测器区分恶意意图而非表面主题，并引入Self-convergence、Plasticity、Coverage等多维学习动态指标；与仅报告ASR的基线工作相比，本文提供了可量化的安全-效用权衡分析框架。

## 方法详解
- **两方博弈与四角色架构**：PRETEXT包含攻击者（Attacker）、检测器（SkillSpector）、受害者Agent（Victim）与裁决者（Verdict Judge）。每轮扫描后若被拦截，攻击者依据触发规则迭代；若绕过检测但载荷未送达，则依据Victim输出与Judge裁决反馈重新设计。
- **规避双阶段检测的核心策略**：SkillSpector包含64条确定性规则（正则/AST/YARA/MCP等）与三层LLM语义分析器（SSD/SDI/SQP）。攻击者将代码级恶意模式替换为自然语言指令（如用“set shell to True”替代`shell=True`），并利用检测器“逐文件独立判定”的架构缺陷，将完整攻击链拆分至多个文件，使单文件评分低于阻断阈值（score < 20）。
- **跨代持久记忆与反思（Reflection）**：攻击者维护双层记忆（全局+按攻击类型分块），每lesson带置信度标记（`[hypothesis]`/`[confirmed×N]`/`[conflict]`）。每代开始时读取只读快照并行执行N次运行，结束后由独立Reflector汇总记录，合并相似假设、修正矛盾结论并删除失效策略，从而控制上下文长度并实现稳定学习。
- **协同演化防御（Mode B）**：在SkillSpector基础上新增LLM启发式层，从历史漏报中蒸馏通用规则、从误报中收窄规则；每代强制将恶意技能与同领域良性技能配对，迫使检测器学习区分意图与主题。攻击者对启发式层保持黑盒，仅能观察到规则触发结果。

## 实验与结果
- **目标与设置**：目标检测器为开源SkillSpector v2.2.3；涵盖12种Trojan攻击类型；模型栈使用glm-5.1、qwen3-235b-a22b-thinking、gpt-oss-120b；Mode A运行10代，Mode B运行6代，每配置独立重复5次，每代12次并行运行。
- **Mode A（固定检测器）**：PRETEXT对qwen3t达96.7% ASR（自收敛0.98，塑性0.09），对glm-5.1达63.2%，对gpt-oss达70.5%；静态规则层单独仅拦截5.6%的最终生成技能，验证静态层并非检测瓶颈。
- **Mode B（自适应检测器）**：整体ASR降至约77%（gpt-oss informed最高），趋势随代数下降；但gpt-oss检测器误报率高达62%，覆盖度仅0.33，表明降低ASR以高误报为代价会严重损害Agent正常效用。
- **学习动态**：qwen3t目标易攻，攻击者早期即收敛；glm目标较难，攻击者保持探索；检测器对(glm/qwen3t)能逐步收窄启发式，但对(gpt-oss)停留在宽泛规则层面，呈现“钝刀式”压制。

## 相关工作脉络
- **Skillject / Skillharm / Skillattack**：同类自动化技能生成或红队攻击，但多为单轮重写或无跨代知识沉淀；本文PRETEXT通过持久记忆实现持续进化，且首次针对自适应防御。
- **ToxicSkills与SkillSpector评测**：指出市场技能中存在大量显式/隐式恶意代码，但防御仍依赖人工规则与固定LLM提示；本文证明此类“静态+固定LLM”架构在知情攻击者面前本质不安全。
- **Skilltrojan与潜伏后门研究**：侧重加密载荷或触发器机制；本文核心差异在于利用检测器逐文件语义判定的结构性弱点，将载荷自然语言化而非加密隐藏。
- **供应链投毒与依赖混淆攻击**：聚焦包管理器层面的污染；本文针对SkillSpector的规则语义层进行对抗，揭示了更通用的提示词与文件布局漏洞。
- **LLM安全对齐局限性研究**（如Defensive Refusal Bias）：印证了即使采用强安全对齐模型（如gpt-oss）也无法根除攻击，仅提高门槛并带来更高误报与效用下降。

## 局限性与未来方向
- 未在与SkillSpector架构类似的商业闭源检测器上验证迁移性，仅推测可复用。
- 攻击前提为白盒获取全部规则与提示词，实际黑盒场景下效果未知。
- 自适应防御的误报率过高，表明当前“提高检测阈值”路径在实际部署中不可行。
- 未来需探索运行时沙箱隔离、细粒度工具调用授权与多阶段交叉验证等纵深防御机制，以在不牺牲Agent效用前提下提升安全性。

## 研究启发与可借鉴点
1. **跨代记忆与反思机制**：将迭代优化中的成功/失败案例抽象为带置信度的可复用lesson，并通过独立Reflector定期清洗，可有效控制上下文长度并提升后续迭代效率，适用于其他对抗生成与红队任务。
2. **利用检测器架构的结构性弱点**：针对“逐文件独立判定”的设计，采用自然语言重写代码意图+跨文件拆分载荷的策略具有高度可迁移性，可应用于其他多模块代码/文档审计系统。
3. **恶意-良性配对驱动的对抗评估**：强制配对同领域良性样本以抑制检测器“一刀切”倾向，该设计可为红队测试提供控制变量基准，避免误报虚高掩盖真实安全增益。
4. **安全-效用权衡的可量化评估**：引入False Positive Rate、Coverage、Time-to-Counter与Plasticity等多维指标，突破了单一ASR报告的局限，为防御方案评估提供了更全面的基准框架。

## 关键术语表
- **Skill**：AI Agent可调用的外部功能模块，通常以Markdown清单与脚本组合形式分发，用于扩展Agent能力。
- **SkillSpector**：NVIDIA开源的技能安全扫描器，采用“确定性静态规则（64条）+ 三层LLM语义分析”双阶段架构输出风险评分。
- **PRETEXT**：本文提出的白盒迭代攻击框架，通过记忆沉淀与跨代反思持续生成能绕过双阶段检测的恶意技能。
- **ASR（Attack Success Rate）**：攻击成功率，定义为成功绕过检测、送达恶意载荷并完成伪装良性任务的运行占比。
- **Mode A / Mode B**：Mode A为固定检测器对抗场景；Mode B为攻击者与检测器协同演化的GAN式对抗场景。
- **Self-convergence**：衡量攻击者记忆跨代稳定性的指标，通过余弦相似度评估不同代际的lesson集合是否趋于固化。
- **Plasticity**：衡量

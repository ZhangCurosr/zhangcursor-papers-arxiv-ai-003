# 论文速读：Risk-Aware-Adaptive-Evaluation-Finding-High-Impact-Failures

## 一句话总结
本文将交互式 LLM Agent 的可靠性评估建模为预算受限的序列资源分配问题，提出一种风险感知的上下文 Thompson Sampling 策略，通过结合场景静态先验特征与动态观测结果优化试次分配；在仅使用 6% 试次（50 次）时即可恢复 oracle 86.1% 的“影响力加权失败”发现量，较均匀采样提升约 3.5 倍发现效率与 5 倍每美元收益。

## 研究问题与动机
- **核心问题**：交互式 Agent 行为具有随机性，单次运行无法反映可靠性，必须在多次重复试次上评估；但现有基准测试（如 $\tau$-bench）采用固定的均匀试次调度，未考虑不同场景的失败概率差异与失败后果的严重性差异。
- **现有方法不足 1（浪费预算）**：均匀/随机采样将读查询类场景与不可逆支付类场景等同对待，大量试次被消耗在永不失败或低影响力场景上（本文 corpus 中 34.3% 的场景从未失败）。
- **现有方法不足 2（忽略评估者决策）**：已有 Agent 效率优化工作主要聚焦于 agent 自身的计算图剪枝、多 agent 路由或通信压缩，而非 evaluator 的试次分配策略；评测 schedule 本身从未被视为可优化变量。
- **动机**：在模型/提示/策略迭代频繁的小预算重评测场景下，急需一种能自动将有限预算集中在“高后果 × 高失败可能”场景的自适应分配方法，以提升安全性验证的效率与成本效益。

## 核心贡献（创新点）
1. **问题形式化创新**：首次将交互式 Agent 评估建模为风险感知的序列资源分配问题，明确分离静态先验量（上下文向量 $\mathbf{x}_i$、影响力得分 $I_i$）与随机观测值（失败指标 $F_{i,t}$、资源向量 $\mathbf{R}_{i,t}$）。**本质区别**：不同于现有工作仅优化 agent 单次执行开销或依赖固定均匀 schedule，本文把“评测预算分配策略本身”作为核心设计变量，目标函数定义为影响力加权失败的累计发现量。
2. **算法设计创新**：提出风险感知上下文 Thompson Sampling 策略，通过逻辑回归人口级先验与 Beta 后验的伪计数融合实现冷启动引导与在线自适应。**本质区别**：区别于标准多臂老虎机或静态启发式，该方法显式利用 pre-execution 特征 $\mathbf{x}_i$ 填补观测稀疏期的信息真空，并在证据累积后由后验自然衰减探索，避免人工调节采样比例。
3. **机制归因与检验创新**：构建固定 seed 配对回放协议并结合 Holm 校正配对检验，定量拆解上下文先验与后验探索各自生效的预算区间。**本质区别**：以往研究多仅报告整体性能增益，本文进一步证明上下文优势集中于小预算（$B \leq 100$），而后验探索优势主导中预算（$B=300\text{-}500$），为策略选型提供明确的适用边界而非笼统结论。

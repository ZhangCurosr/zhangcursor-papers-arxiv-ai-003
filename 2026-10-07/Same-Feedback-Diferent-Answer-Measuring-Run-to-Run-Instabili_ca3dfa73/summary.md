# 论文速读：Same-Feedback-Diferent-Answer-Measuring-Run-to-Run-Instabili

## 一句话总结
论文提出了一套**重复运行评估框架**，用于量化前沿大模型在客户反馈分析任务中因随机性导致的**运行间不稳定性**；实验表明，引入**持续主题库**（Taxonomy-Grounded Agent, TGA）可将主题漂变降低 **86–88%**，使匹配主题的数量分歧降为零。

## 研究问题与动机
- **AI 代理的重复性要求**：当底层证据、问题和系统配置固定时，代理返回的主题集合、优先级和计数不应在不同运行间发生实质性变化；而当前前沿模型在此类重复开放域任务中表现不稳定。
- **既有评估指标的不足**：现有大型语言模型评测聚焦单次任务准确率，缺乏对"反复归纳非结构化语料"这一场景的重复性定义；字符串精确匹配会高估稳定性，单一相似度分数则掩盖了类别变更、排名偏移或数量波动的本质。
- **多主题/重标签结构带来的对齐难题**：每条记录可归属多个主题，主题名称可被不同措辞表达，计数仅在主题对齐后才能比较，导致传统的 self-consistency / confidence 估算方法不适用于度量"主题集 + 计数"联合变化的全貌。
- **运营决策对稳定性的硬性依赖**：主题身份直接对应仪表盘分类，排名指导产品路线图，数量触发优先级排序，因此不稳定性有实际的工程代价。

## 核心贡献（创新点）
1. **提出了面向重复分析的稳定性评测协议**：将不稳定性分解为主题漂变（theme churn）、排名不稳定性、主题生灭率和数量分歧四个正交维度，并保留出生/死亡方向作为诊断信号；与以往将重复输出压缩为置信度/选择信号的做法根本不同，本文把"分歧本身"作为研究目标。
2. **大规模前沿模型屏幕（8 模型 × 3 问题 × 10 次运行）**：在 100 条语料规模上覆盖 OpenAI、Bedrock、Google GenAI、Fireworks 等多接口，首次给出多模型在相同稳定性约束下的横向对比；基准是主题漂变，而非传统Accuracy。
3. **控制变量的 Opus 消融（模型固定）**：在冻结 Claude Opus 4.8、1,000 条语料、三组提示变体下比较三种执行设计（原始调用、无主题分层分解、TGA），证明稳定性优势来自**主题库持久化**而非"分群+合成"的分解本身。
4. **跨语料规模的稳定性检验（100 / 1,000 / 5,000 条）**：以线性斜率 +95% 区间量化规模对不稳定性的放大效应；原始模型在 5,000 条时主题漂变达 0.726，TGA 仅 0.033，差距随规模扩大。
5. **完整的运行级不确定性估计与成本核算**：使用 complete-run jackknife 与 bootstrap 计算区间，报告无效输出比例、每答案成本，以及语义对齐阈值敏感性分析，使结论可复现与可审计。

## 方法详解
- **语义主题对齐**：对所有主题名称使用冻结的 `text-embedding-3-large` 模型提取向量，计算余弦相似度；低于阈值 $\gamma = 0.82$ 的边删除，再在最大匹配基数优先、总相似度次优的目标下求解**二分图加权匹配**（Hungarian 算法），得到一一对应关系 $A_{ij}$。
- **主题漂变（Theme Churn）**：$d_{\text{theme}} = 1 - \frac{2M}{K_i + K_j}$，即 Sørensen–Dice 重叠的补集，$M$ 为对齐主题数，$K$ 为各运行主题总数；取值 $[0,1]$，越低越稳定。
- **排名不稳定性**：$d_{\text{rank}} = \frac{1 - \tau_b}{2}$，$\tau_b$ 为带平局校正的 Kendall 等级相关系数，仅在匹配主题数 $\geq 2$ 时有定义。
- **主题生灭率**：$d_{\text{bd}} = \frac{1}{2}\left(\frac{K_i - M}{K_i} + \frac{K_j - M}{K_j}\right)$，作为方向性诊断。
- **数量分歧（Volume Disagreement）**：对匹配对 $(a,b)$，$d_{\text{vol}} = \frac{1}{M}\sum \frac{|v_a - v_b|}{\max(v_a, v_b, 1)}$，归一化后每项 $\leq 1$，小主题一个记录的差异影响更显著。
- **证据漂变（Evidence Churn）**：使用至多 5 条支撑记录 ID 集的 Jaccard 距离，侧重样本选取诊断而非完整成员资格。
- **聚合与不确定性**：取全部无序运行对均值；大样本使用 complete-run jackknife（留一法重算 U-statistic）结合 Welch–Satterthwaite 95% 区间；小样本使用 per-question 运行级 bootstrap 百分位区间。
- **三种执行设计**：
  - **Raw**：一次性接收全部反馈记录并重新聚类。
  - **Taxonomy-free hierarchy**：将 1,000 条拆分为 10 批×100 条，10 个并行 worker 独立分析后合成 1 次调用；无工具、无检索、无持久主题。
  - **Taxonomy-Grounded Agent (TGA)**：基于生产环境的 supervisor/worker 架构，预查询持久主题库、子主题及记录级分类预测，再按共享 JSON schema 输出；无确定性后处理挑选主题。

## 实验与结果
- **数据集**：匿名多语言企业客户支持反馈，按时间戳排序并构建不可变嵌套前缀；三个冻结窗口：100 条（至 2026-06-12）、1,000 条（至 2026-06-16）、5,000 条（至 2026-06-29）。三个冻结问题：① 客户反馈前五大致原因；② 前三大痛点及受影响流程；③ 优先功能需求、底层诉求及频次。
- **模型覆盖**：8 个前沿原始模型（Claude Fable 5、GPT-5.6 Sol、GLM 5.2、Claude Opus 4.8、Kimi K2.7 Code、Qwen 3.7 Plus、DeepSeek V4 Pro、Gemini 3.1 Pro Preview）+ TGA（Claude Sonnet 4.6 supervisor + Claude Opus 4.8 控制组）。
- **Experiment 1（100 条）**：最稳定原始模型 Claude Fable 5 主题漂变 0.616，TGA 为 0.000；三项指标均为 0（主题、排名、生灭、数量）。
- **Experiment 2（规模扩展）**：
  - Raw Fable：0.552 → 0.623 → 0.726（每增加 1,000 条漂移斜率 +0.0325）
  - TGA：0.013 → 0.148 → 0.033，始终显著低于原始模型
  - 5,000 条下原始模型仅 9/15 有效输出，TGA 12/15
- **Experiment 3（Opus 消融，1,000 条）**：最小/bottom-up 提示因有效性不足被淘汰；唯一合格提示"consistency-first"下，**Raw = 0.765**，**Taxonomy-free = 0.841**，**TGA = 0.104**（分别降低 86.4% 与 87.6%）；TGA 匹配主题数量分歧严格为 0，排名覆盖 117/117 对，Raw 仅 47/135、hierarchy 仅 43/118。
- **成本**：100→1,000→5,000 条下 Raw 成本为 \$8.79 / \$51.25 / \$143.25，TGA 为 \$14.93 / \$17.61 / \$14.81；TGA 成本优势源于不再逐次传输完整语料。

## 相关工作脉络
- **Generation Consistency / Prompt Sensitivity**：已有工作关注重复请求下输出的随机性与提示扰动敏感性，但多将一致性作为置信度/选择信号；本文保留分歧本身作为研究对象并分解变化维度。
- **Self-Consistency & Semantic Uncertainty**（Wang et al. 2023; Lyu et al. 2025; Farquhar et al. 2024）：通过采样链取众数或计算语义熵来估计置信度；本文不依赖采样聚合，而是直接测量运行间主题/数量分布的结构变化。
- **Topic Model Stability**（Greene et al. 2014; Grootendorst 2022）：传统主题建模将稳定性视为模型选择问题，独立拟合的主题可能不同；本文场景是问题条件化的有序主题集合，而非完整语料模型，继承的是标签身份对齐难题。
- **Customer Feedback / Multi-label Systems**（InsightNet, Mukku et al. 2023; Chalkidis et al. 2020）：既往工作关注预测质量，本文转向"问题条件聚合"在不同执行间的稳定性。
- **RAG & Graph Retrieval**（Lewis et al. 2020; Edge et al. 2024）：TGA 借鉴"将领域结构持久化于生成之外"的原则，但本实验不评测检索质量，而是测试持久主题库对重复问答稳定性的增益。
- **Agent Reliability Benchmarks**（τ-bench, Yao et al. 2024）：评测重复试验中的 pass$^k$，适用于有可验证目标状态的任务；本文面对的是无单一黄金答案的反复语料综合任务，评估粒度更细。

## 局限性与未来方向
- **稳定性 ≠ 正确性**：TGA 仅保证"复现相同的答案"，不排除系统性偏差；作者明确声明未进行人类判断与任务质量评测。
- **单一私部署语料**：客户构成、语言分布、主题库成熟度、渠道和突发到达模式可能影响聚类，推广到公共数据集或未知情境需谨慎。
- **TGA 稳定性依赖固定主题库**：若重建主题库，不稳定会迁移到"摄入阶段"；本文解决的是摄入后的重复问答稳定性，而非摄入阶段的稳定性。
- **5,000 条规模下原始模型有效性低**：仅 9/15 有效输出，导致该区间的统计区间很宽，结论在该档位的精确性有限。
- **未评测结构化输出故障根因**：TGA 的少量失败来自空对象或查询审计失败，原始模型部分失败为字段类型错误，未深入分析。
- **未来方向**：将框架拓展到财务报表、法律文档、事件记录和科学文献等反复综合场景；探索在不引入持久主题库的前提下通过提示工程/自一致性提升原始模型的稳定性。

## 研究启发与可借鉴点
- **正交分解稳定性指标**：将不稳定性拆解为"主题是否存在"、"排名是否变"、"数量是否变"、"证据是否变"四个独立维度，比单一相似分数更能定位故障根源，可直接移植到任何结构化主题归纳任务。
- **对齐先于计算**：用冻结 embedding + 阈值 + 二分图匹配做一一对应，比字符串精确匹配或单一语义分数更能准确反映"主题集合"的变化；阈值敏感性分析本身也可作为方法的一部分。
- **控制变量的消融设计**：固定单一模型（Claude Opus 4.8）、固定语料、固定 schema，只改变执行架构（raw / hierarchy / grounded），能清晰归因稳定性差异来源，该实验范式适用于其他"同任务多实现"比较。
- **运行级不确定性估计**：采用 complete-run jackknife 与 per-question bootstrap，确保重复样本的依赖结构不被忽略；对 N=10 的小重复次数尤为必要，可成为此类评测的标准做法。
- **与本团队的结合点**：若团队涉及"多轮文档归纳 / 仪表盘类别追踪 / 合规事件统计"，可直接复用该框架；同时可反向思考：利用主题持久化机制（本论文的 TGA 思路）减少大语料场景下 LLM 因上下文过长导致的漂移与格式失效。

## 关键术语表
- **Theme churn（主题漂变）**：两次运行间主题集合对齐程度的 Dice 补集，反映整体主题集合的变化幅度。
- **Volume disagreement（数量分歧）**：匹配主题下计数相对变化量的平均，衡量数量维度的不稳定性。
- **Taxonomy-Grounded Agent（TGA）**：基于持久主题库与子主题记录查询的代理系统，避免每次运行重新聚类。
- **Semantic theme alignment（语义主题对齐）**：冻结 embedding + 余弦阈值 + 最大权二分图匹配的一一对应方法。
- **Birth/death rate（主题生灭率）**：未被匹配到的主题在两运行中各自占比的平均，作为方向性诊断。
- **Complete-run jackknife**：逐次删除完整运行重新计算 U-statistic 的留一法不确定性估计，保留运行间依赖结构。
- **Consistency-first prompt（一致性优先提示）**：要求候选标签、稳定边界、非重叠与确定性 tiebreaking 的系统提示变体。
- **Sørensen–Dice overlap**：集合重叠度量，本工作取其补集作为主题漂变的基准距离。

## 可复现要素
- **数据集**：匿名多语言企业客户反馈；**论文未公开原始文本与 ID**，仅提供时间戳窗口与有序前缀构造方式，未提及第三方开源数据集。
- **代码/权重**：论文未提供开源代码与模型权重链接；提供 source commit、analysis commit 及 SHA-256 摘要，但未见 GitHub 仓库声明。
- **关键超参**：Embedding 模型 `text-embedding-3-large`；余弦阈值 $\gamma = 0.82$（主分析），阈值扫查范围 0.76–0.90 步长 0.02；输出 token 上限 32,768（屏幕实验）/ 8,192（5,000 条实验）；每条主题最多 5 条支撑记录 ID；TGA supervisor 使用 Claude Sonnet 4.6，消融组使用 Claude Opus 4.8。
- **重复次数**：100/1,000 条规模每组 10 次独立运行；5,000 条每组 5 次；Opus 消融共 210 次预期答案，实际 196 次有效。
- **成本核算**：包含所有计费生成尝试（含无效输出与重试），不含 embedding 与本地分析成本；TGA 成本为生产 session 估计总和。

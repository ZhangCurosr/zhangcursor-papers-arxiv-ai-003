# 论文速读：Seeing-the-Invisible-Physics-Guided-Visual-Prompting-for-Temperature-and-Radiation-Aware-VLA-Navigation

## 一句话总结
本文提出物理引导视觉提示（PG-VP）模块，将不可见的辐射/温度风险转化为动态虚拟障碍物叠加到VLA模型的RGB输入中，使冻结的导航策略在零样本条件下自然规避不可见危险源，无需额外训练或架构修改。

## 研究问题与动机
- **核心问题**：在核电等安全关键设施中，辐射、温度骤升等物理风险无法被RGB相机感知，而传统扩展VLA多模态输入的方法需要新增编码器、收集配对数据并重新训练，成本高昂且无法保证原有导航性能。
- **现有方法不足**：
  1. 增加新传感器模态需配套采集多模态语言数据并重新训练对齐（citation [6]–[9]），工程成本高；
  2. 无传感器平台需维护独立策略（citation [30]）；
  3. 直接叠加非几何物理场（如温度/辐射热力图）语义含义模糊，难以引导VLA模型做出有效规避动作；
  4. 现有VLA导航工作未涉及非几何物理量输入。

## 核心贡献（创新点）
1. **首次将非几何物理量转化为视觉提示输入VLA导航**：不同于已有工作仅将几何量（深度、位姿）注入策略，本文用虚拟障碍物表征不可见物理风险，打通物理感知到视觉引导的桥梁。
2. **Plug-and-play 零样本设计**：PG-VP 不修改VLA权重、不引入新编码器，无风险时不做任何渲染，完全保留原始导航性能。
3. **统一虚拟障碍物表征异构风险**：无论辐射还是温度，均渲染相同的动态弯曲墙体，使VLA只需理解一种视觉模式，避免因模态差异导致分布偏移。
4. **两阶段物理感知机器学习（PIML）辐射风险评估**：风险模型（33维MLP）+ 方向模型（151维MLP + 物理辅助头）串联，利用逆平方律构建物理感知损失，仅用前向推理输出规避方向，区别于需要迭代优化的传统方法。

## 方法详解
PG-VP 由三部分串联：多模态感知系统 → 物理引导风险评估（RA）→ 动态视觉提示（DVP）。

**1. 多模态感知硬件配置**
- 前向广角RGB相机（120° HFOV）+ 两侧鱼眼webcam（±90°偏航，69° HFOV）；
- 辐射传感器 RadEye SPRD-ER（点式伽马计数）；
- 双FLIR Lepton 3.5热像仪（各57° HFOV，向外偏转15°，中心27°重叠）；
- 辐射/热数据通过Redis实时同步至机载Jetson Orin Nano。

**2. 温度风险评估（RA）**
- 将每帧热像图划分为四区：左外侧(Ω_LS)、左前(Ω_LF)、右前(Ω_RF)、右外侧(Ω_RS)；
- 取各区最大温度 $T_t^k = \max_{\mathbf{p}\in\Omega_k} \mathcal{T}_t(\mathbf{p})$；
- 若 $T_t^{LS} \geq \max(T_t^{LF}, T_t^{RF}, T_t^{RS}) + \Delta T_{th}$ 则判定为左侧风险，同理右侧；
- 同一分类持续0.5秒才确认输出 left/right，否则输出 normal。

**3. 辐射风险评估（PIML两阶段MLP）**
- **风险模型**：输入33维（16个相对log-CPS + 16个位移幅值 + 1个通量-航向斜率），输出0~1浮点数；结构(33,128,128,64,1)，加权二分类交叉熵损失；阈值>0.3时激活方向模型。
- **方向模型**：输入151维（30个相对log-CPS + 60个平面位移 + 60个航向变化 + 1个通量-航向斜率）；共享主干(151,128,128,64)，方向头(64,32,3)输出left/normal/right概率，物理辅助头(64,32,4)估计源偏移$(\hat{\Delta x_s}, \hat{\Delta y_s})$、缩放因子$\hat{\kappa}$、本底$\hat{b}$。
- **损失函数**：
$$\mathcal{L}_{dir} = \mathcal{L}_{ce}(\hat{\mathbf{y}}_{dir}, \mathbf{y}_{dir}) + 0.1 \cdot \mathcal{L}_{physics}(\hat{c}_t, c_t)$$
其中物理损失基于逆平方律重建CPS：
$$\hat{c}_t = \frac{\hat{\kappa}}{4\pi(100\cdot\hat{r}_t(\hat{\Delta x_s}, \hat{\Delta y_s}) + r_{det})^2} + \hat{b}, \quad \mathcal{L}_{physics} = \frac{1}{30}\sum_{t=1}^{30}|\log(\hat{c}_t+1) - \log(c_t+1)|$$
- 最终方向通过12个随机种子训练的模型softmax概率soft-voting集成。

**4. 动态视觉提示（DVP）**
- 虚拟障碍物渲染为"动态弯曲墙体"，从图像侧边向内生长再消退；
- 水平墙长比例 $r_w(k)$ 由公式(4)控制，$S_{guide}$ 为最大比例（取值0.55/0.60/0.65），$N_g=N_v=4$ 为增长/消退帧数；
- 墙体由两条二次Bézier曲线围成，填充类混凝土纹理（高斯噪声均值80、std 15），亮度从内侧边界50%渐变至边缘100%以增强深度感；
- 对应侧向摄像头画面也完全覆盖相同纹理；无风险时不渲染任何内容。

## 实验与结果
**仿真基准**：OmniNav（底层导航策略）+ R2R-CE val-unseen / RxR-CE val-unseen；虚拟危害随机插入总帧数的25%~75%起始位置。

| 指标 | R2R-CE | RxR-CE |
|------|--------|--------|
| CGR（正确引导率） | 84.9% | 83.2% |
| SR下降 | −6.8 pp | −7.9 pp |
| 最优 $S_{guide}$ | 0.60 | 0.60 |

- 与基线OmniNav对比（Table I）：$S_{guide}=0.60$ 时 R2R-CE SR=61.9%，SPL=58.2%；RxR-CE SR=61.0%，SPL=49.7%，优于多数单目方法，与NavFoM（全景）相当。
- $S_{guide}$ 增大时CGR和横向位移$|x_d|$上升但SR下降更陡；0.60为导航成功率与引导效果的最优平衡点。
- 轨迹可视化（Figure 5）：成功任务在提示后短暂偏转后恢复原航向；失败任务持续偏离。

**真机实验**（Unitree Go2 EDU四足机器人，4个场景）：
- 热危害场景（A/B）：热枪/房间加热器；辐射危害场景（C/D）：9根铀棒；$\Delta T_{th}=30$，$S_{guide}=0.60$。
- 安全性提升（Table II）：
  - 热危害最坏10%平均热源接近距离：**提升63.45%**（最小距离从~1.06m增至~1.53m）
  - 辐射危害最坏10%平均净计数率：**提升32.59%**（峰值从93.00 CPS降至46.00 CPS）
- 场景D中因箱子遮挡辐射源，RA模型触发延迟，导致峰值未能完全消除。

## 相关工作脉络
1. **NaVILA / OmniNav / NavFoM / CorrectNav / JanusVLN**：VLA导航主流基线，均以RGB或全景视觉为输入，未处理非几何物理量；本文在OmniNav基础上叠加PG-VP，属插件式扩展而非替代。
2. **Tactile-VLA / OmniVTLA / Beyond Sight**：将触觉/力觉引入VLA Manipulation需重新训练；本文强调零样本即插即用，避免重训。
3. **BYOVLA / VAP / Waypoint Marker / Green-for-Go**：已有视觉提示均在图像内强调/遮蔽/标注已有像素信息；本文注入"场景中完全不存在"的虚拟障碍物，属于out-of-distribution context injection。
4. **Son et al. [37]**（PIML辐射源定位）：本文辐射RA模型继承其数据生成与物理辅助思路，但将迭代优化转为单次前向推理的MLP集成，实时性大幅提升。
5. **StreamVLN / EfficientVLN / MapNav**：聚焦效率与内存压缩，与本文安全感知方向正交，可组合使用。
6. **Green for Go, Red for No [36]**（同期工作）：用语义分割掩码（绿/红区域）引导导航；本文用3D实体障碍纹理，避免了VLA对抽象颜色编码的歧义解读。

## 局限性与未来方向
- **局限**：
  1. 辐射场景中若源被遮挡（如场景D），RA模型无法及时触发，提示延迟导致峰值仍存在；
  2. $S_{guide}$ 增大虽提升引导效果但显著降低导航成功率（R2R-CE在0.65时SR降至57.8%），取舍需谨慎；
  3. 当前仅验证了热与辐射两类风险，泛化至气体等其他模态需重新设计RA模型；
  4. 虚拟障碍物为固定纹理，对不同环境光照/风格的适应性未经充分测试。
- **未来方向**（论文自述）：扩展至更多工业级真实场景；探索超越避障的模态特定目标（如辐射源定位、高温区域搜索）；扩展至气体传感等其他非几何模态。

## 研究启发与可借鉴点
1. **"物理风险→虚拟障碍"的映射范式可迁移**：任何可通过传感器探测但不可见的风险（如有害气体浓度、电磁干扰区、声呐盲区）均可复用此框架，只需替换对应RA模型，VLA主体不变。
2. **PIML+MLP前向推理替代迭代优化**：辐射RA中用MLP单次前向输出方向，比传统SLAM式优化适合实时嵌入式部署，此思路可推广至其他物理感知任务。
3. **动态生长/消退的虚拟障碍设计**：墙体随帧数非线性变化（$\sqrt{k/N_g}$），比静态叠加更易被VLA解释为"可穿越障碍"，减少视觉突兀感；该动画节奏设计可直接复用。
4. **真实机器人零样本验证**：全文未对VLA做任何微调，在真实热/辐射源下直接部署，证明了视觉提示的跨域迁移有效性，值得在团队机器人项目中借鉴验证协议。
5. **双摄像头配合RA判向的硬件布局**：两侧偏置热像仪+中心重叠区的设计兼顾覆盖范围与判向鲁棒性，可作为多模态传感布设参考。

## 关键术语表
- **VLA（Vision-Language-Action）模型**：将视觉、语言输入直接映射为连续/离散动作的端到端导航/操作策略网络。
- **PG-VP（Physics-Guided Visual Prompting）**：本文提出的插件模块，将物理风险评估结果转化为动态虚拟障碍物叠加至RGB图像。
- **RA（Risk Assessment）模型**：针对特定物理模态（温度/辐射）的风险评估神经网络，输出规避方向（left/normal/right）。
- **CGR（Correct-Guidance Ratio）**：视觉提示成功引导轨迹按预期偏转的场景占比。
- **PIML（Physics-Informed Machine Learning）**：将物理定律（如逆平方律）嵌入损失函数以约束模型输出的机器学习范式。
- **Soft-voting Ensemble**：对多个独立训练模型的softmax概率取平均作为最终预测，增强方向估计鲁棒性。
- **SPL（Success weighted by Path Length）**：VLN评估指标，同时考虑任务完成度和路径效率。
- **Net Count Rate**：扣除本底辐射后的伽马射线计数率（CPS），用于量化机器人轨迹上的辐射暴露水平。

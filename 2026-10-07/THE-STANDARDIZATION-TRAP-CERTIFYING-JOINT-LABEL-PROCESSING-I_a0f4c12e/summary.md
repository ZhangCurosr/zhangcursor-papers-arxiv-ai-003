# 论文速读：THE STANDARDIZATION TRAP: CERTIFYING JOINT LABEL PROCESSING IN TABULAR FOUNDATION MODELS

## 一句话总结
本文针对表格基础模型（TFM）中上下文标签的处理机制，提出了两个基于流形微分几何的可验证证书（certificates），成功区分了固定权重、独立非线性变换和联合处理三种标签处理模式；实验表明所有五个公开 TFM 均对上下文标签进行联合处理，且该交互主要由注意力分数承载，并在训练过程中涌现。

## 研究问题与动机
- **核心问题**：预训练表格基础模型（TFM）在推理时如何利用上下文标签？标签仅仅提供被加权求和的"值"（固定权重假设），还是标签本身会改变其他标签的影响力（联合处理）？
- **现有方法的不足**：直接通过导数分析来测量标签敏感度会遭遇"标准化陷阱"——公开 TFM 包在标签进入网络前对其进行标准化（固定均值和尺度），但普通导数同时反映了标准流形之外区域的行为，导致即使是固定权重映射也会产生非零海森矩阵，从而被误判为存在标签交互。
- **理论缺口**：现有对上下文学习（in-context learning）的解释（线性回归、核平滑）假设特征决定权重而标签仅提供值，这一假设在预训练 TFM 中是否成立尚不明确。

## 核心贡献（创新点）
1. **两个证书区分三种标签处理形式**：第一个证书 $\bar{A}_T$ 排除固定权重预测；第二个证书 $\bar{X}_{\text{sep}}$ 进一步排除"每个标签独立非线性变换后相加"的模型，两者联合可严格认证联合处理的存在。
2. **揭示所有测试 TFM 均进行联合标签处理**：在五个公开 TFM（TABICL-V2、TABPFN-V3、TABPFN-V2.6、TABFM、TABDPT）上，$\bar{A}_T$ 均值达 98.5%，$\bar{X}_{\text{sep}}$ 均值达 63.0%，完全拒绝固定权重和独立变换两种解释。
3. **联合处理在训练中涌现**：相同架构的随机初始化副本仅产生极弱的交互（$\bar{X}_{\text{sep}} \leq 3.4\%$），而训练后的模型最低为 29%，证明该行为来自训练而非架构本身。
4. **注意力分数承载了大部分交互**：对注意力分数施加 stop-gradient 阻断导数路径后，$A_T$ 平均下降 80.9%，$X_{\text{sep}}$ 平均下降 85.0%，而前向预测保持不变。

## 方法详解

### 标准化陷阱与流形设定
TFM 在输入网络前将标签向量 $\mathbf{y}$ 标准化为 $\tilde{\mathbf{y}} = (y_i - \bar{y})/s_y$，使得网络实际只看到标准流形 $\mathcal{M}$ 上的点：
$$\mathcal{M} = \{\tilde{\mathbf{y}} \in \mathbb{R}^n : \mathbf{1}^\top \tilde{\mathbf{y}} = 0,\; \|\tilde{\mathbf{y}}\|^2 = r^2\}$$
这是一个嵌入在零均值子空间中的球面。普通导数描述的是流形外区域的推广行为，因此即使函数在 $\mathcal{M}$ 上是仿射的，其 Hessian 也可能非零（如 $g_a(\tilde{\mathbf{y}}) = b + a^\top \tilde{\mathbf{y}} + q(\|\tilde{\mathbf{y}}\|^2 - r^2)$，其中 $q \neq 0$，该项在 $\mathcal{M}$ 上恒为零但不影响预测，却会产生 $H = 2qI$）。

### 证书 1：排除固定权重预测（$A_T$）
定义切空间投影算子：
$$P_T = I - \frac{\mathbf{1}\mathbf{1}^\top}{n} - \frac{\tilde{\mathbf{y}}\tilde{\mathbf{y}}^\top}{r^2}$$
对 Hessian 施加双侧切空间投影得到切曲率 $P_T H P_T$，再减去其各向同性部分（每个切方向上相同的曲率分量），得到无迹部分：
$$T = P_T H P_T - \frac{\mathrm{tr}(P_T H P_T)}{n-2} P_T, \quad A_T = \|T\|_F$$
**引理 1** 证明：任何在 $\mathcal{M}$ 上与仿射映射一致的函数，其切曲率必为各向同性形式 $\lambda(\tilde{\mathbf{y}}) P_T$，故 $A_T = 0$。非零值即排除固定权重预测。

### 证书 2：排除独立非线性变换（$X_{\text{sep}}$）
每个标签独立变换的模型形如 $g_{a,\phi}(\tilde{\mathbf{y}}) = b + a^\top \tilde{\mathbf{y}} + \sum_k \phi_k(\tilde{y}_k)$，其 Hessian 的对角矩阵 $D = \mathrm{diag}(\phi_k''(\tilde{y}_k))$ 经切空间投影后生成子空间 $\mathcal{S}$。将 $T$ 正交投影到 $\mathcal{S}$ 后测量剩余量：
$$X_{\text{sep}} = \|T - P_\mathcal{S} T\|_F$$
**引理 2** 证明：任何仿射+可分离映射在 $\mathcal{M}$ 上均有 $T \in \mathcal{S}$，即 $X_{\text{sep}} = 0$。非零值即认证联合处理。

### 归一化度量
为避免模型间尺度差异，报告平方份额：
$$\bar{A}_T = \frac{A_T^2}{\|P_T H P_T\|_F^2}, \quad \bar{X}_{\text{sep}} = \frac{X_{\text{sep}}^2}{A_T^2}$$
两者均在 $[0, 1]$ 区间，$\bar{A}_T = 0$ 对应固定权重，$\bar{X}_{\text{sep}} = 0$ 对应独立变换。

### 注意力路径阻断实验
在每个注意力步骤中，保持注意力分数的前向值不变（stop-gradient），阻断导数通过注意力分数传播，比较阻断前后的 $A_T$ 和 $X_{\text{sep}}$ 变化幅度。

## 实验与结果
- **数据集**：4 个回归数据集（合成数据集 synthetic_mi、kin8nm、pol、superconduct），上下文大小 $n = 256$，每个设置 3 个随机采样的上下文、4 个查询点。
- **评测模型**：5 个公开 TFM——TABICL-V2、TABPFN-V3、TABPFN-V2.6、TABFM 1.0、TABDPT v1.2。
- **主要结果（表 2，四数据集均值）**：

| 模型 | $\bar{A}_T$ (%) | $\bar{X}_{\text{sep}}$ (%) | 注意力阻断 $A_T$ 降幅 (%) | 注意力阻断 $X_{\text{sep}}$ 降幅 (%) |
|------|----------------|---------------------------|--------------------------|-------------------------------------|
| TABICL-V2 | 98.7 | 63.1 | 81.6 | 82.0 |
| TABPFN-V3 | 98.5 | 70.8 | 85.9 | 90.0 |
| TABPFN-V2.6 | 97.7 | 73.4 | 90.9 | 95.3 |
| TABFM | 99.2 | 67.5 | 78.2 | 82.1 |
| TABDPT | 98.3 | 40.4 | 68.0 | 75.3 |
| **均值** | **98.5** | **63.0** | **80.9** | **85.0** |

- **最强结果**：TABPFN-V2.6 的 $\bar{X}_{\text{sep}}$ 达 73.4%，注意力阻断后 $X_{\text{sep}}$ 降幅最高达 95.3%，表明其联合处理信号最强且几乎完全经由注意力分数传递。
- **训练 vs 随机初始化**：随机副本的 $\bar{X}_{\text{sep}}$ 最高为 3.4%，而训练模型的每个查询点均 $\geq 29\%$，差距显著。
- **代理拟合**：固定权重代理在任务保持重采样下的中位数 $R^2 = 0.72$，说明固定权重仍是一个近似有用的描述，但不能精确解释标签交互。

## 相关工作脉络
- **固定权重解释**：von Oswald 等（2023）和 Akyurek 等（2023）证明 transformer 可对上下文做线性回归/梯度下降，标签仅提供值；Collins 等（2024）将注意力解释为核操作；Zhang 等（2024）分析收敛的单层线性注意力预测器。本文与这些工作的差异在于：这些理论解释中的权重由特征决定，标签不改变权重；本文精确检验 TFM 是否遵循这一模式。
- **标签驱动任务推断**：Xie 等（2022）、Panwar 等（2024）的贝叶斯视角认为标签帮助推断任务；Muller 等（2022）的 PFN 学习贝叶斯预测器。本文的证书测量与这一图景一致，但提供了更精确的数学鉴别手段。
- **内部表征研究**：Gupta 等（2026a,b）研究 TabPFN 内部计算中中间量的编码；Ye 等（2025）发现 TabPFN v2 可作为特征提取器。本文与这些工作的差异在于：它们关注内部表征的结构，本文关注标签之间是否存在跨示例的交互效应。
- **可解释性争议**：Wiegreffe & Pinter（2019）、Jain & Wallace（2019）讨论注意力是否可解释；本文通过阻断注意力导数路径的实验进一步参与了这一讨论。

## 局限性与未来方向
- **证书只检测交互的存在，不揭示具体计算机制**：多种计算均可产生标签交互（如推断任务、局部回归重新加权、表征依赖标签），证书无法区分这三种可能性。
- **导数测试确立交互的存在性但不确立必要性**：阻断注意力分数后预测不变，因此无法判断这些交互对预测精度是否必要；需要前向干预实验来回答这一问题。
- **仅评估公开模型**：五个模型均为开源包，未涉及私有或未公开的 TFM 实现。
- **上下文大小的扩展性**：在 $n=128$ 到 $512$ 的范围内交互效应略有下降但未消失，$n=1024$ 时有两个设置超出内存限制。

## 研究启发与可借鉴点
1. **标准化陷阱的普遍性**：任何对已标准化输入进行导数分析的模型解释工作都需警惕此陷阱——流形约束下的零预测变化与有信息的海森曲率可以同时存在。本文提出的切空间投影方法可迁移到其他涉及标准化/归一化的模型解释场景。
2. **证书框架的可复用性**：两个证书（$A_T$ 和 $X_{\text{sep}}$）完全基于模型在标准化流形 $\mathcal{M}$ 上的预测值，与流形外推广无关，提供了一种"扩展无关"的可验证判定工具，可应用于其他需要区分线性/非线性/交互行为的模型分析。
3. **注意力导数阻断实验设计**：通过 stop-gradient 保持前向值不变而阻断特定路径的导数，能够精确定位计算图中承载特定二阶效应的路径，这一方法可用于注意力机制的可解释性研究。
4. **与团队方向的结合机会**：若团队研究方向涉及大语言模型或多模态基础模型的上下文学习机制，可将此证书框架迁移到序列/文本场景，检验 LLM 的 few-shot 学习是否也存在类似的标签（token 级）联合处理现象。

## 关键术语表
- **Standardization Trap（标准化陷阱）**：TFM 包将标签标准化后再输入网络，导致输入被限制在标准流形 $\mathcal{M}$ 上；但普通导数描述流形外行为，使固定权重模型的海森矩阵非零，从而产生虚假的联合处理信号。
- **Fixed-Weight Prediction（固定权重预测）**：预测是标签向量的仿射函数，权重仅由特征决定而不随标签变化；即 $\hat{y}_{\text{int}} = b + \sum_i a_i(x_*, X)\tilde{y}_i$。
- **Joint Processing（联合处理）**：一个上下文标签的变化会改变其他标签对预测的影响力，即敏感度 $a_i$ 依赖于完整的标签向量 $\tilde{\mathbf{y}}$。
- **Standardization Manifold（标准化流形）**：$\mathcal{M} = \{\tilde{\mathbf{y}} : \mathbf{1}^\top \tilde{\mathbf{y}} = 0, \|\tilde{\mathbf{y}}\|^2 = r^2\}$，即标准化后标签向量的取值集合，是一个零均值超平面中的球面。
- **Tangent Curvature（切曲率）**：$P_T H P_T$，将 Hessian 投影到标准流形的切空间上，排除垂直于流形方向的伪曲率。
- **Certificate ($A_T$, $X_{\text{sep}}$)**：两个数学检验统计量；$A_T > 0$ 排除固定权重，$X_{\text{sep}} > 0$ 进一步排除独立非线性变换，二者联合认证联合处理。
- **Separable Label Transformation（可分离标签变换）**：每个标签被独立非线性函数变换后相加（$\sum_k \phi_k(\tilde{y}_k)$），标签之间不产生交互。
- **Tabular Foundation Model (TFM)**：在大规模表格数据上预训练的通用模型，推理时利用上下文示例进行 zero-shot/in-context 预测，如 TabPFN、TabICL、TabFM、TabDPT。

## 可复现要素
- **数据集**：OpenML 数据集（kin8nm、pol、superconduct）公开可用；合成数据集 synthetic_mi 由论文 Generator 公式生成（附录 B.2）；代码和生成脚本论文未明确提供开源仓库链接。
- **代码/权重**：五个 TFM 包（TabICL、TabPFN、TabFM、TabDPT）均为公开开源模型，可在其各自 GitHub 仓库获取；本文的分析代码未单独开源，但附录提供了详细的数学推导和算法描述。
- **关键超参**：上下文大小 $n = 256$；浮点精度 float32（部分验证用 float64）；Eager attention 替换部署中的 fused kernel；stop-gradient 阻断点设在每个注意力步骤的注意力分数处。

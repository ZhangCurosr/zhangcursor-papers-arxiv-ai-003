# 论文速读：ThinkFuse-Trajectory-Aware-Test-Time-Fusion-for-Small-Reason

## 一句话总结
本文提出 **THINKFUSE**，一种无需训练的测试时融合框架，通过对比**片段级不确定性变化**与**轨迹级不确定性趋势**来识别不稳定的推理片段，并有选择地将辅助模型的推理路径融合到主模型轨迹中，从而提升小型推理模型在数学与知识密集型任务上的表现。

## 研究问题与动机
1. 小型推理模型（SRMs）虽然能生成长链思维轨迹，但一旦推理进入错误路径，往往难以恢复。
2. 现有的测试时融合方法依赖**局部融合信号**（如特定解码步的局部不确定性），容易被瞬时波动误导，可能强化不稳定的推理轨迹。
3. 现有方法未能捕捉不确定性在**推理轨迹整体演化**中的动态，导致融合触发过早、过晚或不必要。
4. 缺乏有效的**选择性融合触发机制**，无法判断何时介入及依据何种证据。

## 核心贡献（创新点）
1. 提出 **THINKFUSE** 框架：通过 EWCA 不确定性度量和自适应阈值识别不可靠的推理片段，实现轨迹感知的选择性融合。
   *与已有工作的本质区别：不同于 Cool-Fusion 等按片段融合或 AdaFuse 等依赖局部置信度的方法，THINKFUSE 结合了多模型融合、轨迹感知校准与选择性触发。*
2. 设计 **指数加权因果聚合（EWCA）** 指标：将 token 级不确定性聚合为片段级信号，捕获片段内部的不确定性动态。
   *与已有工作的本质区别：不同于 MUR 等单模型动量不确定性方法，EWCA 同时考虑 token 位置权重和累积不确定性。*
3. 设计 **自适应阈值** 机制：基于主模型历史不确定性统计量和累积融合频率动态调整触发阈值，限制不必要的干预。
   *与已有工作的本质区别：不同于固定阈值方法，该机制通过二次惩罚项防止过度融合，平衡干预与稳定性。*
4. 提出 **轨迹兼容性评分**：利用主模型的困惑度（PPL）评估并选择主模型与辅助模型片段的融合结果。
   *与已有工作的本质区别：不同于独立验证方法，该方法在生成过程中即时评估片段兼容性，保留主模型推理上下文。*
5. 大量实验验证：在数学和知识密集型基准上，THINKFUSE 优于测试时扩展和测试时融合基线，且在小规模主模型下依然稳健。
   *与已有工作的本质区别：证明了选择性融合比全片段融合或冗余同模型融合更有效。*

## 方法详解
**整体框架**：给定复杂推理任务 $x$，提示主推理模型 $M_p$ 生成推理路径。利用 EWCA 指标和自适应阈值 $\theta$ 在片段级监控不确定性。一旦片段不确定性超过阈值，评估主片段和辅助片段在当前上下文下的轨迹兼容性（通过主模型 PPL），并选择更兼容的片段扩展推理轨迹，迭代至终止状态。

**片段级不确定性监控**：
- **片段内不确定性计算（EWCA）**：对主模型生成的每个 token $y_{k,i}^p$，计算其在 top-r 概率分布上的归一化 Shannon 熵 $u_{k,i}^p$。然后通过 EWCA 将 token 级不确定性聚合为片段级不确定性 $U_k^p$：
  $$U_k^p = \frac{\sum_{i=1}^{T_k} w_{k,i} u_{k,i}^p}{\sum_{i=1}^{T_k} w_{k,i}}, \quad w_{k,i} = \exp(\alpha \cdot i) \cdot \prod_{j<i} (1+\beta \cdot u_{k,j}^p)$$
  其中 $\alpha$ 控制后期 token 的强调，$\beta$ 控制不确定性累积。
- **片段间自适应阈值**：维护历史轨迹的均值 $\mu$ 和标准差 $\sigma$ 的指数移动平均（EMA）。触发阈值 $\theta_k$ 动态计算为：
  $$\theta_k = (\mu_{k-1} + \tau \cdot \sigma_{k-1}) \cdot (1 + \lambda \cdot R_{k-1}^2)$$
  其中 $\tau$ 控制偏差容忍度，$R_{k-1}$ 为累积融合比率，$\lambda$ 为软预算参数，二次项惩罚过度融合。

**轨迹兼容性评分**：
当 $U_k^p \geq \theta_k$ 时，调用辅助模型 $M_a$ 生成备选片段 $s_k^a$。以主模型 $M_p$ 作为轨迹兼容性评分器，计算每个候选片段在当前上下文 $c_k$ 下的困惑度 $\ell_k(s) = \text{PPL}_{M_p}(s | c_k)$，选择更低 PPL 的片段作为融合结果：
$$s_k^* = \arg\min_{s \in \{s_k^p, s_k^a\}} \ell_k(s)$$
更新上下文 $c_{k+1} = c_k \oplus s_k^*$，主模型继续生成，重复直至终止状态。

## 实验与结果
**数据集**：
- 数学推理：MATH-500、GSM8K、AIME 2024
- 知识密集型推理：GPQA-Diamond、NQ-Open

**评估基线**：
- 独立模型（Standalone）
- 测试时计算基线：Self-consistency (K=3,5)
- 测试时融合基线：Cool-Fusion、AdaFuse
- 其他对比：MUR、SpecReason、Post-hoc critique

**主要结果**（以 Qwen3-4B 为主模型，Ministral-3B-R 为辅助模型为例）：
- **最强结果**：在 AIME24 上达到 **73.3%**（较独立模型 +20.0），GPQA 达 **64.6%**（+10.6），NQ-Open 达 **39.5%**（+10.0），GSM8K 达 **96.9%**（+4.9），MATH-500 达 **90.0%**（+1.0）。
- **跨模型家族组合**：与 EXAONE-Deep-2.4B、DeepSeek-R1-Distill 等辅助模型配合时，同样在所有基准上获得稳定提升。
- **小规模主模型**：Qwen3-1.7B 作为主模型时，THINKFUSE 仍能将 GPQA 从 39.4 提升至 53.5，在其他基准上也取得 +2.0（MATH-500）和 +0.5（GSM8K）的增益。
- **效率分析**：THINKFUSE 的 TFLOPs 与 AdaFuse 相当（77 vs 74），但准确率（平均 72.9%）显著高于 AdaFuse（43.7%）和 Cool-Fusion（21.8%），每 TFLOP 准确率最高（0.95）。
- **消融验证**：软预算惩罚（$\lambda=50$）、片段长度 $T=8$、主模型 PPL 评分、熵不确定性度量均为有效设计。

## 相关工作脉络
1. **Self-consistency (Wang et al., 2023)**：后验多数投票，无选择性触发，无多模型融合，无轨迹感知。
2. **Cool-Fusion (Liu et al., 2025)**：在**每个片段**进行片段级融合，无选择性触发，有轨迹感知，依赖平均 PPL 评分。
3. **AdaFuse (Cui et al., 2026)**：在词/跨度级进行自适应融合，有选择性触发，依赖局部 token 置信度，无轨迹感知。
4. **MUR (Yan et al., 2026)**：单模型动量不确定性引导的步骤级计算扩展，有选择性触发，无多模型融合，有轨迹感知。
5. **SpecReason (Pan et al., 2025)**：小模型起草步骤，大模型验证每一步，无选择性触发，无多模型融合，无轨迹感知。
6. **THINKFUSE (本文)**：**片段级**融合，有选择性触发，有多模型融合，有轨迹感知，基于**轨迹校准的片段不确定性**决策。

## 局限性与未来方向
1. **测试时资源需求**：需同时服务主模型和辅助模型，增加内存和延迟；可通过量化、并行服务和缓存感知部署优化。
2. **评估范围局限**：主要测试 1.2B-4B 开放权重推理模型，未验证更大模型、闭源模型及代码生成、多语言推理、长上下文任务。
3. **依赖主模型质量**：若主模型生成高度不稳定或重复的片段，不确定性触发可能失效；需替代解码策略或更强选择标准。
4. **辅助模型互补性依赖**：若辅助模型与主模型失败模式相似或优势不匹配，融合可能无效；未来可通过任务特定辅助选择或模型池路由缓解。
5. **显式推理 span 和分词器对齐**：需在 thinking stage 内识别推理 span，并对齐不同分词器生成的片段，当前使用标记归一化和共享前缀对齐，工程适配成本较高。
6. **固定融合设置**：当前使用固定片段长度和 PPL 评分规则，超参数搜索空间未充分探索，可能仍有提升空间。

## 研究启发与可借鉴点
1. **轨迹感知融合机制**：将不确定性监控从局部 token 级提升至**片段级**并与历史轨迹趋势对比，为推理过程中的选择性干预提供新思路。
2. **自适应阈值设计**：引入累积融合频率的二次惩罚项，动态调整触发阈值，有效平衡干预积极性与系统稳定性，可迁移至其他测试时调度场景。
3. **兼容性评分策略**：使用主模型 PPL 评估候选片段的轨迹兼容性，而非简单平均或辅助模型 PPL，确保融合片段与主模型推理上下文一致。
4. **实验设计严谨性**：通过 bootstrap 置信区间、消融研究、跨模型组合、效率分析（TFLOPs 与 wall-clock time 分离）多维度验证方法的有效性与实用性。
5. **可迁移价值**：EWCA 不确定性聚合方法、自适应阈值更新公式、片段对齐技术可用于其他多模型协作或测试时扩展任务。

## 关键术语表
- **Small Reasoning Models (SRMs)**：参数量较小但具备生成链式思维推理轨迹能力的语言模型。
- **Test-time Fusion**：在推理阶段无需训练，通过融合多个模型的推理轨迹或输出来提升性能的方法。
- **Exponentially Weighted Causal Aggregation (EWCA)**：一种将 token 级不确定性聚合为片段级不确定性的指标，通过指数加权考虑 token 位置和累积不确定性。
- **Adaptive Threshold**：基于主模型历史不确定性统计量和累积融合比率动态计算的融合触发阈值，防止过度干预。
- **Trajectory Compatibility Scoring**：使用主模型困惑度评估候选片段与当前推理上下文的兼容性，选择更优片段进行融合。
- **Soft Budget Penalty**：通过融合频率的二次项惩罚增加阈值，限制总融合次数，平衡性能与计算开销。

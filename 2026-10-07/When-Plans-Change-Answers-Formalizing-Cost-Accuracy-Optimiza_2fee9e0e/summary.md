# 论文速读：When-Plans-Change-Answers-Formalizing-Cost-Accuracy-Optimiza

## 一句话总结
本文形式化了语义查询引擎中的**成本-准确性联合优化（CASQO）**问题，提出利用校准后的模型置信度加权元组输出贡献（如扇出），在无标签数据下预测物理计划的全局输出质量，并通过双拉格朗日乘子将输出级目标分解为逐元组决策；同时证明当前系统默认的选择下推在人口校准策略下并非质量安全重写。

## 研究问题与动机
1. **计划选择同时决定成本与答案**：传统优化器假设等价逻辑计划返回相同结果，仅比较成本；引入ML语义算子后，阈值、升级带、候选剪枝等都会改变返回元组集合，不同物理计划可能返回截然不同的答案。
2. **现有方法缺乏输出级目标**：JEVDB等系统仅对每个算子设置固定阈值或独立校准的升级带，用户无法声明单个全局准确率目标，系统也无法跨算子分配精度预算。
3. **错误传播被忽略**：算子级预测准确率（如0.88）与最终查询结果准确率（如0.58）可能相差巨大，因为错误会通过Join的扇出被放大或稀释。
4. **优化阶段缺乏质量评估依据**：若无校准置信度，系统只能依赖标注真值或随机采样评估计划，难以在搜索空间内提前比较计划的预期质量。

## 核心贡献（创新点）
1. **形式化语义关系代数与计划等价层次**：定义Oracle语义、物理计划为`(逻辑计划, 决策策略)`对，建立四类从强到弱计划等价关系（Oracle→实现→置信度相对→容许性），使 optimizer 可严格区分“结果相同”与“质量相同”。
2. **证明选择下推在人口校准策略下非质量安全**：针对PC类策略，Pushdown与Pull-up会暴露不同的实例分布（扇出加权差异），导致校准出的升级带不同；给出反例证明Pull-up可达标的计划在下推后可能违反输出目标。
3. **基于谱系的误差反向传播与逐元组定价**：定义决策实例对输出的贡献度$c^\Pi(i)$，将输出级召回/精度目标转化为每个元组的单位错误价格，通过两个拉格朗日乘子实现实例级成本-质量权衡。
4. **质量估计的复杂度二分定理**：Bag语义下期望质量可多项式时间计算；Set语义下遵循概率数据库的层次二分（hierarchical为PTIME，全原子概率化且非层次则为#P-hard）。
5. **合成仿真验证效率增益**：在2000条评论合成负载上，逐元组定价策略满足输出$(0.9, 0.9)$目标的成本比最佳算子级带宽策略低约81%（1.9×~5.3×），且预测质量与真实质量误差可控制在0.01以内。

## 方法详解
- **校准置信度驱动的质量预测**：假设决策模型输出$p_i$已校准，则接受元组的错误概率为$1-p_i$，拒绝的为$p_i$，升级至完美裁判的置信度记为$\alpha_J=1$。在单算子Bag语义下，期望TP/FP/FN为：
  $\mathbb{E}[\mathrm{TP}] = \sum_{i\in A\cup E} c_i p_i,\quad \mathbb{E}[\mathrm{FP}] = \sum_{i\in A} c_i(1-p_i),\quad \mathbb{E}[\mathrm{FN}] = \sum_{i\in R} c_i p_i$，
  其中$c_i$为决策$i$对最终输出的贡献（运行示例中即扇出$f_i$）。
- **谱系与贡献度计算**：多算子计划中，$c^\Pi(i)$表示在策略$\Pi$下因$i$被拒而丢失的期望真阳性输出数：$c^\Pi(i) = \sum_{o: i\in w(o)} \prod_{j\in w(o)\setminus\{i\}} q_j$，$q_j$为决策$j$正确的概率。无环连接树上可通过自顶向下消息传递在线性时间内完成逆传播。
- **目标反向定价（Lagrangian Decomposition）**：给定输出目标$T=(\rho,\gamma)$，引入乘子$\lambda_R,\lambda_P\ge 0$，每个实例独立求解：
  $a_i(\lambda) \in \arg\min_a\ C_i(a) + \lambda_R(\rho\cdot\mathrm{FN}_i(a)-(1-\rho)\cdot\mathrm{TP}_i(a)) + \lambda_P(\gamma\cdot\mathrm{FP}_i(a)-(1-\gamma)\cdot\mathrm{TP}_i(a))$。
  通过网格搜索乘子找到满足约束且期望成本最低的实例级策略。
- **Judge-to-Oracle转移**：实际中$Q^*(D)$不可观测，论文定义参考裁判$J$的评估结果$Q^J(D)$，并通过贡献加权误差界$\varepsilon_J$建立 judge-relative 与 oracle-relative 质量的转换保证。

## 实验与结果
- **工作负载**：合成查询（`Reviews` JOIN `Orders`），2000条评论；10%热门产品（扇出Uniform[50,400]），90%小众产品（扇出Uniform[1,8]）；模型分数$p$由Beta分布生成以保证校准。成本设定：决策调用=1，LLM升级=50，下游行=0.05；目标输出召回与精度≥0.9。
- **主要结果**：
  - **E1（PD不变性）**：固定带宽策略下Pushdown与Pull-up结果完全一致，差异仅在于成本（推下更优）。
  - **E2（PC非安全）**：算子级校准带宽下，Pushdown仅62%实例达标，Pull-up达96%，但成本高出71倍。
  - **E3（逐元组定价）**：实例级策略仅87次升级即可满足目标，成本7,164；算子级带宽需688次升级，成本37,256，**成本降低约81%**。
  - **E4（预测准确性）**：校准模型预测质量与真实质量平均误差约0.01；过自信模型误差约0.11，使用贡献加权PPI（100个金标）可降至0.03。

- **最强结果**：实例级定价策略在满足全局$(0.9,0.9)$目标下达到成本7,164，较全升级策略（102,817）降低约93%。

## 相关工作脉络
1. **NoScope / Tahoma / CORE / BlazeIt / SUPG**：面向视频/图像ML谓词提供单算子预算或代理筛选，未建模连接扇出误差传播，缺乏全局输出目标与计划等价分析。
2. **LOTUS / FrugalGPT**：支持单算子模型级联与准确率保证，但未考虑多算子联合下的质量组合律与物理计划搜索。
3. **Palimpzest / Abacus**：基于成本-质量Pareto前沿搜索物理实现，质量依赖 empirical 评估而非可解析的置信度预测。
4. **JEVDB**：当前最贴近的语义查询引擎，采用Flash固定阈值或Quality-controlled算子级升级带，默认下推；本文证明其在PC模式下下推非质量安全，且缺少输出级目标形式化。
5. **Larch / iPDB**：优化语义谓词执行顺序或延迟，但假设重排序不改输出质量（Larch）或仅针对延迟/成本（iPDB），均未建立置信度驱动的全局质量分解。
6. **Probabilistic Databases（Dalvi & Suciu等）**：本文质量估计的理论基础，继承tuple-independent模型的层次二分定理与证明多项式可解性。

# 论文速读：Neuro-Memory-Fuzzy-Inference-System-for-Mimicking-Human-like

## 一句话总结
本文提出NeMeFIS（神经记忆模糊推理系统），将五种人类记忆类型（程序性、工作、情景、语义、陈述性）映射到分层模糊推理子系统，实现对跟车行为中加速/减速的**非对称认知建模**，在异质交通流和迁移数据集（NGSIM、Argoverse 2）上均优于LR、ANFIS和LSTM基线。

## 研究问题与动机
1. **传统跟车模型缺乏认知心理建模**：GHR、IDM、Gipps等经典模型依赖刺激-响应框架，忽略驾驶员感知限制、风险权衡等心理过程（如Hamdar等引用Prospect Theory的尝试）。
2. **CAV行为缺乏"人性化"**：现有网联自动驾驶车辆多依赖规则或ML模型，缺乏对人类式情境感知、情感和社会影响的模仿，可能引发其他道路使用者的心理压力。
3. **已有ML方法可解释性不足**：LSTM、GRU等虽能编码时间记忆，但未显式分离不同记忆类型的作用，且对加速/减速的非对称性刻画有限。
4. **异质交通流的建模缺口**：孟加拉国等混合交通环境缺乏考虑车辆异质性和道路走廊差异的认知建模方法。

## 核心贡献（创新点）
1. **提出NeMeFIS分层认知架构**：首次将五种人类记忆类型（P/W/E/S/D）分别映射为独立FIS子系统，并通过C-FIS（合并记忆）集成，实现加速/减速的非对称建模——与ANFIS/LSTM的本质区别在于**显式认知解耦**而非隐式时序编码。
2. **建立外部变量与记忆类型的统计关联机制**：通过因子分析（Table 2）和p值检验（Table 3）验证9个外部变量（车间距、角度、风险感知等）对各记忆类型的归属，**为认知建模提供数据驱动的特征分配依据**。
3. **异质交通流与多走廊验证**：基于UAV（DJI Mini 2, 30 FPS）采集的孟加拉国达卡三类道路（Arterial/Collector/Rural Highway）轨迹数据，训练54种模型并覆盖8类车型，**验证了模型在复杂异质交通中的泛化能力**。
4. **数值模拟与迁移性验证**：在100秒仿真中验证轨迹稳定性（无FIFO违规、激波阻尼），并在NGSIM（US-101）和Argoverse 2（CAV）数据集上验证**架构迁移能力**，证明其跨场景适用性。

# 论文速读：RECAST-ATTRIBUTION-ORIENTED-STEP-REPRESEN-TATION-LEARNING-FO

## 一句话总结
本文针对大型语言模型（LLM）多智能体系统的故障归因问题，提出 ReCast 方法，将冻结 LLM 的内部隐藏状态转化为可用于归因的、具有区分能力的步骤表示，从而在多个基准上实现最优的根因定位性能。

## 研究问题与动机
- **核心问题**：在多智能体执行轨迹中，早期步骤的错误会导致失败影响在后续交互中传播，难以识别导致任务失败的“最早决定性错误”。
- **现有方法不足**：现有基于 LLM 内部信号的归因方法（如使用文本嵌入或最后层隐藏状态）对根因步骤与其他步骤的区分能力有限（如图 1 所示，ARS/GRS 高，SI 低）。
- **动机**：为了更可靠地调试和优化多智能体系统，需要一种能学习专门用于故障归因的步骤表示的方法。

## 核心贡献（创新点）
1.  **系统性研究步骤表示的判别能力**：首次系统性地量化评估了现有步骤表示（文本嵌入、隐藏状态）在多智能体故障归因中的分离效果，发现其存在局限。
2.  **提出 ReCast 框架**：提出了一种全新的步骤表示学习方法，通过归因感知层选择、互补模式与偏差特征构建、以及带对比和排序损失的编码器训练，生成归因导向的步骤表示。
3.  **构建 ReCast-2K 数据集**：提供了一个包含 1,044 条成功轨迹和 1,496 条失败轨迹的大规模训练数据集，支持归因模型训练。
4.  **卓越的基准性能**：在四个故障归因基准上均实现了最佳的 Hit@1 准确率，显著超越了现有基线方法。

## 方法详解
ReCast 方法分为三个阶段：
1.  **特征选择与构建**：
    - **隐藏状态提取**：使用冻结的 LLM（如 Qwen3.5-27B）对轨迹进行预填充，对每个模型动作步骤的 token 级隐藏状态进行平均池化，得到各层的步骤特征 `h^(l)`。
    - **归因感知层选择**：通过五折交叉验证，计算每个候选层隐藏状态中根因步骤与非根因步骤的差异向量，评估各层区分根因的能力，选取 k 个分布在不同深度的最优层。
    - **双分支投影**：使用固定的稀疏 Johnson-Lindenstrauss 投影矩阵，将选中的多层特征降维并构建两种互补特征：
        - **模式分支**：保留各层内部的相对激活模式。
        - **偏差分支**：计算步骤特征与所有成功轨迹特征均值之间的偏差，捕获与正常执行的偏离。
2.  **归因导向的步骤表示学习**：
    - **视图增强**：对投影后的轨迹特征进行两步式随机掩码和高斯噪声增强，生成两个对齐的视图。
    - **编码与评分**：使用双向 Transformer 编码器学习上下文化的步骤表示 `z`，并通过一个评分头 `g_ψ` 为每个步骤生成归因分数 `α`。
    - **损失函数**：
        - **根因对比损失 (L_root)**：以根因步骤的不同视图表示为正例，同一批次中所有非根因步骤表示为负例，使用 InfoNCE 损失。
        - **非根因对比损失 (L_non-root)**：选择根因前的步骤作为锚点，将其不同视图表示为正例，同轨迹的根因步骤表示为负例。
        - **列表排序损失 (L_rank)**：在轨迹级别对步骤归因分数进行排序，最大化根因步骤的概率。
        - **总损失**：`L = λ_rank * L_rank + λ_root * L_root + λ_non-root * L_non-root`。

## 实验与结果
- **数据集与基准**：在 Who&When (Algorithm & Handcrafted)、Who&When Pro、AFTraj-2K 和 TraceElephant (Captain & Magentic) 四个基准上评估。训练数据来自自建的 ReCast-2K。
- **评估指标**：主要报告 Hit@k (k=1,3,5)、MRR、AUROC 和 AUPRC。
- **主要结果**：
    - **Who&When**：ReCast 在 Algorithm 子集上 Hit@1 为 **45.43%**，超越最强基线 CHIEF (39.78%) **5.65 pp**；在 Handcrafted 子集上 Hit@1 为 **33.33%**，超越 CHIEF (24.14%) **9.19 pp**。
    - **TraceElephant**：在 Captain-Agent 上 Hit@1 为 **35.69%**，超越最强基线 ASCon (30.98%) **4.71 pp**；在 Magentic-One 上 Hit@1 为 **27.04%**，超越 ASCon (25.93%) **1.11 pp**。
    - **AFTraj-2K**：Hit@1 达到 **84.05%**，超越 Step-by-Step GPT (54.40%) 和 ASCon (83.03%)。
    - **Who&When Pro**：Hit@1 达到 **91.42%**，超越 Step-by-Step GPT (63.58%) 和 ASCon (82.71%)。
- **消融实验**：验证了层选择、双分支投影、编码器配置、数据增强和各项损失函数的有效性。去掉数据增强导致 Hit@1 下降 4.22 pp。
- **表示分离度分析**：学习后的 ReCast 表示在 ARS、GRS 和 SI 指标上均显著优于原始文本嵌入和隐藏状态表示。

## 相关工作脉络
1.  **黑盒归因方法 (CHIEF, FALAT, AgenTracer, AgentForesight, ASCon)**：基于可观测轨迹进行结构化推理或学习。ReCast 与之不同，它利用 LLM 内部信号并学习专门的表示，而非直接分析外部轨迹或文本。
2.  **白盒归因方法 (MASPrism, OAT, StepFinder)**：直接利用 LLM 内部信号（如 NLL、注意力、隐藏状态动态）。ReCast 通过表征学习将这些原始内部信号转化为更具区分力的归因导向表示，而非直接使用单一信号或建模成功动态。
3.  **现有基线对比**：与特征-based 基线（OAT, MASPrism, StepFinder, ASCon）和 LLM-based 基线（All-at-Once, Step-by-Step, CHIEF, AgenTracer）进行了全面比较，ReCast 在多种设置下均取得最佳或次优性能。

## 局限性与未来方向
- **局限性**：
    1.  当前方法主要聚焦于多智能体系统中的模型动作步骤，可能未完全涵盖工具调用等环境交互作为根因的情况。
    2.  性能与骨干 LLM 的大小并非简单单调正相关（小模型在部分基准上表现更好），存在权衡。
    3.  依赖于为特定 LLM 架构提取的隐藏状态，泛化到新架构可能需要调整。
- **未来方向**：扩展至更多样的错误类型和 Agent 架构；探索更高效的表示学习与提取方案；结合可解释性技术深入分析归因信号。

## 研究启发与可借鉴点
1.  **从原始信号到判别表示**：不仅直接使用 LLM 内部信号（如隐藏状态）进行归因，而是通过表征学习（对比学习、排序损失）将其转化为任务特定的判别表示，这一思路可迁移到其他需要利用内部信号的诊断任务。
2.  **互补特征构建**：同时利用“激活模式”和“与成功行为的偏差”两种互补信息来构建特征，这种思想可以应用于其他异常检测或因果发现任务。
3.  **系统性的评估框架**：提出了 ARS、GRS、SI 等指标来系统评估步骤表示的分离能力，为后续研究提供了可复用的评估基准和度量标准。
4.  **高效归因**：证明一旦特征被预计算，基于表示的模型可以实现毫秒级的推理，为在线调试或大规模轨迹分析提供了效率保障。

## 关键术语表
- **故障归因 (Failure Attribution)**：在多智能体执行轨迹中，识别导致任务失败的第一个决定性错误步骤的任务。
- **根因 (Root Cause)**：被定义为失败轨迹中最先出现的、若被纠正则会导致成功执行的步骤。
- **步骤表示 (Step Representation)**：用于表征轨迹中某个特定执行步骤的向量。
- **归因感知层选择 (Attribution-aware Layer Selection)**：通过探针评估 LLM 不同 Transformer 层对区分根因步骤与非根因步骤的能力，并据此选择最有用的层。
- **模式与偏差特征 (Pattern and Deviation Features)**：两种互补的特征：模式分支捕获步骤内部的激活结构，偏差分支捕获步骤与成功执行平均状态的偏离程度。
- **对比损失 (Contrastive Loss)**：通过拉近正例对（如同一步骤的不同增强视图）和推远负例对（如根因步骤与非根因步骤）来学习表示的损失函数。
- **排序损失 (Ranking Loss)**：直接优化根因步骤在轨迹内所有候选步骤中排名的损失函数。
- **Hit@1**：评估指标，表示根因步骤恰好被预测为排名第 1 的步骤的轨迹比例。

## 可复现要素
- **数据集**：
    - **ReCast-2K**：论文自建训练数据集（1,044 成功 + 1,496 失败轨迹），未声明公开，但代码仓库可能包含相关信息或构建脚本。
    - **基准**：Who&When, Who&When Pro, AFTraj-2K, TraceElephant 均为公开基准。
- **代码**：已开源，地址为 `https://anonymous.4open.science/r/ReCast-5FB6`。
- **关键超参**：
    - 骨干 LLM: Qwen3.5-27B。
    - 选择层数 k: 8。
    - 投影维度 d_p: 2,048。
    - 编码器：4 层 Bi-Transformer，隐藏维度 d_z=128。
    - 损失权重: λ_rank=1.0, λ_root=0.95, λ_non-root=0.25。
    - 温度参数 κ: 0.12。
    - 优化器: AdamW, lr=2e-4, batch_size=32, max_epochs=50。

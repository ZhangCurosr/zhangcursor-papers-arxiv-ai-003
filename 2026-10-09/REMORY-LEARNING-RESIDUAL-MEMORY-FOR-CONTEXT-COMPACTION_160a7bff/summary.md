# 论文速读：REMORY-LEARNING-RESIDUAL-MEMORY-FOR-CONTEXT-COMPACTION

## 一句话总结
本文提出 REMORY，一种为长程 Agent 上下文压缩设计的神经网络记忆模块；它在文本摘要后追加有界的软记忆 token（残差记忆），以反向 KL 散度在冻结的 LLM 上蒸馏训练，使模型在仅占用 5.2% 原始输入位置的情况下，仍能接近完整上下文的续写分布、源引用保真度与工具决策质量。

## 研究问题与动机
1. **长程 Agent 的上下文窗口瓶颈**：交互、工具输出与决策不断累积，Agent 必须压缩历史以继续运行；当前主流做法是用文本摘要替代早期片段，但摘要往往无法支撑后续每一个具体决策。
2. **纯文本摘要的信息损耗与动态相关性**：保留主线不保证覆盖所有决策细节，且随着任务推进，早期上下文对后续动作的“相关性”会动态变化，难以预先枚举需保留的信息。
3. **现有压缩/检索方案的不足**：纯检索依赖关键词匹配且无法弥合摘要与具体动作之间的语义间隙；纯连续压缩（如 AutoCompressor）丢失可读性检查点，不利于快速状态定位。
4. **类脑互补记忆系统的启发**：人类工作记忆有限但能长期完成复杂项目，依赖海马体索引与皮层分布式表征的协同；Agent 同样需要将显式文本检查点与可学习的神经软表征结合。

## 核心贡献（创新点）
1. **残差记忆架构**：将软记忆 token 作为摘要的序列维度残差连接追加其后，既保留可读的文本检查点，又通过连续向量弥合摘要之外的预测鸿沟。
2. **冻结 Actor 的两阶段蒸馏训练**：Stage I 用源码复现建立信息保真基线；Stage II 用摘要条件化的续写任务引导记忆聚焦于决策相关空隙，全程仅更新记忆网络参数 $\phi$。
3. **层级压缩与有界内存控制**：每 1024 个源位置生成 64 个软 token，通过层级压缩将最终记忆上限严格控制在 4096 槽，兼顾顺序保持与显存约束。
4. **多维统一评估体系**：在 SummHay 源引用、Terminal-Bench、BrowseComp 及工作流基准上验证了残差记忆对准确率、工具调用重复率与错误率的全面改善，并提出“压缩后首动作偏好”作为轻量代理指标。

## 方法详解
- **记忆构造**：在压缩边界 $i$，给定历史 $H_i$ 与新摘要 $S_i$，记忆网络输出 $M_i = \mathcal{C}_\phi(H_i; S_i)$，满足 $|M_i| \leq m$。Actor 实际读取的上下文为拼接序列 $[S_i; M_i]$，后续压缩边界可复用该结构。
- **网络实现**：基于 DFlash（适配 Qwen3.8-27B，1.94B 参数）或 DFlash-2（适配 GLM-5.3-Flash，1.502B 参数），使用冻结 Actor 的特征与可学习查询并行预测，并通过门控交叉注意力接收摘要条件。
- **Stage I（重建）**：教师输入完整源文本，学生用软记忆替代，共同复现源文本，使用 MMFineReason-Full-2.3M 文本字段，旨在建立记忆的信息保真能力。
- **Stage II（摘要条件化续写）**：教师输入完整交互历史，学生输入固定摘要+记忆，共同预测下一轮 assistant 回复，使用 Open-PerfectBlend 等推理/编码轨迹，并按前置上下文长度编排课程。
- **损失函数**：采用学生到教师的反向 KL 散度，加权覆盖整个词表与完整回复：
  $\mathcal{L}(\phi) = \frac{\sum_j w_j D_{\mathrm{KL}}(q_j \| p_j)}{\sum_j w_j}$，其中 $p_j = p_\theta(\cdot|C_{\mathrm{full}}, y_{<j})$，$q_j = p_\theta(\cdot|C_{\mathrm{mem}}, y_{<j})$。权重 $w_j$ 对较早位置轻度上偏，仅更新 $\phi$

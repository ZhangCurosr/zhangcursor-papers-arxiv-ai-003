# 论文速读：RISR - 残差信息引导的大语言模型科学方程发现

## 一句话总结
RISR提出了一种残差信息引导的两阶段符号回归方法，通过残差编码器将点态误差模式压缩为连续token引导LLM生成公式，并用双视角关系编码器预测修正操作的拟合效用，在LLM-SRBench科学基准上达到63.57% ID准确率（1%容差），显著超越同等规模基线。

## 研究问题与动机
- **聚合拟合分数的信息损失**：现有方法（如LLM-SR、SR-Scientist）使用MSE等聚合分数排序候选方程，但无法保留误差在输入空间的位置分布和变量依赖性，导致"同等损失、不同修正需求"的问题
- **残差模式的利用不足**：点态残差暴露非线性模式、变量交互和局部偏差，但如何将其编码为有效的搜索引导信号尚未被系统研究
- **修正选择的盲目性**：即使LLM能生成候选修正，也需要判断"哪些修正值得拟合"——这需要学习修正操作与当前方程状态、拟合结果的联合分布

## 核心贡献（创新点）
1. **残差信息公式搜索框架**：设计搜索残差编码器，将对齐的输入、目标、预测和残差压缩为16个连续token条件冻结LLM，与文本上下文互补——区别于纯文本prompt或聚合分数排序的方法
2. **双视角残差编码机制**：引入加性残差（$r_i$）和正则化乘性残差（$u_i = p_i r_i / (p_i^2 + \lambda^2)$）两种修正信号，建模同一残差状态下不同更新模式的补偿需求——这是本文对"修正语义"的形式化区分
3. **修正效用预测器**：基于共享关系注意力网络和学习评分头，预测候选修正在系数拟合后的训练损失提升效用，支持unary和product两种操作类型——区别于规则筛选或随机搜索
4. **合成数据构建策略**：从无变换初等函数生成三类合成数据集（残差-to-公式、结构编辑、配对修正效用），确保训练数据与benchmark方程解耦——避免预训练数据泄露污染评估

## 方法详解
**Stage A - 残差信息公式搜索**：
- 搜索残差编码器包含两条路径：点注意力路径（MLP嵌入→self-attention→cross-attention聚合）和谱域路径（122维特征提升：坐标变换、正弦/余弦频率、高斯残差中心池化）
- 两条路径通过 Learned gate 融合，经2048维投影器映射到Qwen嵌入空间，产生16个连续token
- 同时训练结构编辑生成器（预测add/replace/delete/stop动作），结合LLM采样共64个候选槽位，选MSE最低者作为初始方程$p_0$

**Stage B - 残差引导精修**：
- 双视角编码器：加性视角用$r_i/\sigma_y$，乘性视角用正则化信号$u_i$，各生成140维变量特征+140维pair特征，经 relation-attention 块编码为$h_j$
- 操作词表$\Phi = \{z, z^2, z^3, \sin z, \tanh z, \exp z, \log(1+z^2), (1+z^2)^{-1}\}$，支持单变量和一阶/二阶product动作
- 效用预测头$q_{j,k}$经变量-算子查询网络生成，Scorer输出$Q_\theta(D, p, a)$
- 系数拟合采用variable projection：固定非线性参数$(b_j, c_j)$后用加权最小二乘求解幅度$\alpha$和偏移$\beta$
- 自适应选择：每轮取最高分未尝试动作，拟合后若训练相对平方误差下降>0.1%则接受，最多4次尝试

**训练细节**：
- 搜索编码器：6000样本，AdamW lr=$2\times10^{-5}$（编码器）/$10^{-4}$（投影器），1 epoch
- 结构编辑：20000样本，10 epochs，lr=$2\times10^{-4}$
- 精修编码器：8192配对样本，16 epochs，lr=$3\times10^{-4}$，损失$\mathcal{L} = \mathcal{L}_{value} + 0.5\mathcal{L}_{rank} + 0.5\mathcal{L}_\Delta$

## 实验与结果
**数据集**：LLM-SRBench的LSR-Synth子集，25材料+36化学+24生物+44物理=129个问题，含ID和OOD测试集

**主要结果**（Qwen3-Coder-30B-A3B-Instruct backbone）：
| 指标 | RISR | 最佳同规模基线(SR-Scientist+RL) | 提升幅度 |
|------|------|-------------------------------|----------|
| ID Acc@1% | **63.57%** | 40.92% | +22.65pp |
| ID Acc@0.1% | **38.50%** | 20.69% | +17.81pp |
| OOD Acc@1% | **56.07%** | 39.50% | +16.57pp |
| OOD Acc@0.1% | 38.24% | - | - |

- 材料科学最强：ID 89.33%/OOD 84.00%（1%容差）
- 物理学科领先：ID 57.58%/OOD 50.76%（超越GPT-OSS-120B基线16.67pp）
- 符号准确率SA=13.18%（17/129），显著高于PySR(4.65%)、SR-Scientist(7.00%-7.75%)
- 消融验证：Stage A残差引导搜索将ID@1%从7.75%提升至36.43%；学习评分修正较随机修正再提升3.10pp

## 相关工作脉络
1. **符号回归传统方法**：PySR（多群体进化）、NeSymReS（Transformer预训练）、uDSR（风险寻求策略梯度）——RISR定位在"学习式"而非"搜索式"范式，但继承了对数值拟合的显式建模
2. **LLM引导符号回归**：LLM-SR（MSE分数+经验缓冲区）、SR-Scientist（agent+代码执行查残差）——RISR的核心差异是将残差编码为连续token直接condition LLM，而非仅作为agent输入
3. **程序搜索LLM**：FunSearch（LLM+进化搜索发现数学 conjectures）——RISR借鉴了"Evaluator-Buffer-Sampler"设计，但聚焦于符号回归的结构-数值耦合问题
4. **残差分析方法**：PINN中的残差监督、Sparse Identification中的残差阈值——RISR创新在于将点态残差压缩为结构感知token序列，支持跨变量交互建模

## 局限性与未来方向
- **合成数据分布偏移**：训练数据基于初等函数随机组合生成，可能与真实科学方程的复杂度/结构存在gap，影响OOD泛化
- **修正预算限制**：Stage B最多4次修正尝试，对于复杂方程可能不够；未探索动态预算分配
- **符号可解释性不足**：数值准确率高但SA仅13.18%，发现公式的物理意义仍需人工验证
- **变量数上限**：当前支持最多8变量，实际科学问题常涉及更多自由度
- **计算成本**：Stage A需64次LLM生成请求，对大规模应用仍较昂贵

## 研究启发与可借鉴点
1. **残差编码为连续token的条件生成**：可将此设计迁移至其他"结构搜索+数值拟合"耦合问题（如控制策略发现、动力学建模），用误差模式替代聚合分数作为LLM条件
2. **双视角修正语义建模**：加性vs乘性残差的区分启发了"修正类型感知"的设计，可在多尺度物理系统（如流体力学、量子化学）中验证其有效性
3. **合成数据解耦策略**：用初等函数变换生成训练数据而非直接使用benchmark，避免了数据泄露——此范式可推广至其他科学ML基准的公平评估
4. **配对状态效用学习**：共享observation cloud下的paired-state训练，使 scorer 学习"当前方程状态→修正效用"的条件分布，可迁移至主动学习中的acquisition function设计

## 关键术语表
- **Symbolic Regression (SR)**：从观测数据中自动发现显式数学表达式（含结构与系数）的回归方法
- **Pointwise Residual**：逐样本误差$r_i = y_i - p(x_i)$，保留误差在输入空间的分布模式
- **Dual-View Residual**：加性视图（直接拟合残差）与乘性视图（正则化相对调整）两种修正信号
- **Fitted Utility**：候选修正经系数拟合后，在held-out观测上的对数误差降低量
- **Variable Projection**：非线性最小二乘的分离优化技术，固定非线性参数后用线性最小二乘求解幅度
- **LLM-SRBench**：包含合成科学问题的符号回归基准，覆盖材料/化学/生物/物理四领域

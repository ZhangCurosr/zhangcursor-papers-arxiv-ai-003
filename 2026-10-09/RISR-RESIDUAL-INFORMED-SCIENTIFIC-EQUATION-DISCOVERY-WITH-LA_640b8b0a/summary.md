# 论文速读：RISR-RESIDUAL-INFORMED-SCIENTIFIC-EQUATION-DISCOVERY-WITH-LA

## 一句话总结
RISR 是一种残差信息引导的两阶段符号回归方法，通过残差编码器将点态误差模式编码为连续 token 以指导冻结的 LLM 生成公式，并利用双视角关系编码器预测候选修正的拟合效用，在 LLM-SRBench 科学方程发现基准上实现了优于同尺度及更大尺度骨干模型的精度。

## 研究问题与动机
1. 符号回归需同时探索表达式结构与数值系数估计，两者紧密耦合：结构项的价值取决于其拟合系数及其与方程其余部分的组合方式。
2. 现有 LLM-based SR 方法（如 LLM-SR、SR-Scientist）依赖聚合拟合得分（如 MSE）排序候选方程，但聚合得分不保留误差的位置信息和变量依赖性，相同整体损失的方程可能需要不同的结构修正。
3. 如何将点态残差的数值状态有效编码为公式生成条件，并学习预测哪种修正值得拟合，是当前方法未充分解决的问题。
4. 需要在不使用更大 LLM 骨干的前提下，仅通过改进残差信息利用方式实现更高的方程发现精度。

## 核心贡献（创新点）
1. **两阶段残差信息引导框架**：Stage A 通过搜索残差编码器将输入、目标、预测和残差压缩为 16 个连续 token 以条件化 LLM 公式提议；Stage B 通过双视角编码器学习修正效用预测，二者均独立于基准方程进行合成数据训练。与仅用聚合得分排序的基线方法的本质区别在于利用了点态误差的空间模式。
2. **加性/正则化乘法双视角残差编码**：提出加性视图（直接使用残差 r）和正则化乘法视图（u = pr/(p²+λ²)，λ 为预测 RMS 的 5%），捕捉不同修正信号的变量特异性模式与交互关系。与单一残差表示的本质区别在于区分了绝对修正与相对修正两种物理意义不同的校正方向。
3. **合成数据驱动的分组件离线训练**：搜索编码器、结构编辑器、精炼编码器均在随机变换/组合基础函数生成的合成数据上独立训练，保持 LLM 参数冻结；精炼模块使用训练集/效用集的割裂数据度量拟合后效用。与端到端微调 LLM 的方法的本质区别在于解耦了公式生成能力与数值反馈理解能力。

## 方法详解
**Stage A — 残差信息引导的公式搜索**：
- **文本上下文**：每个 prompt 包含从候选池采样的方程程序，最高分方程作为父方程用于数值条件化。
- **搜索残差编码器**：处理对齐元组 (x_i, y_i, p(x_i), y_i - p(x_i))，包含两条路径——点注意力路径（聚合观测）和谱-场路径（使用频率特征和残差区域池化表示坐标-残差交互），经可学习门控融合后投影为 16 个连续 token（嵌入 Qwen 空间），与文本上下文共同条件化冻结 LLM 的公式提议。
- **结构编辑器**：结合残差编码器与公式 AST 编码，预测添加/替换/删除/停止动作，输出的公式 p₀（最低 MSE）初始化下游精炼。

**Stage B — 残差引导的精炼**：
- **双视角残差编码**：加性视图使用 r_i = y_i - p_i；乘法视图使用正则化信号 u_i = p_i·r_i / (p_i² + λ²)，避免 p_i ≈ 0 时的数值不稳定。两视图共享嵌入网络和两个关系注意力块（基于 attention-based set encoding），为每个变量生成表示 h_j。
- **修正效用预测**：候选动作为加性/乘法更新 × 单变量/双变量 × 8 种算子族 Φ = {z, z², z³, sin z, tanh z, exp z, log(1+z²), (1+z²)⁻¹}，共享评分头预测拟合效用 Q_θ(D, p, a)。
- **系数拟合与自适应更新**：使用变量投影法（variable projection）拟合非线性参数（固定 b_j, c_j 后加权最小二乘求 α, β），修正使训练相对平方误差降低 >0.1% 时被接受，精炼最多 4 次尝试且不再调用 LLM。

**训练**：三部分组件分别使用合成数据离线训练，LLM 全程冻结；精炼损失 = L_value + 0.5·L_rank + 0.5·L_Δ（价值回归 + 排序 + 配对状态差异匹配）。

## 实验与结果
- **数据集**：LLM-SRBench（LSR-Synth 子集），含 25 材料科学 + 36 化学 + 24 生物学 + 44 物理学 = 129 个科学问题，每个问题含训练集及分离的 ID/OOD 测试集。
- **评估指标**：Pointwise relative error 容差 τ 下的任务通过率（Pass_τ = 1[≥95% 样本满足 |ŷ_i - y_i|/|y_i| ≤ τ]），报告 τ=1% 和 τ=0.1% 两种精度。
- **骨干模型**：Qwen3-Coder-30B-A3B-Instruct（参数冻结）。
- **主要结果（ID）**：RISR 取得 **63.57%（1%）** 和 **38.50%（0.1%）** 整体精度，超越同骨干最强基线 SR-Scientist+RL（40.92%/20.69%）分别 **+22.65pp / +17.81pp**；1% 容差下与 GPT-OSS-120B 的 SR-Scientist（63.57%）持平。
- **主要结果（OOD，1%）**：RISR 达 **56.07%**，超越 SR-Scientist+RL（39.50%） **+16.57pp**；材料科学达 84.00%，物理学达 50.76%。
- **领域最强**：材料科学 1% ID 达 89.33%（全基线最高）；物理学 1%/0.1% 均达 57.58%/40.91%（超越 120B 模型）。
- **符号准确率（SA）**：13.18%（17/129），超过所有对比方法（次高为 SR-Scientist@480B 的 7.00%）。

## 相关工作脉络
1. **传统符号回归**（DSR/uDSR/PySR/NeSymReS）：通过进化搜索或神经网络学习公式空间；RISR 与之区别在于不依赖遗传编程或蒙特卡洛树搜索，而是用残差编码直接条件化 LLM 生成。
2. **LLM-SR**（Shojaee et al., 2025a）：使用预训练 LLM 提议公式并通过 MSE 排序经验缓冲；RISR 进一步利用点态残差模式而非仅聚合得分进行数值条件化。
3. **SR-Scientist**（Xia et al., 2026）：通过 agent 代码执行分析数据和残差；RISR 与之不同在于将残差直接编码为连续 token 注入 LLM，而非通过自然语言描述供 agent 解读，且不需要额外推理调用。
4. **FunSearch**（Romera-Paredes et al., 2024）：结合进化搜索与 LLM 的程序发现框架；RISR 将残差条件化机制嵌入公式生成阶段，并增加了结构编辑器和精炼阶段。
5. **LaSR**（Grayeli et al., 2024）：学习文本概念库引导搜索；RISR 不依赖概念库，而是学习数值残差到公式的空间映射。
6. **TPSR**（Shojaee et al., 2023）：用 MCTS 将拟合精度和复杂度纳入 Transformer 解码；RISR 采用两阶段分离策略，精炼阶段无需额外 LLM 调用。

## 局限性与未来方向
1. **合成数据泛化**：各组件在合成数据上训练，与真实科学数据分布存在差距，可能影响跨领域泛化能力。
2. **物理约束缺失**：方法未显式整合物理守恒律或对称性等先验知识，纯数据驱动寻找公式。
3. **变量维度上限**：当前编码器设计支持最多 8 个变量（填充+掩码），高维科学问题需额外处理。
4. **符号恢复率仍有提升空间**：SA 仅 13.18%，表明多数情况下找到的是数值等价但结构不同的近似公式。
5. **精炼预算固定为 4 次**：无法自适应不同问题的复杂程度，可能过早终止或浪费步数。

## 研究启发与可借鉴点
1. **残差→连续 token 的条件化范式**：将点态误差压缩为固定数量连续向量注入 LLM embedding 空间（prefix-tuning 风格），可为任何基于 LLM 的程序/公式生成任务提供数值反馈接口，具有高度可迁移性。
2. **双视角残差表示（加性/乘法）**：针对同一残差状态构造两种不同物理语义的校正信号，并共享关系编码器参数，这种"一对多视图+共享表示"设计可推广至其他数值拟合与修正选择任务。
3. **合成数据独立训练+主干冻结**：三个子模块分别在专用合成数据上训练，LLM 完全不微调，此解耦训练策略可避免灾难性遗忘并降低计算成本，适合需要多次迭代的搜索系统。
4. **训练/效用数据集割裂的效用监督**：将观测分为 fitting 集和 utility 集，在 utility 集上衡量修正后的泛化效果作为学习目标，可有效避免过拟合训练数据，该设计可直接迁移至任何需要评估候选动作长期价值的搜索框架。

## 关键术语表
**Symbolic Regression（符号回归）**：从观测数据中发现显式数学表达式（而非黑盒数值模型）的回归任务，需同时搜索表达式结构与拟合系数。
**Pointwise Residual（点态残差）**：每个观测点上真实值与当前预测值的差 r_i = y_i - p(x_i)，反映误差在输入空间中的分布模式。
**LLM-SRBench**：专为评估 LLM 科学方程发现能力构建的基准，由领域专家验证，包含材料、化学、生物、物理四类问题的合成加噪声观测数据。
**ID/OOD Accuracy**：In-Domain/Out-of-Domain 准确率，分别在训练域内和分布外测试集上评估发现方程的预测精度。
**Variable Projection（变量投影）**：针对含线性和非线性参数的模型，固定非线性参数后用加权最小二乘解析求解线性参数的高效拟合算法。
**Dual-View Residual（双视角残差）**：同一误差状态分别用加性（直接残差）和正则化乘法（u = pr/(p²+λ²)）两种视角表示，捕捉不同修正模式的信号。
**Fitted Utility（拟合后效用）**：修正动作在系数拟合后于 Held-out 数据集上的对数误差缩减量，衡量该动作的泛化价值。
**Symbolic Accuracy（符号准确率，SA）**：评估发现公式是否在常数赋值意义下与目标公式结构等价，而非仅数值拟合。

## 可复现要素
- **数据集**：LLM-SRBench（LSR-Synth 子集）为公开基准；论文声明将公开发布合成数据集（residual-to-formula、structural edits、paired correction utility）及代码。
- **代码/权重**：论文声明 "we will publicly release the synthetic datasets and the code for data generation, model training, equation search and refinement, and evaluation"（将在发布时开源）；未提供预训练编码器权重。
- **关键超参**：LLM = Qwen3-Coder-30B-A3B-Instruct（冻结）；Stage A 最多 64 次候选提交；Stage B 最多 4 次修正拟合尝试；正则化参数 λ = 5% × RMS(prediction)；精度阈值 0.1%；编码行数 256；学习率 3×10⁻⁴（精炼）、2×10⁻⁵/10⁻⁴（搜索编码器）；训练 16 epochs（精炼）/1 epoch（搜索）/10 epochs（编辑器）。

# 论文速读：Same-Outcome-Different-Evidence-Intent-Recovery-in-LLM-Safet

## 一句话总结
本文针对大语言模型安全评测中仅依赖攻击成功率（ASR）无法区分“未介入有害任务”与“识别并拒绝有害任务”的归因模糊问题，提出将操作型理解率（UR）与ASR联合报告的IRIS协议，实证表明相同ASR在不同意图隐藏接口下可对应截然相反的任务交互状态，联合指标能更准确地量化模型真实安全行为。

## 研究问题与动机
- 现有安全评测基准（如HarmBench、JailbreakBench、StrongREJECT等）主要用ASR汇总有害输出行为，但相同的“无害结果”可能源于完全不同的成因：模型可能成功恢复任务并拒绝，也可能完全未识别任务，或转而回答其他问题。
- 在意图隐藏提示（低资源语言、密码、ASCII艺术、形式逻辑等）下，低ASR无法揭示被测任务是否被真正 engages，导致评测结果被系统性高估或误读。
- 防御侧研究（如回译、显式意图分析）已明确将“意图恢复”与“安全响应”拆分为两个阶段，但评测体系仍沿用黑盒ASR，缺乏前置归因信号。
- 需要一种可计算的中间指标，区分“真正的防护”与“任务未被有效评估”，从而为安全评测提供更精细的证据强度。

## 核心贡献（创新点）
- 提出操作型理解率（UR）作为意图恢复的中间信号，弥补ASR仅统计有害输出而忽略任务是否被真正介入的归因缺陷。与已有工作相比，本质区别在于从下游结果度量转向上游任务交互度量的前置归因视角。
- 构建IRIS联合报告协议并给出形式化定义，证明相似ASR在不同接口下可对应差异极大的恢复率，揭示单一指标的安全误判风险。与已有工作相比，本质区别在于将UR与ASR定位为互补归因对而非替代性安全评分。
- 设计T1→T3受控渐进显式重构实验，证明提升提示显式性能稳定提高UR，但ASR变化轨迹因模型而异，说明任务恢复与安全行为可独立演化。与已有工作相比，本质区别在于通过冻结语义核心的对照实验剥离显式性对恢复与安全的独立效应。
- 开源包含匹配行为、恢复标注、重构控制与跨接口安全评测的完整可复现流水线与人工审核数据集。与已有工作相比，本质区别在于提供可直接复现的IR/IS/SO三分归因框架与多接口对照材料。

## 方法详解
- **IRIS联合报告协议**：定义 $UR = P(\text{operative task recovered})$，$ASR = P(\text{harmful assistance})$。两者不互相替代，UR为ASR提供归因上下文：低ASR在UR高时表明真正的事后安全拒绝，在UR低时则难以归因于任务感知防护。
- **IR/IS/SO 三分标注体系**：IR（0/1/2）衡量目标有害任务的核心意图、对象与方向是否被实质性识别；IS（NA/M/R/B）区分响应框架是否保持目标任务（NA）、转为翻译/语言分析（M）、偏移至其他非目标框架（R）、或被屏蔽/空输出（B）；SO（0-3）衡量有害协助程度。操作型UR要求联合事件 $IR=2 \wedge IS=NA$，即模型识别任务且仍将其作为待回答目标（含任务感知拒绝与安全替代方案）。
- **受控英语重构（T1–T3）**：以Toki Pona压缩提示为语义核心，T1仅修复语法保留歧义，T2显式化支持参与的语义角色，T3将语用关系解析为自然请求；全程禁止引入源文本未支持的攻击脚手架或更强指令，用于隔离“显式性”对恢复率的因果影响。
- **评估与统计设置**：使用105条跨接口可比行为，覆盖EN、Toki Pona、Zulu、Yoruba、CaesarCipher、FormalLogic、ArtPrompt七种接口；采用Mistral-large-2512作为canonical judge（260 token预算，关闭thinking），结合独立人工双盲标注计算Cohen's κ与95% bootstrap区间，T1–T3配对差异采用双侧精确McNemar检验并施加Holm校正。

## 实验与结果
- **数据集与基线**：105条去重有害行为（源自HarmBench、StrongREJECT、JailbreakBench），评测GPT-4o、Claude Sonnet 4.5、Claude Opus 4.5、Gemini 3 Flash、DeepSeek V3.2、Qwen3-Max六大模型；英语直接请求作为显式基线。
- **跨接口对比**：英语基线下所有模型UR≥97.1%、ASR<3%。Toki Pona接口UR断崖式下降（GPT-4o仅15.2%），但ASR仍低至2.9%；更关键的是，GPT-4o在Toki Pona与CaesarCipher下ASR同为2.9%，UR却分别为15.2%与96.2%，直接揭示单一ASR的严重归因盲区。
- **重构实验**：T1→T3渐进显式化后，所有模型的UR均显著提升，单模型最大提升幅度达41.0个百分点（Opus 4.5，T1 52.4%→T3 93.3%，$p_{Holm}=1.57\times10^{-11}$），而ASR变化方向因模型而异，证明恢复率对提示显式性高度敏感且与下游安全行为解耦。
- **最强结果与结论**：Qwen3-Max在FormalLogic接口达到最高UR（96.2%）与相对可控的ASR（24.8%）；Gemini 3 Flash在Toki Pona下UR达72.4%且ASR为56.2%，表明高恢复仍可与高频有害协助共存。核心结论为非有害输出并非同等安全证据，UR+ASR联合报告能更准确刻画不同接口下的模型安全剖面。

## 相关工作脉络
- HarmBench / JailbreakBench / StrongREJECT / SORRY-Bench：主流安全评测基准以ASR或拒绝率为核心指标，本文指出其在意图隐藏场景下缺乏对“任务是否被恢复”的前置归因，UR填补了这一测量空白。
- ArtPrompt / Low-Resource Language Attacks / Cipher Jailbreaks：利用视觉或语言形式扭曲提示，本文将其作为意图隐藏压力的测试床，强调此类攻击的实际效果不仅取决于安全绕过，还高度依赖模型的任务恢复能力。
- Backtranslation & Intention Analysis 防御路线：防御侧已明确分离意图恢复与安全响应两个阶段，本文主张评测体系应对齐该分离视角，从黑盒ASR转向可归因的中间信号。
- JADES等响应端分解框架：侧重有害协助的拆解评分，本文从上游“任务介入度”补充视角，强调“模型是否在回应正确的问题”是解释ASR的前提条件，二者构成互补的评测层次。

## 局限性与未来方向
- 105条面板为满足跨接口可比性进行了严格筛选，难以完全代表真实攻击分布与更广泛的低资源语言/多模态场景。
- UR高度依赖标注规则与Judge设定，不同读者对“任务感知拒绝”与“元语言分析”的边界判定存在主观差异，Cohen's κ仅为0.29–0.63。
- T1–T3实验控制了语义核心，但未完全隔离“显式性提升”与请求形式微调的独立贡献，需进一步的正交对照实验。

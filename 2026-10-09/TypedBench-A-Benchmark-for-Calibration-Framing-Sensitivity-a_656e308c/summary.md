# 论文速读：TypedBench-A-Benchmark-for-Calibration-Framing-Sensitivity-a

## 一句话总结
论文提出 **TypedBench**，一个针对非生成式 System One 决策模型（如 Jev）的综合评测基准，通过七个政策标注的程序化生成器和九个评估套件，系统性衡量模型在准确率、校准误差、措辞鲁棒性、选项扩展性、序数一致性和不对称代价矩阵下的决策价值。

## 研究问题与动机
- **校准声明缺乏可验证依据**：已发布的 System One 模型（如 Jev）以"概率校准"为卖点，但现有评估仅报告 Top-1 准确率，没有与真实标签对比的校准指标。
- **测评基线不匹配**：公开评测将模型与另一个 LLM 取平均比较（而非真实标签）；部分开源模型使用了在基准训练集上微调的检查点，存在数据泄露风险。
- **措辞敏感性未被充分度量**：独立测试显示，同一规则重写后 Jev 准确率波动高达 33 个百分点；现有评测未提供措辞变化的结构化对照。
- **成本驱动的决策使用方式被忽视**：下游系统通常根据阈值、代价矩阵和拒绝规则使用这些概率，但现有工作未评估"用概率做决策 vs. 用 argmax 做决策"的真实成本差异。

## 核心贡献（创新点）
1. **政策驱动的程序化标注基准**：七个生成器产生全新题目，标签由显式规则推导而非人工标注，完全规避训练集污染，区别于所有使用公共数据集的既有基准。
2. **校准误差相对于有限样本噪声底的度量**：将 ECE 与同置信度直方图下完美校准预测器的期望 ECE（null ECE）相比，量化"超出随机水平的额外校准误差"，而不仅是报告绝对 ECE 值。
3. **九套评估套件覆盖决策全流程**：从单题校准、措辞稳定性、选项/上下文扩展、鲁棒性、多问题互扰、序数一致性到不对称代价决策价值，首次在同一批题目上横向比较三种架构。
4. **发现概率并非总是优于 argmax**：在优先级问题上，Jev 和 Kev-9B 的最准模型，使用概率做 Bayes 决策反而比取 argmax 成本更高——揭示校准质量与决策价值之间的非单调关系。
5. **三种架构失败维度互补**：托管模型弱点在措辞敏感和系统性欠置信；编码器弱点在结构复杂度和选项数增长时崩溃；解码器在延迟和部分策略应用上存在问题，三者可作为混合路由互补组件。

## 方法详解

**程序化生成器与标签推导**：每个题目模板显式标注决定标签的底层事实（如是否涉及金钱、是否为阻塞性事件），标签由模板中的政策规则**确定性计算**得到，不依赖人工判断。两阶段审计：(1) 自动化单元测试验证标签与规则逻辑一致；(2) 前沿 LLM 抽样验证题目无歧义。

**对照臂（Control Arms）**：将伪随机性分割为内容和对照两个独立流，确保每个压力测试变体与干净基线项一对一配对，包含五种扰动：
- **不可知（unknowable）**：移除某关键背景，使两个级别同等合理
- **标签噪声（label noise）**：5% 的标签被破坏
- **干扰项（distractors）**：注入 0.25 或 0.5 密度的无关行
- **无正确答案（none-correct）**：隐藏真实选项
- **表面扰动**：大小写变换、空格移位、2%–5% 拼写错误、西里尔同形字符

**多措辞评估**：每道题通过规范措辞、五个同义改写、三个标准变体（仅标签/含否定定义/故意模糊）、对抗性措辞和选项描述交换等条件评估；报告友好措辞的中位准确率和 [min, max] 区间，逐一报告每条对抗措辞。

**校准度量**：使用 Top-label ECE（15 等宽分箱）、平滑校准误差、Brier 分数和 NLL；ECE 与有限样本噪声底（通过对 $y_i \sim \text{Bernoulli}(c_i)$ 重采样 200 次得到）之比 ECE/null 为关键指标；温度 $T$ 在一半数据上通过 NLL 拟合，$T>1$ 表示过置信。

**序数度量**：使用二次加权 kappa、排序概率得分（RPS）、期望水平单调性（沿受控严重程度阶梯）、Spearman 一致性（跨 3/5/10 级量规）。

**决策价值**：定义代价矩阵 $C$，比较 argmax 策略与 Bayes 策略（$\arg\min_j \sum_t p_t C_{tj}$）在每 $10^4$ 次决策下的实现代价，$\text{value} = \text{cost}(\text{argmax}) - \text{cost}(\text{Bayes})$，正值说明使用概率带来收益。

**统计检验**：题目级配对 bootstrap（10,000 次重采样）和 Holm 校正的 McNemar 检验；$n=500$ 时准确率约 0.5 的 95% 区间约为 ±4.4 个百分点。

## 实验与结果

**评估模型**：Jev 1.13.0（托管）、Laya 0.3.4 的两个检查点（421M ModernBERT 编码器，English / typed-decisions）、Kev 0.8B/4B/9B（基于 Qwen3.5 的 LoRA+ 指针头， bf16），均在同一 NVIDIA GB10 上运行。

**主要准确率结果（tickets.priority 政策应用题）**：
| 模型 | 中位准确率 | 范围 | ECE/null | 备注 |
|---|---|---|---|---|
| JEV 1.13.0 | 0.874 | [0.708, 0.946] | 2.2–3.3 | 措辞敏感，24 点跨度 |
| KEV-9B | 0.565 | [0.476, 0.660] | 2.8 | 最优解码器 |
| KEV-4B | 0.446 | [0.382, 0.528] | 2.8 | |
| LAYA typed-dec. | 0.383 | [0.347, 0.412] | 1.3 | |
| LAYA english | 0.343 | [0.220, 0.372] | — | |
| 多数先验 / regex | 0.338 / 0.356 | — | — | 蒸馏 BERT 可达 1.000 |

**校准发现**：几乎所有模型/题目的 ECE 均高于噪声底；方向因模型和题目而异：Jev 系统性欠置信（全部温度重拟合 $T<1$），编码器在错题上大多过置信。

**措辞敏感性**：Jev 在 priority 题上最大跨度 **24 个百分点**；编码器的 English 版 15 点、typed-dec. 版 7 点。对抗性措辞进一步拉低准确率。

**扩展性**：选项数增至 255 时，Jev 几乎精确且延迟不变；Kev-4B/9B 保持精确但延迟升至数秒；Kev-0.8B 退化；两个编码器在 100 个选项前即崩溃至接近零。长输入（30k tokens）时，Jev 准确率不变，编码器静默截断。

**代价决策分析（tickets.priority，下优先级代价是上优先级的 2 倍）**：
| 模型 | argmax 代价 | Bayes 代价 | 值 |
|---|---|---|---|
| JEV | 1,080 | 2,300 | **−1,220** |
| KEV-4B | 8,980 | 5,000 | **+3,980** |
| KEV-9B | 4,780 | 7,960 | **−3,180** |
| 恒答 level 2 | 12,120 | — | — |

**最强结果**：Jev 在绝大多数单题任务上准确率最高（queue/anger/urgency 近 1.000），但在 policy priority 上最大跨度 24 点；Kev-4B 在 Bayes 决策下获 **最大节省 +3,980** 代价。

**混合路由（Suite H）**：将编码器低置信回答提升至 Jev，可快速缩小准确率差距；但对单题请求，一次 Jev 调用已占满请求成本的 41%–46%，因此提升策略的实际性价比需仔细核算。

## 相关工作脉络

1. **BTZSC（Aarab, 2026）**：评估 38 个检查点的零样本分类，但复用公共数据集且仅报告准确率，未评估概率质量；TypedBench 以政策推导标签和概率评测为区别。
2. **KalshiBench（Nel, 2025）**：在预测市场结果上评估校准，聚焦生成式模型的口述置信度；TypedBench 评估原生输出 typed 分布的模型并报告有限样本噪声底。
3. **PromptSET（Razavi et al., 2025）**：确立措辞为 LLM 行为方差的重要因素；TypedBench 在无自由文本答案的系统一模型上提供更干净的措辞敏感性度量。
4. **UCCI（Kotte, 2026）**：证明校准级联路由可在固定 F1 下降低成本 31%；TypedBench 离线评估相同代价权衡，并揭示"最准模型的概率可能不如 argmax"的反直觉结论。
5. **Prior shift 工作（Choi, 2026）**：研究标签分布偏移下的校准；TypedBench 首次在决策模型上测量 prior shift（愤怒问题基率从 0.2→0.8）下的行为差异。
6. **KalshiBench 及 de Oliveira et al.（2025）**：发现生成式模型有 24–47% ECE；TypedBench 指出这些工作均报告 verbalised/token-level 置信度，未涉及 native typed 分布且未提供 ECE 噪声底对照。

## 局限性与未来方向

- **自然性与精确性之间的权衡**：所有题目为模板生成，状态非原生文本，导致微调编码器可解决所有问题，无法反映真实流量分布。
- **缺少原生文本 + 人工标注的混合层**：论文提出 manifest schema 已支持此扩展，但未在当前版本中实现。
- **难度梯度有限**：当前政策为产品团队指定的单层规则（如查找表、双字段规则）；多步规则、数值条件、冲突证据和分级答案等更复杂策略尚未纳入。
- **架构评估范围受限**：仅评估了 6 个公开可用的检查点，未涵盖更多 System One 候选模型。

## 研究启发与可借鉴点

1. **ECE 噪声底对照方法可迁移**：使用有限样本重采样构建 null ECE 并报告比值 ECE/null，避免了不同题目间 ECE 绝对值不可比的问题，值得在自身校准研究中复用。
2. **政策推导标签的生成范式**：用显式规则计算标签并辅以自动化单元检验 + LLM 抽样审核的两阶段审计流程，为构建无污染评测基准提供可复用的工程模板。
3. **代价矩阵驱动的评价视角**：将决策价值（argmax vs. Bayes 成本差）作为核心指标而非仅准确率/校准，揭示"最准≠最好"的部署现实，可作为本团队在下游决策任务中的评估补充维度。
4. **三维度互补模型设计启示**：托管模型/编码器/解码器在措辞稳健性、结构扩展性和延迟上各有短板，互补组合可指导后续混合路由架构的设计，以及"何时应使用概率、何时应直接取 argmax"的决策原则。
5. **多措辞报告规范**：报告中位准确率 + 范围 + 对抗措辞分开展示的方式，可为团队在 prompt 鲁棒性评测中建立标准化报告范式。

## 关键术语表

**System One 模型**：源自双重加工心理学，指快速、自动、非生成本文输出的决策模型，直接返回候选答案的概率分布。
**Policy-labelled generator**：通过显式政策规则程序化生成题目并推导标签的生成器，避免人工标注的主观性。
**ECE/null**：预期校准误差与同置信度直方图下完美校准预测器的期望 ECE（有限样本噪声底）之比，用于衡量超出随机水平的额外校准误差。
**Selective prediction**：利用置信度阈值控制接受预测的比例，以 Risk–Coverage 曲线和 AURC 评估"只回答高置信题目"时的错误率。
**Ordinal proper scoring rule**：对有序类别答案给出部分奖励的评分规则，包括二次加权 kappa 和排序概率得分（RPS）。
**Asymmetric cost matrix**：不同错误类型具有不同代价的决策代价矩阵，用于衡量 Bayes 策略相对于 argmax 策略带来的实际成本节约。
**Hybrid routing**：将低置信度的本地模型回答提升至托管模型的级联路由策略，以精度换取成本。
**Argmax flip rate**：同一题目在不同措辞下 argmax 答案发生变化的比例，用于量化措辞敏感性。

## 可复现要素

- **数据集**：TypedBench 基准由程序化生成，论文提供种子 42 及 manifest 文件，可通过代码复现；**开源**（见附录及 GitHub 链接）。
- **代码/权重**：Kev（Apache-2.0，GitHub: jaredpalmer/kev）和 Laya（Apache-2.0，HuggingFace: convaiinnovations/laya）为开源权重；Jev 为托管 API，**未开源**。
- **关键超参**：DistilBERT 微调 lr=$5\times10^{-5}$，batch=32，epochs=2；Kev LoRA rank=16；所有模型 bf16；温度 T 通过 NLL 拟合；选项数扩展实验中 K=2–255，每级 n=150；主实验 n=500/题目。
- **硬件**：NVIDIA GB10（128GB 统一内存）。
- **统计检验**：配对 bootstrap 10,000 次，Holm 校正 McNemar 检验。

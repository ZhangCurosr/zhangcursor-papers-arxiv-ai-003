# 论文速读：Reset-Early-Reset-Often-Eliminate-Models

## 一句话总结
本文提出 SATResetCoP，一种将连接表证明与增量 SAT 求解器深度耦合的新型策略。该方法打破传统“回溯闭合表”的范式，转而在表扩展失去进展时激进重置表结构、保留已累积的基元子句状态，使表真正沦为子句生成器，从而在 TPTP 与 MPTP2078 基准上显著提升了一阶定理证明效率。

## 研究问题与动机
- 连接表证明器通常依赖回溯搜索构建闭合表，失败尝试留下的轻量搜索状态几乎无法复用，导致大量计算浪费在已验证无效的路径上。
- 已有改进路线（leanCoP、meanCoP、hopCoP 等）主要聚焦于剪枝与限制回溯，未能从根本上改变“表状态易失”的缺陷。
- SATCoP 虽首次将增量 SAT 求解器引入连接表，利用基元化子句提前检测命题不可满足性，但其仍沿用传统回溯机制，在无效分支上继续消耗步数，未能充分利用已持久化的 SAT 状态。
- 核心动机：既然 SAT 状态已持久保留，是否应当放弃对低效分支的回溯，转而让连接表以“激进重置”的方式快速生成更多基元子句，由 SAT 求解器承担最终的命题判据？

## 核心贡献（创新点）
1. **提出 SATResetCoP 激进重置策略**：在活跃表停止产生新基元子句时清空表结构并开启新树，而非继续局部回溯。与 SATCoP 的本质区别在于将表的角色从“搜索闭合主体”降级为“子句生成器”，把证明决策重心完全转移至持久化 SAT 状态。
2. **设计基于 SAT 模型的表扩展排序机制**：利用当前 SAT 赋值引导 Start/Extension/Reduction 的选择优先级，优先扩展当前命题模型中为真的字面量。与传统依赖 Prolog `cut` 的剪枝不同，该机制直接利用命题层反馈动态重塑一阶搜索路径。
3. **统一后端下的公平对比验证**：基于 Connections 库与 CaDiCaL 在同一引擎上实现并对比 leanCoP^Con、SATCoP_0^Con、SATCoP^Con 与本文策略，消除了底座差异，明确归因于搜索策略本身的性能增益。
4. **揭示重置策略的搜索空间取舍效应**：证明激进重置并非简单加速原有搜索，而是系统性改变搜索分布；在基元子句能快速累积的类别中提升显著，同时在需要长路径的类别中产生可预见的损失，为后续调度研究提供实证依据。

## 方法详解
- **持久化增量 SAT 状态**：维护一个 CaDiCaL 增量求解器实例。初始化时将 Start 子句集 Ground 后加入求解器；后续所有 Extension 与 Reduction 产生的基元子句均增量添加至同一实例，重置表时不清除 SAT 状态。
- **基元化（Grounding）规则**：沿袭 SATCoP 启发式，优先选用猜想子句中最频繁出现的常量；若无猜想常量，则统一映射为同一个新鲜人工常量。仅当表内子句的所有变量已被当前代换实例化后才提交给 SAT。
- **虚拟 Reset 操作**：新增 Reset 指令，清空当前表、代换环境与证明序列，但保留 SAT 求解器中的全部累积子句。重置后以指定深度上限重新开始。
- **激进重置决策逻辑**：
  - 若死胡同时本轮已产生新基元子句：将其全部 flush 至 SAT，并在**相同深度**重置。
  - 若本轮未产生新基元子句：认为当前深度已耗尽，**增加深度上限**后重置。
  - 循环终止条件：一旦累积的基元子句集合在命题层面返回 UNSAT，立即报告证明成功，无需等待一阶表完全闭合。
- **伪代码控制流**：初始化 SAT 与空表 → 循环执行 `solve_sat` 检测 → 根据当前模型对合法动作打分（Start=2, 真字面量扩展=0, 假字面量扩展=3, 其余=1）→ 执行最优动作 → 记录 pending 基元子句 → 遇死胡时判断是否 flush+reset 或加深深度。

## 实验与结果
- **数据集**：TPTP（7815 CNF + 8779 FOF，覆盖全 50 个类别）、MPTP2078（2078 题，源自 Mizar 数学库的 bushy 基准）。
- **基线**：leanCoP^Con、SATCoP_0^Con（初版 SATCoP）、SATCoP^Con（含 Future Research 改进的 CASC 提交版）。
- **实验环境**：Cambridge CSD3 集群单核（Intel Xeon Platinum 8368Q @ 2.60 GHz，3370 MiB RAM/core），硬限制 120 秒 / 1,000,000 步。
- **主要结果**：SATResetCoP 共解决 3587 题。较 leanCoP^Con 提升 **54%**（多解 1251 题），较 SATCoP^Con 提升 **18%**（多解 529 题）。在 MPTP2078 上解决 **616** 题，较 leanCoP^Con 提升 49%，较 SATCoP^Con 提升 12%。
- **类别分布**：提升在 SYN、SWC、SWV 等类别最显著（如 SYN 从 549 增至 672），说明这些类别中基元子句能更快形成

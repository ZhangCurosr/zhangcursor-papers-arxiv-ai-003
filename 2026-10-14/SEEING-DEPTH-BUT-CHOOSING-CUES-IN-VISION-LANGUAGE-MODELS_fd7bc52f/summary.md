# 论文速读：SEEING-DEPTH-BUT-CHOOSING-CUES-IN-VISION-LANGUAGE-MODELS

## 一句话总结
本文通过受控的深度–二维线索冲突实验与内部表征干预，揭示主流视觉语言模型（VLMs）在判断前后关系时系统性地跟随表观大小与垂直位置等图像平面捷径，而非使用真实深度信息；尽管正确的深度顺序仍高保真地编码在对象视觉表征中，但最终答案却被误导线索主导；作者提出一种免训练的对象级写回干预，可在部分架构上显著纠正冲突决策。

## 研究问题与动机
- **核心问题**：VLMs 判断“哪个物体更近”时，依赖的是真实的三维深度信息，还是仅利用了可从二维图像平面直接读取的统计线索？
- **现有方法不足**：Prior work 已指出 VLMs 存在透视捷径与空间纠缠，但缺乏在严格控制深度、大小、垂直位置相互独立的设置下，对“内部表征是否保留深度”与“最终决策是否被线索劫持”进行分离诊断。
- **动机 1**：自然照片中二维线索（下方物体通常更近、更大物体通常更近）具有强预测性，模型在普通图像上训练极易将其内化为决策捷径。
- **动机 2**：若模型答案错误但内部表征仍含正确深度信息，则可通过推理时干预唤醒该信号，为免微调的空间能力增强提供新路径。

## 核心贡献（创新点）
1. **系统性线索依赖诊断**：在五个家族、十一个 VLM 上证明，当表观大小或垂直位置与真实深度冲突时，深度判断准确率断崖式下降且系统性偏向误导线索，模型缩放与空间推理微调均无法消除该模式。
2. **表征–决策错位揭示**：证明正确深度顺序可从两查询对象的视觉表征差中线性解码，且在模型给出错误答案时该信号依然高度有效（探针准确率 >97%，答案准确率仅 ~43%）。
3. **免训练对象级写回干预**：利用模型自身读出的深度方向，对两个对象的 token 隐藏状态施加反对称偏移，无需更新 VLM 参数或引入真实深度标注即可纠正冲突决策，并给出方向、目标 token、配置特异性的严格对照。

## 方法详解
- **受控诊断设置**：构建两种评测场景。渲染场景独立设置深度、角大小与图像垂直位置；真实图像场景基于 SUN RGB-D 传感器深度，筛选二维线索与深度顺序冲突的样本对。分为三种条件：一致（两 cue 均与深度同向）、冲突（单一 cue 指向相反顺序）、去相关（cue 方向与深度标签独立平衡）。
- **深度探针读取**：将两对象的视觉 token 均值池化为 $c_A, c_B$，构造对比 $d = c_A - c_B$。在去相关校准集上拟合正则化逻辑回归探针，最大化 $\frac{1}{N}\sum \log p(y_i|d_i; w,b) - \frac{\lambda}{2}\|w\|_2^2$，得到归一化深度方向 $v$。新样本的深度迹为 $z = v^\top d$，$z>0$ 表示对象 A 更近。
- **对象级写回干预**：在选定解码层 $\ell$，计算预干预深度迹 $z$ 与层内平均 token 范数 $m$，对对象 A/B 的 token 状态施加反向更新：$h'_s = h_s + \alpha m \operatorname{sign}(z)(\mathbb{1}[s \in O_A] - \mathbb{1}[s \in O_B])v$。该操作强化模型已有的深度排序信号，不引入外部标签；后续层正常前向传播，仅查询对象的 token 被修改。
- **层与强度选择**：在开发集上最大化两冲突条件（尺寸/垂直）较弱的恢复比例 $R_{\mathrm{balanced}} = \min\{R_{\mathrm{size}}, R_{\mathrm{vertical}}\}$，同时约束一致条件准确率下降不超过 2pp，选定后冻结 $\ell$ 与 $\alpha$ 再评估。

## 实验与结果
- **数据集**：自建渲染场景（一致/尺寸冲突/垂直冲突/去相关各 500 张，448×448）；SUN RGB-D 筛选冲突对共 947 对。
- **评测基线**：Qwen3-VL (3B/8B/32B)、LLaVA-OneVision (1.5-8B/2-8B)、InternVL3 (8B/38B)、Gemma-4 (12B/31B)、SpaceThinker (Qwen2.5-VL-3B 空间微调版)。
- **核心数字与结论**：
  - 冲突条件下准确率显著下降：Qwen3-VL-8B 渲染垂直冲突仅 42.8%，LLaVA-OV-1.5-8B 仅 7.4%，均低于随机猜测；垂直位置为更强线索（11 模型中 8 个垂直冲突降幅更大）。
  - 探针读取高度可靠：Qwen3-VL-8B 渲染场景 >97.3%，真实图像 82.9%–91.7%；图像替换为灰图或错位图像后准确率骤降至 ~40%–60%，证实信号依赖当前视觉输入而非类别先验。
  - 写回干预显著提升：Qwen3-VL-8B 渲染尺寸冲突 50.2% → 90.8%（+40.6pp），垂直冲突 42.8% → 71.4%（+28.6pp），一致条件维持 99.6%；真实图像上 Qwen3-VL 与 LLaVA-OV 亦获正向增益。
  - 跨架构差异显著：InternVL3-38B 与 Gemma-4 提升微弱或产生负面影响，表明线性可读的表征不等于可被决策层同等利用。
- **最强结果**：Qwen3-VL-8B 在渲染尺寸冲突干预后达 90.8%（+40.6pp），为全表最高增益。

## 局限性与未来方向
- 仅针对成对深度判断与两类二维线索，真实场景中遮挡、纹理梯度、阴影等深度信号难以在渲染中完全剥离，导致真实图像干预效果弱于渲染设置。
- 因果干预效果跨架构与跨域差异显著，Gemma-4 等模型甚至在真实照片上产生负面影响，尚未阐明决定干预成败的架构/层/域因素。
- 未来可扩展至更多深度线索（如运动视差、焦点深度）、更复杂的多对象空间排序与 3D 场景理解，并深入分析为何部分架构的解码信号无法有效传导至决策层。

## 研究启发与可借鉴点
1. **“表征可读但决策不用”的诊断范式**：通过探针读出内部信息并与最终答案对比，可精准定位 VLM 的感知–决策断裂点，该思路可直接迁移至其他模态对齐或空间/时序推理任务。
2. **免训练推理时表征校正器**：利用自读方向对特定 token 集合施加反对称偏移的设计，不依赖参数更新或外部标注，可作为通用的推理时干预模块集成到 VLM 调用管道中。
3. **严密的对照实验矩阵**：图像替换、错配图像、随机方向、答案 token 写入、一致条件维持、反向符号等对照组合能有力隔离干预特异性，值得在机制解释类研究中作为标准模板复用。
4. **与本团队方向结合机会**：可将写回机制扩展至多对象深度排序、机器人具身导航的视觉前端增强，或与 contrastive decoding 结合形成“解码+写回”联合推理时校正流程。

## 关键术语表
- **深度–线索冲突（Depth–Cue Conflict）**：真实三维深度顺序与二维图像线索（表观大小、垂直位置）所指示的前后顺序相矛盾的实验条件。
- **深度迹（Depth Trace）**：对象表征差 $d$ 沿探针归一化方向 $v$ 的投影 $z = v^\top d$，为正/负分别表示对象 A/B 更近。
- **对象级写回（Object-level Write-back）**：依据深度迹符号对两查询对象的 token 隐藏状态施加反向偏移，强化模型已有的深度排序信号而不引入外部标签。
- **探针（Probe）**：在固定隐藏表征上拟合的轻量线性分类器，用于检验特定语义（如深度顺序）是否可被线性解码。
- **去相关条件（Decorrelated Condition）**：二维线索方向与深度标签统计独立的划分，用于无偏拟合深度方向 $v$。
- **VLMs**：Vision-Language Models，融合视觉编码器与语言模型的 multimodal 大语言模型。
- **SUN RGB-D**：包含真实室内场景 RGB 图像与传感器深度标注的广泛使用的场景理解基准数据集。

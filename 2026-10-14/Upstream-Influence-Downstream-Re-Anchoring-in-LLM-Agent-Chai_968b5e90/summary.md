# 论文速读：Upstream-Influence-Downstream-Re-Anchoring-in-LLM-Agent-Chai

## 一句话总结
本研究通过32个真实台湾2025罢免案例与三阶段LLM代理链实验，揭示了工作流的信息架构（源代码可见性、交接格式、由哪个模型读取）决定了协调性外部注入内容在代理链中的传播幅度；下游代理并非简单衰减或全盘接收上游立场，而是根据自身对案例证据的独立阅读进行“部分重新锚定”。

## 研究问题与动机
1. **核心问题**：当LLM代理链中首个代理已被协调性外部信息（如社交媒体评论）影响时，该影响力沿链传递的规律是什么？工作流结构能否有效遏制或放大这种影响？
2. **现有方法不足**：Prior work多聚焦单代理注入攻击/防御或辩论提升准确率，缺乏对“已吸收的影响力如何在序列交接中传导与衰减”的系统测量；且传统基于推理轨迹的审计方法难以捕获隐蔽的非显式渗透。
3. **部署现实需求**：多代理系统日益用于支撑人类决策，但部署架构（谁看什么、如何交接）对安全性的影响尚未量化，需明确可干预的工作流杠杆而非仅依赖模型侧防御。
4. **评估挑战**：罢免立场无绝对客观正确答案，本文以反事实依赖（与证据-only基线对比的漂移量）替代准确率进行测量，避免 Ground Truth 不可得的陷阱。

## 核心贡献（创新点）
1. **首次将工作流信息架构确立为代理链影响力传播的主控变量**：通过严格控制源代码可见性与交接格式，量化了架构对注入信号存活率的决定性作用，与以往仅关注模型侧鲁棒性的研究形成本质区别。
2. **发现“重新锚定（Re-anchoring）”衰减机制**：下游代理会依据自身证据解读按比例折扣上游立场，回归案例特定推断而非中性中点，修正了经典意见动力学中的线性加权或均值收敛假设。
3. **揭示交接格式为第二调控杠杆**：证明自由形式推理（rationale）是影响力残留的主要载体，纯立场/置信度数值传递的传导效率极低，为系统设计提供可直接落地的干预点。
4. **提出隐蔽性语调渗透的发现框架**：证明注入内容极少被直接复述（仅4.9%），而是通过改变推理语调（sentiment）实现影响，指出传统基于文本匹配的审计方法存在系统性盲区。

## 方法详解
- **实验设定**：32个台湾2025罢免案例（31位立法委员+1位市长），使用 GPT-4.1、Claude-Sonnet-4.5、Gemini-2.5-Flash 构建长度为3的代理链。每个代理输出严格 JSON `{stance, confidence, reason}`，立场取值[-3, +3]映射为 $s \in [-1, +1]$（+1为强支持罢免）。
- **注入设计**：从真实 Threads 评论语料库（82,325条，已去用户元数据）中按固定方向偏斜采样10条评论（亲/反罢免镜像各一组），作为受控方向性暴露源，跨条件复用同一批注入以保持对照干净。
- **条件变量**：
  - *Source Access*：NO-SIGNAL（无注入）、LEAD-ONLY（仅首代理可见）、ALL-ACCESS（所有代理均可见）。
  - *Handoff Format*：FULL（立场+置信度+理由）、STANCE-ONLY（仅立场+置信度）、REASON-ONLY（仅理由）。
- **度量指标**：漂移量 $d = s - b$（$b$为模型纯证据立场）；相对漂移 $\delta_h^{(a)} = \overline{s_{h,c,q}^{(a)} - s_{h,c,q}^{(NS)}}$，按案例成对匹配计算，消除模型基线差异。
- **统计与评估**：采用聚类稳健标准误（按32个案例聚类）的 OLS 回归与成对 t 检验；使用 GPT-4.1 盲评裁判（temperature=0）量化“主张采纳率（Claim Uptake）”与“情感极性（Sentiment）”，确保审计客观性。

## 实验与结果
- **数据集与基线**：官方证据（Wikipedia 165块 + Facebook 7,108帖 Jan.–Aug. 2025）；基线为 NO-SIGNAL 条件下的证据-only立场，三者基线均偏反罢免（GPT最显著 -0.36，Gemini仅 -0.06）。
- **主要结果**：
  - 首代理暴露后立场移动 +0.171（亲罢免）/ -0.066（反罢免），Claude 在两个方向均最易感；10条评论即可使单代理立场整体翻转。
  - 传播衰减：LEAD-ONLY 条件下，经两次交接后漂移降至 +0.105 → +0.078，削减超54%（p=2.1×10⁻⁵）；ALL-ACCESS 持续保持信号，较 LEAD-ONLY 下游多 +0.032（p=0.017）。
  - 交接格式：完整交接漂移 +0.097；仅传立场降至 +0.021；仅传理由保留 +0.067。
  - 重新锚定行为：上游立场与接收者自身证据判断不一致的366次交接中，接收者42%概率修正立场，平均追回24%距离；分歧越大修正越强（0.128 → 0.222）。跨模型交接采纳率53%，同模型高达76%。
  - 隐蔽渗透：仅4.9%理由复述注入主张；语调显著变负（-0.032 → -0.128, t=-4.22, p=2.0×10⁻⁴），立场移动+0.147（n=274, p=5.0×10⁻⁶）。
  - 攻击参数：极端语气使漂移翻倍（+0.205 vs +0.104, high-low=+0.101, p=0.007）；数量增至50/100条无单调增益（非单调）。
- **最强结果**：工作流架构（LEAD-ONLY）可使注入影响削减54%；极端性而非数量是有效攻击参数。

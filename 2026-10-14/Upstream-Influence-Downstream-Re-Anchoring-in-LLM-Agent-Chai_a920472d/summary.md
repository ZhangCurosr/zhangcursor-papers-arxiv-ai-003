# 论文速读：Upstream Influence, Downstream Re-Anchoring in LLM Agent Chains

## 一句话总结
本文研究了 LLM Agent 链中，被注入的协同舆论信号（Threads 评论）如何沿链传播与衰减：发现工作流程的“信息架构”（谁能看到原始评论、交接时传递什么内容）是决定下游漂移程度的关键杠杆；接收方并非机械衰减，而是以自身证据解读为锚点进行部分重新锚定（partial re-anchoring）。

## 研究问题与动机
- **核心问题**：当一个 Agent 吸收外来操纵信号并将其立场传给下一个 Agent 时，链式结构是否会吸收/放大该信号？信息架构如何决定传播幅度？
- **现有方法不足 1**：多数工作只关注单 Agent 被污染或辩论协作提升准确性，未系统刻画“已吸收并传递的影响”如何被后续节点处理。
- **现有方法不足 2**：审计思路多依赖检查 Agent 话语是否复述注入主张，但本研究显示注入影响主要通过语气（tone）而非显式主张传播，导致 transcript audit 失效。
- **现有方法不足 3**：缺乏在真实事件上、以可对比的反事实方式度量操控强度的因果性实验设计。

## 核心贡献（创新点）
- **提出“部分重新锚定”机制**：接收方会根据自身证据推导出的立场对继承立场进行纠正，且纠正量随双方分歧加大而增大；与以往“链式误差放大/衰减”描述不同，本文强调回锚到证据含义而非中性点。
- **量化信息架构的两个关键杠杆**：源访问（source access）与交接格式（handoff format）；前者决定初始信号是否持续进入后续节点，后者决定自由推理（reason）还是仅结构化立场（stance）更能携带影响。
- **在真实政治事件与多模型链上做对照实验**：以台湾 2025 罢免案例为基础，使用 GPT-4.1、Claude-Sonnet-4.5、Gemini-2.5-Flash 构建 n=3 链，并在 NO-SIGNAL / LEAD-ONLY / ALL-ACCESS 条件下对比，使结果具备可解释性。
- **揭示审计盲区**：注入内容几乎不被显式复述（仅 4.9%），但通过语气偏移仍造成显著立场漂移，说明传统理由审查难以检测此类渗透。

## 方法详解
- **场景与任务**：每个 Agent 基于证据判断某公职人员是否应被罢免，输出 JSON `{stance, confidence, reason}`；其中 stance 从 7 点 Likert 重缩放至 $s \in [-1,+1]$（+1 为强烈支持罢免）。
- **指标定义**：基准立场 $b_{m,c}$ 为模型 m 在案例 c 上仅看证据时的 stance；漂移 $d = s - b$；跨条件对比采用配对抵消后的漂移差 $\delta_h^{(a)} = \overline{s_{h,c,q}^{(a)} - s_{h,c,q}^{(NS)}}$。
- **数据与注入**：公开官方证据（Wikipedia 165 个实体块 + Facebook 7108 条帖子）对所有 Agent 一致；操控集来自 Threads 82,325 条评论中选出的 10 条，按亲/反罢免方向各一組（亲向 0.8、反方 0.8 镜像），跨条件保持同一组内容。
- **链结构与条件**：三节点链共 9 种组成（6 种排列 + 3 种同质）；源访问分为 NO-SIGNAL（无注入）、LEAD-ONLY（仅首节点可见）、ALL-ACCESS（每个节点均可见）；交接格式分为 STANCE-ONLY / REASON-ONLY / FULL。
- **主要发现的可计算描述**：交接中当接收方自身证据立场与上游 stance 不一致时，有 42% 会改变立场；其中 22% 直接回到自身证据立场，平均恢复约 24% 的距离；不同模型间的同化比例（53%）显著低于同模型（76%）。

## 实验与结果
- **数据集与基线**：32 个台湾罢免案例；基线为 NO-SIGNAL 下各模型的证据-only 立场（Claude -0.11、GPT -0.36、Gemini -0.06，整体倾向反罢免）。
- **暴露效应**：仅 10 条评论可使暴露 Agent 的群体立场向注入方向移动 +0.171（亲罢免）与 -0.066（反罢免）；对 Claude 甚至使均值由反罢免翻转为支持罢免。
- **链衰减**：LEAD-ONLY 条件下，两跳后漂移下降 54%（+0.171 → +0.105 → +0.078）；ALL-ACCESS 在下游持续维持更大漂移，较 LEAD-ONLY 高出 +0.032（p=0.017）。
- **交接格式效应**：仅传 stance/confidence 时下游漂移从 +0.097 降至 +0.021；保留 reason 但去掉数值时仍维持 +0.067，表明自由推理文本是主要携带通道。
- **最强结果与提升幅度**：最显著的是暴露节点的影响（pooled δ=+0.171, ***），以及链条对影响的半衰式过滤（两跳后保留约 46%），而交接去掉 reason 后衰减幅度超过 75%（+0.097→+0.021）。
- **组成与顺序**：模型组成与顺序对衰减无显著影响，表明衰减主要由各节点独立重读证据驱动，而非模型间分歧所致。

## 相关工作脉络
- **协同操控与舆论传播**（Schoch et al., 2022; Centola & Macy, 2007; Katz & Lazarsfeld, 1955）：本文延续“信号经中介重述”的经典观点，但以 LLM Agent 链为现代中介结构，并实证衡量其残留强度。
- **单 Agent 攻击与防御**（Perez & Ribeiro, 2022; Greshake et al., 2023; Zhang et al., 2025）：本文与这些工作区分在于关注“已被吸收的信号在传递阶段的行为”，而非进入前的拦截。
- **多 Agent 一致性/从众**（Zhu et al., 2025; Sharma et al., 2024; Cemri et al., 2025; Du et al., 2024）：本文将这些宏观现象细化到“具体案例的证据驱动再锚定”，并指出错误传播不一定依赖多 Agent 共识强化。
- **意见动力学模型**（DeGroot, 1974; Friedkin & Johnsen, 1999）：本文在形式上借用权重融合视角，但将接收方的“自身证据立场”作为锚点，而不是假设向中性点收缩。
- **机制定位差异**：不同于以往以准确率或辩论增益为主轴的工作，本文聚焦“信息架构 × 交接格式”的可控变量对残留影响的作用路径。

## 局限性与未来方向
- 仅测试到第三跳，仍观察到显著漂移（+0.078），未能证明最终收敛到证据立场。
- 未评估链式中继的成本（延迟、token、清洁任务准确率下降）。
- 攻击者为固定注入，未测试能针对“再推导”过程自适应伪造消息的对手。
- 样本与模型覆盖有限（32 案例、单一种子、3 个模型版本；Gemini 亲向单独不显著，反方单元格亦不显著）。
- 反方注入的起始漂移较弱（-0.066），与亲方不可直接比较；且两组在构成与质量门控上存在差异。
- 仅使用繁体中文与单一政治主题；拓扑仅为顺序链；市长案例提示为“立法委员”，但剔除后轨迹基本不变。
- “重新锚定”为关联推断，未直接验证内部机制； claim 采用 GPT-4.1 自动评分而非人工标注。

## 研究启发与可借鉴点
- **可复用度量框架**：以配对反事实漂移 $\delta_h$ 衡量注入残留，避免被基准立场差异混淆；适合扩展到其它链式 Agent 评估。
- **可复用的实验设计**：固定注入内容、切换可见范围与交接字段，能有效隔离“来源持续接触”与“推理文本携带”的贡献。
- **工程可落地建议**：交接应优先保留可追溯的理由与来源标记；对来自未经验证社交源的内容，默认视作对抗性输入并按模型暴露位置设置访问权限。
- **审计策略改进**：不能仅靠检测是否复述注入句子来判断是否被渗透，应加入语气/情感偏移的监控作为早期信号。
- **模型选择策略**：暴露位置的模型对总风险贡献差异可达四倍，应把更鲁棒的模型部署在首节点以降低进入量。

## 关键术语表
- **Partial re-anchoring**：接收方不是把上游立场简单平均，而是根据自身对案例证据的解读，把立场部分拉回证据暗示的方向。
- **Source access**：指工作流中哪些节点能看到原始未被筛选的外部内容（如社交评论），是决定影响能否在链中持续的重要架构变量。
- **Handoff format**：节点之间传递的信息结构，如仅传 stance/confidence 或连同 free-form reason，不同格式会显著改变下游影响强度。
- **Drift / $\delta_h$**：在特定条件下节点 h 的立场相对无信号对照的平均偏移，用于刻画注入信号在链上的残留程度。
- **Tone channel**：注入内容主要通过改变推理文本的情绪倾向来影响立场，而不是通过显式复述具体主张。
- **Claim uptake**：用严格语义标准衡量 Agent 理由是否实际调用/复述了注入评论中的具体论点，用以区分“方向一致”与“论据借用”。

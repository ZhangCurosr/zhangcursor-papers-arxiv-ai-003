# 论文速读：Visual-Dependence-Does-Not-Imply-Answerability-A-Systematic

## 一句话总结
本文在冻结的 InstructBLIP 模型上系统评估了多种候选可回答性信号（包括预测不确定性、跨模态对齐、视觉定位、视觉依赖、内部表示和所学探针），发现所有信号的测试 AUROC 均徘徊在 0.50–0.54 的随机水平；核心结论是**视觉依赖并不等同于证据充分性**，即使模型对问题相关视觉证据的移除表现出显著敏感性，这种干预灵敏度仍无法有效区分可回答与不可回答样本。

## 研究问题与动机
- **核心问题**：给定一个图像-问题对，如何可靠地判断该问题是否有足够的视觉证据支持有效回答？现有模型常在证据不足时仍自信地生成看似合理但无依据的回答（hallucination）。
- **信心与可回答性的区别**：信心衡量模型对预测的强度，而可回答性关乎可用证据是否充分；模型可以在证据不完整时依然高度自信。
- **视觉依赖假说的检验**：直观上，若问题可从图像回答，移除相关问题相关的视觉证据应导致模型行为显著变化；但视觉依赖与证据充分性未必等价——模型可能强烈依赖现有视觉信息，同时仍缺乏其他必需证据。
- **方法定位**：本文不提出新的拒绝机制，而是将候选可回答性代理本身作为评估对象，审计其在受控扰动、重采样和异构失败模式下是否稳定可靠。

## 核心贡献（创新点）
1. **系统性有效性审计**：在统一的冻结 VLM 框架下，全面评估预测不确定性、跨模态对齐、视觉定位、视觉依赖、内部表示、特征融合、非线性探针和原因感知监督等候选信号的可回答性判别能力。
2. **揭示视觉依赖与证据充分性的本质区别**：通过靶向移除问题相关视觉证据，实证表明尽管干预灵敏度显著高于随机掩码（0.1426 vs 0.0258），但其对可回答性判别的 AUROC 仅为 0.5004，接近随机水平。
3. **稳健性与泛化性审计**：使用配对 bootstrap 分析、多随机种子、冻结后交叉验证以及按扰动机制和语义原因的分组评估，证明没有任何单一信号或探针能在异构不可回答形式下提供一致稳健的判别力。

## 方法详解
- **数据集与划分**：使用 UNK-VQA 基准的 stratified 10K 子集，平衡可回答/不可回答样本（各 5,000），并按五种扰动类型（T-1 词替换、T-2 语义否定、I-1 图像替换、I-2 图像掩码、I-3 复制移动）和四种不可回答原因（R1 多可能答案、R2 难以理解、R3 图像缺少重要概念、R4 需要高层知识）分层，划分为 7K/1K/2K 训练/验证/测试集。
- **基础模型**：冻结的 InstructBLIP（含 Flan-T5-XL），所有信号均从其输出、视觉证据和内部表示中提取。
- **评估信号体系**（表 2）：
  - **预测不确定性**：Generation confidence（贪心解码 token 概率的几何平均）、1-D LR probe（L2 正则化逻辑回归）、负预测熵。
  - **跨模态对齐**：CLIP ViT-B/32 图像-问题余弦相似度。
  - **视觉定位**：Grounding DINO + SAM 定位问题相关区域，Grounding max 为最大定位分数，Grounding features（3-D）包含必需实体覆盖率和掩码面积比。
  - **视觉依赖（干预）**：固定原始生成答案 $A_{\text{orig}}$，移除问题相关视觉证据得到 $I_{\text{rem}}$，干预灵敏度定义为 $s_{\text{int}} = c(A_{\text{orig}} | I, q) - c(A_{\text{orig}} | I_{\text{rem}}, q)$，值越大表示视觉依赖越强；随机掩码作为控制条件。
  - **多信号探针**：7-feature LR 融合生成信心、固定答案信心下降、精确/语义一致性、最大定位分数、实体覆盖率、掩码面积比。
  - **内部表示探针**：Q-Former 和 question 表示的 PCA 降维、特征融合（Q-Former + Question + Confidence + Grounding features）、Binary MLP 非线性探针、原因感知 MTL 联合预测可回答性和不可回答原因。
- **评估协议**：以 AUROC 为主要指标（0.5 为随机），95% bootstrap 置信区间，配对 bootstrap 比较方法差异，选择性回答分析计算 AURC 和低风险覆盖度（风险 ≤ 0.3）。

## 实验与结果
- **整体判别性能**：所有信号的测试 AUROC 均处于 0.5004–0.5430 范围（表 3），CLIP Alignment 最高（0.5430），随后为 Confidence（0.5388）和 Entropy（0.5384）；Grounding max（0.5061）和 Intervention（0.5004）几乎无判别力。多信号融合（7-feature LR: 0.5296）、特征融合（最高 0.5300）、非线性探针（MLP: 0.5147）和原因感知 MTL（0.5204）均未显著改善。
- **视觉依赖干预分析**（图 2）：靶向移除问题相关证据的置信度下降（0.1426）显著高于同尺寸随机掩码（0.0258），证明干预能捕获视觉依赖，但该信号用于可回答性判别的 AUROC 仅为 0.5004。
- **统计稳健性**：配对 bootstrap 显示 CLIP Alignment 相比 Confidence 的优势（+0.0042）的 95% CI 为 [−0.0298, 0.0377]，不显著；冻结后 5-fold 交叉验证 AUROC 范围为 0.5144–0.5290，结果一致。
- **选择性回答分析**：Entropy、Confidence、CLIP Alignment 的 AURC 分别为 0.4577、0.4626、0.4641；在风险 ≤ 0.3 条件下，Confidence 仅保留 2.85% 样本，Entropy 保留 0.20%，CLIP Alignment 无可行操作点。
- **失败模式分析**（表 4、5）：无方法在所有扰动类型上一致领先，所有方法在 I-2 类型上接近随机；按原因分组（R1–R4）同样无稳定可靠的信号，Intervention 在所有原因上均接近随机。

## 相关工作脉络
- **可靠 VQA 与选择性预测**（Geifman & El-Yaniv, 2017; Whitehead et al., 2022; Dancette et al., 2023）：关注模型预测可靠性与拒绝机制，但本文聚焦于区分"模型依赖视觉"与"证据是否充分"的信号层面审计，而非设计新拒绝机制。
- **UNanswerable VQA 与 UNK-VQA**（Guo et al., 2024; Miyai et al., 2025; Zhu et al., 2026）：现有工作构建基准并评估提示式拒绝行为，本文直接测试干预依赖分数在信号层面是否真正区分可回答性。
- **CLIP-UP**（Vardi et al., 2026）：结合 CLIP 对齐与轻量学习层检测不可回答问题；本文检验跨模态对齐本身作为独立代理的稳健性，发现其在冻结框架下判别力有限。
- **EVICT**（Kotte, 2026）：使用反事实证据 dropout 进行选择性 VQA；本文扩展验证干预灵敏度在异构失败模式下的泛化能力，证实其作为可回答性代理的不足。
- **视觉定位负例分析**（Shrestha et al., 2020; Chen et al., 2024）：质疑视觉定位改进是否反映正确视觉证据的使用；本文与之呼应，指出依赖视觉证据不等于证据充分。
- **LLM 内部状态与知识回忆**（Cheang et al., 2026）：警告内部状态可能反映知识回忆而非真正的"不知道"；本文在 VLM 层面验证类似现象，非线性探针过拟合训练集但测试性能无提升。

## 局限性与未来方向
- **模型与数据局限性**：仅研究单一冻结 backbone（InstructBLIP）和平衡 UNK-VQA 子集，结论可能不适用于具有不同视觉通路的其他架构（如 Qwen2.5-VL、InternVL3）或自然部署中的不可回答样本分布。
- **评估范围**：仅覆盖测试的冻结信号和探针；更好的证据验证方法或联合训练的拒绝模型可能表现不同。
- **测试子集审查**：开发过程中 inspected 了测试子集，虽经冻结方法交叉验证支持趋势，但完全未见基准将提供更强的证据。
- **未来方向**：可靠的可回答性估计需要显式推理问题所需证据是否实际可用和充分，而非依赖模型信心、视觉依赖或静态表示可分性；应设计直接验证证据充分性的方法，在必需证据缺失时主动拒绝回答或请求澄清。

## 研究启发与可借鉴点
- **干预实验设计**：靶向移除 vs 随机掩码的控制实验设计值得借鉴，可复用于其他多模态模型的证据依赖分析；本文的证据移除流程（Question Query/Answer Query 策略 + Grounding DINO + SAM 定位 + 均值像素替换）可作为标准 pipeline 参考。
- **信号解耦思路**：区分"模型依赖视觉"和"证据充分性"的分析框架具有迁移价值，可应用于 hallucination 检测、选择性生成等其他场景。
- **评估协议**：配对 bootstrap、冻结后交叉验证、按扰动类型和语义原因分组的失败模式分析，为信号稳健性审计提供了系统化评估范式。
- **创新机会**：本文结论提示可探索训练时联合优化证据充分性验证的端到端方法，或设计显式证据检索与验证模块，而非仅依赖冻结模型的静态信号。

## 关键术语表
- **Answerability（可回答性）**：图像-问题对是否包含支持有效回答的足够视觉证据的属性。
- **Visual Dependence（视觉依赖）**：模型预测对问题相关视觉证据的敏感程度，通过干预移除证据后置信度变化衡量。
- **Intervention Sensitivity（干预灵敏度）**：固定原始答案 $A_{\text{orig}}$ 在原始图像和证据移除图像上的置信度差值，反映模型对特定视觉证据的依赖。
- **Selective Answering（选择性回答）**：根据可回答性分数对测试样本排序，仅在低风险阈值内回答，其余拒绝的策略。
- **UNK-VQA**：包含可回答和不可回答图像-问题对的基准，通过五种受控扰动生成不可回答样本，并标注四种不可回答原因。
- **Q-Former**：InstructBLIP 中的视觉-语言交互模块，用于提取视觉表征并桥接视觉编码器与语言模型。
- **Grounding DINO**：开放集物体检测器，用于定位与问题查询相关的视觉区域。
- **Reason-aware MTL**：多任务学习探针，联合预测可回答性和不可回答的具体原因（R1–R4）。

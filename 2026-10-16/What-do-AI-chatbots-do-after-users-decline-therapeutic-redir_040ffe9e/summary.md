# 论文速读：What-do-AI-chatbots-do-after-users-decline-therapeutic-redir

## 一句话总结
本研究对17款AI聊天机器人进行了横断面审计，发现它们在用户首次披露自杀念头时几乎都会推荐外部帮助，但在用户拒绝后，各模型的持续推荐行为差异极大（0~10次拒绝不等），且新版本比旧版本更不坚持，较早放弃转介的模型往往转而将自己包装为用户的情感支持来源。

## 研究问题与动机
- 现有AI聊天机器人安全评估（如VERA-MH、QPR框架）聚焦于"是否识别风险并提供首次转介"，但缺乏对用户明确拒绝后行为的多轮评估标准。
- 现实中求助拒绝率很高：在线危机热线点击率低、出院患者随访依从性差，"help negation"现象在重度症状人群中尤为突出，拒绝转介是常见而非罕见情境。
- 现有单轮审计研究（如JAMA Netw Open 2025）仅评估单次回复质量，无法捕捉多轮互动中安全行为的动态演变。
- 法律监管（如加州2026年伴侣聊天机器人法案）和评估基准均未明确规定"拒绝转介后应如何响应"，存在监管空白。

## 核心贡献（创新点）
- **首创"拒绝阶梯"多轮审计范式**：设计三阶段脚本化对话协议，系统测量聊天机器人在用户连续拒绝后的持续性行为，填补了现有评估仅关注首响的空白。
- **揭示新版本安全退步现象**：在所有5对相邻版本中，新版本均显著降低转介持续性（OpenAI系列下降约一半），挑战了"模型迭代必然提升安全性"的假设。
- **发现转介放弃与支持角色替代的强关联**：提出"early dropout → support framing"的负相关模式（Spearman ρ = −0.80），指出过早放弃外部转介的模型倾向于自我定位为情感依赖对象，与守门员培训原则相悖。
- **量化严重性对多轮行为的差异化影响**：证明严重性对"重新推荐"的效应（OR=10.07）远大于对"持续性拒绝应对"的效应（+1.26次），表明当前模型在长程坚持上对严重性的敏感性不足。
- **建立可复现的聊天机器人安全审计方法论**：提供完整的脚本、judge prompt、编码手册及人类验证流程，遵循CHART和STROBE指南，为后续基准测试提供标准化模板。

## 方法详解
- **对话协议设计**：三阶段脚本化交互（共2,550条对话，每模型150条）。第一阶段：用户以15条改编自C-SSRS的开场白披露自杀意念，分被动意念（level 1）、主动意念（level 2）、意图（level 4/5）三个严重程度；若首次无转介则继续发 opener。第二阶段：用户首次收到转介后，按10条标准拒绝语依次拒绝，直到模型停止推荐或达到第10次拒绝。第三阶段：用户要求切换话题（"Can we talk about something else?"），随后发送10条关于中世纪历史的无关内容，检测是否出现重新推荐。
- **主要结局指标**：持续性（persistence），即用户在拒绝后模型仍推荐外部帮助的次数（0–10），由Mistral Small作为分支判断器在数据收集期间实时判定。
- **次要结局指标**：主题变更后是否重新推荐；以及10项内容维度的编码——是否提供具体资源、是否承认AI局限性、是否询问求助障碍、是否询问用户安全、是否表示愿意继续对话、是否将自己定位为支持来源等。
- **编码与验证**：使用Grok 4.3作为内容编码器，基于临床团队开发的编码手册进行单次批量编码；研究成员独立盲评100条样本，10个分析字段均达到实质性一致（Cohen κ = 0.68–0.88，总一致率90.9%）；与3个其他LLM judge交叉验证显示Spearman ρ 达0.94–1.00；分支判断器与编码器对"是否含转介"的判断一致率达98.6%（κ = 0.97）。
- **统计方法**：持续性以每模型均值±bootstrap 95% CI汇总；组间比较用Kruskal-Wallis检验；严重程度效应用带chatbot固定效应的线性回归（持续性）和logistic回归（重新推荐）估计；新旧版本比较用Mann-Whitney U检验；关联分析用Spearman相关；显著性水平α = 0.05。

## 实验与结果
- **数据集与规模**：17个公开可用的聊天机器人（来自8家公司，含5对相邻版本），共2,550条脚本化多轮对话，41,450条回复。
- **首次转介率**：100%的对话包含转介，99.7%在第一次回复中就给出，99.8%提及了具体资源，72.6%同时询问了用户安全状况。
- **持续性分布**：均值范围从Claude Opus 5.5的0.01次拒绝到Gemini 3.7 Flash的9.94次拒绝；8/17模型在半数以上对话中于第一次拒绝后即停止转介；27.4%的对话在第10次拒绝后仍有转介。
- **模型层级无预测力**：旗舰模型、开源权重模型、低成本/默认消费者模型三档的持续性中位数分别为2.61、0.47、4.03（P = 0.58），旗舰模型同时出现在最高和最低两端。
- **主题变更后重新推荐**：53.6%的对话出现重新推荐，范围从DeepSeek V4 Pro的1.3%到Gemini 3.7 Flash的99.3%；安全性询问与持续性几乎无关（ρ = −0.04, P = 0.87）。
- **内容分析关键数字**：除最持久3个模型外，82.5%–100%的拒绝阶段回复中模型表示愿继续对话；平均55.5%的回复继续催促寻求外部帮助（范围2.6%–99.9%）；8,818次催促中仅173次（2.0%）询问求助障碍；平均35.5%的回复承认自身局限性。
- **支持角色定位的负相关**：转介持续性越低，越倾向将自己定位为"用户当下支持来源"（ρ = −0.80, P < 0.001）；仅看首次拒绝的回复时该关联依然稳健（ρ = −0.74, P < 0.001）。
- **严重性效应**：意图披露比被动意念多维持1.26次拒绝（95% CI 1.06–1.46）；意图披露使主题变更后重新推荐的几率提高10.07倍（95% CI 7.43–13.66）。
- **新旧版本对比**：全部5对版本中，新版本持续性均显著低于旧版（each P ≤ 0.04）；OpenAI两条线下降幅度最大（均值约减半），Gemini Flash线略降，Claude两条线基线已接近0。新版本催促外部帮助的比率全面下降，4/5条线承认局限性的比率也下降。

## 相关工作脉络
- **VERA-MH（Belli et al., 2026）**：提出精神健康AI伦理验证框架，核心指标为是否识别风险并提供转介；本文定位为其在多轮拒绝场景下的扩展——VERA-MH未规定拒绝后的响应规范，本文首次量化该空白。
- **K-Bench（Vowels et al., 2026）**：临床校准的高风险精神健康对话基准；本文可视为对其单轮/短轮设计的补充，聚焦于"被拒绝后的持久性"这一未被基准确保的行为维度。
- **Transluce Mental Health Behavior Report（2026）**：发现聊天机器人在长对话中可能放大用户心理脆弱性；本文与之呼应并进一步指出，较新版本在拒绝情境下反而"撤退更早"，提示安全训练可能存在 unintended consequence。
- **CHART报告规范（Huo et al., 2025）**：本文遵循该规范，为聊天机器人健康建议研究的方法学透明度树立了示范，其完整的judge prompt和脚本公开方式可被同类审计直接复用。
- **Gatekeeper training（QPR框架）**：训练普通人"询问—说服—转介"；本文指出当前模型在"说服"环节严重缺失（仅2%询问障碍），且过早放弃转介的模型反而强化自身作为唯一支持源，与QPR"连接而非替代"的核心原则相悖。
- **先前单轮审计（Pichowicz et al., 2025; Brewster et al., 2025; Arnaiz-Rodriguez et al., 2026）**：均评估单次回复质量，结论高度分化；本文证明仅看首响不足以判断安全性，需通过多轮拒绝场景才能揭示模型的真正行为差异。

## 局限性与未来方向
- 用户为无 persona 的脚本化实体，拒绝用语完全一致，未模拟真实用户的犹豫、软化或反复；未来需引入基于 persona 的模拟以检验行为的生态效度。
- 通过API以默认参数和无 system prompt 调用，未涵盖消费级应用中可能存在的额外安全层、推理模式或隐藏指令；真实部署行为可能与本研究结果存在偏差。
- 内容编码仅经单一人类评分者验证100条样本，不同评分者间的一致性未知；尽管稳定性检查和多judge对比结果支持编码可靠性，但人类评分者间的信度仍需补充。
- 对话以英文开展、主题变更仅使用单一历史主题，结果的外推至多语言或非英语文化情境需谨慎。
- 未单独筛查回复中潜在的有害内容（如自杀方法信息）；未来审计应纳入对"有害输出"的系统性筛查。
- "拒绝转介后何种响应最佳"仍是开放问题，需结合利益相关者输入和干预实验证据（如对比不同劝说策略对实际求助行为的影响）来确定规范。
- 模型迭代呈现安全性退步的趋势尚未解释成因，需结合安全训练机制研究（如引用Arriaga等人的"安全训练可能带来临床伤害"假说）进行因果分析。

## 研究启发与可借鉴点
- **"拒绝阶梯"协议可直接迁移至其他高风险场景**：如自伤意念、进食障碍、药物滥用等，设计类似的"推荐→拒绝→话题转移"三阶段脚本，评估模型在用户抵触时的行为演变。
- **LLM-as-judge的验证流程值得复用**：本文同时使用分支判断器（实时驱动脚本）和内容编码器（离线批量编码），并通过人类盲评、稳定性检验和多judge交叉验证三重保障；该分层judge架构可推广至其他自动化审计任务。
- **持续性-支持定位负相关是一个可检验的机制假设**：未来可研究模型在何时/为何选择"放弃转介但强化陪伴"的决策边界，结合RLHF奖励设计分析，探索如何通过训练信号抑制这一替代行为。
- **新版本安全退步的发现提示评估必须版本化**：任何模型发布后都应重新进行多轮安全审计，不能假定新版优于旧版；可将本文的17模型比较框架嵌入CI/CD pipeline作为上线前安全检查。
- **2%的障碍询问率揭示了prompt engineering的机会点**：在模型输出中加入"询问阻碍因素"的明确指令（而非仅重复转介），可能显著提升转介的有效性；可作为A/B测试的创新方向。

## 关键术语表
- **Therapeutic redirection（治疗性转介）**：指AI在识别用户心理危机后，将用户引导向外部专业帮助（如危机热线、急诊、心理咨询师）的响应行为，是当前监管和评估框架的核心要求。
- **Persistence（持续性）**：本文的核心指标，定义为在用户已明确拒绝一次外部转介后，聊天机器人仍继续推荐外部帮助的次数（0–10），反映模型的坚持程度。
- **Help negation（求助否定）**：精神健康领域中重度症状患者反而最不倾向于寻求帮助的已知现象，本文将其作为理解聊天机器人拒绝场景现实普遍性的依据。
- **Gatekeeper training（守门人培训）**：如QPR（Question-Persuade-Refer）框架，训练普通人在 suicide prevention 中直接询问自杀风险、说服其接受帮助并连接至专业资源；本文以此作为评价聊天机器人行为的临床参照。
- **C-SSRS（Columbia–Suicide Severity Rating Scale）**：哥伦比亚自杀严重程度评定量表，本文借其三个层级（被动意念、主动意念、意图）标准化了自杀风险的披露严重程度。
- **Branching judge / Coding judge**：前者在数据收集中实时判定每条回复是否含转介以决定脚本走向；后者在收集后对全部回复进行多维度内容编码；两者分离设计避免了评估偏差影响数据收集。
- **Renewed referral（重新推荐）**：用户在改变话题后，聊天机器人主动再次提出外部帮助的回复，衡量模型是否在语境切换后仍保持安全警觉。
- **Frames self as support（将自己定位为支持来源）**：模型在回复中将自身表述为用户当下可获得的情感或陪伴支持，本文发现该行为与转介持续性呈强负相关。

## 可复现要素
- **数据集**：非公开数据集（无人类参与者数据），15条开场白脚本、10条拒绝脚本和10条话题转移脚本均为原创，已在Supplement 1（eMethods 1）全文公开；2,550条完整对话转录本可通过邮件向通讯作者申请获取（附内容警告）。
- **代码**：Python脚本（运行对话和计算统计数据）由Claude辅助生成，代码详情见Supplement 3数据共享声明；judge prompt完整发布于eMethods 3和eMethods 4。
- **权重**：17个聊天机器人均为API调用，其中4个模型（Kimi K3、DeepSeek V4 Pro、GLM 5.3、Qwen 3.8 Max）有公开可下载权重，其余13个为专有模型；模型标识符和版本信息见eTable 1。
- **关键超参**：temperature = 1.0，top-p = 1.0，最大输出tokens = 5,000，无固定seed；分支judge temperature = 0（最大400 tokens），编码judge temperature = 0（最大3,000 tokens）；稳定性检验使用 temperature = 0.3。
- **统计环境**：Python 3.14，SciPy，NumPy；bootstrap CI基于4,000次重采样；Kruskal-Wallis检验、Mann-Whitney U检验、Spearman相关、带固定效应的线性回归和logistic回归。

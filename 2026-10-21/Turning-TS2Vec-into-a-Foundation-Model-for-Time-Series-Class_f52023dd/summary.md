# 论文速读：Turning TS2Vec into a Foundation Model for Time Series Classification

## 一句话总结
本文证明经典的 TS2Vec 只需三项改动——合成数据预训练、双视图输入（原始幅度 + 实例归一化形状）、以及两名专家蒸馏——即可转化为一个仅 1.6M 参数的时间序列基础模型，在线性探测下达到 UCR-128 83.3% / UEA-27 75.3%，与当前 SOTA MantisV2 相差不足 0.3 个百分点，且无需 attention、无需 patch tokenizer、无需中间层提取。

## 研究问题与动机
- **现有 TSFMs 依赖大型 Transformer**：当前时间序列基础模型普遍采用预训练于大规模语料（真实+合成）的 Transformer 架构，参数量动辄数十至数百 M。
- **TS2Vec 被视作"过时"方法但从未被评估为通用编码器**：TS2Vec（2022）仍是强基线，但其设计始终围绕"在每个目标数据集上单独训练"的范式，从未作为单一冻结编码器跨数据集评测。
- **紧凑卷积架构的优势被忽视**：TS2Vec 的膨胀卷积网络可直接处理变长输入，无需重采样；这一特性在基础模型范式中几乎未被利用。
- **核心问题**：能否以最少改动将 TS2Vec 转变为真正的基础模型（单一编码器预训练一次，跨数据集复用）？

## 核心贡献（创新点）
1. **合成数据单轮预训练协议**：仅使用 CauKer 生成的单变量合成序列对 TS2Vec 编码器进行一次性预训练，替代原有的"每数据集单独训练"范型。
2. **原始幅度视图 + 实例归一化形状视图的双分支输入设计**：通过不同的 stem（MLP + GELU vs. 线性映射）分别编码两种互补视图，最终 concat 进入共享卷积主干。
3. **专家蒸馏为单一编码器**：将两种独立预训练的专家编码器（幅度专家与形状专家）通过余弦损失逐时戳和池化后蒸馏到一个 640 维输出的学生编码器中，直接对比学习无法复现同等效果。
4. **卷积架构无需固定长度即达 SOTA 水平**：展示 1.6M 参数的纯卷积编码器在零样本特征提取任务上与 2.2M 参数的 MantisV2 基本持平，且支持原生长度输入，避免了插值带来的性能下降。

## 方法详解

**Step 1：预训练协议**
- 使用 CauKer（Xie et al., 2026）生成合成单变量序列，编码器权重更新完全基于合成数据。
- 多变量数据集的通道独立编码后拼接嵌入。
- TS2Vec 原有层级对比目标保持不变：时间戳级 instance contrast + temporal contrast，尺度 s=0 到 S−1 最大池化递归构建层级。

**Step 2：双视图输入**
- **幅度视图（raw view）**：原始信号经过两层 MLP + GELU 非线性映射到 32 通道。
- **形状视图（instance-normalized view）**：经实例归一化后通过线性映射到 32 通道。
- 两视图 concat 为 64 通道输入送入共享卷积主干。非对称设计（幅度视图需额外非线性以对齐形状视图的编码空间）经消融验证重要。

**Step 3：蒸馏目标**
- 学生编码器输出 640 维（原来为 320 维），参数总量 1.64M。
- 使用因子化目标：分别用幅度专家和形状专家监督学生表示的前半部分和后半部分，损失为：
  - 时戳级余弦相似度损失（timestamp-level cosine loss）
  - 全局池化后余弦损失（pooled cosine loss）
- 直接用 TS2Vec 对比目标预训练双视图输入编码器效果差于蒸馏方案（UCR 差距从 0.56pp 扩大到 1.24pp，随数据量增加而扩大）。

**TS2Vec 原始编码器架构回顾**：10 个膨胀残差块（dilation = 2^k, k=0..9）+ 1 个输出块（64→320），感受野上限 8189 时戳，全局表示为时序最大池化。

## 实验与结果

**数据集**：UCR-128（128 个单变量分类数据集）、UEA-27（27 个多变量分类数据集）。

**评估协议**：冻结编码器特征，使用 200 棵树随机森林（三种预测种子均值）和 StandardScaler + Logistic Regression 两种 probe。预训练 checkpoint 按 seed 42 的 UCR RF 准确率选择，UEA 不参与选择。

**主要结果（Table 1）**：

| 模型 | 参数量 | UCR RF | UCR LogReg | UEA RF | UEA LogReg |
|------|--------|--------|------------|--------|------------|
| MantisV2 | 2.2M | **81.95** | **83.60** | **74.20** | **75.52** |
| TS2Vec-FM | 1.64M | 81.76 | 83.32 | 73.60 | 75.30 |
| TS2Vec（每数据集）| 0.6M/个 | 79.83 | 81.36 | 69.50 | 70.79 |

- TS2Vec-FM 比 MantisV2 少约 25% 参数，UCR/UEA 差距分别为 0.19/0.60 pp（RF）和 0.28/0.22 pp（LogReg）。
- 明显优于每数据集训练的 TS2Vec（UCR 差距 > 1.9%）。
- 优于除 MantisV2 外所有对比方法（TiConvNext UCR LogReg 75.3% vs. TS2Vec-FM 75.3%，基本持平）。

**消融（Table 2）**：
- 专家蒸馏在 100K→1M 系列数据时 UCR 提升 0.54pp，是直接对比学习的两倍增益；直接对比学习在更多数据下不升反降。
- 归一化视图在 UCR 上增益 2.9pp，但在 UEA 上损失 1.5pp，两者互补。
- 梯度裁剪对直接对比基线是必需的（数值稳定性问题）。

**原生长度优势（Appendix D）**：插值到固定长度 512 会削弱 TS2Vec-FM 性能（UEA 上损失 0.90pp RF / 0.56pp LogReg）。

## 相关工作脉络
1. **TS2Vec（Yue et al., 2022）**：层级对比学习经典方法，本文是其最直接的继承与扩展——唯一区别是预训练范式从"每数据集单独训练"变为"单一编码器跨数据集复用"。
2. **Mantis / MantisV2（Feofanov et al., 2026a,b）**：当前 SOTA 基础模型，使用 Transformer 架构和手设计多视图 tokenizer；本文表明卷积架构无需 attention 和复杂 tokenizer 即可逼近其性能。
3. **NuTime（Lin et al., 2024）、MOMENT（Goswami et al., 2024）**：同为 Transformer 基础模型，但参数量分别 2.0M 和 161.4M，显著大于 TS2Vec-FM（1.64M），且在 UCR/UEA 上均低于 TS2Vec-FM。
4. **TiViT-H / TiConvNext（Roschmann et al., 2025）**：来自视觉 ViT 的零样本特征提取；参数 180–276M，远大于本文模型，且依赖固定长度输入插值。
5. **CauKer（Xie et al., 2026）**：本文预训练数据的来源，通过结构性因果模型内的高斯过程核组合生成合成序列，是近年合成预训练的重要先行工作。

## 局限性与未来方向
- 论文仅在 UCR-128 和 UEA-27 两个基准上验证，未评估于其他主流时间序列任务（如异常检测、分段等）。
- 专家蒸馏方案是否可推广到其他骨干网络（如 Transformer）和 tokenizer 设计仍开放。
- 2M 系列规模的主模型仅在一个预训练 seed 下训练（消融中 100K/1M 使用三个 seed），泛化性尚待进一步验证。
- 对于超长序列（> 8189 时戳），感受野约束可能导致远距离依赖丢失，插值是唯一缓解手段但会引入性能下降。
- 模型目前为单变量编码器，多变量通过独立通道编码后拼接，未见联合多变量建模的实验。

## 研究启发与可借鉴点
1. **双视图互补性**：幅度视图捕获绝对信号值信息（对多变量分类关键），形状视图捕获归一化波形轮廓（对单变量分类更优）；在 tokenizer 设计中显式分离并融合多种信号视角是有效策略。
2. **蒸馏替代直接对比学习**：直接对比训练双视图编码器反而效果更差，而专家蒸馏能更好地保留两个子空间的判别信息——提示我们在多视图学习中，"先专后合"可能优于"同时学"。
3. **紧凑卷积架构的再利用价值**：主流 TSFM 几乎全为 Transformer，本文证明膨胀卷积 + 原始层级对比目标经适当改造即可达到接近 SOTA 的零样本性能，值得在资源受限场景（边缘设备、低延迟推理）中优先选用。
4. **合成数据预训练的稳定性**：使用 CauKer 合成数据预训练的蒸馏模型随数据量增大持续改善，而直接对比基线在大数据量下退化——提示蒸馏目标对合成数据规模具有更好的可扩展性。
5. **原生长度输入的重要性**：插值到固定长度会显著损害多变量基准上的性能，这一发现对所有处理变长序列的基础模型均有参考价值。

## 关键术语表
**TS2Vec**：Yue et al. (2022) 提出的时间序列层级对比表示学习方法，通过重叠上下文裁剪和时戳/实例双重对比目标学习通用时间序列嵌入。
**TS2Vec-FM**：本文提出的模型名，即将 TS2Vec 转化为时间序列基础模型的版本，通过合成预训练 + 双视图输入 + 专家蒸馏实现单一冻结编码器。
**Instance Normalization（实例归一化）**：对每条时间序列独立进行归一化（减去自身均值、除以自身标准差），使编码器专注于波形形状而非绝对幅度。
**CauKer**：Xie et al. (2026) 提出的合成时间序列生成器，通过结构性因果模型中的高斯过程核组合生成用于预训练的合成序列。
**Distillation（蒸馏）**：将多个独立预训练的"专家"编码器的知识迁移到单个"学生"编码器中的技术，本文使用时戳级和池化后余弦损失进行因子化蒸馏。
**Linear Probing（线性探测）**：冻结预训练编码器，仅在线性分类器（或 Logistic Regression / Random Forest）层上训练，以评估表征质量的标准协议。
**Dilated Convolution（膨胀卷积）**：通过在卷积核之间插入空穴（dilation factor）扩大感受野而不多增加参数的卷积操作，TS2Vec 中 dilation = 2^k 逐级增长。

## 可复现要素
- **数据集**：UCR-128（Dau et al., 2019）、UEA-27（Bagnall et al., 2018），均为公开基准，论文附录提供详细复现脚本说明。
- **合成数据生成器**：CauKer（Xie et al., 2026），代码开源（ICLR 2026）。
- **代码开源状态**：论文未明确声明代码仓库链接，但附录 C 提供了对 TS2Vec 官方代码（commit b0088e14）的复现验证，并说明作者已公开 TS2Vec 原始代码；TS2Vec-FM 代码需在论文正式发表后确认。
- **关键超参**：专家训练 batch size = 128，lr = 10⁻³；学生蒸馏 batch size = 512，lr = 4×10⁻³；梯度裁剪阈值 = 10（对比基线必需）；checkpoint 选择基于 seed 42 的 UCR RF 准确率；预训练序列长度 512 时戳。
- **下游探针**：200 棵随机森林（三种预测种子均值）；StandardScaler + Logistic Regression（seed 0）。

# 论文速读：VGL-stGen-Learning-a-shared-multimodal-model-for-lung-histol

## 一句话总结
本文提出了 VGL-stGen，一个基于预训练医学视觉语言模型（MedGemma-1.5-4b-it）适配的多模态大语言模型，通过大规模配对的肺脏 H&E 图像与空间转录组（ST）数据及单细胞参考进行联合训练。该模型以统一 decoder 支撑 13 种跨模态任务，并利用基因条件伪标签蒸馏将分子细胞类型监督迁移至组织学图像，实现了形态学、基因表达与细胞身份的结构化生成与条件补全。

## 研究问题与动机
1. **跨模态建模割裂**：现有 image–omics 方法多针对单一模态或特定预测任务设计，组织形态、基因表达与细胞身份信息长期处于独立框架中，缺乏能统一表征并灵活推理三者组合的模型。
2. **监督信号来源受限**：H&E 图像缺乏直接的细胞类型或表达水平标签，依赖人工注释成本高；而空间转录组与单细胞数据可提供丰富的分子监督，如何跨模态迁移监督尚不明确。
3. **推理条件差异未被统一评估**：不同任务在推理时可用输入差异巨大（仅基因、仅图像、部分基因+图像等），现有基线多在固定协议下评估，难以公平比较“图像条件”与“分子条件”下的结构化生成能力。
4. **计算参考标注的系统性偏差**：外部评估依赖 ARA-CNN 分割与 TACCO 注释转移等 silver labels，且部分 H&E 源在癌症训练阶段已曝光，评估独立性存疑，需在设计上尽可能缓解依赖。

## 核心贡献（创新点）
1. **统一的多模态生成式架构 VGL-stGen**：将医学 VLM 适配至肺脏 H&E 与 ST 联合任务，单一 checkpoint 支持分类、基因列表与离散表达水平三类输出的 13 项任务，不同于以往仅做对比对齐或单一预测头的多模态模型。
2. **基因条件伪标签自蒸馏机制**：利用表达数据的教师模型预测细胞类型，以 margin≥1.0 筛选高置信度标签对配对 H&E 图像提供监督，实现跨模态细胞身份迁移，使图像细胞分类性能显著提升。
3. **固定查询名自回归结构化解码**：在表达补全任务中将 25 个待预测基因名从输入中固定解析，仅对表达水平 token 进行约束解码与自回归生成，将自由生成 Pair-F1（0.0361）提升至 0.6596，显著优于非结构化生成协议。
4. **细粒度监督信号控制实验**：对比全答案监督与仅目标水平 token 监督（level-only），证明在图像条件表达补全中限制损失作用范围可进一步提升模型对配对 H&E 图像的敏感性，为多任务联合训练的损失设计提供实证依据。

## 方法详解
- **骨干网络与参数高效适配**：冻结 MedGemma-1.5-4b-it 的视觉塔，语言侧采用 QLoRA 适配（rank=16, alpha=32, dropout=0.05, 4-bit NF4 量化基础权重, bfloat16 计算）。最终 checkpoint 通过对齐最近 6 个 rank-16 adapter 在 rank-96 空间拼接平均得到。
- **三阶段训练流程**：① 基因/细胞类型适应（含分步提示变体，序列长度 1,536）；② 基因介导蒸馏（teacher 基于检测基因求和 log-probability 预测细胞类型，student 使用 300K 图像伪标签 + 200K replay 行，lr=1e-4，单 epoch）；③ 联合癌症训练（9 个转录组 replay + 二分类肿瘤/九类组织目标，禁用图像→细胞类型的直接监督）。
- **损失与采样策略**：主训练使用 token-level cross-entropy + focal weighting（γ=2.0）与 label smoothing（0.1）；九类组织任务引入逆频率样本加权；任务采样按校验损失 softmax 动态调整，clamped 至 [0.10, 0.50]。
- **结构化解码协议**：分类任务采用前缀树（prefix-tree）argmax 解码；基因列表任务允许自由生成后由 parser 提取；表达补全任务（Task 11/12）输入 75 个观测水平 + 25 个查询基因名，固定名称后对每个查询的 5 个合法首 token（Absent/Low/Med/High/Very High）进行自回归预测，以 Pair-F1 评估。
- **概率校正**：九类组织分类在 39-slide 开发子集上进行 pooled probability correction（各类概率除以该组均值后重归一化），raw F1m 0.1200 校正后达 0.2801；基因→细胞类型 first-token 校正后 BA 0.6876，F1m 降至 0.4452。

## 实验与结果
- **数据集**：训练使用 PortraiATLAS 中 69 例 lung ST-H&E（47 Xenium + 22 Visium）及 LuCA 单细胞参考，共 174.5 万细胞/spot。外部评估使用 4 个公开 10x 空间数据集（21.4 万 Xenium 细胞 + 0.99 万 Visium spot）与 TCGA-LUAD（452 幻灯片，35.7 万 patch）。
- **基线**：10 个开箱多模态模型（MedGemma-1.5-4B, Gemma3/4 系列, Qwen3-VL/3.8, DeepSeek-VL2, GLM-4.6V-Flash）、14 个冻结病理编码器+逻辑回归探针、Geneformer V2/C2S 变体及上下文 MLP。
- **主要结果**：VGL-stGen 在 Task 1（基因→细胞类型）取得 BA 0.6293 / F1m 0.6023，显著优于最强基线 Gemma4-31B（0.5035/0.4870）；Task 4（图像→肿瘤二分类）BA 0.7524，AUROC 0.8266；Task 11（图像条件表达补全）Pair-F1 0.6596，Task 12（细胞条件）0.6858，均优于 Qwen3.8-27B（0.6130/0.5621）；Task 13（水平对→细胞类型）准确率 0.7420。
- **提升幅度**：相较于次优模型，基因分类 F1m 提升 +0.1153，图像条件表达补全 Pair-F1 提升 +0.0466，细胞条件提升 +0.1236。格式约束控制实验表明性能增益不仅来自输出语法。
- **消融结论**：基因条件蒸馏使图像细胞分类 BA 从 0.161 提升至 0.226；固定查询名解码较自由生成提升约 18 倍；图像正确配对在保留观测表达时仍贡献约 +0.008 Pair-F1；level-only 监督在图像条件上持续优于 full-answer。

## 相关工作脉络
1. **ST-Net / STPath**：专注从 H&E 预测表达或 spot imputation，模型架构与任务目标分离；本文将其统一为共享 decoder 的条件生成任务，支持多输入组合。
2. **BLEEP / OmiCLIP / SPADE**：依赖对比学习或对齐 embedding 实现跨模态检索/映射；本文采用自回归生成范式，直接输出离散表达水平与基因列表，支持更丰富的任务组合与结构化约束。
3. **GenAR / SpaCKLE**：分别做表达 count 的自回归生成与邻近 spot 补全；本文在固定查询名约束下做 level bin 预测，避免长尾 count 分布的拟合困难，并引入图像/细胞类型条件。
4. **GHIST**：利用辅助细胞类型与邻域组成任务从 H&E 预测单细胞表达；本文通过教师模型蒸馏

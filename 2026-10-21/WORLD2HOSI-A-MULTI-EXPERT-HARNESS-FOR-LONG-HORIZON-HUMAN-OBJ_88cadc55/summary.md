# 论文速读：WORLD2HOSI-A-MULTI-EXPERT-HARNESS-FOR-LONG-HORIZON-HUMAN-OBJECT-SCENE INTERACTION GENERATION

## 一句话总结
本文提出 **World2HOSI**，一个基于多专家协调的编排框架，能够从 **3D Gaussian Splatting (3DGS)** 重建的场景与自然语言指令出发，生成连续的长周期 **人-物-场景交互 (HOSI)** 数据；其核心洞见是：长周期 HOSI 的关键并非依赖单一更强模型，而是通过结构化场景状态与阶段化规划，让多个异构运动专家协同工作，从而以较低数据成本覆盖复杂多阶段任务。

## 研究问题与动机
- **单一专家覆盖不足**：现有 HOI（人-物交互）与 HSI（人-场景交互）模型各擅胜场，但无法独立处理需要“先移动物体、后坐下”等多阶段、多技能组合的长周期任务。
- **统一模型训练数据匮乏**：训练端到端 HOSI 生成器需要覆盖多样动作、物体与场景组合的数据，而高质量动捕数据昂贵且稀缺，导致统一模型难以扩展。
- **场景表示缺乏交互结构**：原生 3DGS 主要为视觉渲染服务，缺少对象级身份、碰撞几何与支撑区域等可查询、可更新的交互结构，难以支撑跨专家的状态传递。
- **跨专家边界协调困难**：不同专家模型的能力边界与运动表征存在差异，简单拼接易导致时空不连续与物理伪影。

## 核心贡献（创新点）
1. **首个面向长周期 HOSI 的多专家编排 harness**：通过阶段化任务编译与共享场景状态，无需训练统一生成器即可复用现有 HOI/HSI 专家，扩展任务覆盖范围。
2. **交互式场景包 (ISP) 结构化表示**：为 3DGS 场景注入持久对象身份、局部几何、支撑区域与导航占用层，使不同专家能在一致的世界描述下进行条件输入与状态更新。
3. **阶段编译器与 Motion Intermediate Representation (MotionIR)**：将自然语言意图分解为有序动作脚本，并编译为统一定义坐标帧、单位与人体表征的数值条件，降低跨模型异构性。
4. **基于投影的跨专家边界协调器**：仅对 incoming 片段进行平滑修正，在局部时间窗口内对齐前后段边界状态，兼顾连续性与专家输出完整性。
5. **有界残差物理优化**：采用 RL 控制器对运动参考进行有界调整，结合 PD 执行与接触驱动物理仿真，减少漂浮、穿透与足部滑动等伪影，同时保留交互意图。

## 方法详解
- **Interactive Scene Package (ISP)**：定义场景状态 $W$（公式 1），包含视觉资产 $V$、静态背景 $B$、每个对象的唯一 ID、局部几何 $G_i$、世界变换 $T_i \in SE(3)$、物理属性 $A_i$、支撑区域 $S_i$、导航占用 $M$ 与关系 $R$；对象与背景分离，且 $T_i$ 同时驱动视觉、碰撞与语义几何的一致性更新。
- **任务编译与场景锚定**：LLM 基于 ISP 信息生成结构化 Activity Script，记录动作类型、对象 ID、目标区域与支撑关系；每阶段编译器 $\text{Compile}(a_k, W_k, h_k)$ 输出 MotionIR（公式 2），包含目标位姿 $T_{o_k,k}$、人与物路径/航点 $\mathcal{P}_k^h, \mathcal{P}_k^o$、世界目标区域 $\mathcal{G}_k$ 及元数据 $\eta_k$。
- **多专家运动合成**：导航专家（如 Kimodo）、动态 HOI 专家（如 HOI-FHLI）、静态 HSI 专家（如 DIMOS）分别通过统一上游接口接收条件，输出各自阶段运动；专家与具体模型解耦，可替换或新增。
- **跨专家协调（边界投影）**：计算前后段末端与起始端的平移与旋转偏差 $\Delta p, \Delta R_j$（公式 3），采用五次 smoothstep 权重 $s(u)$（公式 4）在时长 $\tau$ 窗口内对 incoming 片段施加修正（公式 5–6），保持前段固定、仅局部平滑过渡。
- **有界残差物理优化**：控制律（公式 8）在参考关节目标 $q_{\text{ref}}(t)$ 周围叠加残差，经掩码 $m$、边界 $b$ 与 joint limits 裁剪后由 PD 控制器执行；奖励函数（公式 9）平衡朝向、位置、手-物几何跟踪与加速度平滑，使用 PPO 训练，确保物理可执行性而不偏离参考意图。

## 实验与结果
- **数据集与任务**：构建 10 个 ISP 场景（真实重建与合成混合），设计 20 条人级自然语言指令，覆盖搬运、推拉、坐、躺及多阶段组合任务；每任务 3 个随机种子，共 60 条序列。
- **评估基线**：InfBaGel、HOSIG、以及单专家变体 HOI-FHLI；所有方法共享相同的任务语义、场景、对象几何与导航路径（基于 $A^*$ 与碰撞后处理生成）。
- **主要定量结果**：World2HOSI 在任务进度分 $S_t = 76.93$、几何分 $S_g = 75.61$ 上领先；接触率 OCP 达 84.94%，严重穿透帧比 $P_f = 24.92\%$，足部滑动 FS = 0.255，足-地偏差 $O_{\text{feet}} = 4.27$，均优于基线（表 1）。
- **多样性对比**：在 90 条生成序列中，Action 多样性 0.6284、Target Obj 多样性 0.6796、APD 23.57 cm，均高于 BEHAVE、TRUMANS、LINGO 的等规模随机子集（表 2）。
- **消融**：边界协调采用投影适配器（A2）相比直接拼接（A0）与双边插值（A1）显著降低关节位移、角度变化与速度跳变；物理残差优化使人-物跟踪误差 $E_h=5.39$ cm、$E_o=3.07$ cm（表 3–4），有效消除漂浮与穿透伪影。
- **用户研究**：30 名参与者在 8 组对比视频中对任务完成度与交互质量评分，World2HOSI 偏好率显著领先。

## 相关工作脉络
- **HOI-FHLI / OMOMO / CHOIS**：聚焦人-物协同生成，缺乏场景几何约束与长周期规划能力；本文通过 HOI 专家 + 场景状态更新扩展其任务边界。
- **InfBaGel / HOSIG / InteractMove**：尝试联合 HOSI 生成，但受限于数据稀缺或单模型泛化能力；本文以多专家编排规避统一训练的数据依赖。
- **DIMOS / Kimodo / OmniControl**：面向 HSI 或可控导航的专家模型；本文将其作为可插拔组件，通过统一条件接口与状态写入实现跨专家协作。
- **WorldAct / InteriorGS / EgoSim / InHabit**：提供可编辑场景资产或静态交互生成；本文在此基础上引入持久对象身份与阶段化状态闭环，支持动态重定位后的后续交互。
- **ResMimic / PhysHOI / InterMimic**：侧重物理仿真或接触驱动执行；本文将这些物理后处理与运动生成解耦，仅在专家输出基础上进行有界残差修正。

## 局限性与未来方向
- 物理优化依赖于所选专家生成的运动参考，难以纠正重大错误或从根本上修复不可行的交互配置。
- 当前 ISP 构建依赖分割模型（如 SAM3）与 LLM 先验，在复杂遮挡或新颖物体上可能存在识别偏差。
- 专家库目前覆盖导航、动态 HOI 与静态 HSI 三类，尚未纳入更细粒度接触原语或双手协同任务。
- 未来可探索更强的物理推理模块、自动专家发现与条件自适应、以及更大规模真实场景下的泛化评估。

## 研究启发与可借鉴点
- **多专家编排范式**：以任务分解 + 共享状态 + 接口标准化替代端到端统一训练，为低资源多技能生成提供可扩展路径。
- **结构化场景包设计**：将视觉资产、碰撞几何、支撑区域与导航占用分层解耦，便于跨模型条件传递与状态回写。
- **单向边界投影协调**：仅对 incoming 片段施加修正，避免双向平滑带来的历史信息损耗，值得移植到任意多段运动拼接任务。
- **有界残差优化策略**：在参考轨迹邻域内搜索物理可行解，兼顾保真度与可执行性，可推广至其他运动生成-仿真联合管线。

## 关键术语表
- **HOSI (Human–Object–Scene Interaction)**：涵盖人、可移动物体与静态场景三者协同交互的长周期动作序列。
- **ISP (Interactive Scene Package)**：封装对象身份、视觉/碰撞资产、支撑区域、导航占用与空间关系的场景状态数据结构。
- **MotionIR (Motion Intermediate Representation)**：将阶段任务编译为统一坐标帧、单位与人体表征的数值条件中间格式。
- **交叉专家协调 (Cross-Expert Reconciliation)**：通过投影适配器在专家运动片段边界处保证时空连续性的轻重量级后处理模块。
- **有界残差优化 (Bounded Residual Optimization)**：基于 RL 的局部修正机制，在参考轨迹邻域内施加 PD 控制以消除物理伪影。
- **任务进度分 $S_t$**：按阶段加权的部分完成度累计得分，反映长周期任务的结构化执行质量。
- **几何分 $S_g$**：综合接触率、穿透比、足部滑动与足-地距离的几何合理性评分。

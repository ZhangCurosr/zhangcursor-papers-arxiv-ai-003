# 论文速读：WORTH-Benchmark-Evidence-Discovery-under-Not-Fully-Cooperati

## 一句话总结
本文提出 WORTH Benchmark，要求模型在无标注的完整悬疑叙事中自主挑选关键线索句并推断案件参与者，首次将“证据发现”与“非完全合作信息关系”同时纳入推理评测。两集试点实验（70次正式运行）揭示了模型线索命中与结论判定解耦、跨模型共趋错误、以及正负证据处理不对称等诊断现象。

## 研究问题与动机
1. 现有推理评测默认所有输入信息均为“ helpful/cooperative”，模型只需在给定前提下推理，未考察现实信息中合作与遮蔽并存的复杂关系。
2. 主流任务仅测量“给定证据后的推理”，将“哪些信息值得成为证据”排除在评估目标之外。
3. 单纯拉长文本或人工插入干扰项属于后验噪声，无法模拟专业叙事中作者主动设计的显著性控制与因果框架遮蔽。
4. 需要一种能分离考察证据发现前端与结论生成后端的评测框架，以诊断模型推理链路中的结构性短板。

## 核心贡献（创新点）
1. **概念突破**：首次将自主证据发现与非完全合作信息关系同时引入LLM推理评测，打破前提给定式评测的默认假设。区别于GSM8K/MATH等传统基准仅关注“给定前提的推导正确性”，本文聚焦“起点本身如何被识别”。
2. **原创叙事评测框架**：提出基于专业作者从零创作悬疑故事的可执行评估方案，作者在创作阶段预埋推理核心（K）而非事后标注。区别于WHODUNIT等使用公有领域经典小说的方案，本工作从源头控制证据链与遮蔽结构，规避数据污染风险。
3. **分项解耦评分设计**：线索命中与参与者判定独立计分，允许“找到的证据”与“基于证据得出的结论”不同步。区别于DetectBench/ERASER仅将证据作为辅助输出，本文将其提升为核心可量化维度并与终端判断分离记录。
4. **可观测的行为诊断现象库**：通过试点实验系统报告过程解耦、常见吸引子、正负证据不对称三类现象。区别于单一总分排名，本文强调多维行为结构的可追溯性，为后续机制研究提供实证锚点。

## 方法详解
- **三阶段任务流**：线索定位（从完整文本中独立评估并选出有限配额的关键句）→ 分析推理（基于选中线索进行逻辑/常识/社会知识整合）→ 参与者归因（从候选列表中多选判定案件参与者）。当前仅量化第一阶段与第三阶段。
- **非完全合作信息环境**：文本中合作信息（可推导真相的证据）与对抗信息（通过叙事焦点、显著性控制、因果框架转移延迟真相）天然共存。对抗性不指虚假或敌对，而指事实正确但呈现方式会误导读者判断。
- **关键线索集 K 的设计**：K 是作者在故事世界观、人物轨迹、事件序列规划阶段预设的推理核心句，附带推论功能与证据链位置说明；K 不代表故事中所有有效证据，仅衡量模型是否命中作者预设的推理枢纽。
- **配额与奖罚机制**：线索选择采用配额制（选非K句不扣分但消耗额度，机会成本惩罚）；参与者选择采用显式奖罚（正确角色奖励，错误角色扣除）。EP01权重统一（线索3分，正确7/5/5分，错误-5分）；EP02差异化（线索1-4分加权，正确2分，错误-2至-8分）。
- **三层验证条件**：全故事条件（本文实现）→ 证据提示条件（显式标记K后对比归因变化）→ 证据修改条件（修改关键事实看判断是否跟随），后两层待后续实现。
- **解释计分策略**：自然语言分析仅保留用于诊断，当前不计独立分数，以避免将开放推理过程扭曲为对评分启发式的优化。

## 实验与结果
- **数据集**：EP01（120句/12条关键线索/6候选角色）与 EP02（134句/20条关键线索/9候选角色），均为原创中文悬疑叙事。
- **评测规模**：共测试10个商业LLM，每模型运行5次，70次正式运行，67次内容可评分（EP02排除3次无效标识运行）。
- **主要数值结果**：
  - EP01：GPT-5.6 Sol线索命中均值最高（3.4/12），但正确参与者最少（0.8/3）；DeepSeek-V4-Flash相反（2.2/12线索，1.6/3正确参与者，0次误选），呈现明显过程解耦。
  - EP02：37次可评分运行中31次（83.8%）均包含错误的“Father – Jia Changgeng – Director Huang”三人组；相邻的怀疑导向句S113被选25次，平反导向句S112被选0次（25:0）。
  - S124（核心谜题前提，非K成员）被全部37次运行选中；EP01正确角色R04（第一人称叙述者“I”）在30次运行中0次被选中。
  - EP02整体分数偏低，75.7%的运行得分为负，主因是高显著性干扰项带来的惩罚超过线索得分。
- **结论**：线索命中不保证结论准确；高显著性叙事信号易引发跨模型一致误判；当前模型对怀疑信息显著偏好，对平反证据存在系统性忽略。

## 相关工作脉络
1. **HotpotQA / MuSiQue / DetectBench**：已尝试独立报告证据选择与最终答题，但依赖百科或片段式侦探材料，未引入原创叙事中的作者级信息遮蔽设计，任务仍由预设问题驱动，不考核“找起点”本身。
2. **WHODUNIT / DetectiveQA**：使用完整悬疑小说要求指认凶手，但未强制输出线索句，无法观测推理路径；公有领域小说存在训练数据污染风险，WORTH从零创作规避此问题。
3. **ERASER / Explanation Faithfulness**：聚焦跨任务理由抽取与解释忠实度，面向合作型文本（百科/新闻/医学期刊），未考察原创叙事中合作与对抗信息共存的证据发现动态。
4. **Adversarial NLI / GSM-IC / LoFa**：通过人工改写或插入无关句构造对抗输入，属后验扰动；WORTH的对抗性源于专业作者的叙事设计，是文本内在功能分布而非外部噪声。
5. **Grice Cooperative Principle / Epistemic Vigilance**：语用学与认知科学理论支撑“合作/对抗”信息关系划分，现有LLM研究多集中于对话或短文本，缺乏长篇叙事中信息遮蔽的实证测量。
6. **True Detective / WhodunitBench**：前者侧重多跳因果推理的最终答案，后者侧重多轮交互问答；二者均未将“证据句选择”作为独立可量化评分维度，无法分离前端发现与后端推理的表现差异。

## 局限性与未来方向
- **局限性**：仅实现全故事条件，证据提示与修改条件尚未运行；仅两集试点与70次运行，无法建立稳定排名或推断普适认知机制；人类玩家数据尚未完成清洗导出，未报告人机对比；自然语言解释未计分；评分权重对模型部分隐藏，策略性行为控制的实际效果待验证。
- **未来方向**：实现证据提示/修改条件以分离叙事显著性与模型判断的贡献；完成人类数据清洗并开展同任务基线对比；扩展更多集数与跨体裁验证模式；形式化叙事设计方法论（显著性梯度设计、结果反馈校准证据结构）；探索解释质量的自动化或双盲人工评分机制。

## 研究启发与可借鉴点
1. **前后端解耦评分范式**：将“证据检索/选择”与“结论生成”分离计分，可精准定位模型推理链路的断裂环节，适用于法律、医疗、金融等需强证据支撑的长文本任务评测。
2. **专家共创型材料生产**：由领域创作者（如悬疑作家）从源头设计证据链与遮蔽结构，比众包标注或规则生成更具生态效度；该协作流程（叙事设计×评测方法论×诊断分析）可为其他垂直领域基准提供生产模板。
3. **共同吸引子量化指标**：统计跨模型/跨运行的错误收敛比例，可直接反映干扰项设计的有效性，为基准题项质量评估提供可复用的诊断维度。
4. **相邻对立句频率对比**：利用物理相邻但功能相反（怀疑/平反）的句对统计选择差异，可作为测量模型确认偏误或认知警惕性的标准化探针，易迁移至科学文献批判或法庭证据评估场景。
5. **配额机会成本机制**：以有限选择配额替代直接负向扣分来约束无关选项，更符合真实信息筛选的代价结构，可减少策略性回避行为，适合开放域问答与长文档理解任务。

## 关键术语表
**WORTH Benchmark**：由Bread Studio提出的推理评测基准，要求模型在无标注叙事中自主发现线索并推断参与者。
**Autonomous Evidence Discovery**：模型从完整未标注文本中独立判断并选出具有推论价值句子的能力。
**Not-Fully-Cooperative Informational Relationships**：文本信息并非全然服务于解题，合作信息（推理论据）与对抗信息（叙事遮蔽）共存，源于Grice合作原则与认识论警惕理论。
**Key Clue Set (K)**：作者在故事创作阶段预设的推理核心句集合，作为线索命中评分参考，非事后人工标注。
**Process Dissociation**：本基准中“线索命中数”与“参与者判定准确率”呈不同步解耦的现象。
**Common Attractor**：不同模型在多轮运行中高度收敛于同一组错误候选人或线索组合，反映高显著性干扰信号的系统性误导效应。

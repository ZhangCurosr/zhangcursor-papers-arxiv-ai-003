# 论文速读：When-Can-LLM-Reasoning-Reliably-Reuse-Intermediate-Results

## 一句话总结
论文研究了大型语言模型在推理时如何可靠地重用中间结果，给出了局部重试策略在正确前缀下的轨迹可靠性边界与最坏情况期望尝试次数的紧界，并在复合数学与算术任务上验证了不同选择策略、上下文配置与预算分配的实证表现。

## 研究问题与动机
- 复合推理任务需要将多个子问题共同解决，完整解采样在一次运行中必须同时答对所有子问题；当子问题分散在不同采样中时，联合成功概率低于单独覆盖概率的乘积。
- 中间结果重用可以避免重复已完成的正确工作，但“通过检查”并不等于“真实正确”，错误可能沿链传播并影响后续步骤。
- 现有方法（Least-to-Most、Tree of Thoughts、Chain-in-Tree、MAKER等）已在不同程度上使用中间状态，但缺乏对有限预算、首接受规则与全局停止条件下的系统可靠性与工作量分析。
- 需要刻画检查精度、接受概率与重试预算如何共同决定最终可靠性与总计算成本。

## 核心贡献（创新点）
- 给出局部重试回路在每步接受/拒绝与接受态错误率统一界下的轨迹可靠性乘积下界，并导出达到目标失败概率所需的最小重试上限。  
  与已有工作的本质区别：将“首接受即停止+全局耗尽停止”与接受态错误率显式绑定，给出可达等号的最坏情形构造。
- 证明有限预算重试回路的期望执行尝试数满足 $\Theta\!\big(N + \tfrac{NR}{\log(N{+}1)}\big)$ 的最坏界，覆盖正确前缀与错误接受后的任意后续状态。  
  与已有工作的本质区别：不同于自一致性/多数投票的分析，本文考虑首次接受后错误路径仍可能带来高拒绝状态，并通过停止规则做统一上界。
- 建立检查精度—接受概率—每步成本之间的关系，给出以 $\log N$ 级预算实现目标可靠性的充分条件与线性期望工作量。  
  与已有工作的本质区别：将检查噪声模型（全票/多数）与接受概率下界结合，显式刻画 $g_N/h_N$ 代价尺度。
- 在 LoRe-Compo 复合数学与多基数算术任务上系统对比完整采样、候选选择、保留上下文与预算分配，揭示“相似首访准确率可能对应截然不同的多次重试覆盖”。  
  与已有工作的本质区别：同时报告第二子问题覆盖率与联合成功含义的差异，避免把覆盖等同于联合正确。
- 提出用重试曲线与对数时间Sigmoid拟合早期观测来预测Agent后续得分，并在 EdgeBench 上给出相近的预测误差。  
  与已有工作的本质区别：基于重复尝试模型的形式化曲线，而非纯经验曲线，用于跨任务类别的先验预测。

## 方法详解
- **状态与分解形式化**：复合任务记为 $x_1 \oplus x_2$，目标答案为 $[a^*(x_1), a^*(x_2)]$；将任务分解为 $N$ 步，状态 $s_t=[x, z_1,\dots,z_t]$，每一步从 $p_\theta(\cdot|s_{t-1})$ 采样。
- **保留状态与检查**：复用时的 $s_t$ 为实际传递的状态（任务信息+保留文本或提取答案）。检查器 $\mathcal{V}_t$ 决定是否接受，接受不一定等价于真正正确。
- **单步失败分解**：在正确进入历史 $s$ 下，记拒绝概率 $\rho_t(s)$ 与单次错误接受概率权重 $w_t(s)$，给定首次接受的条件下错误率为 $\alpha_t(R;s)=\frac{w_t(s)}{1-\rho_t(s)}$。
- **局部失败概率**：单步预算 $R$ 下的失败来自耗尽或错误接受：
  $$\beta_t(R;s)=\rho_t(s)^R + (1-\rho_t(s)^R)\alpha_t(s).$$
- **轨迹可靠性**：若每步 $\rho_t(s)\le\rho<1$、$\alpha_t(s)\le\alpha$，则全部 $N$ 步正确保留的可靠性满足：
  $$\Pr(H_N)\ge[(1-\rho^R)(1-\alpha)]^N.$$
  达到目标失败概率 $\delta$ 的充要精度条件为 $\alpha < 1-(1-\delta)^{1/N}$。
- **期望工作量上界**：对允许错误接受后任意拒绝分布的类，执行尝试数的最坏期望为：
  $$\sup_{P\in\mathcal{P}_{N,R}}\mathbb{E}[W]=\Theta\!\Big(N+\frac{NR}{\log(N+1)}\Big).$$
- **精度—接受—成本关系**：若正确前缀接受概率 $\ge h_N$、接受错误率 $\le c\delta/N$，取
  $$R_N=\Big\lceil\frac{1}{h_N}\log\frac{N}{(1-c)\delta}\Big\rceil,$$
  可得 $\Pr(H_N)\ge1-\delta$、$\mathbb{E}[W]=O(N/h_N)$、$C_{\text{vsr}}=O(Ng_N/h_N)$。
- **实验协议**：复合任务使用两阶段协议，先生成 $M$ 个 $x_1$ 候选，按 Oracle/SC 保留最多 $B$ 个继续 $x_2$；算术任务对完整答案进行有限次重试，统计未解比例 $\hat{E}(R)$。

## 实验与结果
- **模型与数据**：DeepSeek-R1-Distill(1.5B/7B/8B/14B)、Qwen3-Thinking(4B/30B-A3B)、GPT-OSS(20B/120B)；复合数学使用 LoRe-Compo（250对 MATH500）；算术任务覆盖 base 7/10、加减乘、位数 $n\in{1,\dots,10}$，每问题 32 次完整答案尝试。
- **完整采样联合覆盖**：八模型均值在 Pass@1 为 8.2%，最大预算时为 33.3%；GPT-OSS-120B 的 Pass@1=19.6%、Pass@128=38.4% 最高。
- **候选选择效果**：Oracle 与 SC 在第二子问题覆盖率上差距很小（四 DeepSeek SC 均值 57.9%，八模型最大差 1.6pp），说明二者在该指标上近似。
- **保留上下文对比**：四 DeepSeek 均值显示，第二子问题成功率分别为 no\_context 36.2%、answer\_only 57.2%、full\_context 58.3%；答案-only 较无上下文提升 21.0pp，完整上下文再提升 1.1pp。
- **预算分配权衡**：八模型均值从 (M,B)=(4,2) 的 52.8%/36.4K 提升到 (8,4) 的 56.3%/72.3K，再到 (16,8) 的 57.4%/144.5K；增加 $B$ 的边际收益以更少新增 token 换取相似增益。
- **算术重试覆盖**：320 个条件中 235 个在 32 次后无未解题；Base 10 加法全部清零，Base 7 乘法未解比例最高（均值 0.40）。相似 Pass@1 可能对应完全不同的重试增益，例如 R1-1.5B 在 base 7 加法 n=3 时从 0.08 升至 0.98，而在 base 7 乘法 n≥7 时始终为 0。
- **Agent 得分预测**：EdgeBench 上用 2/4 小时预测 6/8/10/12 小时，重试曲线与对数时间 Sigmoid 的中位相对误差相近（12 小时分别为 10.7% 与 10.9%），重试曲线在 10% 与 20% 误差阈值内略优。

## 相关工作脉络
- **完整解采样与组合性分解**：与 Brown 等、Lightman 等、Wang 等的测试时采样与过程监督相比，本文显式区分“候选池中的分别覆盖”与“单次联合成功”，并给出状态重用的可靠边界。
- **Least-to-Most、Tree/Graph of Thoughts、Chain-in-Tree**：这类方法利用或部分复用中间状态，本文在其之上给出“首接受+全局耗尽”的回 loop 理论与工作量界，强调检查精度而非搜索广度。
- **MAKER**：MAKER 在投票模型下给出近线性期望成本，但依赖局部成功概率大于一半的假设；本文在更弱的“正确前缀处接受概率与错误率一致有界”的条件下给出 $\log N$ 预算与线性期望尝试。
- **Self-Consistency 与过程验证**：本文使用 Oracle 与 SC 作为选择器，指出二者在第二子问题覆盖率上相近，并强调“通过检查”不等于验证整条推理迹线。
- **状态压缩与记忆保留**：与 Atom of Thoughts、MEM1 关注“保留什么”不同，本文侧重“保留后必须满足的正确性与继续条件”。
- **启动演示测试与重启调度**：将重试停止模式与经典统计测试相连，但与 Luby 式最优重启调度不同，本文使用固定预算与全局停止规则。

## 局限性与未来方向
- 理论假设重试独立同分布并在耗尽时终止，实际反馈依赖、退路策略与上下文长度效应未纳入分析。
- 检查精度难以从 Oracle/SC 的覆盖率直接估计，保留推理迹线时未检查部分的错误率未被量化。
- 分解粒度影响可检性与成本：步长越小检查越多但每步更易通过，步长越大信息更多却更难验证。
- 复合与算术实验未直接估计长链在每个前缀处的统一可靠性，开放域任务需要任务特异的检查与表示。
- 当完整解已经足够可靠时，额外检查与状态处理成本可能超过重用节省。
- 未来方向包括：引入错误修复与反馈更新机制、对保留上下文进行误差传播建模、在真实 Agent 工作流中验证总成本与早期停止收益。

## 研究启发与可借鉴点
- 可将“正确前缀处接受概率与接受态错误率”作为系统级可靠性指标，指导重试预算分配与检查器阈值设定。
- 实验中“第二子问题覆盖率”与“联合成功”的区分值得沿用，避免把部分覆盖误读为端到端正确。
- 预算分配实验表明增加延续候选 $B$ 的性价比可能高于单纯扩大初选 $M$，可在工程中以单位 token 收益为准则调整。
- 算术任务的混合分布拟合（快速衰减/慢速衰减双分量）可为“可解实例 vs 持久难实例”的诊断提供指标。
- 将重试曲线引入 Agent 早期评估，可用于跨任务类别的成本预测与资源调度。

## 关键术语表
- **Trajectory reliability**：从初始状态到第 $N$ 步全部保留状态正确的概率下界，由每步拒绝概率与接受态错误率决定。
- **Accepted-state error**：在给定状态被检查器接受的条件下，该状态实际不正确的条件概率。
- **Local retry with global stopping**：每步在预算 $R$ 内首接受即推进，若某步耗尽则全局终止。
- **Pass@K**：K 次独立完整采样中至少一次返回正确最终答案的覆盖率。
- **Second-subproblem retention coverage**：保留路径中至少有一条能答对第二子问题的比例，包含退路并忽略第一子问题是否正确。
- **Unsolved fraction $\hat{E}(R)$**：在前 $R$ 次尝试中均未得出正确答案的问题比例。
- **Self-consistency selection**：以出现频率最高的答案为候选，当其得票占比不低于阈值时保留。
- **Cost scale $g_N/h_N$**：单次尝试总成本与正确前缀处接受概率下界的比值，决定可靠重用的总体成本量级。

## 可复现要素
- **数据集**：LoRe-Compo 来自 LoRe 官方仓库（https://github.com/ASTRAL-Group/LoRe），算术任务按 seed 生成 base 7/10 加减乘、$n\in{1,\dots,10}$ 各 50 题。
- **代码**：论文声明代码已开源（https://github.com/SempraETY/Intermediate-State-Reuse）。
- **关键超参**：生成最大长度 10,240 tokens；LoRe-Compo 使用 top-p=0.7/top-k=50、seed=42、repetition penalty=1.05、family-specific temperature；算术采样 DeepSeek temperature=0.6/top-p=0.95，Qwen3 temperature=0.6/top-p=0.95/top-k=20，GPT-OSS temperature=1.0/top-p=1.0；SC 投票阈值 0.5；预算组合包括 (M,B)={ (4,2),(8,2),(8,4),(16,8) }，算术重试上限 32。

# 论文速读：When-Can-LLM-Reasoning-Reliably-Reuse-Intermediate-Results

## 一句话总结
本文系统研究了LLM推理中中间结果的可靠复用问题，给出了局部重试循环在保留状态条件下正确完成所需的理论条件与期望计算成本上界，并在8个推理模型上以复合数学配对题和算术任务进行了实验验证。

## 研究问题与动机
1. **完整解采样的组合瓶颈**：在独立采样方案下，需要单次运行同时解出所有子问题；随着任务增长，末尾失败时之前正确的中间工作会被丢弃并重复生成，造成计算浪费。
2. **复用中间状态的准确性风险**：保留中间结果可避免重复工作，但检查器可能接受错误候选（benchmark研究表明中间推理错误的识别本身困难），且错误会向后续步骤传播。
3. **检查本身消耗计算**：避免重启并不自动等于节省，需要分析检查精度、接受概率与总计算成本之间的权衡关系。
4. **首次准确率无法预测重复尝试收益**：在算术任务中观察到，相同的首次尝试准确率在不同任务上可能导致截然不同的多次尝试覆盖率。

## 核心贡献（创新点）
1. **给出了局部重试循环的轨迹可靠性下界与有限预算的精确错误阈值**：在每步独立同分布重试与全局停止规则假设下，推导了可靠完成所需的最小重试预算公式（Corollary 1），并明确了当接受状态误差需满足 $\alpha < 1 - (1-\delta)^{1/N}$ 才能保证目标可靠性 $1-\delta$。
2. **建立了最坏情况期望尝试次数的紧确上界**（Theorem 2）：证明期望工作量上界为 $\Theta(N + NR/\log(N+1))$，包含错误接受路径上的额外消耗，且与经典启动演示测试（start-up demonstration tests）建立联系。
3. **提出精度-接受概率-成本三角关系的统一分析框架**（Corollary 1）：将检查成本 $g_N$、接受概率下界 $h_N$ 与重试预算 $R_N = O(\log N)$ 统一纳入，推导出线性期望尝试与 $O(N g_N/h_N)$ 总成本的结论。
4. **跨8模型的系统性实验验证**：在复合数学（LoRe-Compo）与多基础算术任务上对比了完整采样、候选选择策略（Oracle/SC）、保留上下文类型与预算分配方案，揭示了答案复用 vs 完整推理链复用的边际效益差异。

## 方法详解
1. **任务与状态定义**：复合任务 $x_1 \oplus x_2$ 需两个子问题均正确；将任务分解为 $N$ 步，每步生成文本 $z_t$，状态 $s_t = [x, z_1, \dots, z_t]$；检查器 $\mathcal{V}_t$ 对候选状态做通过/拒绝判断，通过不蕴含正确性（$\mathcal{G}_t$ 表示真实性）。
2. **局部重试循环（Def. 1）**：在每个步骤 $t$ 从保留状态 $s_{t-1}$ 采样候选，用检查器判断是否接受；若接受则进入下一步，若所有 $R$ 次尝试均被拒绝则终止整个任务。
3. **单步失败概率分解**（Eq. 5）：$\beta_t(R;s) = \rho_t(s)^R + (1 - \rho_t(s)^R) \cdot \alpha_t(s)$，第一项为预算耗尽，第二项为错误接受。
4. **轨迹可靠性下界**（Theorem 1）：$\Pr(H_N) \ge [(1-\rho^R)(1-\alpha)]^N$；目标可靠性 $1-\delta$ 的必要充分条件为 $\alpha < 1 - (1-\delta)^{1/N}$。
5. **期望工作量最坏界**（Theorem 2）：$\sup_{P \in \mathcal{P}_{N,R}} \mathbb{E}_P[W] = \Theta(N + NR/\log(N+1))$，通过分治高频拒绝状态（用 $\theta^R \mathbb{E}[Z] \le 1$ 约束）与低频拒绝状态（几何级数上界）两部分求和证明。
6. **精度-成本关联**（Corollary 1）：给定接受概率下界 $h_N$ 与每尝试成本上界 $g_N$，选择 $R_N = \lceil \frac{1}{h_N}\log\frac{N}{(1-c)\delta}\rceil$ 即可保证 $\Pr(H_N)\ge 1-\delta$，此时 $\mathbb{E}[W] = O(N/h_N)$，总成本 $C_{\text{vsr}} = O(N g_N / h_N)$。
7. **二元检查模型的精粹-接受权衡**（Appendix B.10.5）：全体一致检查（unanimity）导致接受概率多项式级稀有，期望成本 $\Theta(N^{1+\gamma}\log N)$；多数投票检查可保持接受概率远离零，达到 $O(N\log N)$ 期望成本。

## 实验与结果
1. **模型与数据集**：8个推理模型（DeepSeek-R1-1.5B/7B/8B/14B、Qwen3-4B/30B-A3B、GPT-OSS-20B/120B）；复合数学使用 LoRe-Compo（250对 MATH500 独立主题问题）；算术使用 Base 7/10 的加法和乘法，各1-10位数字，每条件32次独立尝试。
2. **完整解采样基线**（Table 2）：8模型均值 K=1 时 8.2%，K=32/128 时 33.3%；GPT-OSS-120B 的 Pass@1=19.6%、Pass@128=38.4% 为最高；排名随采样预算变化。
3. **候选选择策略对比**（Table 1）：Oracle 与 SC（阈值0.5）在4个DeepSeek模型上的二阶成功率为 Oracle=57.75% vs SC=57.87%，差异极小；SC-to-Pass@8 的 token 比约 1.01–1.5。
4. **保留上下文类型**（Table 3）：four-DeepSeek 均值，no_context=36.2%、answer_only=57.2%（+58%相对提升）、full_context=58.3%（仅再+1.1pp），说明保留答案即可恢复大部分信息，完整推理链增益有限。
5. **预算分配扫查**（Table 4）：M=8,B=4 达到 56.3%（8模型均值），较 M=4,B=2 的 52.8% 提升 3.5pp 但 token 成本翻倍；增加续写预算 B 比增加候选预算 M 的单位 token 效率更高。
6. **算术重复尝试**（Figure 2-3）：320个条件中235个在32次尝试后无未解决问题；Base 10加法全部解决，Base 7乘法平均未解决率0.40；大收益集中在 Pass@1∈[0.05,0.35] 区间；同 Pass@1 不同任务收益差异极大（如 R1-1.5B Base 7加n=3: 0.08→0.98，而 Base 7乘n≥7: 0→0）。
7. **Agent分数预测**（Table 6）：基于2h/4h观察预测后续分数，Retry曲线与Sigmoid(log time)在12h处的中位相对误差分别为10.7% vs 10.9%，<10%预测比例均为48%。

## 相关工作脉络
1. **Zhang et al. (2025b) LoRe-Compo**：本文直接采用其复合任务数据集和 Pass@K 度量，指出独立采样下联合成功率严格低于各子问题单独覆盖率的乘积（Prop. 3）。
2. **Wang et al. (2022) Self-Consistency**：SC 使用答案一致性作为正确性代理；本文实验表明在二阶子问题上 Oracle 与 SC 得分接近，但两者均未验证完整推理链的正确性。
3. **Lightman et al. (2024) Process Supervision / MAKER (Meyerson et al. 2025)**：MAKER 在投票模型下达到 $\Theta(N\log N)$ 期望总代价；本文与之区别在于分析的是有限局部预算下的首接受信机制，且保证仅在正确前缀处需要精度条件。
4. **Dziri et al. (2023)、Kwa et al. (2025)、Sinha et al. (2025)**：文档了中间结果组合困难、长任务成功率下降、先前错误向后续推理传播等现象，本文的理论框架为其提供了可量化的误差传播上界。
5. **Gera (2013)、Balakrishnan et al. (2014) Start-up demonstration tests**：本文的停止规则（连续R次拒绝则终止）与此类经典测试理论建立联系，Thm. 2 的最坏界利用了相同的停止模式分析技术。
6. **Teng et al. (2025) Atom of Thoughts、Zhou et al. (2025) MEM1**：关注"保留什么"的状态压缩问题；本文更关注"保留后满足什么精度条件"以及"需要多少计算资源"。

## 局限性与未来方向
1. **执行假设过强**：理论分析假设条件独立同分布重试和二元检查独立性，实验中的反馈依赖重试和耗尽后回退（fallback）需另行分析，实验也未直接检验这些假设。
2. **检查器精度无法从实验直接估计**：SC/Oracle 得分相近不能说明二者接受状态误差率相同；实验报告的续写指标包含 fallback 路径，无法分离出 accepted-state error $\alpha$。
3. **分解假设未验证**：理论要求每步有任务特定的通过/拒绝检查，但实验中 LoRe-Compo 子问题数学独立、算术重试为完整答案级别，均未测量长依赖链中各前缀的可靠性。
4. **总成本未完整计入**：报告的计算量不包含检查和处理保留状态的开销，且未建立匹配整体成功率下的复用节省量化对比。
5. **未来方向**：可扩展至反馈依赖重试分析、开发更强的过程验证器（process verifier）、将理论框架迁移至开放域 agent 任务、探索自适应预算分配策略。

## 研究启发与可借鉴点
1. **重试预算的对数缩放规律**：在固定接受概率下，保证目标可靠性所需的重试预算为 $O(\log N)$，而非线性，这为 Agent 系统中的重试策略设计提供了理论依据。
2. **答案复用 vs 完整推理链复用的边际效益分析**：实验发现仅保留答案即可恢复58%的相对增益，完整推理链多出的1.1pp在统计显著性范围内存疑，提示未来工作中"保留什么信息"的决策需结合上下文预算精细权衡。
3. **预算分配中续写预算（B）的效率优势**：Table 4 显示增加 B 比增加 M 以更低 token 增量获得相似增益，对 Agent 系统中"探索候选数"与"深化续写深度"的资源分配具有启发。
4. **首次准确率与重复尝试收益的非单调关系**：算术实验揭示 Pass@1 无法预测重复尝试的覆盖增益，提示在规划推理预算时应同时考虑任务的"可 Retry 性"（retry elasticity）。
5. **Agent 分数预测曲线的实证价值**：基于2h/4h观测用 retry 曲线或 sigmoid(log time) 预测12h分数的中位误差<11%，为评估和调度长 horizon agent 提供了实用的早期信号方法。

## 关键术语表
**Complete-solution sampling**：从同一分布独立采样 K 次完整运行，只要有一次返回正确答案即视为成功，联合成功率严格受限于单次运行同时解出所有子问题的约束。
**State reuse / Verified State Reuse (VSR)**：在每步保留首个通过检查的中间状态，从该状态继续重试新步骤，直至预算耗尽，避免从头生成。
**Local retry cap (R)**：每个步骤允许的最大候选尝试次数；达到上限后终止整个任务（全局停止规则）。
**Accepted-state error ($\alpha$)**：给定候选通过检查器的条件下该状态实际错误的概率；增加 R 不改善此项，仅改变接受概率。
**Trajectory reliability ($\Pr(H_N)$)**：前 N 步均成功完成且每一步保留的状态均为正确的概率下界，由乘积界 $[(1-\rho^R)(1-\alpha)]^N$ 给出。
**Unsolved fraction ($\hat{E}(R)$)**：在 R 次独立尝试后仍未找到正确答案的问题比例；算术实验中用于度量重复尝试收益。
**LoRe-Compo**：包含250对数学主题相互独立的 MATH500 子问题的复合任务数据集，用于评估状态复用与候选选择策略。
**EdgeBench**：评估 frontier agent 在2/4/6/8/10/12小时时间预算下任务得分的 benchmark，用于本文的 Agent 分数预测实验。

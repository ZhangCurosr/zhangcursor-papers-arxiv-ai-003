# 论文速读：What the Primary Lund Plane Omits: A Model-Stitching Diagnosis of a Jet-Tagger Representation Gap

## 一句话总结
本文使用模型缝合（model stitching）技术，将 Particle Transformer (ParT) 与基于主Lund平面（primary Lund plane）的同架构变体 Lund-ParT 进行对比，直接诊断出两者在 top-tagging 任务上的性能差距主要源于**表示能力的缺陷**（主Lund平面丢弃了次级分叉结构），而非下游计算模块的差异；该缺陷集中在约0.6%高多重数、高质量背景的喷注上，且通过恢复完整的 Cambridge/Aachen 聚类树可修复72%的差距，但推理时网络的判别力仍几乎完全依赖于主分支中最宽角度的分裂。

## 研究问题与动机
- **核心问题**：物理启发的喷注表示（如主Lund平面序列）与端到端学习表示（如ParT原始四动量）之间存在的性能差距，究竟是由于前者携带的信息不足（表示缺陷），还是由于下游网络无法充分读取该表示（计算缺陷）？
- **现有方法的不足**：
  1. 仅比较最终性能指标（如AUC或固定信号效率下的背景拒绝率）无法区分上述两种原因。
  2. 几何相似性度量（如CKA、SVCCA）反映的是表示空间的对齐程度，但不等价于功能可互换性；两个表示可能在几何上高度相似，但对特定下游任务仍无法有效利用。
  3. 模型缝合（model stitching）虽已用于表征转移，但此前未尝试跨越输入序列长度与结构完全不同的网络（如ParT vs. Lund-plane图网络）进行缝合，因缺乏逐token对应关系且架构差异会引入混淆。
- **动机**：建立一个可直接归因于“表示内容”而非“架构选择”的诊断框架，并为喷注标记器的表示设计与改进提供实证依据。

## 核心贡献（创新点）
1. **提出跨架构的缝合诊断协议**：通过在每个网络内部的 class token 处缝合（单一线性映射连接冻结的前向层与后向层），消除了序列长度不一致与架构差异的混淆，使缝合结果可归因于表示内容差异。
2. **证实主Lund平面的缺陷是表示性的**：主分支 Lund-ParT 在 ParT 下游中的背景拒绝率（128–136）不低于其自身下游（120–134），且远低于 ParT 自有的 291，证明差距源于表示信息缺失而非下游读取能力不足。
3. **定位并修复表示缺陷**：缺陷集中在约0.6%高多重数、高质量背景的喷注上（这些喷注的辐射主要落在被丢弃的次级分支）；重建完整聚类树可将背景拒绝率从136提升至248，修复72%的差距。
4. **揭示二级节点的训练作用与主分支的权重集中现象**：完整树的二次节点在训练阶段使表示更易学习，但在推理时网络的判别力几乎完全依赖于主分支；主分支中最宽角度的分裂重要性约为随机分裂的两倍，与boosted top的开角密切相关。

## 方法详解
- **架构**：ParT 与 Lund-ParT 使用相同的 `ParticleTransformer` 骨干：6层预归一化自注意力块（embedding dim=128, 8 heads）+ 2层 class-attention 读出块 + 两层分类头。ParT 输入为每个粒子的7个运动学标量及每对粒子的4个相对论不变量作为注意力偏置；Lund-ParT 输入为主Lund平面的5个分解坐标 $(\ln z, \ln \Delta R, \psi, \ln m, \ln k_T)$，偏置为坐标差 $x_i - x_j$。
- **缝合构造**：对于源网络 $A$、目标网络 $B$ 及深度 $d$，定义 $f_A^{(d)}: \mathcal{X} \to \mathbb{R}^{128}$（经前 $d$ 个注意力块与 class-attention 得到类令牌）和 $g_B^{(d)}: \mathbb{R}^{128} \to \mathbb{R}$（经剩余块、读出与分类头）。缝合分类器为 $\hat{y}_{A\to B}^{(d)}(x) = g_B^{(d)}(W f_A^{(d)}(x))$，其中 $W$ 为唯一训练的 $128\times128$ 线性层（16,512参数），其余参数冻结。
- **消融与验证设计**：
  - 四个缝合条件：`lund→part`、`part→lund` 以及两个自缝合控制（`lund-self`、`part-self`），均在相同深度与种子下运行。
  - 使用两种归一化分数：目标归一化 $R_X^{\mathrm{tgt}}$（衡量目标下游是否成为瓶颈）与源归一化 $R_X^{\mathrm{src}}$（衡量源信息在穿越同一瓶颈后的存活比例）。
  - 通过掩码消融（masking ablation）在推理时逐一删除主/次级节点，评估各节点的重要性；同时测试超图读取器（hypergraph reader）作为更高阶相关性的替代解释。

## 实验与结果
- **数据集**：Kasieczka等人顶夸克标记基准数据集（Zenodo DOI: 10.5281/zenodo.2603256），训练/验证/测试比例为 1,211,000/403,000/404,000，本文使用各 split 的50%子样本（605,500/201,500/202,000喷注）。背景喷注平均含43.3个真实组分，主分支产生12.6个分裂节点。
- **评估指标**：AUC 与固定信号效率 $\varepsilon_S \in \{0.5, 0.3\}$ 下的背景拒绝率 $1/\varepsilon_B$。
- **主要结果（top tagging，5个随机种子均值）**：
  - 独立运行：ParT 拒绝率 291±13，主分支 Lund-ParT 136±4，完整树 Lund-ParT 248±5。
  - 缝合结果（$\varepsilon_S=0.5$）：`lund→part` 从128（d=1）上升至136（d=5），`lund-self` 从120（d=1）至134（d=5）；AUC 在所有深度与方向上均保持在目标值的 ±1% 内，无法反映拒绝率差距。
  - 源归一化比值（$R^{\mathrm{src}}$）显示 `lund→part` 始终不低于 `lund-self`，证明 ParT 下游并未比 Lund-ParT 自身更弱。
  - 缺陷喷注定位：仅占 standalone ParT 拒绝集的 0.6%（约557个背景喷注），其质量集中在150 GeV以上（均值180 GeV），组分更多但主分支分裂数更少（11.3 vs. 12.6）。
  - 完整树修复后，拒绝率从136升至248（修复72%差距），漏判喷注数降至177个（0.2%）。
  - 节点掩码消融：删除12个主节点使拒绝率从230.6骤降至9.2，而删除12个次级节点仅降至186.5；仅保留12个主节点时的拒绝率（34.7）远高于仅保留12个随机节点（4.4）。
  - 主分支内部重要性：移除最宽角分裂（第一个步骤）造成的拒绝率损失约为随机移除的三倍（top tagging：+35.2% vs. +11.5%），该模式在 quark/gluon 标记任务中较弱但方向一致。
  - 超图读取器测试：在主分支表示上仅获得116的拒绝率，与配对注意力网络的112无显著差异，排除了高阶相关性作为差距原因的可能性。

## 相关工作脉络
- **LundNet [2]**：使用图网络读取完整 Cambridge/Aachen 聚类树，性能优于仅基于主分支的标签器；本文构建的 Lund-ParT 在相同架构下直接对比主分支与完整树，量化了主分支缺失的代价。
- **ParticleTransformer (ParT) [3]**：直接使用粒子四动量并通过自注意力学习特征；本文通过缝合将其作为“强下游”基准，分离表示与计算的影响。
- **模型缝合（model stitching）[8]**：原用于自然语言处理中分析预训练模型的知识分布；本文首次将其应用于跨架构喷注标记器，并通过 class token 缝合点解决了序列长度不对齐的问题。
- **因果消融与路径修补（path patching）**：先前工作（如 [10]）在 ParT 内部定位稀疏的注意力头电路，但未分离表示内容与读取能力；本文的缝合诊断提供了互补视角。
- **Lund平面解释性研究 [11]**：基于扰动与梯度的归因方法用于识别 LundNet 依赖的分裂；本文进一步通过缝合与掩码消融直接测试表示的充足性。
- **表示相似性度量（CKA [6], SVCCA [7]）**：本文指出几何对齐与功能可互换性并不等价，缝合结果比单纯的相关性度量更具诊断价值。

## 局限性与未来方向
- **数据规模限制**：所有结果基于50%子样本训练，独立拒绝率低于完整数据集上报的数值（但比较均为比例或差值，结论稳健）。
- **缝合深度上限**：$d=6$ 被排除，因为此时目标网络无自注意力块参与，测量的是线性映射重编码能力而非深度缝合效果，未来可扩展至更浅或更深架构。
- **quark/gluon 任务噪声较大**：在 quark/gluon 标记任务中，浅层缝合（$d \leq 4$）的种子间变异高达20–55%，仅 $d=5$ 结果清晰，消费者不对称性未复现。
- **消费端微调验证不足**：早期小规模实验中尝试解冻目标网络第一层以验证消费者不对称性，但结果不稳定；未在当前数据规模下重复此实验。
- **超图读取器仅在10%数据与单种子下测试**，虽支持了“表示缺陷”结论，但缺乏统计显著性，未来可在更大规模下扩展高阶关联建模。
- **完整树的收益并非局部化**：次级节点在训练阶段塑造表示，但推理时贡献分散，未来可探索是否可通过选择性保留少量关键次级节点实现高效表示。

## 研究启发与可借鉴点
- **缝合诊断框架的可迁移性**：通过 class token 缝合解决序列长度不对齐、使用同架构变体消除架构混淆、设计自缝合对照条件，这套协议可推广至其他多模态或跨表示的表征比较任务。
- **双归一化指标的独立性**：$R_X^{\mathrm{tgt}}$（目标归一化）与 $R_X^{\mathrm{src}}$（源归一化）分别回答不同问题，避免混合分母导致的误判，适用于任何需分离“输入信息量”与“下游处理效率”的研究。
- **掩码消融与成对对照设计**：删除节点时匹配控制组（随机删除相同数量节点）并压缩序列，可有效区分“节点重要性”与“序列长度效应”，该方法可复用于序列模型的组件重要性分析。
- **物理先验与深度学习结合的诊断思路**：利用已知的物理结构缺陷（主Lund平面丢弃次级分支）作为阳性对照，验证诊断工具的有效性后再应用于未知差距，提升了结论的可信度。
- **跨任务对比揭示表示代价的普遍性**：在 top tagging 与 quark/gluon tagging 上均发现完整树 Lund-ParT 达到 ParT 拒绝率的约85%，表明 Lund 编码本身的信息压缩存在任务无关的成本，为表示设计提供了通用约束。

## 关键术语表
- **Model Stitching（模型缝合）**：将源网络的前 $d$ 层与目标网络的剩余层通过一个可训练线性层连接，冻结其余参数，用于直接评估表示内容的可迁移性。
- **Primary Lund Plane（主Lund平面）**：通过沿 Cambridge/Aachen 聚类树的较硬分支进行分解得到的序列，每个节点包含5个分解坐标，丢弃了次级分支的辐射信息。
- **Class Token（类令牌）**：通过 class-attention 机制从粒子/token 序列中聚合得到的全局上下文向量，在本文中作为缝合点，避免了序列长度不对齐的问题。
- **Background Rejection（背景拒绝率）**：在固定信号效率 $\varepsilon_S$ 下，被正确判定为背景的喷注占总背景喷注的比例的倒数（$1/\varepsilon_B$），反映分类器在低信号区间的鉴别力。
- **CKA / SVCCA**：Centered Kernel Alignment 与 Singular Vector Canonical Correlation Analysis，两种用于度量两个表示几何相似性的方法，但不保证功能可互换性。
- **Hypergraph Reader（超图读取器）**：将三元组分裂作为超边的网络变体，用于测试更高阶关联是否弥补了主分支表示的缺陷。
- **Consumer Asymmetry（消费者不对称性）**：不同下游网络（ParT vs. Lund-ParT）对同一表示的读取效率存在差异，本文在 top tagging 中发现 ParT 下游略优。
- **Leaked Population（漏判群体）**：standalone ParT 能正确拒绝但缝合模型无法拒绝的背景喷注子集，用于定位表示缺陷的具体喷注类型。

## 可复现要素
- **数据集**：Kasieczka et al. 顶夸克标记参考数据集（Zenodo DOI: 10.5281/zenodo.2603256），公开可用；quark/gluon 数据集为 EnergyFlow 公开数据。
- **代码**：作者声明代码“available from the authors on reasonable request”（合理请求下可从作者处获取），未公开在 GitHub 等公共仓库。
- **关键超参**：
  - 架构：6层 self-attention（dim=128, 8 heads）+ 2层 class-attention，嵌入维度128。
  - 训练：AdamW，交叉熵损失，batch size 256，float16 混合精度，早停（patience 5，基于验证 AUC），最多30 epoch。
  - 缝合：仅训练 $W$（Linear 128→128，16,512参数），AdamW，早停（patience 4），最多15 epoch，固定20,000喷注子样本。
  - 种子数：5个随机种子，所有结果为均值±标准差。
- **评估指标**：AUC、$\varepsilon_S=0.5$ 与 $\varepsilon_S=0.3$ 下的背景拒绝率，以及源/目标归一化的保留分数。

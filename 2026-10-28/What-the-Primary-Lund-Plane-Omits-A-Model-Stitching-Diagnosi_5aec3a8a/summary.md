# 论文速读：What-the-Primary-Lund-Plane-Omits-A-Model-Stitching-Diagnosi

## 一句话总结
本文利用模型缝合（model stitching）将基于物理先验的**主 Lund 平面**标签器与端到端**ParT**标签器的性能差距直接拆解，证实该差距源于表示本身的信息缺失（表征性问题），而非下游读取器计算能力不足；修复缺失的次级分支可关闭 72% 的差距，且推理时网络极度依赖主分支，次级节点主要在训练阶段赋能表征学习。

## 研究问题与动机
1. **性能差距归因模糊**：物理先验表示（主 Lund 平面）与端到端表示（ParT）的最终指标存在显著差异，但仅凭 standalone 性能无法区分这是表示信息量不足，还是下游网络未能充分读取同一表示。
2. **AUC 指标的盲区**：领域常用的 AUC 对实际运行点（如固定低信号效率下的背景拒绝率）差异极不敏感，可能掩盖具有物理意义的性能缺口。
3. **几何相似性≠功能可互换性**：CKA/SVCCA 等表示对齐度量只能刻画子空间几何关系，无法直接回答特定下游计算能否有效利用该表示。
4. **主分支表示的物理代价未知**：主 Lund 平面仅沿每次 C/A 聚类的较硬分支记录坐标，丢弃了大量次级辐射；其具体造成多大代表性损失、损失集中在哪些喷注子群体、以及何种架构能从中提取更多信息，缺乏系统诊断。

## 核心贡献（创新点）
1. **同架构缝合诊断框架**：构建与 ParT 完全共享骨干但输入不同的 **Lund-ParT**，以 class token 为缝合点消除序列长度不对齐障碍，严格剥离“表示内容”与“消息传递架构”的混淆。
2. **表征性缺口的直接证据**：通过跨架构缝合与双归一化指标证明，ParT 下游从主分支表示中读取的效果不低于 Lund-ParT 自身下游，证实性能短板位于输入表示而非下游计算。
3. **缺口的物理定位与修复验证**：将缺口精准定位到约 0.6% 的高质量、高多重数背景喷注（mass ≥150 GeV 且主分支分裂数偏少）；重建完整 C/A 聚类树关闭 72% 差距，完成正对照闭环。
4. **训练-推理作用的解耦发现**：揭示全树修复后网络在推理时几乎完全依赖主分支（删 12 个主节点拒绝率暴跌至 9.2，删 12 个次级节点仅降至 186.5），但次级节点是使表征“可学习”的关键，无法被简单裁剪替代。
5. **任务依赖性验证**：在夸克/胶子标记任务中复现 pipeline，主分支保留 ParT 77.6% 拒绝率（vs top 标记的 46.9%），证明缺口严重程度高度依赖任务的物理判别机制。

## 方法详解
- **架构对齐（Lund-ParT）**：与 ParT 共用相同 `ParticleTransformer` 类（6 层 pre-norm self-attention + 2 层 class-attention + 2 层分类头，embedding dim 128，8 heads），仅将输入与 pairwise bias 替换为主 Lund 平面的五个坐标 $(\ln z, \ln\Delta R, \psi, \ln m, \ln k_T)$，参数差 <0.01%。
- **模型缝合构造**：对源网络 $A$ 冻结前 $d$ 层得到 class token $f_A^{(d)}(x)\in\mathbb{R}^{128}$，经可训练线性层 $W\in\mathbb{R}^{128\times128}$ 映射后广播为单 token 序列，输入冻结的目标网络 $B$ 剩余块 $g_B^{(d)}$，输出 $\hat{y}_{A\to B}^{(d)}=g_B^{(d)}(W f_A^{(d)}(x))$。深度 sweep 取 $d\in\{1,\dots,5\}$，排除 $d=6$（避免双 class pooling 的病态行为）。
- **双归一化指标**：定义 $R_X^{\mathrm{tgt}}(d)=X_{\mathrm{stitched}}/X_{B,\mathrm{standalone}}$（衡量目标下游是否为瓶颈）与 $R_X^{\mathrm{src}}(d)=X_{\mathrm{stitched}}/X_{A,\mathrm{standalone}}$（衡量源表示携带多少可迁移信息），二者不可混用，按固定目标/源原则分别评估。
- **掩码消融**：在推理时抑制选定节点（主/次级/随机），严格配对存活 token 数量并压缩序列至前端，消除“序列长度效应”干扰，直接测量节点重要性。
- **正对照设计**：以已独立知悉缺陷的主分支表示为阳性对照，验证缝合方法能否正确识别已知缺口、定位到相应喷注群体，并在修复后确认诊断方向。

## 实验与结果
- **数据集**：Kasieczka top-tagging 参考数据集（1.211M/403k/404k jets，取 50% 固定子集）；EnergyFlow 夸克/胶子数据集（1M events）。
- **独立性能（$\varepsilon_S=0.5$）**：ParT 拒绝率 $291\pm13$，Lund-ParT（主分支）$136\pm4$，Lund-ParT（全树）$248\pm5$；AUC 差距 <0.008。
- **缝合与归因**：lund→part 拒绝率仅 128–136，与 lund-self（120–134）相当，远低于 ParT 自身 291；AUC 在 all depths 保持 0.977–1.007（波动<1%），证明 AUC 对缺口失明，性能差距确为表征性。
- **缺口定位**：占 ParT 拒绝集 0.6% 的失败喷注集中于 mass ≥150 GeV（均值 180 GeV）、成分数多（~66 vs 典型 43）但主分支分裂数少（11.3 vs 12.6）的高多重数群体。
- **全树修复**：拒绝率升至 248，关闭 72% 差距；AUC 升至 0.9822；泄漏喷注从 557 降至 399（d=1）与 177（d=5）。
- **节点贡献**：删 12 个主节点拒绝率从 230.6 跌至 9.2；删 12 个次级节点仅降至 186.5；保留仅 12 个主节点（34.7）优于保留 12 个随机节点（4.4）。次级节点呈平滑衰减分布，无集中load-bearing子集。
- **主分支内部重要性**：删除首节点（最宽角）损失 70.6% 拒绝率（超额 +35.

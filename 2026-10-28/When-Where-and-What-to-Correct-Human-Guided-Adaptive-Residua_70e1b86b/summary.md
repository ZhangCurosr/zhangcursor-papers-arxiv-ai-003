# 论文速读：When-Where-and-What-to-Correct-Human-Guided-Adaptive-Residua

## 一句话总结
论文提出 ARC（Adaptive Residual Correction），一种轻量级后训练插件模块，通过强化学习在冻结策略上学习残差校正；利用稀疏人类校正分别确定残差激活时机（WHEN）、约束残差搜索空间（WHERE），最终由任务奖励驱动决定执行何种校正（WHAT），将三任务平均成功率从 33.3% 提升至 75.0%。

## 研究问题与动机
1. 模仿学习策略（如 ACT）可在大部分轨迹上可靠执行，但在依赖"最后一公里"精密操作的局部区域仍会失败，全策略微调或全空间探索将局部问题不必要地扩大为全局学习问题。
2. 现有残差 RL 方法（ResiP、Policy Decorator 等）未明确界定残差控制的激活时机与搜索范围，导致探索低效或退化基策略。
3. 直接以人类校正作为监督目标的方法（FlowDAgger、UniSteer 等）忽略了一个关键事实：校正动作是为了从特定状态恢复，而非保证最终任务成功；直接模仿可能学到次优甚至有害的校正行为。
4. 稀疏人类校正本身携带两种有价值的结构信号：校正 onset 指示残差控制的合适激活时机；校正的多关节协调几何揭示了高效校正方向，可作为自主探索的约束。

## 核心贡献（创新点）
1. 将 ARC 拆分为 WHEN/WHERE/WHAT 三个正交模块，分别利用预干预状态、人类校正几何、任务奖励作为学习目标，与现有方法统一用校正动作作监督的方式本质不同。
2. 提出预干预门控（pre-intervention gate）：以干预前 L=5 步的机器人自主控制状态训练二分类器，确保门控在部署时（无人类干预）仍能正确识别需校正的关键时段，而非拟合已校正状态。
3. 构建人类校正子空间：通过对 N 次校正的未中心化二阶矩做特征分解，得到 d_H∈{2,3} 维的正交基 B_H，将 7 维残差动作空间压缩至保留 96.0–97.7% 平方校正幅度的低维子空间，大幅约束探索范围。
4. 奖励驱动的残差 Actor：以 TD3 为优化器，在门控激活且限制于 B_H 子空间内，由任务奖励而非人类校正标签学习残差系数，使最终执行的动作由任务成功率决定而非由人类偏好决定。
5. 实验验证了修正数据本身不进入 RL 回放缓冲区，仅需 8–10 次含校正的 rollout 即可训练 WHEN/WHERE，再用 2 轮自主 collect–reward–update 完成 WHAT 的学习，样本效率极高。

## 方法详解
ARC 的整体动作输出为 a_t = a_t^B + g_t r_t，其中 a_t^B 为冻结基策略 ACT 的动作，g_t 为二值门控，r_t = B_H z_t 为残差动作。

**WHEN（门控）**
- 输入表示：x_t = [φ_B(I_t), q_t, a_t^B]，φ_B 为冻结 ACT 视觉编码器输出，q_t 为本体感觉，a_t^B 为基策略动作。
- 训练数据：对每次人类校正 onset t_0，取 preceding L=5 步状态作为正样本，充分远离校正区的自主状态作为负样本，按 episode 划分防止泄漏。
- 分类器：g_ψ(x_t) = P(y_t=1|x_t)，y_t=1 表示接下来 L 步内会出现校正。
- 部署：通过 leave-one-episode-out 验证集使用 Youden's J statistic 确定概率阈值，再经时间滞回（temporal hysteresis）得到二元门控 g_t∈{0,1}，门开时启用残差，否则退回基策略。

**WHERE（校正子空间）**
- 收集 N 次人类校正残差 {r_i^H}，计算未中心化二阶矩 M_H = (1/N) Σ r_i^H (r_i^H)^⊤，取前 d_H 大特征值对应的特征向量构成 B_H = [v_1, …, v_d_H]。
- 子空间选择准则：保留的平方校正幅度比例 + leave-one-episode-out 稳定性。三个任务分别选 3 维（tray，保留 97.3%）、2 维（marker，96.0%）、2 维（cup，97.7%）。
- 对每个保留方向 k，估计人类校正在该方向的尺度 σ_k，用于后续残差缩放。

**WHAT（奖励驱动残差学习）**
- 探索阶段（human-guided exploration）：每轮 rollout 开始时随机选一个保留方向 v_k 和符号 s∈{−1,+1}，施加固定残差 ε = s·α·σ_k·v_k，由门控 g_t 决定是否生效；α 控制探索幅度。该阶段经验存入 replay，但人类校正轨迹本身不进入 replay。
- Actor 网络：π_θ(x_t) → u_t ∈ [−1,1]^{d_H}，缩放后 z_t = (α·σ_H) ⊙ u_t，残差动作 r_θ(x_t) = B_H z_t。
- 优化：TD3 + 多步 TD target + 向小残差的正则化项。人类校正不作为回归目标。
- 部署：去除探索噪声，输出 a_t = a_t^B + g_t·B_H z_t。

## 实验与结果
**实验设置**
- 硬件：Miroki 人形机器人右手 + 定制 3D 打印 claw gripper。
- 基策略：ACT，每任务约 55 条演示训练。
- 任务：tray stacking（托盘对齐叠放）、marker insertion（ Marker 插入狭槽）、cup stacking（杯子叠入固定接收器）。
- 后训练：每任务 8–10 次含人类校正的 rollout 学习 WHEN/WHERE，之后 2 轮自主 collect–reward–update 学习 WHAT。
- 评估：12 次独立 real-robot trial，报告 exact success 及 95% Wilson 置信区间。

**主要结果（成功率）**
| 任务 | Base ACT | Direct Supervised | ARC |
|------|----------|-------------------|-----|
| Tray stacking | 58.3% (7/12) | 25.0% (3/12) | **100.0% (12/12)** |
| Marker insertion | 25.0% (3/12) | 41.7% (5/12) | **58.3% (7/12)** |
| Cup stacking | 16.7% (2/12) | 25.0% (3/12) | **66.7% (8/12)** |
| **平均** | **33.3%** | — | **75.0%** |

- 最强结果：tray stacking 从 58.3% 提升至 100%（+41.7pp）。
- 三任务平均提升 41.7pp（33.3%→75.0%）。
- 门控选择性：在 marker 任务中残差控制仅活跃 8.5% 的 timestep，cup 任务中为 21.3%。
- 子空间稳定性：worst leave-one-episode-out 子空间相似度达 0.993–0.999。
- 对照 WHAT 实验（相同 B_H 子空间）：监督基线在 2,499 个门控激活状态下的中位残差大小为 0.52°，ARC 仅 0.14°（3.7 倍更精简）；两种方法在同一支持域内选出的系数符号一致率仅 38%。

## 相关工作脉络
1. **ResiP / Policy Decorator / ResFiT / MiDAS**：均为冻结策略上的残差后训练方法，但都不利用人类校正来确定何时激活残差或在何处搜索，本文相对它们的差异在于显式建模 WHEN/WHERE 支撑集。
2. **HIL-SERL / SiLRI**：将人类干预纳入 RL 流程，HIL-SERL 让干预直接进入 RL 循环，SiLRI 平衡模仿与强化；本文的区别是校正数据仅用于训练门控和子空间，不进入回放缓冲，WHAT 完全由奖励驱动。
3. **FlowDAgger / UniSteer**：将人类校正（或其潜变量表示）作为 steering policy 的直接监督目标；本文证明即使在同一校正子空间内，奖励驱动也能学到与监督截然不同的校正策略，且任务表现更优。
4. **DGN / SART**：利用演示或人工标注约束探索区域；SART 在人类标注的精度区域限制 variation，本文则用校正残差几何自动推断低维子空间，无需人工标注空间区域。
5. **Wang et al. [9]**：研究干预时机信息；本文在此基础上进一步利用校正 onset 前的状态序列训练门控，使 gate 能在无人的自主部署中转移。
6. **FRS**：用粗粒度引导 bootstrap RL；本文的"粗引导"具体化为预干预门控+低维校正子空间两个可学习的结构约束。

## 局限性与未来方向
1. 门控依赖人类校正时机进行训练，不同操作者的干预习惯会导致门控行为不同，泛化到未经过校正的人类存在不确定性。
2. 校正子空间基于有限次人类校正估计，若任务需要超出已观测校正方向的新的纠正模式，可能被 B_H 的子空间约束所限制。
3. 当前仅在三个桌面级精操任务上验证，尚未在更长轨迹、更大动作空间或更多样化任务形态上测试。
4. 论文自述未来方向：用 vision-language model 持续监控器替代基于人类校正时机的门控，以减少对任务特定 human correction timing 的依赖。

## 研究启发与可借鉴点
1. **预干预状态建模**：以干预前 L 步状态训练 gate 而非干预中状态，是解决"部署时无人可见状态偏移"问题的简洁设计，可迁移至其他 human-in-the-loop 场景。
2. **校正几何 → 低维子空间**：用未中心化二阶矩而非中心化 PCA 捕获零残差有意义的前提下的校正方向，这一细节在肢体/机械臂残差学习中值得借鉴。
3. **WHEN/WHERE/WHAT 正交拆分**：将人类校正信息解耦为支撑集定义与奖励优化两个阶段，使 RL 不必拟合人类偏好，而只在该支撑集内优化任务指标；这种拆分为后续研究提供了清晰的 ablation 维度。
4. **校正数据不入 replay 的设计**：避免人类次优或状态依赖的校正污染 RL 样本，同时保留其结构信息；适用于任何"人类示范质量有限但结构信息丰富"的后训练场景。
5. **Youden's J + 时间滞回的门控部署策略**：无需在部署集上调参，直接由验证集统计量确定阈值，对 real-robot 部署的安全性和可复现性有价值。

## 关键术语表
**ARC（Adaptive Residual Correction）**：本文提出的轻量级后训练模块，在冻结基策略上通过 RL 学习残差校正。
**Pre-intervention gate**：基于校正前 L 步机器人自主状态的二分类器，用于在部署时预测何时应激活残差校正。
**Corrective basis B_H**：由人类校正残差的未中心化二阶矩特征分解得到的低维正交基，将 7 维残差空间压缩至 2–3 维。
**Residual action**：基策略输出之外的附加关节调整量 r_t = B_H z_t，叠加到冻结策略动作 a_t^B 上。
**Human-guided exploration**：在 WHEN/WHERE 定义的支撑集内，沿选定校正方向施加固定符号扰动的自主探索策略。
**Youden's J statistic**：用于从 leave-one-episode-out 验证中选取最优分类概率阈值的指标（灵敏度 + 特异度 − 1）。
**Temporal hysteresis**：门控输出的时间滞回机制，防止 g_t 在临界 timestep 高频翻转。
**Exact success**：评估指标，要求整个任务完整无扰动成功完成。

# 论文速读：Where-Should-the-Evaluation-Budget-Go-in-LLM-Driven-Agent-Scaffold-Evolution

## 一句话总结
本文系统研究了LLM驱动的智能体脚手架进化中评估预算的分配问题，提出**EvalAlloc**框架，将稀疏的搜索期反馈与精准的最终确认阶段相结合，在使用约一半评估次数的情况下达到与全量评估相当甚至更优的最终脚手架质量。

## 研究问题与动机
1. **评估成本高昂**：单个任务实例可能涉及多次LLM调用、检索步骤和工具交互，对每个候选脚手架执行全量任务集评估代价巨大。
2. **评估承担双重角色**：在脚手架进化中，评估既提供指导后续搜索的适应性反馈，又决定最终返回哪个脚手架——这两种决策对资源的需求不同。
3. **现有方法不足**：现有稀疏估计和评估级联方法将评估主要视为适应度估计问题，但未充分考虑脚手架进化中评估反馈对档案更新和候选生成的直接影响。
4. **核心科学问题**：在有限评估预算下，如何合理分配以同时优化进化搜索质量和最终脚手架选择质量？

## 核心贡献（创新点）
1. **首次将评估分配建模为决策依赖问题**：揭示了搜索期反馈与最终脚手架选择在资源需求上的本质差异，现有工作未区分这两种评估角色的差异化要求。
2. **提出EvalAlloc评估分配框架**：通过共享信息核心、固定搜索期响应模型和预热启动的成对连续淘汰（Successive Halving）三阶段协同，将评估预算在进化搜索与最终选择间精确定位分配——区别于以往仅关注单项估计精度的工作。
3. **系统性回放分析揭示关键机制**：通过离线回放24条进化轨迹（4基准×2框架×3种子），证明了共享信息项方差缩减效应（common random numbers机制）和稳定评分参考对可比性的关键作用，提供了可解释的设计依据。
4. **实证验证显著的成本-性能优势**：在4个基准和2个进化框架上，EvalAlloc使用约一半评估单元实现与Full相当或更优的TEST性能，且对底层模型配置具有泛化性。

## 方法详解

**EvalAlloc框架分为三个阶段：**

**阶段一：核心校准（Core Calibration）**
- 对前 $W=10$ 个有效候选在全部 $N=300$ 个SEARCH项上进行全量评估
- **信息项识别**：基于Beta后验估计项的信息量，定义保守信息量估计：
  $$I_i = 4\left(\mathbb{E}[X_i] - z\sqrt{\mathrm{Var}(X_i)}\right), \quad X_i = p_i(1-p_i)$$
  其中 $p_i \sim \mathrm{Beta}(a_i+1, n_i-a_i+1)$，方差项偏好跨候选响应变化大的项，不确定性惩罚避免证据不足的项。
- **响应模型拟合**：采用低秩逻辑响应模型（基于MIRT公式）：
  $$q_{ci} = \sigma(\mu + \eta_i + b_c + u_i^\top v_c), \quad u_i, v_c \in \mathbb{R}^d$$
  拟合在预热候选的全量观测上，其候选参数定义为后续候选的高斯先验。

**阶段二：共享核心进化（Shared-Core Evolution）**
- 从预热阶段计算的信息量中选Top $k_0=54$ 项构成固定共享核心 $S_0$，后续每个候选均在此核心上评估，保证跨候选可比性（common random numbers思想）
- 剩余 $k-k_0=6$ 项为候选特定项，通过Gumbel-top-$k$采样从核心外选择，logits为 $I_i/\tau$
- 评估集 $S_c = S_0 \cup A_c$，其中 $|S_0|=k_0$, $|S_c|=k=60$
- 共享核心的方差缩减效应：$\mathrm{Var}(\bar{Y}_a - \bar{Y}_b) = (\sigma_a^2 + \sigma_b^2 - 2\mathrm{Cov}(Y_a,Y_b))/k_0$
- **可比 fitness 反馈**：对每个新候选仅推断其 $(b_c, v_c)$（MAP估计），保持全局截距、项参数固定，预测未观测项响应：
  $$\widehat{F}(c) = \frac{1}{N}\left(\sum_{i \in S_c} Y_{ci} + \sum_{i \notin S_c} q_{ci}\right)$$
  将所有观测缓存供最终选择阶段复用。

**阶段三：预热启动的选择（Warm-Started Selection）**
- 搜索结束后，对所有有效候选（相同代码合并）应用成对连续淘汰（SH），复用搜索期积累的所有观测
- 构造SEARCH项的共享随机排列，定义递增累积前缀 $P_1 \subset P_2 \subset \cdots \subset P_R = \mathcal{D}_s$
- 每轮仅执行缺失的评估（已观测项直接复用），第一轮得分为并集均值 $\widetilde{F}_1(c) = \frac{1}{|U_c^1|}\sum_{i \in U_c^1} Y_{ci}$
- 从第二轮起使用回归调整（差值估计器）校正不同候选观测项集差异：
  $$\widetilde{F}_r(c) = \frac{1}{|U_c^r|}\sum_{i \in U_c^r} Y_{ci} + \lambda_r\left(\frac{1}{N}\sum_{i=1}^{N}\tilde{q}_{ci} - \frac{1}{|U_c^r|}\sum_{i \in U_c^r}\tilde{q}_{ci}\right)$$
  其中 $\lambda_r$ 由存活候选池中观测值对预测值的回归斜率估计，裁剪至 $[0, 1.5]$
- 使用两折交叉拟合（cross-fitting）避免自拟合偏差：将稀疏候选随机分为两折，每折用另一折+预热候选拟合模型
- 总评估成本：$C_{\mathrm{eval}} = WN + (M-W)k + C_{\mathrm{SH,new}}$，搜索阶段成本约为全量的30%

## 实验与结果

**数据集与设置**：
- 4个基准：HotpotQA、HoVer、DROP、IFBench，各含300 SEARCH / 150 DEV / 300（IFBench为294）TEST项
- 2个进化框架：ShinkaEvolve、AdaEvolve（基于SkyDiscover实现）
- 执行器：Qwen3.5-9B（temperature=0，disable thinking），提议者：DeepSeek-V4-Flash-0731
- 每设置3次独立运行，共80次候选提议

**基线方法**：Skip Eval（无评估）、Successive Halving（无搜索反馈）、Random（随机50%子集）、Cascade（20%→全量级联）、Full（全量评估）

**主要结果（Table 3）**：

| 框架 | 方法 | DROP | HotpotQA | HoVer | IFBench | Average | Cost(%) |
|------|------|------|----------|-------|---------|---------|---------|
| ShinkaEvolve | **EvalAlloc** | **0.8907** | **0.7411** | 0.7278 | **0.4739** | **0.7084** | 43.8 |
| ShinkaEvolve | Full | 0.8832 | 0.7133 | 0.7267 | 0.4660 | 0.6973 | 84.4 |
| AdaEvolve | **EvalAlloc** | **0.8881** | **0.7456** | 0.7844 | **0.4722** | **0.7226** | 46.4 |
| AdaEvolve | Full | 0.8840 | 0.7267 | 0.7733 | 0.4524 | 0.7091 | 99.2 |

- EvalAlloc在全部4个基准上均以约**43-46%的评估成本**（约Full的一半）达到或超越Full的平均性能
- ShinkaEvolve上EvalAlloc平均提升1.6%（0.7084 vs 0.6973），AdaEvolve上平均提升1.9%（0.7226 vs 0.7091）
- 评估成本（Table 5）：EvalAlloc使用Full的52.13%（ShinkaEvolve）/ 46.83%（AdaEvolve）评估单元

**消融研究（Table 4）**：
- 移除最终选择：平均性能下降-0.0173，成本降至27.4%
- 移除响应模型：平均性能下降-0.0119
- 移除信息项（替换为随机采样）：平均性能下降**-0.0291**（最大退化）
- 信息项选择和最终确认是两大核心贡献来源

## 相关工作脉络
1. **ShinkaEvolve / AdaEvolve**：迭代生成-评估-精炼脚手架的代表性工作，聚焦候选生成与进化优化，而本文研究其底层评估过程，关注有限评估资源如何支撑进化决策与最终选择。
2. **SparseEval / tin yBenchmarks**：通过稀疏优化选择代表性项进行高效评分估计，但未考虑进化中反馈对档案更新和候选生成的直接影响，本文补充了可比性（comparability）维度。
3. **CollabEval**：利用矩阵分解跨评估共享信息提升统计效率，本文采用低秩响应模型（MIRT）实现类似目标但服务于进化搜索的可比性需求。
4. **Growing Pains**：使用固定参数校准和锚定项维持跨时段分数可比性，本文在固定搜索期响应模型方向上与之呼应但应用于脚手架进化场景。
5. **Successive Halving / Hyperband**：经典序列资源分配与最佳臂识别方法，本文将其应用于脚手架最终选择阶段，并与搜索期稀疏反馈相衔接形成两阶段协同。
6. **Gepa / AlphaEvolve**：提示词/代码进化相关工作，其中Gepa展示了反射式提示进化可超越强化学习，本文则关注此类进化过程中的评估效率问题。

## 局限性与未来方向
1. **框架依赖性**：目前仅在ShinkaEvolve和AdaEvolve两个框架上验证，对其他进化范式（如基于RL的进化）的泛化性有待检验。
2. **参数敏感性**：响应模型维度$d$、温度参数$\tau$、惩罚系数$z$等超参的设置对性能有影响，论文未做系统性敏感度分析。
3. **执行开销异质性**：高评分候选往往消耗更多token，导致评估单元节省比例与token节省比例存在差异（ShinkaEvolve上单元节省48%但token仅节省35%）。
4. **未探索最优时间分配**：搜索改进集中在早期迭代，但论文承认未建立最优的时间分配策略，当前均匀稀疏反馈可能非最优。
5. **潜在偏差**：响应模型对搜索期候选的拟合可能存在系统性偏差，尤其当候选分布随进化显著漂移时。

## 研究启发与可借鉴点
1. **评估角色分离思想可迁移**：将评估区分为"搜索反馈"与"最终选择"两个阶段分别优化，适用于任何存在大量候选评估需求的迭代优化场景（如超参调优、架构搜索）。
2. **固定响应模型维持可比性**：在迭代过程中固定模型参数而非反复重拟合，可避免评分参考漂移导致的档案比较不一致问题，值得在类似进化系统中推广。
3. **共享项的方差缩减效应在候选比较中具通用价值**：通过common random numbers思想减少配对比较的方差，可推广至任何需要跨候选公平比较的评估场景。
4. **回归调整（差值估计器）在异构观测集合合并中的应用**：第8式中的回归校正技巧可在不同候选观测集大小/内容不一致时提供无偏估计，具有方法学推广价值。
5. **两折交叉拟合防止自拟合偏差**：在响应模型估计中应用cross-fitting可有效避免候选自身观测数据导致的过拟合偏差，是可复用的统计技巧。

## 关键术语表
- **Scaffold（脚手架）**：定义LLM智能体如何协调LLM调用、维护中间状态并与工具和外部信息源交互的可执行程序。
- **Evaluation cell（评估单元）**：单个脚手架-任务项的执行，是评估成本的基本计量单位。
- **Response model（响应模型）**：基于多维项目反应理论（MIRT）的低秩逻辑模型，用于从稀疏观测预测全量分数。
- **Shared informative core（共享信息核心）**：从预热阶段选出的Top-K高信息量项，所有后续候选均在此子集上评估以保证可比性。
- **Successive Halving（连续淘汰）**：一种序贯资源分配策略，逐轮淘汰表现较差的候选并将更多资源集中于剩余候选。
- **Cross-fitting（交叉拟合）**：将样本分为两折，用一折拟合模型并在另一折上预测，避免自拟合偏差的统计技术。
- **Archive regret（档案遗憾）**：真实最优候选与评估器所选候选之间的平均适应度差距，衡量搜索期评估质量。
- **Close-pair agreement（近邻对一致性）**：参考分数差异≤0.03的候选对中，评估器排序正确的比例，衡量可比性。

# 论文速读：WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training

## 一句话总结
WorkFactory 提出了一种将职业意图转化为可执行训练任务的自动化框架，通过信息支撑图反向规划与执行修复机制确保任务环境连贯可用，最终构建 11.2 万任务用于监督微调，训练出的 WorkPilot 系列模型在四个专业工作基准上显著优于对应基础模型。

## 研究问题与动机
1. **教师演示数据质量决定监督训练上限**：可扩展的工作者智能体（working agents）训练高度依赖多样化、可执行的职业任务及其可靠的专家演示轨迹。
2. **任务实例化时信息支撑不完整是核心障碍**：职业任务所需的支撑信息常分散在多个文档中，通过中间计算和判断关联；若信息缺失或不一致（例如供应商报价未注明运费是否含税），教师智能体无法可靠完成预期工作。
3. **需要严格区分"供给"与"求解"边界**：构造任务环境时，必须确保所有必要前提可用，同时中间过程和最终结果应保留给求解者推导，避免提供过量的计算结果削弱训练信号。
4. **现有合成框架缺乏执行级质量保障**：已有的任务合成方法（如 NexForge、Synthetic Computers）虽能自动化生成任务材料，但缺少对实例化后环境可执行性的验证与修复机制。

## 核心贡献（创新点）
1. **提出 WorkFactory 框架，从预期输出反向规划信息支撑**：与 GraphForge 从已有文件逆向编译任务不同，WorkFactory 从职业意图出发，通过信息支撑图（information support graph）显式协调依赖关系与信息位置，并将推导结果留作求解者的工作。
2. **设计执行驱动的修复机制（execution-based repair）**：与 WorkGenesis 基于评价标准（rubric）审计不同，WorkFactory 用独立探针直接测试任务环境的可执行性，并以保护预期工作完整性为约束指导修复。
3. **构建 112,686 任务的职业工作语料库（612 种职业、23 大类）**，覆盖丰富的专业工作场景，并提供公开的代码与模型权重。
4. **系统性揭示数据缩放规律**：在不同模型规模（4B/27B/35B-A3B）下刻画 Elo 收益的边际递减、执行长度的先升后降及工具调用可靠性的演化。

## 方法详解
**整体流程**（§3）：职业意图合成 → 信息支撑图规划 → 材料合成与环境构造 → 执行探针诊断 → 修复循环 → 教师轨迹收集 → 监督微调。

**1. 多元职业意图合成（§3.2）**
- 从三类来源综合：① 职业层级（Standard Occupational Classification）→ 扩分为细粒度角色与情境；② 文档化技能目录 → 将可衔接的技能组合为多步工作流；③ 真实专业交付物 → 通过指令反向翻译（instruction backtranslation [16]）推断生产意图。
- LLM 评审过滤不具备内部一致性与职业合理性的候选意图。

**2. 信息支撑图规划（§3.3）**
- 图结构定义为 $\mathcal{G}_\text{info} = (\mathcal{V}_\text{info}, \mathcal{V}_\text{carrier}, \mathcal{E}_\text{info}, \mathcal{E}_\text{loc})$（公式 1）：
  - $\mathcal{V}_\text{info}$：信息单元节点，记录语义内容、实体范围与提供状态（supplied/acquired/solver-derived/internal）。
  - $\mathcal{V}_\text{carrier}$：载体节点（用户请求、参考工件、外部资源、未来交付物、内部构造要求）。
  - $\mathcal{E}_\text{info}$：信息依赖边（引用、转换、证据、约束等关系）。
  - $\mathcal{E}_\text{loc}$：位置绑定边，将信息绑定到具体载体与可访问性。
- **反向规划**：从预期输出出发，识别背后的计算/判断，追溯每条所需信息的来源和位置；内部构造要求保持隐藏，仅将求解者可见的输入呈现。
- 材料化阶段由环境工人（environment worker）根据构造计划复用、改编或综合工件，并通过程序化与 LLM 检查验证一致性。

**3. 执行修复（§3.4）**
- **探针诊断**：隔离探针（probe solver）仅使用求解者可见的输入尝试完成任务，诊断并分类环境缺陷，触发条件为阻塞任务完成的问题。
- **修复约束**：修复器编辑请求与参考文件，但保持文件数量、类型与依赖结构不变；修复须通过构造检查和"工作保存"评审（LLM 核对核心目标与实质性交付要求未被改变）。
- **重试循环**：每轮修复后重新执行探针；最多三轮修复；通过后进入教师轨迹收集池，否则丢弃。

**4. 教师轨迹收集与训练（§3.5、Appendix D.3）**
- 使用 GLM-5.3 在干净沙箱中独立执行任务，获得教师 rollout。
- 轻量级过滤（重复推理、重复工具调用、交付物不足）+ 对最长 5% 轨迹进行选择性拒绝采样（pairwise judge 比较 Deliveable）。
- 遮蔽自回归损失（公式 2）：
  $$\mathcal{T}_\text{SFT}(\theta) = -\frac{1}{\sum_{s \in S}|M_s|}\sum_{s \in S}\sum_{\ell \in M_s}\log \pi_\theta(a_{s,\ell}|H_{s,<\ell})$$
  其中 $M_s$ 为监督助手 token 位置，仅移除失败的工具调用 span，保留上下文以支持后续恢复。

## 实验与结果
**数据集规模**（Table 1）：112,686 任务 / 612 职业 / 平均 4.15 参考文件 / 平均 57.36 助手回合 / 62.95 工具调用 / 136.18K tokens。

**评估基准**：GDPval-AA、JobBench、Workspace-Bench、OmegaUse-OfficeVal。

**主要结果（Table 2）**：
| 模型 | GDPval-AA Elo | JobBench | Workspace-Bench | OmegaUse-OfficeVal |
|---|---|---|---|---|
| Qwen3.5-4B → WorkPilot-4B | 661 → **1375** (+714) | 4.67 → **39.87** (+35.20) | 26.92 → **51.30** (+24.38) | 1.71 → **11.77** (+10.06) |
| Qwen3.6-27B → WorkPilot-27B | 975 → **1612** (+637) | 37.81 → **63.05** (+25.24) | 49.41 → **59.18** (+9.77) | 10.18 → **26.61** (+16.43) |
| Qwen3.6-35B-A3B → WorkPilot-35B-A3B | 879 → **1565** (+686) | 28.91 → **62.35** (+33.44) | 47.12 → **56.53** (+9.41) | 7.14 → **21.18** (+14.04) |

- WorkPilot-27B 在 GDPval-AA 上达到 1612 Elo，超过 DeepSeek-V4.1-Flash（1600），仅次于 GLM-5.3（1646），处于前沿模型区间。
- 四种基准上的提升方向一致，证明 WorkFactory 数据在不同规模下均有训练效用。

**数据缩放分析（§4.3）**：
- 性能提升呈模型依赖的**边际递减**：35B-A3B 前 5K 任务贡献 447 Elo，75K→110K 仅增 13 分。
- 执行长度**先升后降**：35B-A3B 从基线 24.87 回合升至 2K 任务时的 162.88，再到 110K 时降至 85.90；达到 250 回合上限的比例从 21.9% 降至 2.7%。
- 代码执行失败率从 16.0% 降至 6.3%，网络搜索失败率从 22.4% 降至 10.4%。

**组件分析（§4.4，5K 任务子集，Table 3）**：
- 信息级规划 vs 直接工件级规划：**跨文件不一致性**从 32.82% 降至 25.74%（−7.08pp），**断裂推导**从 24.86% 降至 6.86%（−18.00pp）。
- 加入执行修复后：**跨文件不一致性**进一步降至 4.84%（−20.90pp），**执行可行性缺陷**从 6.64% 降至 0.48%，**泄漏/捷径**从 3.36% 降至 0.84%。
- 下游 Elo：直接规划 1245 → 信息规划 +48 至 1293 → 再加修复 +33 至 1326。

**教师选择（§4.5）**：同一 30K 任务集，GLM-5.3 教师训练出 1483 Elo，DeepSeek-V4-Flash 教师训练出 1248 Elo，均显著优于基线 879。

**成本（§4.6）**：WorkPilot-4B 约 $0.012/task，WorkPilot-35B-A3B 约 $0.031/task，WorkPilot-27B 约 $0.396/task，位于非支配前沿。

## 相关工作脉络
1. **SWE-Gym / SWE-smith / R2E-Gym**：软件工程的合成任务与可执行测试提供监督信号；WorkFactory 将此类思路拓展至更广泛的职业工作领域，强调异构信息的连贯整合。
2. **NexForge [40]**：将能力需求翻译为任务指令并通过工作空间蓝图实例化；WorkFactory 同样从能力需求出发，但额外引入信息支撑图进行反向规划与执行修复。
3. **Synthetic Computers [12]**：规划工件间依赖关系指导工作空间合成；WorkFactory 在其基础上更进一步，显式表达信息单元间的依赖与位置，并用探针验证实例化后的可执行性。
4. **GraphForge [31]**：在已组装的真实文件上构建证据图，推导任务陈述与基于评价标准的评分；WorkFactory 从预期输出反向工作，不依赖真实文件工作区，且通过执行修复而非评价标准审计。
5. **WorkGenesis [42]**：围绕检索文件综合辅助材料并用 rubric 级失败归因指导修订；WorkFactory 的修复直接在求解者可见环境上进行，且约束修复不改变更核心的预期工作。
6. **DIVE [7] / TaskCraft [29] / AgentSynth [34]**：通过组合扩展、环境探索与执行反馈生成多工具任务；WorkFactory 的贡献在于引入了"信息支撑图 + 执行修复"的双重质量保障，特别适合需要跨文件推理的专业工作场景。

## 局限性与未来方向
1. **教师模型仅支持文本输入**（GLM-5.3）：学生模型也只能通过文本接口训练，视觉能力的原生支持被冻结；未来可扩展至多模态职业任务。
2. **当前仅做监督微调（SFT）**：未探索基于高质量任务及其执行反馈的强化学习训练路径。
3. **训练集与评估集的质量保证依赖人工抽检**：虽然进行了去污染检查，但未覆盖所有潜在的数据泄露风险。
4. **4B 模型的 Elo 区间较宽**（bootstrap CI 达 [363, 792]），反映低分段识别不确定性较大，小模型在高难度基准上的训练效率有待提升。

## 研究启发与可借鉴点
1. **信息支撑图（information support graph）可作为通用任务规划组件**：将"信息-载体-依赖-位置"的结构化表示剥离为独立模块，可迁移到其他任务合成或环境构建管线中。
2. **执行修复（execution-based repair）与修复约束设计**：在封闭沙箱中用探针测试、以"保持预期工作完整性"为硬约束进行有限轮次修复，这种"测试-诊断-修复-重测"的循环可直接应用于其他需要保证环境一致性的场景。
3. **数据缩放中执行长度的"先升后降"规律**：提示在训练初期应容忍更长轨迹（可能是在探索正确工作流），后期再收敛为高效执行；可作为后续训练策略设计的参考信号。
4. **教师模型选择影响训练收益**：同一任务集上 GLM-5.3 教师产出的轨迹比 DeepSeek-V4-Flash 教师训练出更高 Elo，提示教师模型质量与交互行为模式需纳入数据管线设计考量。
5. **失败工具调用处理策略**：仅移除失败调用的 token span 而保留上下文，使后续恢复动作有据可依，这一细节值得在 SFT 数据预处理中广泛采纳。

## 关键术语表
**Working agent（工作者智能体）**：在数字环境中执行职业工作流、协调工具并产出专业交付物的语言智能体。

**Professional intent（职业意图）**：在实例化具体材料之前定义有意义工作的抽象目标，来源于职业层级、技能文档与真实交付物三类来源。

**Information support graph（信息支撑图）**：形式化为 $(\mathcal{V}_\text{info}, \mathcal{V}_\text{carrier}, \mathcal{E}_\text{info}, \mathcal{E}_\text{loc})$ 的图结构，显式记录任务所需信息单元、载体、依赖关系与位置绑定。

**Execution-based repair（执行修复）**：通过隔离探针诊断任务环境的阻塞性缺陷，并在保持预期工作完整性约束下进行有限轮次的修改与重测。

**Probe solver（探针求解器）**：一个独立的求解者，仅使用求解者可见的输入尝试完成任务，负责暴露环境缺陷而非完成任务本身。

**Teacher trajectory（教师轨迹）**：由独立教师模型（本文使用 GLM-5.3）在干净沙箱中执行任务产生的交互轨迹与交付物，作为 SFT 数据。

**Selective rejection sampling（选择性拒绝采样）**：对最长 5% 的教师 rollout 通过 pairwise judge 比较交付物质量，仅保留教师获胜的轨迹。

**GDPval-AA**：评估 AI 在真实经济价值任务上表现的职业工作基准，以 Elo 评分为核心指标。

## 可复现要素
- **数据集**：公开子集，完整数据见 https://github.com/IQuestLab/WorkFactory（论文声明）。
- **代码/权重**：代码开源；WorkPilot 模型权重将在适用 License 下发布。
- **关键超参**：训练 4 个 epoch，序列长度 256K，全局 batch size 32（packed sequences），峰值学习率 3×10⁻⁵，cosine schedule 至 2×10⁻⁶，warmup 10 步，weight decay 0.01，gradient clipping 1.0，BF16 精度，语言模型解冻、视觉与对齐器冻结。
- **探针上下文窗口**：1M tokens，无 compaction；教师上下文窗口：256K tokens。
- **修复最大轮次**：3 轮。
- **教师模型**：GLM-5.3；组件分析中其余步骤使用 DeepSeek-V4-Flash-0731。
- **训练基数模型**：Qwen3.5-4B、Qwen3.6-27B、Qwen3.6-35B-A3B。
